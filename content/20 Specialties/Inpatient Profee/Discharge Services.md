## Code Range
**[[99238]]-[[99239]]** - Hospital discharge day management

## Overview
Billed on the date of discharge for final management activities.

## Code Selection

| Code | Description | Time |
| :--- | :--- | :--- |
| **[[99238]]** | Discharge ≤30 minutes | ≤30 min |
| **[[99239]]** | Discharge >30 minutes | >30 min |

## Included Activities

> [!IMPORTANT] Bundled Services
> Discharge code includes all discharge activities:
> - Final examination
> - Discharge instructions
> - Medication reconciliation
> - Follow-up arrangements
> - Paperwork completion

## Time Calculation
Discharge Activities:

- Final patient exam: 10 min
- Family discussion: 10 min
- Discharge paperwork: 15 min
- Total: 35 minutes → 99239


## Same Day Rules

| Scenario | Billing |
| :--- | :--- |
| **Admit + Discharge same day** | Initial hospital care |
| **Subsequent + Discharge same day** | Discharge only |
| **Critical Care + Discharge same day** | Both allowed |

> [!WARNING] Date of Service
> Bill discharge on actual discharge date, not date of documentation.

## Death vs. Discharge

| Outcome | Code |
| :--- | :--- |
| **Discharge to home/SNF** | 99238-99239 |
| **Patient death** | 99238-99239 |
| **Transfer to another hospital** | 99238-99239 |

> [!TIP] Time Documentation
> Document total time spent on discharge activities to support 99239 selection.

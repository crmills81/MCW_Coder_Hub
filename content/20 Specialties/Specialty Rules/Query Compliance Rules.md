# 📝 Query Compliance Rules

## 🎯 Purpose
Ensure all provider queries are compliant, non‑leading, and audit‑safe.

---

# 🧩 Core Principles
- Queries must be **non‑leading**  
- Provide **multiple reasonable options**  
- Include **“unable to determine”**  
- Base query on **clinical indicators**  
- Never introduce unsupported diagnoses  

---

# 🧩 When to Query
- Conflicting documentation  
- Missing specificity  
- Unclear POA status  
- Clinical indicators suggest a condition not documented  
- Procedure details incomplete  

---

# 🧩 Non‑Leading Query Structure
1. State clinical indicators  
2. Ask for clarification  
3. Provide multiple options  
4. Include “other” and “unable to determine”  

---

# 🧠 Documentation Tips
- Keep queries factual  
- Avoid suggesting diagnoses  
- Retain query + response for audit trail

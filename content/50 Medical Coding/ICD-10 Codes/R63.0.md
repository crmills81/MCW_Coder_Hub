# 🧬 ICD-10 CM R63.0 — Anorexia

> [!success] Billable Code Confirmed  
> **ICD-10 CM [[R63.0]]** is a **4-character code**: **R63** (**symptoms and signs concerning food and fluid intake**) and .0 (**[[anorexia]]**). It is complete and valid for **FY2026** claims.<sup>1</sup>

> [!warning] Non-Billable Parent Codes  
> **R63** (**Symptoms and signs concerning food and fluid intake**) is a category header and is not reportable alone. It needs the 4th character to be billable.<sup>1</sup>

> [!important] Clinical Context  
> **ICD-10 CM [[R63.0]]** means **loss of appetite** with an organic or unspecified cause. **[[Anorexia]] nervosa** belongs in **F50.0-** and **nonorganic loss of appetite** in **[[F50.89]]**.<sup>4</sup>

> [!danger] Code Classification  
> This is an **ICD-10-CM symptom** and sign diagnosis code (**Chapter 18**). It is not a procedure code, and it should not be used when a related definitive diagnosis is established.<sup>3</sup>

---

## 🔍 Code Description  
**[[Anorexia]]** in **ICD-10-CM** means **loss of appetite as a symptom**, not **the eating disorder**. **[[R63.0]]** is used when a provider documents decreased appetite from conditions such as **cancer, infection, medication effect, depression or chronic illness and no more specific diagnosis** explains it. It sits in the same category as **[[R63.4]]** (**abnormal weight loss**) and **[[R63.6]]** (**underweight**).<sup>1</sup>

Do **not** confuse **[[R63.0]]** with **[[anorexia nervosa]]**, which is a psychiatric eating disorder coded to **F50.0-.** Per the **Excludes1 note**, they are never reported together.<sup>4</sup> If appetite loss is integral to a confirmed disease, **ICD-10-CM guidelines** say do not code it separately, but it can be coded when it is not routinely part of that disease.

> [!example] Symptom vs Disorder  
> **Payers** may expect a **definitive diagnosis** for ongoing workup, and **[[R63.0]]** is a poor primary choice once a cause is found. Choosing **F50.0-** instead changes the **clinical picture, coverage policy and risk adjustment entirely**.

> [!tip]  
> If the patient has **[[anorexia]]** plus documented weight loss, report **[[R63.4]]** too when both are documented and not integral to a confirmed diagnosis.

- **Decreased or poor appetite:** reported here when documented as a symptom.
- **Appetite loss in chronic or terminal illness:** reported when not integral to the underlying disease.

## ❌ Excludes  

### Excludes 1  
- **F50.0-** Anorexia nervosa: a psychiatric eating disorder, never reported with **[[R63.0]]**.<sup>4</sup>
- **[[F50.89]]** Other specified eating disorder (**loss of appetite of nonorganic origin**): **[[R63.0]]** is for organic or unspecified loss of appetite only.<sup>4</sup>

> [!danger]  
> The most common **error** is coding **[[R63.0]]** with an eating disorder code because the chart says "**[[anorexia]]**." Read the provider's words, since "**[[anorexia nervosa]]**" and "**loss of appetite**" point to different chapters.

### Excludes 2  
- No **Excludes2 note** is listed at **[[R63.0]]**. Related findings such as **nausea** or **weight loss can** be reported alongside when documented and **not integral.**

## 📋 Clinical Overview  

### Symptom Code vs Nutrition Diagnosis  
**ICD-10 CM [[R63.0]]** records a symptom, while **[[malnutrition]]** and **[[cachexia]]** are diagnoses with their own criteria. The distinction matters because the symptom has **no severity or risk weight** and the diagnoses do.

| **Feature** | **[[R63.0]]** | **Related [[R63.4]]** | **Related [[E46]]** |
|---|---|---|---|
| **What it captures** | Loss of appetite. | Abnormal weight loss. | Unspecified protein-calorie malnutrition. |
| **Requires provider diagnosis of malnutrition** | No. | No. | Yes, with supporting criteria. |
| **Severity or risk impact** | None expected. | None expected. | Can affect severity and risk adjustment. |

> [!important]  
> **CDI trigger**: **low intake, weight loss or a dietitian assessment** with no provider diagnosis. Query for **[[malnutrition]]** or **[[cachexia]]** when clinical indicators are present.

### Manifestations & Symptom Burden  
- **Reduced oral intake:** smaller meals, early satiety or refusal to eat.
- **Unintentional weight loss:** often accompanies prolonged appetite loss.
- **Fatigue and weakness:** from low caloric intake.
- **Nausea:** frequently coexists and can be coded separately when documented.

> [!tip]  
> These **symptoms** can be coded when not integral to a confirmed diagnosis, and a definitive cause replaces **[[R63.0]]** as the main code.

## 💊 Coding Scenarios and Examples  

### Example 1
> **Clinical Scenario:**  
> A 70-year-old comes to the office with 3 weeks of decreased appetite. The provider orders labs and documents "loss of appetite, workup pending."

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99214]] | Established patient visit with moderate MDM. |
| CPT 2 | [[80053]] | Metabolic panel as part of the workup. |
| PDx | [[R63.0]] | Symptom documented and no definitive diagnosis yet. |

> [!tip]  
> Report the symptom when no cause is established. CDI: ask whether weight loss is also present, which would support [[R63.4]].

### Example 2
> **Clinical Scenario:**  
> A patient with anorexia and weight loss has an EGD, which shows gastritis.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[43235]] | Diagnostic EGD. |
| PDx | [[K29.70]] | Gastritis is now the definitive diagnosis. |

> [!tip]  
> Code the definitive diagnosis first. [[R63.0]] can be added only if it is not integral to gastritis and the provider documents it.

### Example 3
> **Clinical Scenario:**  
> A patient receiving chemotherapy has poor appetite and nausea. The provider documents both and does not diagnose malnutrition.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99214]] | Established patient visit with moderate MDM. |
| PDx | [[R63.0]] | Appetite loss documented as a symptom. |
| Dx 2 | [[R11.0]] | Nausea documented separately. |

> [!tip]  
> [[Neoplasm]] coding and sequencing follow the reason for the visit. CDI: query for malnutrition if dietitian findings support it.

## ⚠️ Coding Pitfalls and Tips  
- **Pitfall 1**: Using **[[R63.0]]** for **[[anorexia nervosa]]**; **Tips**: Use **F50.0-** and do **not** report both because of the **Excludes1 note**.
- **Pitfall 2**: Coding **appetite loss** when it is integral to a confirmed disease; **Tips**: Report the definitive diagnosis only unless the symptom is not routinely associated.
- **Pitfall 3**: Using **[[R63.0]]** as principal when a cause is established; **Tips**: Sequence the definitive diagnosis first.
- **Pitfall 4**: Coding **[[malnutrition]]** from a **dietitian** note alone; **Tips**: The provider must document the diagnosis, so query when indicators are present.
- **Pitfall 5**: Assuming Medicare covers **[[97802]]** for any appetite complaint; **Tips**: Verify the covered conditions before billing **MNT**.
- **Pitfall 6**: Missing the **BMI code** when **underweight** is documented; **Tips**: Add the **Z68 code only** with an associated provider-documented diagnosis like **[[R63.6]]**.

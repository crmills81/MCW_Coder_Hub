# 🧬 ICD-10 CM M54.41 — Lumbago with Sciatica, Right Side

> [!success] Billable Code Confirmed
> **ICD-10 CM [[M54.41]]** is a complete, billable **5-character ICD-10-CM diagnosis code** in the **FY2027** code set (effective October 1, 2026), where the fifth character "**1**" specifies the right side.<sup>1</sup> The code has been in effect since October 1, 2021 when the **M54.4- subcategory** gained laterality characters, and no changes were made to it in the **FY2027** update.<sup>1</sup><sup>2</sup> It is valid for **HIPAA-covered claims** with dates of service October 1, 2026 through September 30, 2027.<sup>1</sup>

> [!warning] Non-Billable Parent Codes
> **M54** (**[[Dorsalgia]]**) is a non-billable category header requiring digit completion.<sup>1</sup> **M54.4** (**Lumbago with sciatica**) is a non-billable subcategory header that must be completed with a fifth-character laterality code (**0, 1, or 2**).<sup>1</sup> Neither header may be submitted on a claim.<sup>1</sup>

> [!important] Clinical Context
> **ICD-10 CM [[M54.41]]** is **a combination symptom code** — it reports **both low back pain ([[lumbago]]) and right-sided [[sciatica]] together**, which means the classification intends for these two symptoms to be captured in a single code rather than reported separately as **[[M54.50]]**/**[[M54.59]]** plus **[[M54.31]]**.<sup>1</sup> Use it only when the provider documents both **lumbago** and **right-sided sciatic distribution pain** without attributing the condition to a specific **intervertebral disc disorder**.<sup>1</sup>

> [!danger] Code Classification
> This is an **ICD-10-CM diagnosis (symptom) code**, not a procedure code. It is a **combination symptom code** in the **[[dorsalgia]]** family, and the **Excludes 1 notes** force selection of an etiologic code whenever the **disc-disorder** or **[[degeneration]]-with-pain** codes apply.<sup>1</sup>

## 🔍 Code Description

**ICD-10 CM [[M54.41]]** sits in **subcategory M54.4- (Lumbago with sciatica) within the M54 Dorsalgia category of Chapter 13**, block **M50-M54 (Other dorsopathies)**.<sup>1</sup> The code pairs a lumbar pain component with a **right-sided sciatica component**, which per the classification's **Excludes 1 structure** eliminates the need — and the permission — to report the **low back pain** and **[[sciatica]]** components separately.<sup>1</sup> When the side is documented as right, this code is preferred over the unspecified **[[M54.40]]** because laterality specificity matters for payer review of interventional pain procedures and imaging.<sup>1</sup>

**ICD-10 CM [[M54.41]]** is a **symptom-level code**, not an etiology code, and the **subcategory's Excludes 1 notes** redirect the coder to disc displacement codes (**M51.1- children** such as **[[M51.16]]**/**[[M51.17]]**) or **disc-degeneration-with-pain** codes (**[[M51.362]]**/**[[M51.372]]**) whenever the provider links the **lumbago-sciatica picture** to a structural cause.<sup>1</sup> There is no bilateral option in the **M54.4- family** — documentation describing bilateral leg symptoms with **lumbago** defaults to the unspecified **[[M54.40]]** unless the provider designates a dominant side.<sup>1</sup>

> [!example] Combination Code Logic Saves Codes — and Errors
> Choosing **[[M54.41]]** instead of stacking **[[M54.50]]** + **[[M54.31]]** matters because the **Classification** explicitly built the **M54.4- family** to be **Excludes 1** against the stand-alone sciatica and low back pain families.<sup>1</sup> An **auditor** who sees a separate **M54.3- code** alongside an **M54.4- code** will treat the **combination** as an invalid double-report of the same symptom.<sup>1</sup>

> [!tip]
> If the record documents **lumbago** and **[[sciatica]]** but skips the side, query before defaulting to **[[M54.40]]** — unspecified laterality in the **M54.4- family** is a soft edit for payers reviewing repeat imaging or **injection** claims when the chart clearly identifies a side.<sup>1</sup>

## ✅ Includes

- **Right-sided lumbago** paired with right sciatic distribution leg pain documented as one clinical presentation.<sup>1</sup>
- **Low back pain with radiation** from the right buttock into the posterior or lateral right thigh, calf, or foot in the sciatic nerve distribution.<sup>1</sup>
- **Right lumbago-sciatica** documented without a structural etiology when the provider has not attributed the symptoms to a herniated disc, stenosis, or spondylolisthesis.<sup>1</sup>
- **Chronic right-sided back-and-leg pain** presentations documented as lumbago with sciatica in conservative-care records before an etiologic workup is complete.<sup>1</sup>

## ❌ Excludes

### Excludes 1

- **M51.1-** — **Lumbago with sciatica due to intervertebral disc disorder**: when the lumbar or lumbosacral herniated or displaced disc is the documented cause, code the etiology (**M51.16** or **M51.17**) and omit the **M54.4- combination code** entirely.<sup>1</sup>
- **[[M51.362]]** — **Intervertebral disc degeneration, lumbar region, with discogenic back pain and lower extremity pain**: the degeneration-with-pain family captures both the lumbar pain and the radiating extremity pain without an **M54.4- code**.<sup>1</sup>
- **[[M51.372]]** — **Intervertebral disc degeneration, lumbosacral region, with discogenic back pain and lower extremity pain**: same **Excludes 1 logic** as **[[M51.362]]**.<sup>1</sup>
- **[[F45.41]]** — **Psychogenic dorsalgia**: at the category level, **[[dorsalgia]]** due to a somatic symptom disorder is excluded from the entire **M54 category**.<sup>1</sup>

> [!danger]
> The most common **Excludes 1 error** with **[[M54.41]]** is stacking it with a **disc disorder code** or with a stand-alone **sciatica/low back pain code** when the documentation shows a structural etiology or a split-component presentation. Both are invalid combinations under the **Excludes 1 notes**, and both are standard compliance-audit findings.<sup>1</sup>

### Excludes 2

- No **Excludes 2 note** is published at the **M54.4- subcategory level** — there are no conditions in this family that may be reported alongside **[[M54.41]]** solely by virtue of an **Excludes 2** instruction.<sup>1</sup> Always verify the parent **M54 category** tabular notes each October 1 for any annual additions.

## 📋 Clinical Overview

### Right Lumbago-Sciatica: Combination vs Etiologic vs Symptom Codes

The choice among these codes is driven entirely by whether the provider documents a structural etiology, **a split-symptom presentation**, or the combined **lumbago-sciatica** complex.<sup>1</sup>

| Feature | **[[M54.41]]** | **[[M51.17]]** | **[[M54.31]]** + **[[M54.59]]** |
|---|---|---|---|
| **Definition** | Lumbago with sciatica, right side — combination symptom code.<sup>1</sup> | Other intervertebral disc displacement, lumbosacral region, with radiculopathy — etiologic structural code.<sup>1</sup> | Split coding of right sciatica + other low back pain — attempted component coding.<sup>1</sup> |
| **When to use** | Provider documents lumbago and right sciatica together, no disc etiology documented.<sup>1</sup> | Provider attributes the right leg radicular pain to a lumbosacral disc displacement/herniation.<sup>1</sup> | Never — the Excludes 1 structure makes this combination invalid when lumbago and sciatica are both documented.<sup>1</sup> |
| **Mutual exclusivity** | Excludes 1 against M51.1-, [[M51.362]], [[M51.372]], and the stand-alone M54.3-/M54.5- families.<sup>1</sup> | Stand-alone sciatica/low back pain codes cannot be added — radiculopathy is built in.<sup>1</sup> | Invalid paired approach; the classification replaces it with the M54.4- combination code.<sup>1</sup> |

> [!important]
> **CDI trigger**: any record saying "**lumbago with [[sciatica]]**" or "**low back pain with radiating leg pain**" should be reviewed for a side designation and for any mention of **[[disc herniation]]**, **[[stenosis]]**, or **[[spondylolisthesis]]**, because either of those findings redirects the coder away from **[[M54.41]]** to **[[M51.16]]**, **[[M51.17]]**, **[[M51.362]]**, **[[M51.372]]**, or **[[M48.062]]** depending on the documented cause.<sup>1</sup>

### Manifestations & Symptom Burden

- **Low back pain in the lumbar or lumbosacral region** combined with shooting, burning, or electric-shock pain radiating from the right buttock down the posterior or lateral right leg, often below the knee, in the L4-S1 dermatomal distribution.<sup>1</sup>
- **Positive right straight leg raise (Lasègue sign)** with reproduction of radicular pain, typically reported on exam before interventional procedures are authorized.<sup>4</sup>
- **[[Paresthesia]] or numbness** in the right lower extremity along the sciatic distribution; isolated neurologic deficit without pain should prompt evaluation for **G57.0-** or a radiculopathy code such as **M54.17** instead.<sup>1</sup>
- **Functional and vocational impairment** — the MAC epidural steroid injection LCDs expect documentation of severity sufficient to impair function before an intervention is considered reasonable and necessary.<sup>4</sup>
- **Concordant imaging (CT/MRI)** demonstrating a structural correlate when interventional procedures are planned; ESI LCDs explicitly require imaging that supports the clinical findings.<sup>4</sup>

> [!tip]
> The **lumbago** and **sciatica** components are not separately coded — **[[M54.41]]** captures the entire combined symptom picture, and any distinct **causative structural finding** must be validated against the **Excludes 1 replacements** before adding codes.<sup>1</sup>

## 🏥 MS-DRG Assignment

| **DRG** | **Title** | **FY2027 Relative Weight** | **GMLOS** | **Notes** |
|:---:|---|---|---|---|
| **551** | Medical Back Problems with MCC | **≈1.6366 (about 70.7% above 552)** | — | Requires an MCC as a secondary diagnosis.<sup>3</sup> |
| **552** | Medical Back Problems without MCC | **0.9584** | **2.9** | Two-tier family — CC-only complications also group here; average national operating payment ≈ $6,563.<sup>3</sup> |

When **[[M54.41]]** is the **principal diagnosis**, the claim groups to **MDC 08, Diseases and Disorders of the Musculoskeletal System and Connective Tissue**, in the two-tier **Medical Back Problems family**.<sup>3</sup> A **CC-listed secondary condition** does not push the case up to **551** — capture **CCs** anyway for severity profiling and quality metrics even when the **DRG assignment** does not change.<sup>3</sup> When **lumbago-sciatica** is the documented admission reason, sequencing is straightforward; when a structural **disc diagnosis** replaces **[[M54.41]]** under the **Excludes 1 logic**, the **DRG path** within **MDC 08** is identical for that etiologic code.<sup>1</sup><sup>3</sup>

**NCD/LCD Information:**

- There is **no NCD** for **epidural steroid injections**; coverage is governed entirely by **MAC LCDs**, such as **LCD L36920** (**Epidural Steroid Injections for Pain Management**).<sup>4</sup>
- Under the **ESI LCDs**, coverage requires documented **radiculopathy/radicular pain** with a structural correlate (**disc [[herniation]], [[osteophyte]] complex, severe DDD producing [[stenosis]]**), pain of at least 4 weeks' duration or failure of **conservative care**, and **concordant CT/MRI imaging**; **ESIs** are limited to 4 sessions per spinal region per rolling 12 months, **TFESIs** are limited to 2 levels per region per session, and **CT** or **fluoroscopic guidance** with contrast is required (**ultrasound without contrast only for documented contrast allergy or pregnancy**).<sup>4</sup><sup>5</sup>
- **Trigger point injections** are **not reasonable and necessary for low back pain** under the **TPI LCDs** and are capped at 3 sessions per rolling 12 months even when they independently qualify — do not expect **[[M54.41]]** to support a **TPI claim**.<sup>6</sup>
- **North Carolina** is served by **Palmetto GBA, A/B MAC Jurisdiction M** — verify the active **ESI** and **TPI LCD** versions on the **CMS MCD for JM** before submission.<sup>8</sup>

### NCCI Bundling Considerations

**Fluoroscopic image guidance** and **contrast administration** are inherent to **[[64483]]** and **[[62323]]** and are not separately billable for the same session — **do not append an image guidance code alongside the injection**.<sup>4</sup> **[[20552]]** and **[[20553]]** are mutually exclusive with each other (**report one per session**), and a **same-day E/M** must be a significant, separately identifiable service supported by **[[-25]]** or it bundles into the **injection**.<sup>5</sup><sup>6</sup>

## 🔬 ICD-10-PCS Crosswalk

For **inpatient facility coding** when **right lumbago-sciatica** progresses to surgical intervention:

- **0SB20ZZ** — **Excision of Lumbar Vertebral Disc, Open Approach**: assigned for open lumbar [[discectomy]]; this is the classic inpatient procedure path for refractory disc-related lumbago-sciatica once the etiologic code (e.g., **[[M51.16]]**) is assigned.<sup>10</sup>
- **0SB24ZZ** — **Excision of Lumbar Vertebral Disc, Percutaneous Endoscopic Approach**: assigned for minimally invasive endoscopic [[discectomy]]; laterality is not captured in the PCS character structure, so match the procedure to the documented side in the operative note.<sup>10</sup>
- **0S520ZZ** — **Destruction of Lumbar Vertebral Disc, Open Approach**: assigned for intradiscal ablative/nucleolysis-type procedures; the percutaneous variant (**0S543ZZ**) applies to needle-based techniques.<sup>10</sup>
- **0SG30J0** — **Fusion of Lumbosacral Joint with Synthetic Substitute, Anterior Approach, Anterior Column, Open Approach**: a representative fusion-table entry; per AHA Coding Clinic, a decompressive [[laminectomy]] performed to free a nerve root codes to root operation Release (e.g., **01NB0ZZ**, Release of lumbar nerve, open approach), not excision.<sup>10,</sup><sup>11</sup>

## 💊 Coding Scenarios and Examples

<br>

### Example 1

> **Clinical Scenario:**
> A 61-year-old established patient presents with 2 months of right lower back pain accompanied by burning pain radiating from the right buttock down the posterior right thigh to the calf, a positive right straight leg raise, and failure of 6 weeks of NSAIDs and physical therapy. MRI shows a small L4-L5 disc protrusion, but the provider documents the symptoms as "lumbago with sciatica, right side," without attributing them to the disc. A right L5 transforaminal epidural steroid injection is performed under fluoroscopic guidance.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99214]]-[[-25]] | Significant, separately identifiable E/M supported by expanded history, exam, and the decision to proceed with interventional injection after failed conservative care. |
| CPT 2 | [[64483]]-[[-RT]] | Single-level right lumbar TFESI; [[-RT]] keeps procedure laterality consistent with the right-sided combination diagnosis, and the LCD criteria (4+ weeks, failed conservative care, positive straight leg raise, concordant imaging) are met. |
| PDx | [[M54.41]] | Combination code correctly captures the documented lumbago-plus-right-sciatica presentation without a structural etiology attribution. |

> [!tip]
> Sequencing is direct — [[M54.41]] supports the injection's medical necessity, but the LCD also requires the structural correlate on imaging, which is present and documented here.<sup>4</sup> CDI note: if the provider had linked the symptoms to the L4-L5 protrusion, the code would have become [[M51.16]] under the Excludes 1 note, and [[M54.41]] would disappear from the claim.<sup>1</sup>

### Example 2

> **Clinical Scenario:**
> A 72-year-old Medicare beneficiary is admitted for intractable right lower back pain with radiating right leg pain unresponsive to outpatient management, treated with IV analgesics and an interlaminar lumbar epidural steroid injection. During the stay, severe anemia from chronic occult GI blood loss is documented as requiring treatment and monitoring, meeting MCC criteria. The physician identifies the lumbago with sciatica as the condition chiefly responsible for the admission.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99223]] | Initial hospital care, high complexity — the admission E/M for the inpatient profee claim, reflecting the severe symptom burden and treatment decisions at admission. |
| PDx | [[M54.41]] | After review of the complete record, the right lumbago-sciatica is the condition after study chiefly responsible for the admission, with no documented structural etiology. |
| SDx | Other MCC-listed secondary diagnosis | The documented MCC-level comorbidity drives the case from DRG 552 to DRG 551 (Medical Back Problems with MCC), raising the relative weight substantially.<sup>3</sup> |

> [!tip]
> The MCC is what converts the two-tier family assignment from 552 to 551 — capture and verify every MCC before final coding because the CC-only tier and the non-CC tier occupy the same DRG here.<sup>3</sup> CDI note: confirm the provider did not tie the lumbago-sciatica to a disc or stenosis, which would require moving the principal diagnosis to the etiologic code and re-reviewing the Excludes 1 logic.<sup>1</sup>

### Example 3

> **Clinical Scenario:**
> A 49-year-old presents with chronic right low back pain radiating down the right posterior thigh and calf documented definitively as secondary to a large L5-S1 disc herniation visible on MRI and confirmed on exam. After failed conservative care, a lumbar interlaminar epidural steroid injection is performed.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[62323]] | Interlaminar lumbar epidural steroid injection; one spinal level per session, with all LCD coverage criteria (4+ weeks duration, failed conservative care, exam, concordant imaging) documented.<sup>4</sup><sup>5</sup> |
| PDx | [[M51.17]] | Lumbosacral disc displacement with radiculopathy — the Excludes 1 logic makes this the etiologic principal diagnosis, not [[M54.41]], because the lumbago-sciatica is attributed to the documented disc herniation. |

> [!tip]
> This is the classic "trap" encounter — the symptoms perfectly describe lumbago with sciatica, but the etiologic disc diagnosis overrides the combination symptom code every time.<sup>1</sup> CDI note: query any record that describes discopathy near dorsalgia-symptom language, because the choice between [[M54.41]] and [[M51.16]]/[[M51.17]] changes the principal diagnosis and the medical-necessity story for the injection.<sup>1</sup>

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Defaulting to **[[M54.40]]** when the chart clearly identifies the affected side. **Payers** scrutinize unspecified laterality on **repeat interventional claims** and **may deny for lack of specificity**. **Tips**: Extract the side from the **exam** and **operative notes** before settling on unspecified; reserve **[[M54.40]]** for genuinely undocumented laterality.<sup>1</sup>
- **Pitfall 2**: Assigning **[[M54.41]]** when documentation ties the symptoms to a **lumbar** or **lumbosacral disc disorder**. The **M51.1- Excludes 1 note** makes that combination invalid. **Tips**: Code **[[M51.16]]** or **[[M51.17]]** as the sole diagnosis whenever the provider attributes the **lumbago-sciatica** to a **disc** cause.<sup>1</sup>
- **Pitfall 3**: Stacking **[[M54.41]]** with a stand-alone **sciatica** or **low back pain code** for the same encounter. The **combination code** already includes both components and is **Excludes 1** against the split-code approach. **Tips**: Never report **M54.3- or M54.5- codes** alongside an **M54.4- code** — either the combined picture or the etiologic picture, not a hybrid.<sup>1</sup>
- **Pitfall 4**: Using **[[M54.41]]** to support a **trigger point injection** claim. The **TPI LCDs** explicitly state TPIs are not reasonable and necessary for low back pain and cap covered use at **3 sessions** per rolling 12 months for qualifying **[[myofascial]]** criteria. **Tips**: Confirm an **independent trigger point documentation story** (**taut band, twitch response, failed conservative care, ≥50% relief documentation for repeats**) exists before submitting **[[20552]]**/**[[20553]]**.<sup>6</sup>
- **Pitfall 5**: Exceeding **ESI LCD utilization limits**. **ESIs** are capped at 4 sessions per **spinal region** per rolling 12 months and **TFESIs** at 2 levels per region per session. **Tips**: Track **injection** history across the chart and align laterality **modifiers** with the right-sided diagnosis to minimize pre-payment review denials.<sup>4</sup>
- **Pitfall 6**: Assuming the combination code **risk adjusts** or groups to a neurology **MDC**. **[[M54.41]]** maps to no **HCC** in **V28** and groups to **MDC 08**, **DRGs 551/552**. **Tips**: Capture it accurately anyway because it builds the clinical story for procedure medical necessity, and don't chase a nonexistent **RAF** impact by overcoding etiologic diagnoses.<sup>3</sup><sup>7</sup>

# 🧬 ICD-10 CM S06.5XAD — Traumatic Subdural Hemorrhage With Loss of Consciousness Status Unknown, Subsequent Encounter

> [!success] Billable Code Confirmed  
> **ICD-10 CM [[S06.5XAD 1]]** is a complete **7-character code**: **S06** (**intracranial injury**), **.5** (**[[subdural hemorrhage]]**), **X** (**placeholder**), **A** (**LOC status unknown**), **D** (**subsequent encounter**). It is valid for **FY2027** (10/1/2026–9/30/2027) and reportable on claims.<sup>1,2,3</sup>

> [!warning] Non-Billable Parent Codes  
> **S06.5XA** is a subcategory that still requires a **7th** character (**A, D or S**). **S06.5** and **S06** are also headers and cannot be reported.<sup>3</sup>

> [!important] Clinical Context  
> The **6th** character "**A**" means the record does not say whether the patient **lost consciousness**. If the provider documents no **LOC** or a duration, use the matching **6th** character (**0-9**) instead. The **7th** character **D** applies after active treatment, during healing or recovery.<sup>3,6</sup>

> [!danger] Code Classification  
> This is an **ICD-10-CM diagnosis code (Chapter 19, injury)**. It is not a procedure code and not a **Z-code**. Do **not** use **Z** aftercare codes for injuries; the guidelines direct you to the injury code with **7th** character **D**.<sup>6</sup>

---

## 🔍 Code Description  

**ICD-10 CM [[S06.5XAD 1]]** reports **a traumatic subdural hemorrhage, meaning blood collected between the dura and arachnoid after head trauma**, when the patient is in the **healing or recovery phase and consciousness status at injury was never documented**. It sits in **category S06**, which includes **traumatic brain injury** and carries the instruction to code also any associated **open wound of head** (**[[S01.01XD]]** as an example) or **skull fracture** (**S02.-**).<sup>3</sup>

The "**unknown LOC**" **6th** character (**A**) is for charts where **LOC** cannot be determined, which differs from unspecified duration (**9**) where **LOC** is known to have occurred. Use an additional code if applicable for **traumatic brain [[compression]]** or **[[herniation]]** (**[[S06.A0XD]]**) and for **mild neurocognitive disorder** due to a known physiological condition (**[[F06.70]]**).<sup>3</sup>

> [!example] Why "A" in the 6th Position Matters  
> Choosing **LOC** status unknown (**A**) instead of **0** or **9** changes the clinical story and may trigger a **CDI query**. **Payers** and **registries** use **LOC** data for injury severity, so query when the **H&P** and **ED** record are silent.

> [!tip]  
> The **7th** character must be **D** only if the patient is past active treatment. **Evaluation** and continuing care by the same surgeon is still **A**; rehab and routine follow-up are **D**.<sup>6</sup>

## ✅ Includes  

- **Traumatic subdural hematoma in recovery:** Routine care during healing, such as monitoring, medication adjustment or rehab, reported with **[[S06.5XAD 1]]**.
- **Traumatic brain injury (S06 includes term):** The **S06** category notes "**traumatic brain injury**", so **TBI** documentation with a subdural bleed lands here.<sup>3</sup>
- **LOC not stated:** Use this code when the chart never addresses LOC; do not assume none occurred.

---

## ❌ Excludes  

### Excludes 1  
- **S09.90 (Head injury NOS):** Unspecified head injury cannot be reported with a specified intracranial injury because the specific diagnosis replaces it. S09.90 is a parent code (needs 6th/7th characters), so it is not wikilinked.<sup>3</sup>

> [!danger]  
> The common error is reporting a vague head-injury code such as **[[S09.90XD]]** alongside **[[S06.5XAD 1]]** from the same episode. This violates the **Excludes1 note** at **S06**. Report only the most specific intracranial injury.

### Excludes 2  
- **None at S06.5.** Associated injuries are reported with "**code also**" instructions: open wound of head (**S01.-**) and skull fracture (**S02.-**) can be reported together with **[[S06.5XAD 1]]** when each is documented and relevant to the encounter.<sup>3</sup>

## 📋 Clinical Overview  

### Traumatic vs Non-Traumatic and Epidural vs Subdural  
Documentation of the cause and anatomic space decides the category. **Traumatic subdural** bleeds (**S06.5-**) stay in **Chapter 19**, while non-**traumatic subdural [[hemorrhage]]** is **Chapter 9** (**I62.0-**). **[[Epidural]]** and **[[subarachnoid]]** bleeds have their own **S06** categories, so the **radiology** report's anatomic location matters.

| **Feature** | **[[S06.5XAD 1]]** | **Related [[S06.4XAD]]** | **Related [[S06.6XAD]]** |
|---|---|---|---|
| **Anatomic space** | Between dura and arachnoid. | Between skull and dura. | Within the subarachnoid space. |
| **Typical cause** | Acceleration/deceleration trauma and bridging-vein tears. | Skull fracture with arterial tear. | Trauma with vessel rupture into CSF spaces. |
| **LOC status** | Unknown (6th character A). | Unknown (6th character A). | Unknown (6th character A). |

> [!important]  
> Watch for provider notes of "**subdural hematoma**" with no mention of **trauma**, or **ED notes** that skip **LOC**. Query for etiology (**traumatic vs spontaneous or anticoagulant-related**) and for **LOC**, since both change the code.

### Manifestations & Symptom Burden  
- **Headache and cognitive change:** Persistent headache, confusion or slowed processing during recovery.
- **Focal deficits:** **[[Hemiparesis]]**, **[[aphasia]]** or visual field deficits may be coded additionally when documented.
- **Seizures:** Post-traumatic seizure risk may need an additional code when documented.
- **Neurocognitive disorder:** Mild neurocognitive disorder is reported with **[[F06.70]]** per the S06 "**use additional code**" note.<sup>3</sup>

> [!tip]  
> **Code manifestations** only when the provider documents them. Do not **infer deficits** from imaging alone.

## 💊 Coding Scenarios and Examples  

### Example 1
> **Clinical Scenario:**  
> A patient with a traumatic subdural hemorrhage transfers to inpatient rehabilitation weeks after the injury. The physiatrist documents routine recovery management. The ED record never states whether the patient lost consciousness.

| **Field** | **Code**             | **Rationale**                                                                              |
| ----- | ---------------- | -------------------------------------------------------------------------------------- |
| CPT   | [[99232]]    | Subsequent hospital visit, moderate MDM, for rehab-phase management.                   |
| PDx   | [[S06.5XAD 1]] | Healing/recovery phase, LOC never documented, so 6th character A with 7th character D. |

> [!tip]  
> Report deficits (for example [[hemiparesis]]) as secondary diagnoses when documented. Check Coding Clinic guidance on 7th character use for rehab admissions.

### Example 2
> **Clinical Scenario:**  
> A radiologist interprets a follow-up non-contrast CT head and MRI brain on a patient recovering from a traumatic subdural hemorrhage. The clinical indication reads "follow-up traumatic SDH, LOC unknown."

| **Field** | **Code**                     | **Rationale**                                       |
| ----- | ------------------------ | ----------------------------------------------- |
| CPT   | [[70450]]-[[26]] | Professional component only for the CT.         |
| CPT 2 | [[70551]]-[[26]] | Professional component only for the MRI.        |
| PDx   | [[S06.5XAD 1]]         | Follow-up imaging during recovery, LOC unknown. |

> [!tip]  
> Radiology codes from the order and indication, so confirm the requisition supports the 7th character D. Check coverage against NCD 220.1 and NCD 220.2.

### Example 3
> **Clinical Scenario:**  
> A neurosurgeon performs discharge day management, 40 minutes, for a patient in the recovery phase of a traumatic subdural hemorrhage. The provider documents mild neurocognitive disorder due to the injury without behavioral disturbance.

| **Field**        | **Code**             | **Rationale**                                                       |
| ------------ | ---------------- | --------------------------------------------------------------- |
| CPT          | [[99239]]    | Discharge day management over 30 minutes, with time documented. |
| PDx          | [[S06.5XAD 1]] | Injury in the healing/recovery phase.                           |
| Secondary Dx | [[F06.70]]   | Reported per the "use additional code" note at S06.             |

> [!tip]  
> Time must be documented to support [[99239]] over [[99238]]. Link the neurocognitive disorder to the injury in the note.

## ⚠️ Coding Pitfalls and Tips  

- **Pitfall 1**: Reporting **S06.5XA-** without a **7th** character; it is a non-billable subcategory. **Tips**: Always finish with **A, D or S**, giving **[[S06.5XAD 1]]** for follow-up care.
- **Pitfall 2**: Using **Z aftercare codes** for the injury. **Tips**: For injuries, use the injury code with **7th** character **D** rather than **Z** aftercare codes.<sup>6</sup>
- **Pitfall 3**: Assuming "**no LOC**" when it isn't documented. **Tips**: Use **6th** character **A**, or query to get **[[S06.5X0D]]** or **[[S06.5X9D]]** if the provider can clarify.
- **Pitfall 4**: Coding **[[S09.90XD]]** with **[[S06.5XAD 1]]**. **Tips**: **Excludes1** at **S06** prevents this; report only the specific intracranial injury.
- **Pitfall 5**: Skipping "**code also**" and "**use additional code**" instructions. **Tips**: Add **S01.-/S02.-**, **[[S06.A0XD]]** and **[[F06.70]]** when documented.
- **Pitfall 6**: Using **7th** character **D** while the patient is still in active treatment. **Tips**: Use **A** for active treatment, including **surgeon evaluation** and **continuing care by the same team**; use **D** for the recovery phase.<sup>6</sup>

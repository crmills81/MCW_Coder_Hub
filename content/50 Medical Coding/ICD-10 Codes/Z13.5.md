# 🔍 ICD-10 CM Z13.5 — Encounter for Screening for Eye and Ear Disorders

> [!success] Billable Code Confirmed — 5 Characters Complete
> **ICD-10 CM [[Z13.5]]** is a valid, billable **5-character ICD-10-CM code** for FY2025/2026. Complete as written — no additional characters required or available.

> [!warning] Inpatient: Unacceptable as Principal Diagnosis
> **ICD-10 CM [[Z13.5]]** cannot be sequenced as principal diagnosis on inpatient claims. Additional/secondary code only in the inpatient setting. **Outpatient**: ✅ Acceptable as first-listed diagnosis when screening visit with no confirmed condition found. 

> [!danger] Excludes1 — Screening vs. Symptoms — Critical Distinction
> **ICD-10 CM [[Z13.5]] cannot be used when the patient has a sign, symptom, or existing diagnosis** driving the visit. Symptoms present → code the symptom/diagnosis, **NOT** **Z13.5**. Screening = asymptomatic patient being evaluated for possible disease. If disease is **FOUND** during screening → code the disease **FIRST**, **Z13.5** additional.

> [!note] POA Exempt
> **ICD-10 CM [[Z13.5]]** is exempt from Present on Admission reporting —> no POA indicator required on inpatient claims.

## 🔍 Code Description

**ICD-10 CM [[Z13.5]]** classifies an **encounter specifically for the purpose of screening for eye and/or ear disorders** — a visit in which an asymptomatic patient undergoes evaluation to detect possible disease before symptoms develop or before a diagnosis has been established. This code covers screening for glaucoma, age-related macular degeneration, diabetic retinopathy, cataracts, amblyopia and strabismus in children, hearing loss (including age-related hearing loss), and any other condition affecting vision or hearing where the purpose of the encounter is early detection rather than evaluation of a known complaint.

The ICD-10-CM classification draws a sharp line between **screening** ([[Z13.5]] — looking for disease that may or may not be present in an asymptomatic patient) and **diagnostic examination** (coded to the sign, symptom, or known condition). Understanding this boundary — and knowing which code leads when something is found — is the core clinical and coding competency this note documents.

## 🔑 The Screening Code Guideline — Section I.C.21.c.5

> [!important] The Two-Scenario Rule for Z13.5

### Scenario A — Screening Visit, Nothing Found → Z13.5 Is First-Listed ✅

Patient presents for glaucoma screening. IOP normal OU. Optic nerves normal. No abnormality detected. → **[[Z13.5]]** is the first-listed/principal outpatient diagnosis. The screening was the reason for the visit; no confirmed disease was found.

### Scenario B — Screening Visit, Condition IS Found → Code the Condition First → Z13.5 Additional ✅

Patient presents for diabetic retinopathy screening. Fundus exam reveals moderate NPDR bilaterally. → **[[E11.3412]]** (T2DM with moderate NPDR bilateral — or appropriate combination code) is FIRST → **[[Z13.5]]** is ADDITIONAL. The confirmed disease now explains why treatment is needed; the screening code documents how it was detected. 

> [!tip] Think of Z13.5 Like a Net Cast Looking for Fish
> - If the net comes up empty → **[[Z13.5]]** is the whole story.
>- If the net catches something → code **WHAT** was caught first.
>- **[[Z13.5]]** stays on the claim either way — it documents the screening intent.
>- It just moves to secondary when the catch is significant enough to **code**.

## 📊 Excludes — What Z13.5 Does NOT Cover

> [!warning] Excludes1 — Mutually Exclusive — Cannot Code Together

| Code | Description | Why Excluded |
|---|---|---|
| **Sign or symptom codes** | Any R-code, pain, blurred vision, hearing loss complaint | Excludes1: "encounter for diagnostic examination — code to sign or symptom" — if the patient has a SYMPTOM, this is a diagnostic visit, not a screening |

> [!warning] Excludes2 — Report Separately If Also Applicable

| Code | Description | Distinction from [[Z13.5]] |
|---|---|---|
| **[[Z01.00]]-[[Z01.01]]** | Encounter for general vision examination | **General** vision exam (refractive check, acuity) vs. **disease screening** (glaucoma, AMD) — use Z01.0x for routine refractive/acuity; [[Z13.5]] for disease-specific screening |
| **[[Z01.10]]-[[Z01.12]]** | Encounter for general hearing examination | **General** hearing exam vs. **hearing disorder screening** — Z01.1x for routine audiogram; [[Z13.5]] for ARHL or disease-specific screen  |

> [!tip] Z13.5 vs. Z01.0x / Z01.1x — The Clinical Distinction
> **[[Z01.00]]** = "Check my glasses prescription / routine eye exam — general acuity and refraction"
> **[[Z13.5]]** = "Screen me for glaucoma / macular degeneration / diabetic eye disease / hearing loss"
>
> A diabetic patient coming in for their annual dilated fundus exam → **[[Z13.5]]** + diabetes code (screening for [[retinopathy]])
> A patient coming in for a glasses prescription update → **[[Z01.00]]** (general vision exam)
> These can co-exist on the same claim if BOTH purposes are documented.

### High-Priority Ophthalmic Screening Targets

| Condition Being Screened             | Population                                                                | Screening Method                        | Code If Found                                            |
| ------------------------------------ | ------------------------------------------------------------------------- | --------------------------------------- | -------------------------------------------------------- |
| **Glaucoma**                         | Age >40, family history, Black/Hispanic race, steroid users, thin corneas | Tonometry, fundus exam, OCT RNFL, HVF   | H40.x — appropriate [[glaucoma]] code                    |
| **Age-related macular degeneration** | Age >55, smokers, family history                                          | Dilated fundus exam, OCT, Amsler grid   | H35.31xx — AMD code                                      |
| **Diabetic retinopathy**             | All T1/T2 DM patients — annual                                            | Dilated fundus exam, fundus photography | E10.3x-E11.3x — DM with [[retinopathy]] combination code |
| **Cataracts**                        | Age >60, steroid users                                                    | Slit lamp exam                          | H26.xx — [[cataract]] code                               |
| **Amblyopia**                        | Children age 3-5                                                          | Vision screening — acuity, cover test   | H53.0x — [[amblyopia]] code                              |
| **Strabismus**                       | Children — school age and younger                                         | Cover test, Hirschberg                  | H50.xx — [[strabismus]] code                             |
| **Retinopathy of prematurity**       | NICU — premature infants                                                  | Dilated exam by retina specialist       | H35.1x — ROP code                                        |
| **Color blindness**                  | School children                                                           | Ishihara plates                         | H53.5x — color vision deficiency                         |

> [!important] Diabetic Eye Screening — Z13.5 With Diabetes Code
> Annual dilated fundus examination in diabetic patients is one of the most common clinical scenarios for [[Z13.5]] in ophthalmology. The correct coding depends on what is found:
>
> | Finding | First-Listed | Additional |
> |---|---|---|
> | No retinopathy found | [[Z13.5]] | [[E11.9]] (T2DM no complications) — documents the reason screening is indicated |
> | NPDR found | [[E11.3412]] (T2DM + NPDR bilateral, no DME) | [[Z13.5]] — how it was detected |
> | PDR found | [[E11.3511]] (T2DM + PDR right eye with DME) etc. | [[Z13.5]] — screening context |
>
> In the glaucoma screening context: **[[Z13.5]]** is also used for steroid-dependent patients screened for drug-induced glaucoma even before any elevation is found — the screening is the purpose.

### High-Priority Audiology/ENT Screening Targets

| Condition Being Screened | Population | Screening Method | Code If Found |

| **Age-related hearing loss (ARHL / presbycusis)** | Age >60, annual PCP visit | Pure tone audiogram, speech discrimination | [[H91.10]]-[[H91.13]] — presbycusis |

| **Conductive hearing loss in children** | Recurrent otitis, fluid | Tympanometry, audiogram | H90.0x — conductive HL |

| **Cholesteatoma screening** | Chronic ear disease history | Otoscopy | H71.xx — cholesteatoma |
| **Otosclerosis** | Family history | Audiogram, tympanometry | H80.xx — otosclerosis |

> [!note]  Z13.5 Bridges Your Ophthalmology AND ENT Vault Sections
> Because **[[Z13.5]]** covers **BOTH** eye and ear screening in a single code, it will cross-link into your ENT/audiology notes (**presbycusis, conductive hearing loss, tympanometry)** as naturally as it connects to your **[[glaucoma]]** and AMD notes. One code, two specialty sections — document cross-links accordingly.

> [!caution] Glaucoma Screening — CMS Coverage and Z13.5
> CMS covers **[[glaucoma]]** screening under **G0117** (**glaucoma screening by optometrist/ophthalmologist**) and **G0118** (**under direct supervision**) for high-risk Medicare beneficiaries — **every 12 months**. These claims typically use **[[Z13.5]]** as the supporting diagnosis. Eligible high-risk patients include: diabetics, family history of glaucoma, African Americans age ≥50, Hispanics age ≥65. Screening for general low-risk Medicare beneficiaries for glaucoma is **NOT** a covered benefit under Part B. Document the high-risk qualifying factor alongside **Z13.5**.

## 💊 Coding Scenarios

---

### Scenario 1 — Annual Glaucoma Screening, Nothing Found (Z13.5 First-Listed ✅)

> **Clinical Vignette:** A 54-year-old African American male with no known eye disease presents to ophthalmology for glaucoma screening — family history of glaucoma in father. IOP: 15 mmHg OD, 14 mmHg OS. Optic nerves: normal C/D ratio 0.4 OU. OCT RNFL: within normal limits OU. No visual field defects. Impression: Normal screening exam — no glaucoma detected. Return in 1 year.

**ICD-10-CM:**
- **[[Z13.5]]** — Encounter for screening for eye disorders *(first-listed — screening purpose, nothing found)*
- [[Z82.1]] — Family history of blindness and visual loss *(glaucoma risk factor — documents screening medical necessity)*
- [[Z91.89]] — Other specified personal risk factors *(race-based risk — optional additional documentation)*

---

### Scenario 2 — Glaucoma Found During Screening (Condition First, Z13.5 Additional)

> **Clinical Vignette:** A 61-year-old Hispanic female presents for first-time glaucoma screening. No symptoms. IOP: OD 26 mmHg, OS 24 mmHg. OCT RNFL: moderate superior thinning OD. HVF OD: MD -7.8 dB. Optic nerve: C/D 0.75 OD with rim thinning. Impression: Open-angle glaucoma, right eye, moderate stage. Left eye: normal. Starting latanoprost OD.

**ICD-10-CM:**
- [[H40.1122]] — Primary open-angle glaucoma, right eye, moderate stage *(first-listed — confirmed condition found during screening)*
- **[[Z13.5]]** — Encounter for screening for eye disorders *(additional — documents how it was detected)*

---

### Scenario 3 — Diabetic Patient Annual Dilated Exam, No Retinopathy Found

> **Clinical Vignette:** A 58-year-old male with T2DM (diet-controlled) presents for annual dilated fundus exam. No visual complaints. Exam: no hemorrhages, exudates, NVE, or neovascularization OU. Macula: normal OU. Impression: No diabetic retinopathy. Return in 1 year.

**ICD-10-CM:**
- **[[Z13.5]]** — Encounter for screening for eye disorders *(first-listed — purpose is diabetic retinopathy screening; nothing found)*
- [[E11.9]] — Type 2 DM without complications *(additional — reason screening is indicated)*

---

### Scenario 4 — Diabetic Patient, Retinopathy Found (Condition First)

> **Clinical Vignette:** Same type of patient — but this time, dilated exam reveals scattered microaneurysms and dot hemorrhages OU, no DME. Impression: Mild NPDR bilateral.

**ICD-10-CM:**
- [[E11.3210]] — T2DM with mild NPDR, bilateral, without DME *(first-listed — confirmed retinopathy found)*
- **[[Z13.5]]** — Encounter for screening for eye disorders *(additional — screening context)*

---

### Scenario 5 — Neonatal Hearing Screening Failure → Audiology Referral

> **Clinical Vignette:** Newborn fails OAE screening in the right ear at hospital discharge. Referred for audiology follow-up. At audiology: repeat OAE confirms right ear hearing loss. ABR ordered.

**ICD-10-CM:**
- **[[Z13.5]]** — Encounter for screening for ear disorders *(first-listed at the audiology screening visit — confirms screening purpose)*
- [[H91.91]] — Unspecified hearing loss, right ear *(additional — finding noted, awaiting full diagnostic workup)*

---

### Scenario 6 — Annual PCP Visit — Combined Eye and Ear Screening Order

> **Clinical Vignette:** A 67-year-old Medicare patient at annual wellness visit. PCP documents glaucoma screening referral (diabetic, age >65, family history) AND hearing screening (age-related concern, patient reports difficulty hearing in noisy environments). Both screenings ordered at the same visit.

**ICD-10-CM at Annual Wellness Visit:**
- [[Z00.01]] — Encounter for general adult medical examination *(primary reason for PCP visit)*
- **[[Z13.5]]** — Encounter for screening for eye and ear disorders *(additional — both screening orders documented at same visit)*
- [[E11.9]] — T2DM *(underlying condition driving eye screening)*
- [[Z82.1]] — Family history blindness/visual loss *(glaucoma risk)*

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never use [[Z13.5]] when the patient has a symptom** — blurred vision, eye pain, hearing loss complaint → code the symptom; Excludes1 prohibits [[Z13.5]] when symptoms drive the visit  |
| ❌ | **Never sequence [[Z13.5]] first when a condition is confirmed** — confirmed diagnosis FIRST, [[Z13.5]] additional  |
| ❌ | **Never use [[Z13.5]] as inpatient principal diagnosis** — unacceptable in that position  |
| ❌ | **Never substitute [[Z13.5]] for Z01.0x or Z01.1x** — general vision/hearing exam vs. disease-specific screening are different codes |
| ✅ | **[[Z13.5]] outpatient first-listed = normal screening** — nothing found, screening was the purpose  |
| ✅ | **[[Z13.5]] stays on the claim even when something is found** — moves to additional when condition is confirmed  |
| ✅ | **One code covers both eye AND ear** — single [[Z13.5]] when screening both systems at same encounter |
| ✅ | **Add the risk factor code** — documents WHY screening is medically necessary (family hx, diabetes, steroid use, age, occupational noise) |
| ✅ | **POA exempt** — no indicator needed on inpatient claims  |
| ✅ | **Glaucoma screening in high-risk Medicare patients** — supports G0117/G0118 billing; [[Z13.5]] is the supporting Dx  |
| ✅ | **Annual diabetic eye exam = [[Z13.5]] scenario** — if nothing found, [[Z13.5]] leads with diabetes code additional |
| ✅ | **CCSR FAC003** — [[Z13.5]] maps to CCSR category FAC003 (Preventive/screening)  |

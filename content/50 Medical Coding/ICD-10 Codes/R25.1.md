# 🧠 ICD-10-CM R25.1 — Tremor, Unspecified

> [!success] Billable Code Confirmed
>
> **ICD-10-CM [[R25.1]]** is a valid, billable **4-character ICD-10-CM
> code** for FY2026. The code is fully specified at the 4-character level:
> `R25` (**abnormal involuntary movements category**) + `.1` (**tremor,
> unspecified**). No additional characters are required or available.

> [!warning] Non-Billable Parent Code — Never Submit This
>
> - ❌ `R25` — 3-character category header — non-billable; never submit alone
>
> Always submit **[[R25.1]]** (all 4 characters) when tremor is documented
> as the presenting finding and the specific tremor type or underlying
> movement disorder has not been established.

> [!important] Symptom Code — Use Only When No Definitive Diagnosis Exists
>
> **[[R25.1]]** is a **Chapter 18 symptom code**. Per ICD-10-CM Official
> Coding Guidelines, symptom codes should **not** be reported when a
> definitive condition that fully explains the symptom has been established
> and documented. If the physician documents essential tremor ([[50 Medical Coding/ICD-10 Codes/G25.0]]),
> Parkinson disease (G20.-), drug-induced tremor ([[G25.1]]), or any
> specific movement disorder under G20-G26 — assign the specific condition
> and **do not additionally code [[R25.1]]**. The Excludes 1 at the R25
> category level is a hard rule.

> [!info] Code Classification
>
> **ICD-10-CM Diagnosis Code** — Fields for wRVU, assistant payable, and
> global period are not applicable. This is a symptom/sign code used when
> a definitive neurological diagnosis for the tremor has not yet been
> established at the time of the encounter or at discharge.

## 🔍 Code Description

**ICD-10-CM [[R25.1]]** classifies **tremor, unspecified** — an involuntary,
rhythmic oscillating movement of a body part for which the specific tremor
type or underlying neurological cause has not been determined. This is a
**symptom-level code**, capturing the clinical finding in its unresolved
state while the diagnostic workup is initiated or completed.

Tremor broadly describes **rhythmic, involuntary muscle contractions**
that produce oscillating movements. Clinically, tremors are classified by
their relationship to motor activity (rest tremor vs. action tremor),
their body distribution, and their frequency and amplitude. **[[R25.1]]**
applies specifically when these characteristics have been observed but the
clinician has not yet determined the tremor subtype or underlying etiology —
placing it firmly in the diagnostic gap between symptom observation and
confirmed diagnosis.

The most critical distinction with [[R25.1]] is that it is a **transitional
code** — it is appropriate at the first encounter, during an inconclusive
workup, or at inpatient discharge when the cause was not established after
study. It is **not** appropriate once a specific movement disorder is
confirmed. [[50 Medical Coding/ICD-10 Codes/G25.0]] (essential tremor), G20.- (Parkinson disease resting
tremor), and [[G25.1]] (drug-induced tremor) are all Excludes 1 — they
replace [[R25.1]] the moment the diagnosis is made.

> [!tip] R25.1 vs. R25.0 — Choose the Right Symptom Code
> **[[R25.1]]** captures **tremor** — rhythmic, oscillatory involuntary
> movement affecting any body part. **[[R25.0]]** captures **abnormal head
> movements** specifically. When a tremor is isolated to the head and
> documented as a head movement abnormality without characterization as
> "tremor," [[R25.0]] may be more appropriate. When the physician
> documents "tremor" — whether upper extremity, generalized, or
> unspecified location — [[R25.1]] is the correct code pending specificity.

The following clinical findings and documentation patterns map to **[[R25.1]]**
when no specific tremor type or movement disorder has been diagnosed:

- Tremor NOS — documented by examiner, type unspecified
- Involuntary rhythmic shaking of the upper extremities, etiology undetermined
- Bilateral or unilateral hand tremor, specific type not yet characterized
- Tremor of unspecified body part, workup pending
- Resting vs. action tremor not yet differentiated at this encounter
- Tremor in context of polypharmacy workup not yet attributed to a specific
  drug or movement disorder

### Excludes 1 — Cannot Be Coded Simultaneously with [[R25.1]]

| Code | Description | Note |
|------|-------------|------|
| G20.- | Parkinson disease | Resting tremor in Parkinson disease → assign G20, not R25.1 |
| [[50 Medical Coding/ICD-10 Codes/G25.0]] | Essential tremor | Essential tremor confirmed → assign G25.0, not R25.1 |
| [[G25.1]] | Drug-induced tremor | Drug-induced tremor → assign G25.1 + external cause code, not R25.1 |
| [[G25.2]] | Other specified forms of tremor | Intention tremor, postural tremor (other specified) → assign G25.2, not R25.1 |
| G20-G26 | All specific movement disorders | **Entire range is Excludes 1** — once any specific movement disorder is diagnosed, R25.1 is excluded |
| [[F98.4]] | Stereotyped movement disorders | Behavioral/psychiatric etiology — mutually exclusive |
| F95.- | Tic disorders | Tic disorder NOS, Tourette's — mutually exclusive; assign F95.x, not R25.1 |

> [!danger] Excludes 1 — G20-G26 Is a Hard, Category-Level Exclusion
> The **entire G20-G26 range** (specific movement disorders) carries an
> **Excludes 1** instruction at the R25 category level. This applies
> to every code within R25, including [[R25.1]]. If **any** specific
> movement disorder is documented and confirmed, **[[R25.1]] cannot be
> coded simultaneously.** This is among the highest-frequency Excludes 1
> violation risks in neurology inpatient coding — particularly with
> Parkinson disease (G20.-) and essential tremor ([[50 Medical Coding/ICD-10 Codes/G25.0]]), which
> are commonly treated on the same unit.

## 📋 Clinical Overview

### R25.1 vs. Specific Tremor Codes — The Critical Distinction

This distinction must come entirely from physician documentation — coders
cannot classify tremor type from exam descriptions alone. The line between
[[R25.1]] and [[50 Medical Coding/ICD-10 Codes/G25.0]] or G20.- is a **physician determination** that
often requires neurological examination, medication history review,
and imaging.

| Feature | **[[R25.1]] — Symptom Code** | **[[50 Medical Coding/ICD-10 Codes/G25.0]] — Essential Tremor** | **G20.- — Parkinson Disease** |
|---|---|---|---|
| **Diagnostic certainty** | Undetermined | Action/postural tremor confirmed | Resting tremor + bradykinesia + rigidity |
| **Tremor type** | Uncharacterized | Bilateral action tremor, head/voice involvement | Unilateral or bilateral resting "pill-rolling" |
| **HCC contribution** | ❌ None | Review HCC mapping | ✅ HCC-mapped — significant RAF |
| **Duration of use** | Temporary — initial/inconclusive encounters | Long-term diagnosis | Long-term diagnosis |
| **CDI opportunity** | ✅ High — query at every inpatient encounter | N/A | N/A |

> [!important] CDI Query Trigger — Every R25.1 on a Completed Inpatient Record
> **[[R25.1]]** on a completed inpatient record without a documented
> upgrade attempt is a **CDI gap**. Parkinson disease (G20.-) in
> particular is a high-RAF, high-priority CDI target — a patient admitted
> with "tremor" who is already on carbidopa-levodopa or who has documented
> bradykinesia and rigidity has an established diagnosis that should be
> captured as G20.-, not obscured behind [[R25.1]].

### Pathophysiology

**Tremor** is an involuntary, rhythmic, oscillatory movement produced by
alternating or synchronous contractions of opposing muscle groups. The
underlying mechanism varies by tremor type: **Parkinson disease** produces
resting tremor through dopaminergic pathway degeneration in the substantia
nigra, affecting the basal ganglia motor circuit; **essential tremor**
involves abnormal oscillatory activity in the cerebello-thalamo-cortical
loop; **drug-induced tremor** results from dopamine receptor blockade
(**as with antipsychotics**) or enhancement of beta-adrenergic activity
(**as with bronchodilators or stimulants**).

At the symptom-code stage captured by **[[R25.1]]**, the precise
neurological mechanism has not been determined. Clinical characterization —
distinguishing rest tremor from action tremor, assessing frequency and
amplitude, identifying associated findings (**bradykinesia, rigidity, [[ataxia]]**)
— is the clinical process that ultimately yields the specific diagnosis
that replaces [[R25.1]]. The code exists precisely at this diagnostic
decision point.

### Tremor Classification and Upgrade Targets

| Tremor Type                                  | Key Features                                                                   | Upgrade Code                                                     |
| -------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------- |
| **Resting tremor**                           | Present at rest, suppressed with movement; pill-rolling; unilateral onset      | G20.- Parkinson disease                                        |
| **Essential (action/postural) tremor**       | Bilateral, worsens with action/posture, head/voice involvement; family history | [[50 Medical Coding/ICD-10 Codes/G25.0]] Essential tremor                                       |
| **Drug-induced tremor**                      | Recent medication change; dopamine blocker, lithium, valproate, bronchodilator | [[G25.1]] Drug-induced tremor                                    |
| **Intention tremor**                         | Worsens at end of goal-directed movement; cerebellar signs                     | [[G25.2]] Other specified tremor                                 |
| **Orthostatic tremor**                       | High-frequency leg tremor upon standing                                        | [[G25.2]] Other specified tremor                                 |
| **Physiologic / enhanced physiologic**       | Anxiety, caffeine, thyroid, metabolic                                          | Underlying cause code; R25.1 may persist if no specific disorder |
| **Psychogenic/functional**                   | Inconsistent, distractible, entrainable                                        | [[F44.4]] Conversion disorder with movement disorder             |
| **Idiopathic — unclassifiable after workup** | No specific type identified                                                    | [[R25.1]] remains as appropriate code                            |

> [!important] Sequencing Principle — When Cause Is Identified
> When the underlying condition causing tremor is identified and documented **code the underlying condition** — G20.-, [[50 Medical Coding/ICD-10 Codes/G25.0]], [[G25.1]], [[G35.A]], etc. — as principal or the relevant diagnosis. **[[R25.1]] is excluded** by the Excludes 1 instruction once a specific movement disorder in the
> G20-G26 range is confirmed. Do not code both.

### Clinical Presentation

Patients presenting with tremor documented under [[R25.1]] typically exhibit:

- **Involuntary rhythmic shaking** of the upper extremities, head, voice, trunk,
  or lower extremities — body part not yet characterizing the tremor subtype
- **Rest tremor** (present when limb is supported, suppressed with movement)
  vs. **action tremor** (present with or worsened by voluntary movement) —
  distinction under evaluation
- **Frequency and amplitude** — coarse (low-frequency) vs. fine (high-frequency)
  tremor; amplitude variable
- **Functional impact** — difficulty with writing, eating, drinking, fine
  motor tasks — severity assessed
- **Associated findings under evaluation:** bradykinesia, cogwheel rigidity,
  postural instability, gait disturbance, ataxia, cognitive changes

### Documentation Requirements

For accurate assignment of [[R25.1]], physician documentation should include:

1. **Observable finding** — explicit documentation that tremor was observed
   on examination; not just patient self-report without clinical confirmation
2. **Tremor characterization** — rest vs. action, body parts affected,
   unilateral vs. bilateral, frequency/amplitude if documented
3. **Negative or inconclusive workup** — explicit statement that specific
   tremor type or movement disorder has NOT been established
4. **Differential diagnostic intent** — workup is pending or ongoing;
   supports continued use of symptom code
5. **Exclusion of specific disorders documented** — "not consistent with
   essential **tremor**," "**Parkinson disease not confirmed**" — this language
   protects the symptom code assignment
6. **Etiology if identified** — if the cause is determined, the specific
   **G20-G26** code replaces [[R25.1]] immediately

**[[R25.1]]** does not map to an HCC under CMS-HCC v28 and does not
contribute to a patient's Risk Adjustment Factor (RAF) score.

> [!caution] R25.1 — The Single Most RAF-Significant CDI Target in Neurology
> [[R25.1]] sitting on a completed inpatient record is one of the highest
> yield CDI review targets in the neurological coding space. Parkinson
> disease (G20.-) carries one of the highest individual RAF coefficients
> in **CMS-HCC v28**. A patient admitted with documented tremor, already
> on sinemet, with known Parkinson's in the medication list but physician
> documentation that says only "tremor" is a missed HCC of significant
> magnitude. Review and ensure complete coding of:
>
> - **Parkinson disease** (G20.-) — HCC-mapped, very high RAF
> - **Multiple sclerosis** ([[G35.A]]) — HCC-mapped
> - **Hemiplegia/hemiparesis** (G81.x) — HCC-mapped
> - **Diabetes with neurological complications** — HCC 18/19 series
>
> The medication reconciliation list is your CDI cheat sheet —
> carbidopa-levodopa → query G20.-; propranolol for tremor → query
> [[50 Medical Coding/ICD-10 Codes/G25.0]]; antipsychotic + new tremor → query [[G25.1]].

## 💊 Coding Scenarios and Examples

---

### Scenario 1 — New Bilateral Hand Tremor, Workup Initiated (Outpatient Neurology — First Visit)

> **Clinical Vignette:** A 72-year-old male is referred to neurology by
> his primary care physician for a 6-month history of bilateral hand
> shaking. Exam reveals bilateral postural and action tremor, upper
> extremities, mild amplitude. No bradykinesia, no rigidity noted.
> Physician documents: "Bilateral hand tremor — differential includes
> essential tremor vs. early Parkinson disease. DaTscan ordered. No
> specific movement disorder established at this time." The specific
> diagnosis is not made at this encounter.

**CPT Codes (Outpatient Neurology):**
- [[99205]] — New patient office visit, high complexity
- [[78607]] — Brain SPECT (DaTscan) *(ordered at this encounter)*

**ICD-10-CM:**
- [[R25.1]] — Tremor, unspecified *(no specific disorder established —
  symptom code is correct for this encounter)*

> [!tip] R25.1 Is Correct Here — Diagnosis Not Yet Established
> The physician explicitly documents "no specific movement disorder
> established." [[R25.1]] is the correct code for this first visit.
> At the follow-up encounter when DaTscan results are reviewed, upgrade
> to [[50 Medical Coding/ICD-10 Codes/G25.0]] (essential tremor) or G20.- (Parkinson disease) as
> appropriate.

---

### Scenario 2 — Tremor, Essential Tremor Confirmed Same Encounter (Outpatient)

> **Clinical Vignette:** A 65-year-old female with a strong family history
> of hand shaking presents to neurology. Exam confirms bilateral postural
> and kinetic hand tremor with mild head tremor, no resting component,
> no bradykinesia. Physician documents: "Essential tremor confirmed —
> bilateral, upper extremity and head. Starting propranolol."

**CPT Codes:**
- [[99213]] — Established patient office visit, low-moderate complexity

**ICD-10-CM:**
- [[50 Medical Coding/ICD-10 Codes/G25.0]] — Essential tremor *(specific diagnosis confirmed — [[R25.1]]
  is NOT coded per Excludes 1; G25.0 replaces it entirely)*

> [!danger] Do Not Assign R25.1 When Specific Diagnosis Is Confirmed
> Once [[50 Medical Coding/ICD-10 Codes/G25.0]] is documented and confirmed, **[[R25.1]] is excluded**
> per the Excludes 1 at the R25 category level. Coding both is a hard
> Excludes 1 violation. The specific diagnosis always replaces the
> symptom code.

### Scenario 3 — Drug-Induced Tremor, Antipsychotic-Related (Outpatient)

> **Clinical Vignette:** A 38-year-old male on risperidone for bipolar
> disorder presents with new-onset bilateral hand tremor over 4 weeks.
> Neurological exam: bilateral resting and postural tremor, upper
> extremities. No other movement disorder features. Psychiatrist
> documents: "Drug-induced tremor, risperidone-related."

**CPT Codes:**
- [[50 Medical Coding/CPT Codes/99214]] — Established patient office visit, moderate complexity

**ICD-10-CM:**
- [[G25.1]] — Drug-induced tremor *(specific — replaces [[R25.1]] per Excludes 1)*
- [[T43.595A]] — Adverse effect of other antipsychotics and neuroleptics,
  initial encounter *(required adverse effect code — identifies the causative agent)*
- [[F31.9]] — Bipolar disorder, unspecified *(underlying psychiatric condition)*

> [!tip] Drug-Induced Tremor Always Requires the Adverse Effect Code
> [[G25.1]] (drug-induced tremor) must always be paired with an adverse
> effect code from the T36-T65 range identifying the responsible medication,
> per ICD-10-CM Official Coding Guidelines. Never assign [[G25.1]] without
> the corresponding T-code.

---

### Scenario 4 — Tremor, Parkinson Disease Identified During Inpatient Admission

> **Clinical Vignette:** A 78-year-old male is admitted for a fall.
> History review reveals a 2-year history of tremor managed with
> carbidopa-levodopa. Neurology consult documents: "Parkinson disease
> with resting tremor — well-established diagnosis, currently on
> carbidopa-levodopa. Fall related to Parkinson gait instability."

**Principal Diagnosis:**
- [[W19.XXXA]] — Unspecified fall, initial encounter *(mechanism of
  admission — or [[Z87.39]] depending on coding conventions at facility)*
- Alternatively, if admission is primarily for evaluation of Parkinson
  management: **G20.-** — Parkinson disease sequences as principal

**Additional Diagnoses:**
- G20.- — Parkinson disease *(confirmed, documented — [[R25.1]] is
  NOT appropriate; G20 captures the tremor diagnosis specifically)*

> [!danger] G20 Always Replaces R25.1 — Never Code Both
> Once Parkinson disease is documented by the physician, G20.- is
> the code — **[[R25.1]] is excluded entirely** by the Excludes 1 at
> the R25 category level. This is the single highest-yield upgrade
> scenario for both RAF capture and coding accuracy.

---

### Scenario 5 — Tremor, Inpatient Workup Negative (Idiopathic — Symptom Code Remains)

> **Clinical Vignette:** A 82-year-old female is admitted with new-onset
> bilateral upper extremity tremor. Comprehensive workup completed:
> brain MRI normal, DaTscan normal, thyroid studies normal, metabolic
> panel normal, medication review — no offending agents. Neurology
> concludes: "Tremor, etiology undetermined — not consistent with
> Parkinson disease or essential tremor. Outpatient follow-up arranged."

**Principal Diagnosis:**
- [[R25.1]] — Tremor, unspecified *(workup completed — no definitive
  etiology established; symptom code remains as principal per Official
  Coding Guidelines Section II.A)*

**MS-DRG Assignment:**
- DRG 093 — Other Disorders of Nervous System without CC/MCC *(if no
  qualifying CCs/MCCs documented)*
- DRG 092 — with CC; DRG 091 — with MCC

> [!note] Symptom Code as Discharge Principal — Acceptable When Workup Is Exhaustive and Negative
> The inpatient workup was thorough and yielded no definitive diagnosis.
> [[R25.1]] correctly sequences as principal. The coding record should
> reflect that workup was completed without definitive etiology to
> support the symptom-as-principal assignment under audit.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|--|----------------|
| ❌ | **Do not assign [[R25.1]] when a specific movement disorder (G20-G26) is documented** — Excludes 1 is a hard rule; the specific diagnosis replaces [[R25.1]] entirely |
| ❌ | **Do not code [[R25.1]] with G20.-** — Parkinson disease tremor is captured in G20; coding both is an Excludes 1 violation |
| ❌ | **Do not code [[R25.1]] with [[50 Medical Coding/ICD-10 Codes/G25.0]] or [[G25.1]]** — all specific tremor codes within G20-G26 are Excludes 1 |
| ❌ | **Do not allow [[R25.1]] to persist as principal in a completed inpatient record** when the workup established a specific diagnosis |
| ❌ | **Do not assign [[G25.1]] without the adverse effect T-code** — drug-induced tremor always requires identification of the causative medication |
| ✅ | **[[R25.1]] is appropriate only in the diagnostic gap** — first encounter, pending workup, or exhaustive workup without definitive etiology |
| ✅ | **Medication reconciliation is your CDI tool** — carbidopa-levodopa on the med list = query G20.-; propranolol for tremor = query [[50 Medical Coding/ICD-10 Codes/G25.0]]; antipsychotic + new tremor = query [[G25.1]] |
| ✅ | **Every [[R25.1]] on a completed inpatient record is a CDI query target** — Parkinson disease (G20.-) is one of the highest-RAF diagnoses in CMS-HCC v28 |
| ✅ | **Upgrade from [[R25.1]] to G20.- is the highest-value single-code CDI swap in neurology inpatient coding** — prioritize this review at every encounter |
| ✅ | **Document why specific diagnosis cannot be established** — protects the symptom code assignment if workup is genuinely inconclusive and supports the coding record under audit |

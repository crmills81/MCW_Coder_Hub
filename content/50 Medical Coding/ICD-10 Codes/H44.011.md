## 🔍 Code Description

**# ICD-10 CM [[H44.011]]** classifies **acute panophthalmitis of the right eye** — the most severe form of **purulent endophthalmitis**, in which infection has spread through all coats of the globe (**cornea, sclera, uvea, retina**) and extended into the surrounding orbital tissues of the right eye.  Unlike the intraocular containment seen in standard endophthalmitis ([[H44.002]]), panophthalmitis has broken through the scleral barrier — the infection is no longer confined to the eye itself. The result is a simultaneous intraocular infection and [[orbital cellulitis]], presenting with the combined clinical picture of both.

This is one of the most clinically feared diagnoses in [[ophthalmology]] — prognosis for visual preservation is extremely poor, risk of losing the eye to evisceration or enucleation is high, and life-threatening complications including cavernous sinus [[thrombosis]], meningitis, [[encephalitis]], and **septic death** are documented sequelae. Every hour without aggressive treatment worsens both ocular and systemic outcomes.

## 🔑 Panophthalmitis vs. Endophthalmitis — The Critical Distinction

> [!important] This Is What Separates H44.011 From H44.002

The single defining anatomical boundary is the **sclera**. 

| Feature | [[H44.002]] Unspecified Endophthalmitis | **[[H44.011]] Panophthalmitis** |
|---|---|---|
| **Infection extent** | Intraocular cavities (vitreous, aqueous) | All ocular coats + **orbital extension**  |
| **Sclera involved?** | No — contained within globe | ✅ Yes — scleral abscess, perforation possible  |
| **Orbit involved?** | No | ✅ Yes — orbital cellulitis component  |
| **Proptosis** | Absent | ✅ Present — orbital involvement  |
| **Ophthalmoplegia** | Absent | ✅ EOM restriction / complete palsy  |
| **Lid edema/erythema** | Minimal | ✅ Significant — orbital signs  |
| **IOP** | Variable | ✅ Often markedly elevated  |
| **Systemic symptoms** | Possible | ✅ Fever, leukocytosis — common  |
| **Visual prognosis** | Poor | ❌ Very poor — worse than endophthalmitis |
| **Risk of evisceration** | Moderate | 🔴 HIGH — frequently required  |
| **Life-threatening complications** | Lower risk | 🔴 Cavernous sinus thrombosis, meningitis, sepsis, death  |
| **ICD-10-CM code (Right Eye)** | [[H44.002]] | **[[H44.011]] ← This code** |

> [!tip] The One-Line Clinical Test — Does It Have Orbital Signs?
> **Proptosis + ophthalmoplegia + lid edema + endophthalmitis = panophthalmitis** 
> Simply: *panophthalmitis = "endophthalmitis with orbital cellulitis"* 
> No orbital signs → stay with [[H44.002]] unspecified
> Orbital signs present → upgrade to **[[H44.011]]**

## 🦠 Organisms & Causes

> [!note] Full Organism Code Table in [[H44.002]]
> The complete pairing table (**B95-B96, B37.5 Candida, B44.x Aspergillus, etc.**)
> is documented in [[H44.002]] — Organism Codes section. All pairings
> apply equally to [[H44.011]]. Reference that note for the full table.

### Organisms That Most Commonly Drive to Panophthalmitis

Panophthalmitis tends to be caused by **high-virulence organisms** — those capable of rapid tissue destruction and scleral penetration. 

| Organism | Code | Why It Progresses to Panophthalmitis |
|---|---|---|
| **Bacillus cereus** | [[B96.89]] | Extremely virulent — trauma/soil; can destroy the globe within 24-48 hours |
| **Streptococcus species** | [[B95.5]] | Rapid toxin-mediated destruction — worst prognosis of common pathogens |
| **Klebsiella pneumoniae** | [[B96.1]] | Endogenous source — liver abscess, DM patients (Asian populations) |
| **Pseudomonas aeruginosa** | [[B96.5]] | Gram-negative virulence — trauma, contact lens |
| **Candida / Aspergillus** | [[B37.5]] / [[B44.x]] | Immunocompromised — fungal panophthalmitis rare but devastating |
| **Polymicrobial** | Multiple codes | Penetrating trauma with soil/vegetation contamination |

> [!danger] Bacillus cereus Panophthalmitis — Know This for the CIC
> **Bacillus cereus** (from penetrating trauma involving soil, vegetation, or retained intraocular foreign body) is the classic organism associated with fulminant panophthalmitis.
> Progression from normal eye to complete globe destruction can occur in **24-48 hours**. It is the textbook scenario for emergency evisceration. When a trauma case with H44.011 + [[B96.89]] (or specific Bacillus code) appears in a coding scenario, this is the organism to think of — and evisceration (CPT [[65091]]) is often the coded procedure.

## 🏥 Inpatient Coding — Panophthalmitis Is Almost Always Inpatient

Unlike many post-injection or **post-op endophthalmitis** cases that can be managed outpatient, **acute panophthalmitis virtually always requires inpatient admission** due to: 
- IV antibiotics (intravitreal alone insufficient)
- Systemic workup — blood cultures, imaging
- Surgical planning — [[vitrectomy]] vs. evisceration vs. enucleation
- Life-threatening complication monitoring

### Additional Codes That Frequently Accompany H44.011 Inpatient

| Code | Description | Relationship |
|---|---|---|
| Organism code | [[B96.89]], [[B95.5]], [[B96.1]], etc. | **Mandatory** — use additional code tabular instruction  |
| [[H05.011]] | Cellulitis of right orbit | Orbital extension component of panophthalmitis |
| A41.x | Sepsis | If systemic sepsis develops — see sequencing note below |
| [[H54.41]] | Blindness right eye, normal vision left | If visual outcome = NLP right eye |
| S05.x | Injury of eye and orbit | Post-traumatic panophthalmitis — injury code as additional |
| [[E11.9]] | Type 2 DM | High association with endogenous Klebsiella panophthalmitis |
| [[T49.5X5A]] | Adverse effect of ophthalmological drugs | If post-injection route (less common cause of panophthalmitis) |

> [!tip] H05.011 (Orbital Cellulitis) — Code It When Documented
> [[Panophthalmitis]] by definition involves orbital extension — when the physician documents both the **endophthalmitis/panophthalmitis** AND the [[orbital cellulitis]] component explicitly, both **[[H44.011]]** and **[[H05.011]]** (cellulitis of right orbit) may be appropriate as additional codes. The orbital involvement is the defining feature of panophthalmitis, and coding it specifically supports the clinical severity of the encounter. Query when orbital signs are documented but the physician has not explicitly stated "**orbital cellulitis.**"

### Sepsis Sequencing — Same Rule as H44.002

When panophthalmitis progresses to or presents with sepsis:
- Sepsis drove the admission → A41.x principal → MDC 18 (**higher DRG**)
- Panophthalmitis drove the admission, sepsis a complication → [[H44.011]] principal → MDC 02

## 🛠️ Surgical Procedures — Panophthalmitis Adds Evisceration/Enucleation

> [!important] Panophthalmitis Has a Unique Surgical Code Set vs. H44.002

| CPT | Description | When Used |
|---|---|---|
| [[67028]] | Intravitreal injection | Early/initial treatment attempt — antibiotics/antifungals |
| [[67036]] | Pars plana vitrectomy | If globe salvage still possible |
| **[[65091]]** | **Evisceration without implant** | **Panophthalmitis — globe destruction, no salvage** |
| **[[65093]]** | **Evisceration with implant** | **Panophthalmitis — remove contents, place conformer** |
| **[[65101]]** | **Enucleation without implant** | **Globe removal — when evisceration insufficient** |
| **[[65103]]** | **Enucleation with implant** | **Globe removal with orbital implant** |

> [!danger] Evisceration vs. Enucleation — Know the Difference for CIC
> **Evisceration ([[65091]]/[[65093]])** = removes the internal contents of the globe (uvea, retina, vitreous) while leaving the scleral shell and [[extraocular]] muscles intact. Preferred in infectious panophthalmitis because it preserves orbital volume and extraocular muscle attachment. Used when the globe structure is destroyed but sclera is relatively intact.
>
> **Enucleation ([[65101]]/[[65103]])** = removes the entire globe. Used when sympathetic ophthalmia risk is high, when there is scleral perforation, or when neoplasm is involved.
>
> In **panophthalmitis** specifically — **evisceration is the more common surgical intervention** because the scleral shell is often still present while the intraocular contents are destroyed. The choice depends on orbital integrity and sympathetic ophthalmia risk assessment.

## 💊 Coding Scenarios

---

### Scenario 1 — Penetrating Trauma → Bacillus Panophthalmitis, Right Eye (Inpatient)

> **Clinical Vignette:** A 34-year-old male sustains a penetrating injury to the right eye from a metal spike in soil. Presents 18 hours later with extreme pain, proptosis, complete [[ophthalmoplegia]], chemosis, and complete loss of vision OD. Cultures: Bacillus cereus. CT orbit: gas within right globe — panophthalmitis with orbital extension. Urgent evisceration performed. Impression: Acute panophthalmitis, right eye — Bacillus cereus. Post-traumatic. Evisceration performed.

**ICD-10-CM:**
- **[[H44.011]]** — Panophthalmitis, acute, right eye *(principal — reason for admission)*
- [[B96.89]] — Other specified bacteria *(Bacillus cereus — mandatory organism identification)*
- [[H05.011]] — Cellulitis of right orbit *(orbital extension documented)*
- S05.x — Injury of right eye and orbit *(penetrating injury — causative event)*
- [[H54.41]] — Blindness, right eye *(NLP — outcome of panophthalmitis)*

**CPT:**
- [[65091]] — Evisceration without implant *(or 65093 with implant per op note)*

---

### Scenario 2 — Endogenous Klebsiella Panophthalmitis, Right Eye — Diabetic (Inpatient)

> **Clinical Vignette:** A 61-year-old Taiwanese male with T2DM and Klebsiella liver abscess presents with acute right eye pain, proptosis, vision loss. Exam: corneal ring abscess, hypopyon, complete vitritis, proptosis 4mm OD, EOM restricted in all fields. Blood cultures and vitreous tap: Klebsiella pneumoniae. Impression: Endogenous Klebsiella panophthalmitis, right eye — source: liver abscess.

**ICD-10-CM:**
- [[A41.51]] — Sepsis due to Escherichia coli *(or appropriate Klebsiella sepsis code — principal if sepsis drove admission)*
- **[[H44.011]]** — Panophthalmitis, acute, right eye *(additional — ocular manifestation)*
- [[B96.1]] — Klebsiella pneumoniae as cause *(mandatory organism identification)*
- [[H05.011]] — Cellulitis of right orbit *(orbital extension)*
- [[E11.9]] — T2DM *(underlying condition — strong risk factor for Klebsiella endogenous panophthalmitis)*
- [[K75.0]] — Abscess of liver *(primary infectious source)*

> [!important] Klebsiella Endogenous Panophthalmitis — CIC-Worthy Scenario
> The association of **Klebsiella pneumoniae liver abscess** with endogenous **panophthalmitis** — particularly in **Asian diabetic patients** — is a classic clinical vignette that appears in ophthalmology board questions.  It represents a unique pathogen-host interaction where Klebsiella's hypermucoviscous phenotype allows metastatic spread to the eye. Code the sepsis/bacteremia first when it is the reason for admission, add **[[H44.011]]** as the ocular complication, and always code the liver abscess source.

---

### Scenario 3 — Post-Op Panophthalmitis Right Eye — Rapid Progression From Endophthalmitis (Inpatient)

> **Clinical Vignette:** A 78-year-old female 5 days post right cataract surgery returns with rapidly worsening eye pain, decreased vision to light perception, proptosis, and lid edema OD. Exam: corneal edema, hypopyon, dense vitritis, scleral injection extending to periorbital tissues, EOM restricted. Culture: Streptococcus mitis. Impression: Acute post-operative panophthalmitis, right eye — **Streptococcal**.

**ICD-10-CM:**
- **[[H44.011]]** — Panophthalmitis, acute, right eye *(principal)*
- [[B95.5]] — Streptococcus as cause *(mandatory organism identification)*
- [[H05.011]] — Cellulitis of right orbit *(orbital extension)*
- [[T81.4XXA]] — Infection following procedure, initial encounter *(post-surgical source)*
- [[Z96.51]] — Presence of right artificial lens *(IOL context)*

> [!tip] Progression From H44.001 to H44.011 Within the Same Admission
> When a patient is admitted for post-op endophthalmitis (**[[H44.001]] unspecified**) and progresses to panophthalmitis ([[H44.011]]) during the same hospitalization, code the **most severe condition** that was present — [[H44.011]] — as it best represents the clinical picture at its highest severity during the encounter. The more specific panophthalmitis code always supersedes the unspecified [[endophthalmitis]] code when documentation supports it.

| | Pitfall or Tip |
|---|---|
| ❌ | **Never use H44.002 when orbital signs are documented** — proptosis + EOM restriction + lid edema = panophthalmitis → **[[H44.011]]**  |
| ❌ | **Never omit the organism code** — mandatory tabular instruction for all H44.0 codes |
| ❌ | **Never code H44.011 for bleb-associated infection** — Excludes1 → H59.4-  |
| ❌ | **Never leave out [[H05.011]]** when orbital cellulitis is explicitly documented alongside panophthalmitis — it captures the full clinical picture |
| ✅ | **Panophthalmitis = endophthalmitis with orbital signs** — proptosis, ophthalmoplegia, lid edema = the clinical triggers for H44.011  |
| ✅ | **Bacillus cereus → rapid evisceration** — the classic panophthalmitis organism/surgery pairing; know it for CIC  |
| ✅ | **Klebsiella + DM + Asian patient + liver abscess → endogenous panophthalmitis** — highly specific clinical scenario, CIC-worthy |

| ✅ | **Sepsis sequencing** — when panophthalmitis and sepsis coexist, principal diagnosis is the condition that drove admission |

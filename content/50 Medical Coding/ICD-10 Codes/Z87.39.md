# 🩺 ICD-10 CM Z87.39 — Personal History of Other Diseases of the Musculoskeletal System and Connective Tissue

> [!info] **Quick Reference**
> **Billable:** ✅ Yes | **Code Type:** Historical / personal history code | **Use When:** Prior musculoskeletal or connective tissue disease is documented as resolved or past history | **Not for:** Active disease, healed traumatic fracture, or current follow-up care<sup>1</sup><sup>2</sup>

---

## 📋 Clinical Description

**ICD-10 CM Z87.39** is used when the provider documents a **personal history of another musculoskeletal or connective tissue disease** that is no longer active.<sup>1</sup> This code belongs in **Chapter 21** and is used to show that the patient has a relevant past history that may affect current care, risk assessment, or surveillance.<sup>2</sup>

This code is not used for an active disorder, and it should not be used as a substitute for a current diagnosis such as **[[arthritis]]**, **[[osteoporosis]]**, **[[myopathy]]**, or **connective tissue disease**.<sup>2</sup> If the condition is still active, code the current condition instead of a history code.<sup>2</sup>

**This code may be used in these clinical contexts:**

- **Resolved inflammatory or degenerative musculoskeletal disease** — The condition is no longer active, but the history is still clinically relevant.<sup>1</sup>
- **Past connective tissue disorder** — A prior connective tissue condition is documented as part of the patient's medical history.<sup>1</sup>
- **Risk-factor documentation** — The history is being tracked because it may affect current evaluation, treatment planning, or monitoring.<sup>2</sup>
- **Follow-up after treatment** — Use only when the active disease has resolved and the encounter is not for current treatment of that condition; follow-up guidance may require Z09 first when applicable.<sup>1</sup><sup>2</sup>

## 🔬 Code Structure & Use

| Element | Meaning | Coding Impact |
|---|---|---|
| **Z** | Factors influencing health status and contact with health services | Indicates the code is a history/status code, not an active disease code. |
| **87** | Personal history of other diseases and conditions | Identifies personal history reporting. |
| **.39** | Other diseases of the musculoskeletal system and connective tissue | Used when no more specific personal history code applies. |

> [!tip] Clinical Pearl
> **Z87.39** is a **history code**, so it should support the chart, not replace a current diagnosis. If documentation describes an active **musculoskeletal disorder**, use the active disease code first and reserve **Z87.39** for relevant past history.<sup>1</sup><sup>2</sup>

## ✅ What This Code Captures

- Prior **musculoskeletal disease** that is no longer active.<sup>1</sup>
- Prior **connective tissue disease** that is no longer active.<sup>1</sup>
- History documentation that supports current care planning.<sup>2</sup>
- Relevant past history that does not meet criteria for an active diagnosis.<sup>2</sup>

| **[[Z87.31]]** | Personal history of (healed) nontraumatic fracture | Use this instead when the history is specifically a healed nontraumatic fracture.<sup>1</sup> |
| **[[Z87.81]]** | Personal history of (healed) traumatic fracture | Use this instead when the history is specifically a healed traumatic fracture.<sup>1</sup> |
| **[[Z09]]** | Follow-up examination after treatment | Code first when the encounter is specifically a follow-up after completed treatment rather than a general history of disease.<sup>1</sup> |

> [!warning] Coding Alert
> **Z87.39** should not be used for current **treatment**, current **symptoms**, or unresolved disease. If the provider is still managing the condition, code the active diagnosis instead of a history code.<sup>2</sup>

## 🏥 MS-DRG Considerations (Inpatient)

> [!important] Inpatient Coding Reminder
> **[[Z87.39]]** is a **history code** and does not independently drive **MS-DRG assignment.**<sup>2</sup> It may be reported as an additional diagnosis when the past **musculoskeletal history** is clinically relevant to the admission.<sup>2</sup> It does not replace the principal diagnosis and typically does not change grouping by itself.<sup>2</sup>

## 📝 Coding Examples

### Example 1 — Office Visit: Relevant History Only

> **Clinical Scenario:** A patient is seen for routine hypertension follow-up. The chart notes a past history of resolved inflammatory arthritis, with no current joint pain, swelling, or treatment. The provider documents the history because it remains relevant to current medication selection and risk assessment.

| Field | Code | Rationale |
|---|---|---|
| **PDx / First-listed** | [[I10]] | Current reason for visit. |
| **Additional** | [[Z87.39]] | Documents the resolved musculoskeletal history.<sup>1</sup> |

### Example 2 — Follow-Up After Resolved Condition

> **Clinical Scenario:** A patient returns after prior treatment for a connective tissue disorder that is now resolved. The provider documents that the condition is no longer active and that the visit is solely to review ongoing status.

| Field | Code | Rationale |
|---|---|---|
| **PDx / First-listed** | [[Z09]] | Follow-up after completed treatment. |
| **Additional** | [[Z87.39]] | Past musculoskeletal/connective tissue history, if still clinically relevant.<sup>1</sup> |

### Example 3 — Healed Fracture History Query

> **Clinical Scenario:** The provider writes “history of prior fracture” but does not specify whether it was traumatic or nontraumatic. No active fracture is present.

| Field | Code | Rationale |
|---|---|---|
| **PDx / First-listed** | [[Z87.81]] or [[Z87.31]] | Select the more specific healed fracture history if documented. |
| **Additional** | [[Z87.39]] | Use only if the history is not a fracture and better fits musculoskeletal/connective tissue history.<sup>1</sup> |

> [!warning]
> If the note only says “history of arthritis” without confirming whether it is active or resolved, do not guess. Query for specificity before assigning [[Z87.39]].<sup>2</sup>

## ⚠️ Common Coding Pitfalls

- **Using Z87.39 for active disease:** If the musculoskeletal or connective tissue condition is still being treated or monitored as active, the history code is incorrect.<sup>2</sup>
- **Missing a more specific history code:** If the history is actually healed traumatic fracture or healed nontraumatic fracture, use the specific code instead of [[Z87.39]].<sup>1</sup>
- **Confusing follow-up with history:** When the encounter is for completed treatment follow-up, [[Z09]] may be the correct first-listed code, with history codes reported only as appropriate.<sup>1</sup>
- **Using the parent code instead of the billable child code:** Z87.3 is the parent category; [[Z87.39]] is the billable specific code to use when the record supports “other” musculoskeletal/connective tissue history.<sup>1</sup>
- **Coding without documentation support:** If the record does not clearly establish that the condition is historical and no longer active, query the provider.<sup>2</sup>

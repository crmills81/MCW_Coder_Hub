# 🧬 ICD-10 CM M48.061 — Spinal Stenosis, Lumbar Region Without Neurogenic Claudication

> [!success] Billable Code Confirmed
> **ICD-10 CM [[M48.061]]** is a **7-character code**. Category **M48**, subcategory .**0**, site **6** (**lumbar**), and the **7th character 1** means "**without neurogenic claudication**." It is a terminal code, so it is valid for claim submission.<sup>3</sup>

> [!warning] Non-Billable Parent Codes
> **M48.06** (**Spinal stenosis, lumbar region**) is non-billable because it needs the claudication distinction.<sup>3,6</sup> **M48.0** (**Spinal stenosis**) and **M48** (**Other spondylopathies**) are category headers and can't be reported.

> [!important] Clinical Context
> The deciding factor is **documentation of neurogenic [[claudication]]**, meaning walking-induced leg pain or weakness relieved by sitting or flexion. If the provider doesn't document it, use **[[M48.061]]**. If they do, use **[[M48.062]]**.

> [!danger] Code Classification
> This is a **diagnosis code (ICD-10-CM)** from the musculoskeletal chapter. It is not a procedure code, and it is not a manifestation code.

---

## 🔍 Code Description

**ICD-10 CM [[M48.061]]** reports **narrowing of the spinal canal, lateral recess, or neural foramina in the lumbar spine when the provider does not document neurogenic claudication**. It is most often degenerative (**facet hypertrophy, ligamentum flavum thickening, disc bulge**). Symptoms can include **axial low back pain**, or **radicular pain** reported separately with **[[M54.16]]** when documented.

For **inpatient profee**, this code is usually a secondary or supporting diagnosis for **[[decompression]]** such as **[[63047]]**. When **[[claudication]]** is later documented in the record, query or review and move to **[[M48.062]]**. For **lumbosacral-level stenosis**, use **[[M48.07]]** instead.

> [!example] Claudication Drives Specificity
> Many **payers** and the **Medicare PILD NCD (150.13)** are tied to **neurogenic claudication**, so choosing **[[M48.061]]** versus **[[M48.062]]** can decide coverage.<sup>2,4</sup>

> [!tip]
> Look for the words "**neurogenic claudication**" or "**[[pseudoclaudication]]**" in the **H&P, progress note, or op report**. Imaging alone showing stenosis does not establish **claudication**.

- **Lumbar central canal [[stenosis]]** — The default home for lumbar stenosis without claudication.
- **Lateral recess or foraminal [[stenosis]] (lumbar)** — Reported to **[[M48.061]]** when only the lumbar region is documented.
- **Caudal [[stenosis]]** — Indexed to the **M48.0- family**. Choose the lumbar or lumbosacral site per documentation.

## ❌ Excludes

### Excludes 1
> **Detail Rule:** No formal **Excludes1 note** is listed at **[[M48.061]]** in my reference. Confirm in your encoder.

- **[[M48.062]]** — The sibling with **[[claudication]]**. Report one or the other for the same lumbar region, not both.

> [!danger]
> The most **common error** is reporting both **[[M48.061]]** and **[[M48.062]]** on the same encounter. Pick the one that matches the documentation of **claudication**.

### Excludes 2
- **[[M48.07]]** — **Lumbosacral stenosis** is a different site and can be reported with **[[M48.061]]** when the provider documents **[[stenosis]]** at both the lumbar and lumbosacral levels.
- **[[M54.16]]** — **Lumbar [[radiculopathy]]** can be reported additionally when the provider documents it as a separate diagnosis.

## 📋 Clinical Overview

### Claudication vs. No Claudication
Both codes describe **lumbar canal narrowing**. They are separated only by documented **neurogenic claudication**, and that single character can change prior auth and LCD outcomes.

| **Feature** | **[[M48.061]]** | **Related [[M48.062]]** | **Related [[M48.07]]** |
|---|---|---|---|
| **Site** | Lumbar region | Lumbar region | Lumbosacral junction |
| **Neurogenic claudication** | Not documented | Documented | Not part of the code |
| **Policy impact** | Often falls outside ESI and PILD criteria that require claudication or radicular pain.<sup>1,2</sup> | Meets the claudication language in many policies.<sup>1,2</sup> | Different region, so separate edits. |

> [!important]
> **CDI trigger**: imaging says "**severe lumbar stenosis**" and the note mentions leg pain with walking, but no one has documented "**neurogenic claudication**." **Query** the provider so the code reflects the clinical picture.

### Manifestations & Symptom Burden
- **Axial low back pain** — Common and may be the only symptom.
- **Radicular leg pain** — Reported separately when documented, for example **[[M54.16]]**.
- **Numbness or tingling** — Reported only if the provider documents it as a diagnosis.
- **Weakness** — Can occur with nerve root compression.

> [!tip]
> Symptoms integral to **[[stenosis]]** are not coded separately unless the provider documents a distinct diagnosis, such as **[[radiculopathy]]**.

| **Scenario** | **MS-DRG** | **Title** |
|---|---|---|
| **PDx, with MCC** | 551 | Medical Back Problems with MCC |
| **PDx, without MCC** | 552 | Medical Back Problems without MCC |
| **[[Decompression]] (e.g., [[laminectomy]])** | 518 / 519 / 520 | Back and Neck Procedures Except Spinal Fusion with MCC or Disc Device/Neurostimulator / with CC / without CC/MCC |
| **Lumbar [[fusion]]** | 459 / 460 | Spinal Fusion Except Cervical with MCC / without MCC |

**ICD-10 CM [[M48.061]]** is not a **CC** or **MCC**. With an **OR** procedure, the **DRG** follows the procedure, not the diagnosis.

**NCD/LCD notes:**
- **NCD 150.13 (PILD):** **Medicare** covers **[[percutaneous]]** image-guided **lumbar decompression** only under **Coverage** with **Evidence Development**, for stenosis with **neurogenic claudication**. **[[M48.061]]** does not fit that population, so use **[[M48.062]]** only when **[[claudication]]** is documented.<sup>2</sup>
- **ESI LCD (e.g., L39015 / L36920):** The LCD requires **[[radiculopathy]]**, radicular pain, or **neurogenic claudication** from **[[stenosis]]**, plus imaging and failed conservative care.<sup>1,5</sup> Review the billing article's covered **ICD-10 list for your MAC**.
- **NCS/EMG policy article:** It lists **[[M48.061]]** among supported diagnoses.<sup>7</sup>

## 💊 Coding Scenarios and Examples

<br>

### Example 1
> **Clinical Scenario:**
> A 68-year-old woman has chronic low back pain and imaging showing severe L4-L5 central canal stenosis. She has no leg symptoms with walking and no documented claudication. She undergoes a single-level lumbar laminectomy with decompression.

| Field | Code | Rationale |
|---|---|---|
| CPT | [[63047]] | Single-level lumbar decompression. |
| PDx | [[M48.061]] | Lumbar stenosis, no claudication documented. |

> [!tip]
> Link the diagnosis to the procedure. If the surgeon later documents claudication, update to [[M48.062]].

### Example 2
> **Clinical Scenario:**
> A 72-year-old man has lumbar stenosis with radicular pain down the left leg. He receives a left L5 transforaminal epidural injection with fluoroscopy and a second level at S1.

| Field | Code | Rationale |
|---|---|---|
| CPT | [[64483]]-[[-LT]] | First level, left side. |
| CPT 2 | [[64484]] | Each additional level. |
| PDx | [[M48.061]] | Underlying lumbar stenosis. |

> [!tip]
> Add [[M54.16]] if the provider documents radiculopathy. The ESI LCD requires radicular pain, so it is the stronger supporting diagnosis.<sup>1</sup>

### Example 3
> **Clinical Scenario:**
> A 60-year-old has lumbar stenosis and Grade 1 spondylolisthesis at L4-L5. The surgeon performs decompression with posterolateral fusion at one level.

| Field | Code | Rationale |
|---|---|---|
| CPT | [[22612]] | Posterolateral lumbar fusion, single level. |
| PDx | [[M48.061]] | Stenosis with no claudication. |

> [!tip]
> Add [[M43.16]] for the [[spondylolisthesis]]. Decompression at the same level as the fusion is often bundled, so check the NCCI edits.

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Reporting **[[M48.061]]** when neurogenic claudication is documented; **Tips**: Read the full note and use **[[M48.062]]** when it is documented.
- **Pitfall 2**: Reporting the non-billable parent **M48.06-**; **Tips**: Always go to the 7th character, and your encoder will block it.
- **Pitfall 3**: Assuming imaging alone supports claudication; **Tips**: **[[Claudication]]** needs provider documentation of the symptoms, not just MRI findings.
- **Pitfall 4**: Using **[[M48.061]]** to support an **ESI or PILD** that requires claudication or radicular pain; **Tips**: Review the LCD and billing article and report **[[M54.16]]** when documented.<sup>1,2</sup>
- **Pitfall 5**: Expecting an **HCC** or **CC** from **[[M48.061]]**; **Tips**: It is neither, so don't add queries just to capture severity.
- **Pitfall 6**: Missing the right or left modifier on injection **CPTs**; **Tips**: Add **[[-RT]]**, **[[-LT]]**, or **[[-50]]** per payer rules.

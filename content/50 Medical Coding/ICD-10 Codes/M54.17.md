# 🧬 ICD-10 CM M54.17 — Radiculopathy, Lumbosacral Region

> [!success] Billable Code Confirmed  
> **ICD-10-CM [[M54.17]]** is a fully billable, valid **5-character code** for **FY2027** representing **[[radiculopathy]]** localized to the **[[lumbosacral]] spine**.<sup>1</sup> It provides complete anatomic specificity, requiring no further characters to be submitted on **inpatient** or **outpatient** claims.<sup>1</sup>

> [!warning] Non-Billable Parent Codes  
> **M54** (**Other dorsopathies**) is a 3-character **non-billable** category code requiring **fourth**- and **fifth**-character subclassification to identify the clinical condition.<sup>1</sup>
> **M54.1** (**[[Radiculopathy]]**) is a 4-character **non-billable** subcategory code that requires a **5th** character specifying the anatomical vertebral region affected.<sup>1</sup>

> [!important] Clinical Context  
> The clinical utility of **[[M54.17]]** centers on **documenting functional nerve root [[irritation]] or [[compression]]** across the **L5-S1 junction** when an underlying structural lesion like a **herniated disc** or **[[spondylosis]]** is either absent or not explicitly documented.<sup>3</sup>

> [!danger] Code Classification  
> This is an **ICD-10-CM diagnosis code** used to substantiate medical necessity for **non-operative treatments**, **electrodiagnostic studies**, **epidural steroid injections**, and **spinal decompressive procedures**.

---

## 🔍 Code Description  
**[[Lumbosacral]] [[radiculopathy]]**, designated by **[[M54.17]]**, describes **mechanical impingement, chemical [[irritation]], or [[inflammation]] of the nerve roots exiting the L5, S1, or transitional sacral segments**.^1 Patients present with **radiating neuropathic pain, [[paresthesias]], or localized motor weakness** extending from the lower back through the **buttocks** down into the lower extremity along specific dermatomes.<sup>3</sup> When diagnostic studies do not identify or link a causal **disc [[displacement]]** or **[[degenerative]] [[spondylosis]]**, **[[M54.17]]** serves as the definitive standalone diagnosis code.<sup>1</sup>

In practical coding workflows, **[[M54.17]]** provides essential medical necessity for **diagnostic procedures** such as **needle [[electromyography]]** with **nerve conduction studies** under **[[95886]]** or interventional pain procedures such as **transforaminal epidural injections** under **[[64483]]**.<sup>2</sup> However, coders must exercise caution regarding **ICD-10-CM Excludes1 conventions**: if neuroimaging confirms that the **[[radiculopathy]]** is secondary to a **herniated disc**, the coder must redirect to combination code **[[M51.17]]** rather than reporting **[[M54.17]]** independently.<sup>1</sup>

> [!example] Etiology Specificity and Payer Criteria
> 
> Distinguishing **[[M54.17]]** from **combination codes** such as **[[M51.17]]** directly influences **prior authorization approval** for **interventional procedures**, as **Medicare Local Coverage Determinations (LCDs)** enforce different **conservative therapy rules** depending on whether **structural disc pathology** is confirmed.<sup>3</sup>
> 
>   

> [!tip]
> 
> **Review MRI reports and clinical summaries** before final code submission; if an **acute herniated disc or [[spondylosis]]** is explicitly cited as the direct etiology of the **radicular pain**, **ICD-10-CM guidelines** prohibit coding **[[M54.17]]** as a primary condition.<sup>1</sup>
> 
>   

## ✅ Includes

- **[[Lumbosacral]] [[radiculitis]] NOS** without underlying structural **[[lesion]]** specified.<sup>1</sup>
    
      
    
- **Nerve root irritation** affecting the lower **lumbar** an**d upper sacral spinal levels**.<sup>1</sup>
    
      
    
- **Isolated sensory or motor dysfunction** following the **L5** or **S1** nerve distribution.<sup>3</sup>
    
      
    

## ❌ Excludes

### Excludes 1

- **[[M47.27]]** — Other **[[spondylosis]]** with **[[radiculopathy]]**, **[[lumbosacral]]** region. **[[Spondylosis]]** with **[[radiculopathy]]** is an etiology combination code that takes coding **precedence** over standalone **[[radiculopathy]]**.<sup>1</sup>
    
      
    
- **[[M51.17]]** — **Intervertebral disc disorders with radiculopathy**, **[[lumbosacral]]** region. When disc **[[herniation]]** causes **[[radiculopathy]]**, guidelines mandate the combination code rather than **[[M54.17]]**.<sup>1</sup>
    
      
    
- **[[M79.2]]** — **[[Neuralgia]] and [[neuritis]], unspecified**. Non-specific **peripheral [[neuralgia]]** excludes anatomically defined spinal **nerve root radiculopathies**.<sup>1</sup>
    
      
    

> [!danger]
> 
> The most frequent **Excludes1 error** occurs when coders submit both **[[M54.17]]** and **[[M51.17]]** for the same patient encounter. Claim editing engines will reject the claim because the **disc disorder code** inherently includes the **[[radiculopathy]]**.<sup>3</sup>
> 
>   

### Excludes 2

- **[[M54.31]]** — **[[Sciatica]], right side**. **Sciatica** can be reported alongside **[[lumbosacral]] [[radiculopathy]]** if documented as distinct **peripheral sciatic nerve irritation**.<sup>1</sup>
    
      
    
- **[[M54.32]]** — **[[Sciatica]]**, left side. **Left-sided sciatic [[neuropathy]]** can coexist when documented separately from true spinal root pathology.<sup>1</sup>
    
      
    
- **[[M54.50]]** — **Low back pain, unspecified**. Axial back pain can be coded concurrently when separate **axial spine evaluations** and **management** are documented.<sup>1</sup>
    
      
    

## 📋 Clinical Overview

### Lumbosacral Nerve Root Compression Distinctions

**Differentiating isolated lumbosacral radiculopathy** from **discogenic pathology** and degenerative **[[spondylosis]]** is essential for appropriate diagnosis reporting and clinical documentation integrity.<sup>3</sup> The presence of structural imaging findings dictates whether a combination code or a **standalone [[radiculopathy]] code** is appropriate.<sup>1</sup>

  

|**Feature**|**[[M54.17]]**|**Related [[M51.17]]**|**Related [[M47.27]]**|
|:---:|---|---|---|
|**Underlying Etiology**|Idiopathic, inflammatory, or unspecified nerve irritation at L5-S1.|Structural disc displacement, protrusion, or extrusion contacting nerve roots.|Chronic facet hypertrophy, osteophytosis, or degenerative arthropathy causing impingement.|
|**Diagnostic Correlation**|Imaging is non-diagnostic, equivocal, or demonstrates no clear mechanical disc defect.|MRI or CT confirms disc herniation or extrusion compressing the traversing root.|Plain radiographs or CT show facet arthrosis, osteophytes, and subarticular narrowing.|
|**Coding Directive**|Default code assigned when provider documents radiculopathy without structural etiology.|Mandatory combination code under Chapter 13 guidelines; supersedes isolated radiculopathy.|Mandatory combination code when spondylosis is explicitly linked with radiculopathy.|

> [!important]
> 
> A common **CDI trigger** occurs when documentation lists "**sciatica with L5 sensory deficit**" alongside an **MRI** demonstrating a **herniated nucleus pulposus**.^<sup>3</sup> **Query** the provider to link the **[[radiculopathy]]** to the **disc lesion** so the record supports the combination code **[[M51.17]]**.
> 
>   

### Manifestations & Symptom Burden

- **Dermatomal [[Paresthesia]]:** **Numbness, burning, or tingling** radiating down the **posterolateral** leg into the dorsum of the foot (L5) or lateral heel and plantar surface (S1).<sup>3</sup>
    
      
    
- **Motor Weakness:** Reduced strength during ankle dorsiflexion, great toe extension (**extensor hallucis longus**), or ankle **[[plantarflexion]]**.<sup>3</sup>
    
      
    
- **Reflex Asymmetry:** **Hypoactive** or completely absent Achilles tendon reflex (**S1 nerve root**) during neurological examination.<sup>3</sup>
    
      
    
- **Provocative Maneuvers:** **[[Exacerbation]]** of radiating symptoms during the straight leg raise test or seated slump maneuver.<sup>3</sup>
    
      
    

> [!tip]
> 
> If persistent **[[radiculopathy]]** causes a distinct functional deficit such as **secondary foot drop** (**[[M21.121]]** or **[[M21.122]]**), report the secondary deficit as an additional diagnosis code.<sup>1</sup>
> 
>

When **[[M54.17]]** is assigned as the **principal diagnosis, the encounter groups into MDC 08 under the Medical Back Problems MS-DRG family**.<sup>1</sup> The assignment shifts from **DRG 552 to DRG 551** only if the inpatient record documents a secondary diagnosis qualifying as a **Major Complication or Comorbidity (MCC)**.<sup>1</sup> If surgery is performed during the admission, **surgical DRGs (518-520 for Back & Neck Procedures)** take precedence over medical back problem **DRGs**.<sup>1</sup> Under **Medicare Local Coverage Determinations** (**such as LCD L36920 and regional MAC policies**), **interventional epidural injections** billed with **[[M54.17]]** require documentation of at **least 4 to 6 weeks** of failed conservative treatment (**physical therapy, NSAIDs**) and objective physical exam findings to qualify for reimbursement.<sup>1</sup>

### NCCI Bundling Considerations

**Fluoroscopic or CT imaging guidance** is inherent in CPT **[[64483]]** and **[[62323]]**; separate billing of **fluoroscopy guidance codes** (**e.g., [[77003]]**) constitutes improper **unbundling** under **NCCI edits**.<sup>2</sup> Furthermore, **nerve conduction studies** and **[[electromyography]]** conducted on the same date are subject to mutually defined testing protocols and must meet **NCCI unit** threshold limits.<sup>2</sup>

## 💊 Coding Scenarios and Examples

### Example 1

> **Clinical Scenario:**
> 
>   
> 
> A 52-year-old established patient presents to the interventional spine PM&R clinic with persistent sharp pain radiating from the lower back through the right buttock and down the lateral calf to the great toe. Physical exam demonstrates a positive straight leg raise on the right, diminished right Achilles reflex, and paresthesias in the right L5 dermatome. Diagnostic imaging reveals no acute disc herniation or severe stenosis. The physician performs a fluoroscopically guided right L5 transforaminal epidural steroid injection.
> 
>   

|**Field**|**Code**|**Rationale**|
|---|---|---|
|CPT|[[64483]]-[[-RT]]|Covers the single-level transforaminal epidural injection on the right side with imaging guidance included.<sup>2</sup>|
|PDx|[[M54.17]]|Primary diagnosis establishing medical necessity for the lumbosacral nerve root injection.<sup>1</sup>|

> [!tip]
> 
> Append modifier [[-RT]] rather than modifier [[-50]] because the injection was administered unilaterally.
> 
> Ensure clinical documentation details prior failed conservative management to comply with local MAC LCD coverage requirements for interventional spine procedures.
> 
>   

### Example 2

> **Clinical Scenario:**
> 
>   
> 
> A 46-year-old patient presents to the PM&R electrodiagnostic laboratory for investigation of unresolved radiating pain and progressive sensory loss in the left lower extremity. The physician performs motor and sensory nerve conduction studies across 8 nerves, followed by a complete needle electromyography study of six muscles in the left lower extremity including lumbosacral paraspinals. The electrodiagnostic report confirms acute L5-S1 lumbosacral radiculopathy.
> 
>   

|**Field**|**Code**|**Rationale**|
|---|---|---|
|CPT|[[95886]]|Complete needle electromyography of one extremity with paraspinal evaluation performed in conjunction with nerve conduction testing.<sup>2</sup>|
|CPT 2|[[95910]]|Nerve conduction study involving 7 to 8 separate nerve tests.<sup>2</sup>|
|PDx|[[M54.17]]|Confirmed diagnostic finding from testing explaining the presenting neurologic signs and symptoms.<sup>2</sup>|

> [!tip]
> 
> Sequence the confirmed radiculopathy finding as primary; avoid coding non-specific symptom codes like leg pain when electrodiagnostic studies yield a definitive diagnosis.
> 
> Ensure both EMG and NCS reports are signed with detailed numeric latency and amplitude tables to support documentation requirements.
> 
>   

### Example 3

> **Clinical Scenario:**
> 
>   
> 
> A 61-year-old established patient visits the PM&R outpatient clinic for reassessment of chronic lumbosacral radiculopathy symptoms causing difficulty with daily ambulation. The physician conducts an interval history, performs a neurological exam of the lower extremities, reviews lumbar radiographs, and prescribes an individualized home physical therapy exercise regimen while modifying the patient's gabapentin dosage.
> 
>   

|**Field**|**Code**|**Rationale**|
|---|---|---|
|CPT|[[99214]]|Established patient office visit with moderate level of medical decision-making based on a chronic illness with exacerbation and prescription drug management.<sup>2</sup>|
|PDx|[[M54.17]]|Supports the moderate-complexity evaluation and medication adjustment for lumbosacral radiculopathy.<sup>1</sup>|

> [!tip]
> 
> Medical decision-making is substantiated by prescription drug management and addressing a chronic condition with symptomatic worsening.
> 
> If the physician discusses invasive or surgical consultation options, document the risk discussion thoroughly to substantiate MDM complexity.
>

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Assigning **[[M54.17]]** when imaging confirms an **intervertebral disc [[herniation]] with [[radiculopathy]]**; **Tips**: Review **MRI and CT reports** carefully and assign **combination code** **[[M51.17]]** instead, adhering strictly to **Excludes1** **guidelines**.<sup>1</sup>
    
      
    
- **Pitfall 2**: Coding **non-specific radiculopathy** (**[[M54.10]]**) when the **[[lumbosacral]]** location is documented; **Tips**: Ensure the coder identifies documentation referencing **L5, S1, or [[lumbosacral]] roots** to assign **[[M54.17]]** at full specificity.<sup>3</sup>
    
      
    
- **Pitfall 3**: Unbundling **fluoroscopic guidance** when reporting **epidural injection** procedures; **Tips**: Never report code **[[77003]]** alongside **[[64483]]** or **[[62323]]**, as **[[fluoroscopy]]** is included in the primary **CPT descriptor**.<sup>2</sup>
    
      
    
- **Pitfall 4**: Submitting claims for **epidural injections** without documenting prior failed conservative treatment; **Tips**: Verify the clinical record clearly demonstrates 4 to 6 weeks of **prior conservative therapy** (**e.g., physical therapy, NSAIDs**) as mandated by **Medicare LCDs**.<sup>1</sup>
    
      
    
- **Pitfall 5**: Reporting modifier **[[-50]]** on **unilateral transforaminal epidural injections**; **Tips**: Apply modifier **[[-RT]]** or **[[-LT]]** for single-side injections, reserving modifier **[[-50]]** strictly for procedures performed bilaterally at the same segment.<sup>2</sup>
    
      
    
- **Pitfall 6**: Failing to code secondary documented neurological manifestations such as **[[foot drop]]**; **Tips**: When persistent **[[radiculopathy]]** causes secondary motor deficits like **paralytic foot drop**, append the appropriate secondary diagnosis code alongside **[[M54.17]]** to fully portray clinical severity.<sup>1</sup>

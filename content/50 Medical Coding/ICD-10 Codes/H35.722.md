# 🧬 ICD-10-CM H35.722 — Serous Detachment of RPE, Left Eye

> [!success] Billable Code Confirmed — 6 Characters Complete
> **ICD-10 CM [[H35.722]]** is a valid, billable 6-character ICD-10-CM code for FY2025.  Structure: `H35` (**other retinal disorders**) + `.7` (**separation of retinal layers**) + `2` (**serous RPE detachment**) + `2` (**left eye**). No additional characters needed — this code is complete.

> [!warning] Non-Billable Parent Codes
> - ❌ `H35.72` — 5-character header — non-billable; missing laterality 
> - ❌ `H35.7` — 4-character header — non-billable; subcategory only

> [!danger] ⚠️ EXCLUDES 1 Alert — Critical Coding Trap
> **[[H35.722]]** carries an **Excludes 1** note at the H35.7 level that is one of the most commonly confused distinctions in retina coding: 
> - ❌ **H33.2x** — Serous retinal detachment — **CANNOT be coded with [[H35.722]]**
> - ❌ **H33.0x** — Rhegmatogenous retinal detachment — **CANNOT be coded with [[H35.722]]**
>
> These are **mutually exclusive** because they represent fluid in fundamentally different anatomical compartments. A serous **RPE** detachment ([[H35.722]]) is entirely different from a serous **retinal** detachment (H33.2x). See the clinical overview below for the anatomical distinction.

---

## 🔍 Code Description

**ICD-10 CM [[H35.722]]** classifies **serous detachment of the retinal pigment [[epithelium]] (RPE) in the left eye** — a condition in which fluid accumulates in the **sub-RPE space** (**between the RPE basal lamina and Bruch's membrane**), creating a dome-shaped elevation of the RPE layer that is visible on OCT and fundoscopy. 

**This condition** — commonly abbreviated **serous PED** (**pigment epithelial detachment**) — is a key finding in several retinal diseases, most notably **wet AMD**, **central serous [[chorioretinopathy]] (CSC)**, and idiopathic conditions. The clinical significance of a serous PED ranges from benign and self-resolving (**CSC-related**) to a harbinger of active CNV requiring anti-VEGF treatment (**AMD-related**). The etiology drives both the management and, critically, whether [[H35.722]] is the appropriate primary code or whether a more specific underlying disease code (**like [[H35.3221]] for wet AMD**) should take precedence.

## 🔬 Anatomy — Why the Compartment Matters

Understanding where the fluid is defines the ICD-10-CM code and determines clinical management:

```
ANATOMY OF THE OUTER RETINA (Inner to Outer)  
────────────────────────────────────────────  
NEUROSENSORY RETINA (photoreceptors, inner nuclear layer, etc.)  
│  
▼  
SUBRETINAL SPACE ←── Fluid here = Serous retinal detachment (H33.2x)  
│ (Excludes 1 with H35.722)  
▼  
RETINAL PIGMENT EPITHELIUM (RPE) — single cell layer  
│  
▼  
SUB-RPE SPACE ←── Fluid here = SEROUS PED (H35.722) ← THIS CODE  
│ RPE lifts off Bruch's membrane  
▼  
BRUCH'S MEMBRANE  
│  
▼  
CHORIOCAPILLARIS / D31.10|Choroidal nevus
	
```


> [!important] Sub-RPE Fluid vs. Subretinal Fluid — Not the Same
> On OCT, these appear at different levels and have different significance:
> - **Sub-RPE fluid** (between RPE and Bruch's) = **[[H35.722]]** — serous PED — fluid lifts the RPE dome upward
> - **Subretinal fluid (SRF)** (between photoreceptors and RPE) = **H33.2x** — serous retinal detachment
> - Both can coexist in wet AMD — but only one H35.7xx code can be used per the Excludes 1 instruction. When both are present in the context of wet AMD, the **wet AMD staging code** ([[H35.3221]] for active CNV) captures the complete picture.

## 📊 Types of PED — Coding and Clinical Decision Guide

Not all PEDs are created equal. The OCT and FA appearance determines the PED subtype, which drives both the correct ICD-10-CM code and the clinical management:

| PED Type | OCT Appearance | Primary Code | Clinical Context |
|---|---|---|---|
| **Serous (avascular) PED** | Smooth dome, homogeneous optically empty sub-RPE space | **[[H35.722]]** | Idiopathic, CSC-related, early AMD |
| **Drusenoid PED** | Undulating RPE elevation with hyperreflective contents | **[[H35.722]]** | Dry AMD — confluent drusen lifting RPE |
| **Fibrovascular PED** | Heterogeneous, irregular sub-RPE contents | Consider [[H35.3221]] | Wet AMD — CNV under RPE — active treatment |
| **Hemorrhagic PED** | Dense, hyperreflective sub-RPE material; blocks signal | **[[H35.732]]** | Wet AMD rupture, polypoidal choroidal vasculopathy |
| **Serous retinal detachment** | Fluid ABOVE RPE, between photoreceptors and RPE | **[[H33.2x]]** ⚠️ Excludes 1 | Different entity entirely |

> [!caution] Fibrovascular PED — H35.722 or H35.3221?
> This is the most clinically important coding decision in the serous vs. fibrovascular PED distinction. A **fibrovascular PED** contains CNV under the RPE — this is wet AMD territory. When the physician documents "fibrovascular PED" in the context of active wet AMD, the correct code is **[[H35.3221]]** (exudative AMD, left eye, active CNV) — the fibrovascular PED is part of the wet AMD complex.
>
> **[[H35.722]]** (serous RPE detachment) is appropriate when:
> - The PED is **avascular/serous** (no CNV on FA or OCT-A)
> - The PED is **drusenoid** (dry AMD context — no CNV)
> - The PED is idiopathic or CSC-related
> - The physician documents PED as a **distinct condition separate from wet AMD**
>
> When uncertain → query the physician to clarify whether the PED is serous/avascular or fibrovascular/neovascular.

## 📋 Clinical Overview — Serous RPE Detachment

### Etiologies and Their Coding Context

| Etiology | Prevalence | Code Primary Condition | H35.722 Role |
|---|---|---|---|
| **Wet AMD** (fibrovascular or serous PED from CNV) | Most common in elderly | [[H35.3221]] — active wet AMD | Additional Dx or subsumed in AMD code |
| **Dry AMD** (drusenoid PED) | Common in advanced dry AMD | [[H35.311x]]-[[H35.314x]] | Additional Dx if separately documented |
| **Central serous chorioretinopathy (CSC)** | Middle-aged males, stress, steroids | **[[H35.712]]** (CSC, left eye) — primary | H35.722 NOT used alongside CSC — CSC includes RPE changes |
| **Idiopathic serous PED** | No underlying disease identified | **[[H35.722]]** | PRIMARY code |
| **Polypoidal choroidal vasculopathy (PCV)** | Asian patients, subtype of wet AMD | [[H35.3221]] or [[H35.3222]] | Consider PED as part of PCV complex |
| **Drug-induced (corticosteroids)** | Iatrogenic — exogenous steroids → CSC-like | [[H35.712]] (CSC) or [[H35.722]] | Per physician documentation |

> [!important] CSC (H35.712) vs. Serous PED (H35.722) — Don't Double Code
> **Central serous chorioretinopathy ([[H35.712]])** frequently produces serous PEDs as part of its pathology. However, the CSC code encompasses the RPE changes — you should **not** code [[H35.722]] additionally when the serous PED is clearly the result of documented CSC. Use [[H35.712]] as the primary code when CSC is the diagnosis. Reserve [[H35.722]] for serous PED when CSC is NOT the documented etiology.

### OCT Features of Serous PED — What Drives the Code

The OCT report is the primary documentation source for [[H35.722]]. Key terms in the OCT or physician note that support this code:

| OCT/Clinical Language | Maps to H35.722? |
|---|---|
| "Serous PED, left eye" | ✅ YES — direct match |
| "Pigment epithelial detachment, serous, OS" | ✅ YES |
| "Avascular PED, left eye" | ✅ YES — avascular = serous |
| "Drusenoid PED, left eye" | ✅ YES — drusenoid is a subtype of serous PED |
| "Sub-RPE fluid, left eye" | ✅ YES — descriptive language for serous PED |
| "RPE elevation, serous, OS" | ✅ YES |
| "Fibrovascular PED, left eye" | ❌ NO — this is wet AMD territory → [[H35.3221]] |
| "Hemorrhagic PED, left eye" | ❌ NO → [[H35.732]] |
| "Serous retinal detachment, left eye" | ❌ NO → H33.22x (Excludes 1) |
| "CNV with PED, left eye" | ❌ NO → [[H35.3221]] (wet AMD with active CNV) |

### Clinical Significance by PED Size

| PED Diameter | Clinical Risk | Management Implication |
|---|---|---|
| Small (<1 disc diameter) | Low risk — likely stable | Observation; annual OCT |
| Medium (1-3 disc diameters) | Moderate — monitor closely | OCT every 3-6 months; FA if CNV suspected |
| Large (>3 disc diameters) | Higher risk — CNV and hemorrhage risk | FA/OCT-A to rule out CNV; consider treatment |
| Giant (>5 disc diameters) | High risk — tear risk, visual impairment | Close monitoring; avoid anti-VEGF if tear-prone |

> [!caution] RPE Tear Risk — Document and Code
> Large serous PEDs are at risk for **RPE tears** (rips) — when the RPE splits at the PED margin, creating a horseshoe-shaped RPE defect with dramatically reduced VA. An RPE tear changes the clinical picture significantly. If an RPE tear is documented:
> - The [[H35.722]] serous PED code may still apply for the original detachment
> - **[[H35.89]]** (Other specified retinal disorders) may be used for the RPE tear itself — query your coding supervisor or check the most current tabular, as a specific RPE tear code may exist in updated ICD-10-CM versions
> - Document the tear explicitly — it affects prognosis and management decisions

## 🛠️ CPT Codes — H35.722 Encounter Templates

### Template A: Diagnostic Evaluation of Serous PED (Outpatient)

| Type | Code | Description | Notes |
|---|---|---|---|
| **Exam** | [[92004]] or [[92014]] | Comprehensive ophthalmic exam | New or established |
| **OCT** | [[92134]] | Posterior segment OCT | Primary imaging tool — documents PED morphology, height, sub-RPE fluid |
| **FA** | [[92235]] | Fluorescein angiography | Characterize PED type — serous vs. fibrovascular; rule out CNV |
| **ICG** | [[92240]] | Indocyanine green angiography | Superior to FA for detecting occult CNV, polypoidal lesions beneath PED |
| **OCT-A** | [[92134]] + modifier | OCT angiography | Detect CNV flow signal within PED — increasingly standard |
| **Diagnosis** | [[H35.722]] | Serous RPE detachment, left eye | Primary diagnosis |

> [!tip] ICG Angiography Is the Gold Standard for PED Characterization
> Fluorescein angiography (FA) can miss occult CNV beneath a serous PED because the RPE elevation blocks visualization of the choroidal circulation. **Indocyanine green angiography (ICG/ICGA — [[92240]])** uses an infrared dye that penetrates the RPE, making it far superior for detecting polypoidal choroidal vasculopathy, occult CNV, and the vascular nature of the PED. When the clinical question is "is there CNV under this PED?" — ICG is the study of choice. Document the clinical rationale for ICG separately from FA to support both on the same date of service.

### Template B: Monitoring Visit — Stable Serous PED (Outpatient)

| Type | Code | Description |
|---|---|---|
| **Exam** | [[92014]] | Established comprehensive exam |
| **OCT** | [[92134]] | PED stability check — height, width, fluid |
| **Diagnosis** | [[H35.722]] | Primary — serous RPE detachment, left eye |

### Template C: Serous PED — Anti-VEGF Injection Given (Outpatient)

> [!important] When Is Anti-VEGF Indicated at H35.722?
> Anti-VEGF injection is **not routinely indicated** for a pure serous avascular PED. However, it IS indicated when:
> - **CNV is identified** within or adjacent to the PED → code shifts to [[H35.3221]] (active CNV wet AMD)
> - **Polypoidal choroidal vasculopathy** is identified → anti-VEGF + photodynamic therapy
> - The serous PED is part of an active **wet AMD** complex → [[H35.3221]] drives the injection
>
> If anti-VEGF ([[67028]][[-LT]] + J-code) is billed with [[H35.722]] as the sole diagnosis, payer scrutiny is likely — the medical necessity documentation must explicitly justify injection for serous PED specifically, not just AMD staging.

## 💊 Coding Scenarios

---

### Scenario 1 — Isolated Serous PED, No AMD (Outpatient)

> **Clinical Vignette:** A 52-year-old male presents with a 4-week history of mildly distorted central vision, left eye. VA: 20/30 OS. OCT OS: smooth dome-shaped elevation of RPE with optically empty sub-RPE space — consistent with avascular/serous PED. No subretinal fluid. FA: slow-filling hyperfluorescent pooling in the early phase — classic serous PED pattern, no CNV. ICG: no polypoidal lesions, no occult CNV. No drusen, no AMD. Impression: Idiopathic serous PED, left eye — likely spontaneous — observe.

**CPT / HCPCS:**
- [[92004]] — Comprehensive exam, new patient
- [[92134]] — OCT posterior segment *(PED characterization)*
- [[92235]] — Fluorescein angiography *(PED type — rule out CNV)*
- [[92240]] — Indocyanine green angiography *(occult CNV excluded)*

**ICD-10-CM:**
- [[H35.722]] — Serous detachment of RPE, left eye *(primary — idiopathic, no underlying AMD or CSC)*

> [!success] H35.722 as Standalone Primary Code — This Is the Clean Scenario
> When the serous PED is idiopathic with no AMD, no CSC, no CNV — [[H35.722]] is the correct and complete primary code. No additional AMD or CSC code is needed.

---

### Scenario 2 — Drusenoid PED in Dry AMD Context (Outpatient)

> **Clinical Vignette:** A 73-year-old female with known bilateral intermediate dry AMD presents for monitoring. OCT right eye: large confluent drusen with undulating RPE elevation — drusenoid PED present. OCT left eye: large drusen with dome-shaped drusenoid PED, avascular — no fluid above or below RPE, no CNV on OCT-A. FA: no active leak, no CNV. Impression: Intermediate dry AMD bilateral with drusenoid PED, left eye.

**ICD-10-CM:**
- [[H35.3132]] — Nonexudative AMD, bilateral, intermediate dry stage *(primary — AMD is the underlying disease)*
- [[H35.722]] — Serous detachment of RPE, left eye *(additional — drusenoid PED documented as distinct finding, left eye)*

> [!note] Drusenoid PED + Dry AMD — Code Both When Separately Documented
> When the physician explicitly documents **drusenoid PED** as a distinct finding alongside dry AMD, coding both is appropriate. The AMD code captures the disease; the PED code captures the specific structural finding. If the physician only mentions "AMD with large drusen" without specifically calling out the PED as a distinct entity, [[H35.722]] may not be necessary — the AMD code stands alone.

---

### Scenario 3 — Serous PED, CNV Found on ICG — Code Shifts (Outpatient)

> **Clinical Vignette:** A 69-year-old female returns for follow-up of known serous PED, left eye (previously coded [[H35.722]]). VA dropped from 20/40 to 20/80 since last visit. OCT: PED now larger with irregular internal reflectivity and new subretinal fluid adjacent to PED. ICG: occult CNV confirmed beneath PED. FA: late-phase staining consistent with occult wet AMD. Impression: Conversion to wet AMD, left eye — newly active CNV beneath serous PED.

**ICD-10-CM — Code Change:**
- **Retire [[H35.722]]** for this eye for now — CNV is now active
- **[[H35.3221]]** — Exudative AMD, left eye, active CNV *(CNV now confirmed — this is the primary wet AMD code going forward)*

**CPT / HCPCS:**
- [[92014]] — Established comprehensive exam
- [[92134]] — OCT *(new SRF and PED enlargement)*
- [[92235]] — FA *(occult CNV confirmation)*
- [[92240]] — ICG *(CNV beneath PED — gold standard confirmation)*
- [[67028]][[-LT]] — Intravitreal injection *(anti-VEGF initiated)*
- J-code — Anti-VEGF agent per drug administered

> [!danger] PED Enlargement or New Fluid = CNV Conversion = Code Change
> When a previously stable serous PED ([[H35.722]]) develops new subretinal fluid, irregular internal contents, or confirmed CNV on FA/ICG/OCT-A — the diagnosis has converted to **wet AMD with active CNV** ([[H35.3221]]). **[[H35.722]] should not be carried forward once active CNV is confirmed** — this is the same principle as the [[H35.3222]] → [[H35.3221]] conversion discussed in the wet AMD notes. The PED that triggered the original diagnosis has now evolved into active neovascular disease.

---

### Scenario 4 — H35.722 Differentiated from H33.22x (Outpatient)

> **Clinical Vignette:** Two patients present on the same day. Coder must assign codes.
>
> **Patient A:** OCT shows fluid between RPE and Bruch's membrane — smooth dome-shaped RPE elevation. No retinal break. No fluid above RPE. Physician documents: "Serous PED, left eye."
>
> **Patient B:** OCT shows fluid between photoreceptors and RPE — RPE is in normal position. No retinal break. Physician documents: "Serous detachment of the retina, left eye."

| Patient | Correct Code | Why |
|---|---|---|
| **Patient A** | **[[H35.722]]** | Fluid BELOW RPE (sub-RPE) = serous RPE detachment |
| **Patient B** | **H33.22x** | Fluid ABOVE RPE (subretinal) = serous retinal detachment |

> [!danger] These Two Codes Are Excludes 1 — They Cannot Be Used Together
> The anatomical distinction drives mutually exclusive coding. **Never assign [[H35.722]] and H33.2x simultaneously** for the same eye — the Excludes 1 instruction prohibits it, and more importantly, they represent fluid in fundamentally different compartments. If both are present (which can occur in wet AMD with both subretinal AND sub-RPE fluid), the **wet AMD staging code** ([[H35.3221]]) captures the full picture, and neither H35.722 nor H33.2x is assigned separately.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never confuse serous RPE detachment (H35.722) with serous RETINAL detachment (H33.22x)** — Excludes 1 — mutually exclusive; different anatomical compartments [web:185] |
| ❌ | **Never code H35.722 when fibrovascular PED is documented** — fibrovascular = CNV = wet AMD = [[H35.3221]] |
| ❌ | **Never code H35.722 alongside H35.712 (CSC) for the same eye** — CSC encompasses RPE changes; don't double-code |
| ❌ | **Never carry H35.722 forward when CNV is confirmed** — once active CNV is documented, transition to [[H35.3221]] |
| ❌ | **Never use H35.722 for hemorrhagic PED** — blood under RPE = [[H35.732]], not [[H35.722]] |
| ✅ | **H35.722 = serous or drusenoid PED without CNV** — fluid under RPE, optically empty or drusenoid, no neovascularization |
| ✅ | **ICG angiography ([[92240]])** is the gold standard for distinguishing serous from fibrovascular PED — bill it when clinically performed; document the rationale |
| ✅ | **Drusenoid PED + dry AMD** → code both [[H35.31xx]] (AMD stage) + [[H35.722]] when separately documented |
| ✅ | **Serous PED + wet AMD complex** → [[H35.3221]] is primary; [[H35.722]] may be additional if separately documented by physician |
| ✅ | **Idiopathic serous PED** (no AMD, no CSC) → [[H35.722]] stands alone as primary code |
| ✅ | **PED enlargement, new SRF, or CNV on OCT/ICG** → immediately re-evaluate: does this belong under [[H35.3221]] now? |
| ✅ | **Right-eye equivalent**: [[H35.721]]; **bilateral**: [[H35.723]] |

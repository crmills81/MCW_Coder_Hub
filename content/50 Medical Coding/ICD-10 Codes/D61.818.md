# 🧬 ICD-10 CM D61.818 — Other Pancytopenia

> [!success] Billable Code Confirmed  
> **ICD-10 CM [[D61.818]]** is a **7-character code**: **D61** (category), **.8** (other specified), **1** (**[[pancytopenia]]**), **8** (other). It is the final level of the **D61.81** branch and is valid for claims in **FY2026**.<sup>1</sup>

> [!warning] Non-Billable Parent Codes  
> **D61.81** (**[[Pancytopenia]]**) is a header and needs a **6th** character. **D61.8** and **D61** are also non-billable headers, so none of them can be reported alone.<sup>1</sup>

> [!important] Clinical Context  
> Use **[[D61.818]]** when all three cell lines are low and the provider has not tied it to **[[chemotherapy]]**, another **drug, marrow infiltration, aplastic anemia**, **MDS** or another **Excludes1 condition**.<sup>1</sup>

> [!danger] Code Classification  
> This is an **ICD-10-CM diagnosis code (Chapter 3)**. It is not a procedure code and not a **manifestation-only code**, so it can be sequenced first.

---

## 🔍 Code Description  
**[[Pancytopenia]]** is a **concurrent reduction in red cells, white cells and platelets, so the patient has [[anemia]], [[leukopenia]] and [[thrombocytopenia]] together**. **[[D61.818]]** captures it when the cause is not specified or does not fit a more specific code, such as **[[D61.810]]** (**antineoplastic chemotherapy induced**) or **[[D61.811]]** (**other drug-induced**).<sup>1</sup><sup>4</sup> Causes can include **[[infection]], [[autoimmune]] disease, nutritional deficiency, [[hypersplenism]] and toxin exposure**, but the code applies only when the provider has not linked it to an **Excludes1 condition**.

The workup typically includes a **CBC** with **differential, smear review, B12/folate**, and often a **bone marrow biopsy** and **aspiration** (**[[38222]]**) to look for **MDS, [[leukemia]] or [[aplasia]]**.<sup>5</sup> If the workup shows **aplastic anemia**, assign **[[D61.9]]** instead. If it shows **marrow infiltration**, assign **[[D61.82]]**. In **inpatient profee**, reassess the code once the diagnostic results are back.

> [!example] Specificity: Cause Drives the Code  
> Always query for **chemo or drug causation** before settling on **[[D61.818]]**. **[[D61.810]]** and **[[D61.811]]** carry the adverse-effect/T-code logic that **[[D61.818]]** does not.

> [!tip]  
> If the documentation says only "**[[pancytopenia]]**," default to **[[D61.818]]**. If the provider documents "**pancytopenia due to chemo**," do not stop at **[[D61.818]]**, because the higher-specificity code is required.

## ✅ Includes  
- **[[Pancytopenia]] NOS:** the index default for "**[[Pancytopenia]]** (**acquired**)" lands on **[[D61.818]]**.<sup>1</sup>
- **Acquired [[pancytopenia]], cause unspecified:** reported here when no Excludes1 condition is documented.
- **Pancytopenia with a cause that has no specific code:** for example, infection or nutritional deficiency, where the underlying condition is coded additionally.

---

## ❌ Excludes  

### Excludes 1  
- **[[D61.9]]** **Aplastic anemia**: **[[pancytopenia]]** due to aplastic anemia is reported with aplastic anemia only.<sup>1</sup>
- **[[D61.82]]** **[[Myelophthisis]]**: **[[pancytopenia]]** from marrow infiltration or leukoerythroblastic anemia goes here instead.
- **[[D61.01]]** **Congenital pure red cell [[aplasia]]**: the congenital process takes precedence.
- **C91.4-** **Hairy cell leukemia**, **[[B20]]** HIV disease and **[[D47.1]]** Myeloproliferative disease: the underlying disease is coded and **[[D61.818]]** is not added.

> [!danger]  
> The most common error is coding **[[D61.818]]** with **[[B20]]** or a myeloproliferative disease just because the **CBC** shows three low lines. The **Excludes1 note** applies unless the provider states the two conditions are unrelated.

### Excludes 2  
- **D46.-** **Myelodysplastic syndromes**: **[[pancytopenia]]** with MDS is not excluded by Excludes2, so both can be reported when documented, with the MDS code sequenced per circumstances of admission.<sup>1</sup>
- **D70.-** **[[Neutropenia]]**: an **Excludes2** at the D61 category level, so a separately documented neutropenia can be reported alongside it when it is not already captured in the pancytopenia.

## 📋 Clinical Overview  

### Unspecified Pancytopenia vs Cause-Specific Pancytopenia  
The main coding decision is whether the cause is documented. **[[D61.818]]** is the default only when it isn't. Once **chemo, a drug**, **marrow infiltration** or **[[aplasia]]** is documented, a more specific code takes over.

| **Feature** | **[[D61.818]]** | **Related [[D61.810]]** | **Related [[D61.82]]** |
|---|---|---|---|
| **Cause** | Not specified or other cause. | Antineoplastic chemotherapy. | Marrow infiltration or leukoerythroblastic anemia. |
| **Extra coding** | Code the underlying condition if known. | Add the T45.1X5- adverse-effect code. | Code the infiltrating process (for example, a neoplasm). |
| **Principal Dx use** | Yes. Groups to DRG 808-810.<sup>2</sup> | Yes, often with the chemo encounter logic. | Yes, based on the circumstances of admission. |

> [!important]  
> **CDI trigger**: **[[pancytopenia]]** on labs with no documented cause, or with a new **drug or chemo in the medication list**. Query for etiology and for clinical significance, and check whether the provider evaluated or monitored it.

### Manifestations & Symptom Burden  
- **Anemia symptoms:** fatigue, pallor and **[[dyspnea]]** from low hemoglobin.
- **Infection risk:** fever and recurrent infections from **[[leukopenia]]** or **[[neutropenia]]**.
- **Bleeding:** petechiae, bruising and mucosal bleeding from **[[thrombocytopenia]]**.
- **Workup findings:** low counts on CBC, possible hypocellular or abnormal marrow on biopsy.

> [!tip]  
> **Symptoms integral to pancytopenia are not coded separately**, but a documented complication such as febrile neutropenia or active bleeding may be.

## 🏥 MS-DRG Assignment  

| **Field** | **Value** |
|---|---|
| **MDC** | MDC 16 |
| **DRG with MCC** | **808** — Major Hematological and Immunological Dx Except Sickle Cell Crisis and Coagulation Disorders with MCC |
| **DRG with CC** | **809** — same title with CC |
| **DRG without CC/MCC** | **810** — same title without CC/MCC |
| **Dx role** | Principal diagnosis (groups to 808-810)<sup>2</sup> |

When **[[D61.818]]** is the principal diagnosis, severity comes from the secondary diagnoses (**MCC for 808, CC for 809, neither for 810**). As a secondary diagnosis, it appears on the **CMS Appendix C list**, so it is a **CC** whose effect can be excluded depending on the principal diagnosis.<sup>2</sup> Sequence it first only when it is the reason for admission after study.

NCD/LCD:
- No **NCD** or **LCD** with a diagnosis-specific coverage restriction for **[[D61.818]]** was found.
- **NCD 110.23** (**Stem Cell Transplantation**) is relevant to **aplastic anemia** and marrow failure work, but it is not triggered by **[[D61.818]]** alone.<sup>5</sup>
- Check your **MAC's** lab and bone marrow **LCDs** for **CBC** (**[[85025]]**) and bone marrow (**[[38222]]**) coverage language, plus **NCD 190.15** (Blood Counts), before claim submission.

### NCCI Bundling Considerations  
Do **not** report **[[38220]]** or **[[38221]]** with **[[38222]]**. **Marrow interpretation** (**[[88305]]**) is reported by the pathologist and is not bundled into the collection code. Confirm current edits in the **NCCI tables** before using modifier **[[-59]]**.

## 💊 Coding Scenarios and Examples  

### Example 1
> **Clinical Scenario:**  
> A 68-year-old is admitted with fatigue and bruising. CBC shows low hemoglobin, WBC and platelets. The workup is negative for infiltration, MDS and drug cause, and the provider documents "pancytopenia, etiology unclear."

| Field | Code | Rationale |
|---|---|---|
| CPT | [[85025]] | CBC with differential to document the cytopenias. |
| PDx | [[D61.818]] | Pancytopenia of unspecified cause. |

> [!tip]  
> It is the reason for admission after study, so sequence it first. If a bone marrow biopsy later shows a cause, update the code.

### Example 2
> **Clinical Scenario:**  
> A 72-year-old with unexplained pancytopenia has a bone marrow biopsy and aspiration at the same session. Pathology shows a normocellular marrow without malignancy.

| Field | Code | Rationale |
|---|---|---|
| CPT | [[38222]] | Biopsy and aspiration at the same session. |
| CPT 2 | [[88305]] | Pathologist's interpretation (reported by pathology). |
| PDx | [[D61.818]] | No specific cause was found. |

> [!tip]  
> Report [[38222]] and not [[38220]] with [[38221]]. CDI: query whether the provider is documenting a clinical significance and plan for the pancytopenia.

### Example 3
> **Clinical Scenario:**  
> A patient on carboplatin has pancytopenia. The provider documents "pancytopenia due to chemotherapy."

| Field | Code | Rationale |
|---|---|---|
| CPT | [[85025]] | CBC to monitor counts. |
| PDx | [[D61.810]] | Chemo cause is documented, so [[D61.818]] is not used. |

> [!tip]  
> Add the adverse-effect T-code for the drug. CDI: always query for cause before assigning **[[D61.818]]**.

## ⚠️ Coding Pitfalls and Tips  
- **Pitfall 1**: Assigning **[[D61.818]]** when **chemo or drug causation** is documented; **Tips**: Use **[[D61.810]]** or **[[D61.811]]** instead.
- **Pitfall 2**: Coding with an **Excludes1 condition** such as **[[D47.1]]** or **[[B20]]**; **Tips**: Report only the underlying condition unless the provider says the two are unrelated.
- **Pitfall 3**: Coding **[[pancytopenia]]** from the lab values alone; **Tips**: The provider must document the diagnosis, and a query is needed otherwise.
- **Pitfall 4**: Adding separate **[[anemia]], [[leukopenia]] and [[thrombocytopenia]] codes** on top of **[[pancytopenia]]**; **Tips**: **[[Pancytopenia]]** includes all three, so do not unbundle them.
- **Pitfall 5**: Missing the **DRG shift** from **811/812** (**[[anemia]]**) to **808-810** when **[[D61.818]]** is principal; **Tips**: Check your grouper after any principal diagnosis change.
- **Pitfall 6**: Reporting **[[38220]]** or **[[38221]]** with **[[38222]]**; **Tips**: Use **[[38222]]** when both are performed in the same session.<sup>5</sup>

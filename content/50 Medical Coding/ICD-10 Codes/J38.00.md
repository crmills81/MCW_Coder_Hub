# 🧬 ICD-10-CM J38.00 — Paralysis of Vocal Cords and Larynx, Unspecified

> [!success] Billable Code Confirmed
>
> **ICD-10-CM [[J38.00]]** is a valid, billable **5-character ICD-10-CM code** for FY2026. The structure is: `J38` (**category** — diseases of vocal cords and larynx) + `.0` (**subcategory** — paralysis) + `0` (**5th character** — unspecified laterality). No 6th or 7th character extension is required or exists for this code.

> [!warning] Non-Billable Parent Code — Never Submit This
>
> - ❌ `J38.0` — 4-character header — missing the laterality/specificity 5th character
>
>   Always submit **[[J38.00]]**, **[[J38.01]]**, or **[[J38.02]]** (all 5 characters). If the documentation specifies unilateral or bilateral involvement, a more specific code is required and must be used over [[J38.00]].

> [!important] Clinical Context: "Unspecified" vs. Laterality-Specific Codes
>
> **ICD-10-CM [[J38.00]]** is appropriate **only** when the medical record does not specify whether the paralysis is unilateral or bilateral. In most real-world clinical documentation, laterality is established via laryngoscopy, so [[J38.01]] (unilateral) or [[J38.02]] (bilateral) is almost always the more accurate selection. Use [[J38.00]] when laterality is genuinely undocumented or when the encounter represents initial evaluation prior to diagnostic workup confirming laterality.

## 🔍 Code Description

**ICD-10-CM [[J38.00]]** classifies a condition in which the neuromuscular function of one or both vocal cords is impaired or absent, without specification of whether one or both cords are affected. The larynx is rendered unable to perform its normal functions of phonation, airway protection, and respiration.

Vocal cord paralysis results from disruption of the neural pathway controlling laryngeal movement — most critically the **recurrent laryngeal nerve (RLN)**, a branch of the vagus nerve (CN X). Common etiologies include:

- Post-surgical injury ([[thyroidectomy]], anterior cervical discectomy, cardiothoracic surgery)
- Malignancy compressing the RLN (l**ung apex tumors, thyroid cancer, mediastinal masses**)
- Viral neuritis (**idiopathic/post-viral, similar mechanism to Bell's palsy**)
- Neurological disorders (**Parkinson's disease, multiple sclerosis, ALS**)
- Intracranial pathology (**brainstem lesion, skull base tumor**)
- Aortic arch [[aneurysm]] (**Ortner's syndrome / cardiovocal syndrome**)

> [!note]
> The clinical consequences of vocal cord paralysis range from dysphonia and aspiration risk (**unilateral**) to life-threatening airway compromise requiring emergency [[tracheostomy]] (**bilateral**). The "unspecified" code **J38.00** should prompt a CDI query if laterality is not clearly documented, as unilateral vs. bilateral paralysis carries vastly different clinical management and reimbursement implications.

## ✅ Includes

The following clinical terms and scenarios appropriately map to **[[J38.00]]** when laterality is unspecified:

- [[Laryngoplegia]], NOS (**laterality undocumented**)
- Paralysis of the [[glottis]], unspecified
- Vocal cord [[paresis]] (**complete or partial**), unspecified side
- Acquired vocal cord palsy, unspecified laterality
- Laryngeal nerve paralysis, unspecified

## ❌ Excludes

### Excludes1 — Cannot be coded together (mutually exclusive; different condition)

The `Excludes1` instruction means these conditions **cannot** be submitted simultaneously with **[[J38.00]]**, as they represent distinct, non-overlapping diagnoses:

- Congenital laryngeal [[stridor]] (**[[P28.89]]**) — A congenital, not acquired, laryngeal condition
- Obstructive [[laryngitis]], acute (**[[J05.0]]**) — Inflammatory, not paralytic etiology
- Postprocedural subglottic stenosis (**J95.5**) — Structural [[stenosis]], not paralysis
- Stridor (**[[R06.1]]**) — Symptom code; if the underlying cause is confirmed vocal cord paralysis, use the etiology code instead
- Ulcerative laryngitis (**[[J04.0]]**) — Infectious/inflammatory process, distinct from paralysis

### Excludes2 — May be coded together when both conditions are present

- **[[Dysphagia]] (R13.1-)** — A direct functional consequence of VCP; code additionally when documented and clinically managed
- **Aspiration [[pneumonia]] (J69.0)** — Frequent complication of VCP; always code if documented
- **Spasmodic dysphonia / laryngeal dystonia** — If [[dystonia]] is documented as a separate concurrent condition, it may be reported additionally

## 💊 Coding Scenarios

### Scenario 1 — Initial ENT Office Evaluation with Flexible Laryngoscopy

> **Clinical Vignette:** A 58-year-old male presents to an ENT clinic with a 3-week history of progressive hoarseness following a recent anterior cervical discectomy and fusion (ACDF) at C5-C6. The surgeon performed a flexible fiberoptic laryngoscopy in the office, noting that the left vocal cord is immobile and sitting in the paramedian position. The right cord abducts and adducts normally. Voice stroboscopy demonstrates absent vibratory wave on the left. Laterality is clearly documented as unilateral left-sided VCP.

**CPT:**
- [[31575]] — Laryngoscopy, flexible; diagnostic _(office-based; note: if stroboscopy was performed and documented separately, [[92520]] may also apply)_

**ICD-10-CM:**
- [[J38.01]] — Paralysis of vocal cords and larynx, **unilateral** _(NOT [[J38.00]] — laterality is clearly documented as left-sided; use the more specific code)_
- [[M43.22]] — Fusion of spine, cervical region _(history of ACDF as the precipitating surgical cause)_

> [!tip] CDI Opportunity
> This scenario illustrates why [[J38.00]] should rarely reach final coding. Once the laryngoscopy is performed, laterality is documented. Always query the attending or review the laryngoscopy report to assign [[J38.01]] or [[J38.02]] instead of defaulting to [[J38.00]].

---

### Scenario 2 — Emergency Department: Acute Bilateral VCP with Airway Compromise

> **Clinical Vignette:** A 44-year-old female presents to the ED in acute respiratory distress with inspiratory stridor and voice changes 72 hours after a total thyroidectomy for multinodular goiter. She is in tripod position and SpO2 is 88% on room air. Direct laryngoscopy by ENT reveals bilateral vocal cord immobility with both cords fixed near midline. She is emergently intubated and subsequently undergoes tracheostomy.

**CPT:**
- [[99285]] — Emergency department visit, high medical complexity
- [[31600]] — Tracheostomy, planned (separate surgical procedure)

**ICD-10-CM:**
- [[J38.02]] — Paralysis of vocal cords and larynx, **bilateral** _(documented bilateral by laryngoscopy — again, NOT [[J38.00]])_
- [[E89.0]] — Postprocedural hypothyroidism _(sequela of total thyroidectomy)_
- [[J95.00]] — Unspecified tracheostomy disorder _(post-procedural respiratory complication)_

---

### Scenario 3 — Appropriate Use of J38.00: Telehealth Encounter Pre-Workup

> **Clinical Vignette:** A 67-year-old male calls into a telehealth ENT consultation reporting a breathy, weak voice for the past 2 weeks following a recent URI. The provider documents vocal cord paralysis as a working diagnosis pending in-person laryngoscopy. No physical exam has been performed. Laterality cannot be determined at this encounter.

**CPT:**
- [[99213]] — Office/outpatient visit, established patient, moderate complexity _(or appropriate telehealth E&M modifier)_

**ICD-10-CM:**
- [[J38.00]] — Paralysis of vocal cords and larynx, **unspecified** ✅ _(Correct and appropriate — laterality genuinely cannot be determined without laryngoscopy; accurately reflects current state of clinical knowledge at this encounter)_
- [[R49.0]] — Dysphonia _(additional symptom code, if separately documented and managed)_

> [!note]
> This is one of the few scenarios where [[J38.00]] is the **correct** final code — when the encounter truly precedes the diagnostic workup. Document a follow-up plan for laryngoscopy to capture the laterality-specific code at the next encounter.

## ⚠️ Coding Pitfalls and Tips

| | **Pitfall or Tip** |
|---|---|
| ❌ | **Do not default to [[J38.00]] if a laryngoscopy report exists:** Once flexible laryngoscopy has been performed and laterality is documented, you must use [[J38.01]] (unilateral) or [[J38.02]] (bilateral). [[J38.00]] at that point represents undercoding. |
| ❌ | **Do not use [[J38.00]] for congenital laryngeal conditions:** Congenital laryngeal stridor is classified to **P28.89** (Excludes1 under J38). Paralysis in a neonate goes to the appropriate congenital/perinatal code, not J38.xx. |
| ❌ | **Do not separately code stridor ([[R06.1]]) when VCP is confirmed:** Per ICD-10-CM guidelines, code the confirmed etiology rather than the symptom integral to it. R06.1 is an Excludes1 under J38. |
| ✅ | **Always code the etiology when known:** VCP is rarely idiopathic. If documentation supports a cause — malignancy, surgical injury, neurological disease — code the etiology as an additional diagnosis (or as PDx if that condition drove the admission). |
| ✅ | **Modifier [[-50]] for bilateral injections:** When therapeutic vocal cord injection ([[31574]], [[31570]]) is performed bilaterally at the same session, append modifier [[-50]] per payer guidelines and verify bilateral payment adjustment rules. |
| ✅ | **[[J38.00]] is a CDI trigger code every time:** A simple laterality query converts it to [[J38.01]] or [[J38.02]], better capturing clinical severity and improving documentation integrity. |
| ✅ | **Watch for associated aspiration pneumonia:** VCP is a major aspiration risk factor. If **[[J69.0]]** (Aspiration pneumonia) is documented, report it as an additional diagnosis — it is a CC under MS-DRG grouping and will impact reimbursement. |

# 👁️ ICD-10 CM H02.053 — Trichiasis Without Entropion, Right Eye, Unspecified Eyelid

> [!success] Billable Code — Valid But Not First Choice
> **ICD-10-CM [[H02.053]]** is a valid, billable, 6-character ICD-10-CM code for FY2026. It classifies **trichiasis** without entropion of the right eye when the **specific eyelid (upper vs. lower) is not documented**. The code is technically correct when lid specificity is genuinely absent from documentation — but it should never be your default. Always pursue [[H02.051]] (**right upper**) or [[H02.052]] (**right lower**) first.

> [!warning] Non-Billable Parent Codes
> - ❌ `H02.05` — 5-character header — missing laterality/lid character
> - ❌ `H02.0` — 4-character header — non-billable, no specificity
> Do not confuse the non-billable header H02.05 with the billable [[H02.053]] — one extra character makes all the difference.

> [!danger] ⚠️ Query Before You Code This — Lid Specificity Is Almost Always Available
> **ICD-10 CM [[H02.053]]** exists for situations where lid specificity is **genuinely unavailable after a query attempt**. In the real world, the ophthalmologist's slit lamp exam note almost always states which lid is affected — "**right upper**," "**right lower,**" or at minimum describes corneal staining location (**inferior = lower lid; superior = upper lid**). Before assigning [[H02.053]], ask yourself:
> - Does the slit lamp exam describe upper or lower lid involvement?
> - Does the corneal staining pattern (**inferior vs. superior SPK**) suggest a specific lid?
> - Can you query the provider for clarification?
> If yes to any of the above — **do not use [[H02.053]]**. Use [[H02.051]] or [[H02.052]] instead.

## 🔍 Code Description

**ICD-10-CM [[H02.053]]** classifies **trichiasis without entropion of the right eye** when documentation confirms right-eye involvement but does not distinguish whether the affected lashes originate from the **right upper eyelid** ([[H02.051]]) or the **right lower eyelid** ([[H02.052]]). The clinical picture is the same as its lid-specific siblings — misdirected right-eye lashes abrading the corneal or conjunctival surface with the eyelid margin in a normal anatomic position — but with insufficient documentation to determine which lid is the source.

This code is most appropriately assigned when a query has been attempted and the provider cannot specify the lid, or in circumstances where a retrospective coding query is not possible. It may also appear in emergency department or urgent care documentation where a non-ophthalmologist notes "**trichiasis** right eye" without a formal slit lamp lid-specific exam. As a CIC-trained inpatient profee coder, you will recognize this as a documentation integrity issue worth flagging for provider education — specificity at the lid level is achievable in virtually every **trichiasis** case and should be standard in ophthalmology documentation.

### The H02.05x Specificity Ladder — Right Eye

| Code | Specificity Level | Use When |
|---|---|---|
| [[H02.051]] | Right upper eyelid ✅ Most specific | Documentation states upper lid OR superior SPK present |
| [[H02.052]] | Right lower eyelid ✅ Most specific | Documentation states lower lid OR inferior SPK present |
| **[[H02.053]]** | Right eye, unspecified ⚠️ Less specific | Lid not documented AND query failed or not possible |
| [[H02.059]] | Unspecified eye ❌ Least specific | Never acceptable when laterality is known — avoid |

> [!tip] The Corneal Staining Pattern Is Your Clinical Query Tool
> Even when the physician writes only "**trichiasis** right eye," the slit lamp exam often contains the answer. **Inferior SPK / inferior PEE** = lower lid source → [[H02.052]]. **Superior SPK / superior PEE** = upper lid source → [[H02.051]]. If the provider documents corneal staining and you can logically infer the lid source, include that reasoning in your query. A well-crafted query referencing the documented staining pattern will almost always yield lid specificity — and [[H02.053]] becomes unnecessary.

## 📋 Clinical Overview

### When [[H02.053]] Is Legitimately Appropriate

There are genuine clinical scenarios where lid specificity may not be documented:

| Scenario | Why Lid May Be Unspecified | Coding Guidance |
|---|---|---|
| **ED / urgent care visit** | Non-ophthalmologist removes a lash without slit lamp — "**trichiasis** right eye" | [[H02.053]] may be appropriate; consider CDI flag for future ophthalmology follow-up documentation |
| **Telemedicine triage visit** | No slit lamp exam; external photo only — lid not definitively identified | [[H02.053]] after failed query |
| **Brief consult note** | Ophthalmologist called to bedside inpatient — limited exam documentation | Query first; if no response, [[H02.053]] |
| **Retrospective coding** | Provider no longer available for query; documentation only says "right eye **trichiasis**" | [[H02.053]] as last resort |
| **Multiple lashes across multiple lids** | Provider documents both lids involved but refers to them together as "right eye **trichiasis**" | Query to clarify — likely both [[H02.051]] AND [[H02.052]] are appropriate together |

> [!caution] "Right Eye Trichiasis" In an Ophthalmology Note Almost Always Has More Specificity Somewhere
> Ophthalmologists perform slit lamp biomicroscopy at virtually every encounter — and slit lamp documentation routinely includes lid margin status. Before assigning [[H02.053]] on an ophthalmology note, check:
> - The slit lamp section of the exam
> - The assessment/plan ("right upper lid lash touching cornea")
> - The procedure note (forceps epilation of right upper/lower eyelid)
> - The technician's chief complaint transcription ("lash in right upper eye")
> The specificity is almost always buried somewhere in the note.

### Trichiasis Without Entropion — Core Clinical Concepts

The clinical picture for [[H02.053]] is identical to [[H02.051]] and [[H02.052]] — the only difference is the unknown lid source:

| Feature | Description |
|---|---|
| **Lash direction** | Inward — toward cornea/conjunctiva |
| **Lid margin position** | Normal — "without entropion" is the essential qualifier |
| **Corneal impact** | Mechanical epithelial abrasion with each blink |
| **Key symptoms** | Foreign body sensation, tearing, photophobia, conjunctival injection |
| **Primary treatment** | Epilation (forceps or other — [[67820]]/[[67825]]) |
| **Recurrence** | Common — lashes regrow, usually more coarse; ablative methods (cryo, laser) have better long-term outcomes |

### Trichiasis vs. Entropion — Still Critical Here

Even when the lid is unspecified, the "without entropion" qualifier still applies and must still be supported:

| Condition | Lid Margin | Code |
|---|---|---|
| **Trichiasis** w/o entropion, right eye | Normal | **[[H02.053]]** (unspecified lid) |
| **Trichiasis** w/o entropion, right upper | Normal | [[H02.051]] (preferred) |
| **Trichiasis** w/o entropion, right lower | Normal | [[H02.052]] (preferred) |
| Entropion, right eye (any type) | Inverted inward | H02.00x-H02.03x range |

> [!important] The "Without Entropion" Qualifier Must Still Be Supported
> [[H02.053]] still carries the same Excludes1 and clinical qualifier as [[H02.051]] and [[H02.052]] — the lid margin must be documented as being in a **normal position**. If the documentation is so sparse that you cannot confirm the lid is not inverted, a query is doubly warranted — both for lid specificity AND to confirm the absence of entropion.

## 🛠️ CPT / HCPCS — Treatment Procedures Linked to [[H02.053]]

### Epilation Codes — Right Eye, Lid Unspecified

| CPT | Description | Modifier(s) | Notes |
|---|---|---|---|
| **[[67820]]** | Correction of **trichiasis**; epilation by **forceps only** | **-RT** (right eye) | No per-lid E-modifier applicable when lid is unspecified on the claim |
| **[[67825]]** | Correction of **trichiasis**; epilation by **other than forceps** | **-RT** (right eye) | Electrosurgery, cryotherapy, laser, radiofrequency |

> [!note] No Per-Lid Modifier When Lid Is Unspecified
> When the diagnosis is [[H02.053]] (right eye, unspecified lid), you cannot accurately apply a per-lid modifier (-E3 for right upper or -E4 for right lower) because the lid source is unknown. Use **-RT** (right eye) only. This is another reason why [[H02.053]] is less desirable than [[H02.051]] or [[H02.052]] — the per-lid modifier is lost, which can affect payer adjudication for practices that bill per lid.

### Evaluation and Management

| CPT | Description | When to Use |
|---|---|---|
| **[[92004]]** | Comprehensive ophthalmologic exam — new patient | New patient with right eye **trichiasis**, lid unspecified |
| **[[92014]]** | Comprehensive ophthalmologic exam — established patient | Follow-up **trichiasis** visit |
| **[[92012]]** | Intermediate ophthalmologic exam — established patient | Brief lash check visit |

## 💊 Coding Scenarios

---

### Scenario 1 — Emergency Department Trichiasis Removal, Lid Not Specified

> **Clinical Vignette:** A 58-year-old male presents to the ED with sudden right eye pain and foreign body sensation. ED physician (not ophthalmologist) performs slit lamp exam: notes "misdirected eyelash touching cornea, right eye" — does not specify upper or lower lid. Removes lash with forceps. No eversion of lids documented. Patient discharged with lubricating drops.

**CPT / HCPCS:**
- [[67820]]-RT — Epilation by forceps, right eye *(no per-lid modifier — lid unspecified)*

**ICD-10-CM:**
- **[[H02.053]]** — **Trichiasis** without entropion, right eye, unspecified eyelid *(lid not documented — appropriate use here; ED provider, no slit lamp lid specificity)*

> [!note] Appropriate Use of [[H02.053]] — ED Context
> This is a legitimate use case. The ED provider's documentation says "right eye" only — no ophthalmologist performed a formal slit lamp lid exam. A query to the ED physician is unlikely to yield meaningful additional specificity. [[H02.053]] is the correct code here and does not reflect a coding error.

---

### Scenario 2 — Ophthalmology Note With Lid Specificity Hidden in the Slit Lamp Section

> **Clinical Vignette:** Assessment reads: "**Trichiasis** right eye — epilation performed." At first glance this looks like [[H02.053]] territory. However, the slit lamp section reads: "right lower lid — one lash misdirected, inferior corneal contact noted" and the procedure note reads: "forceps epilation of one lash, right lower eyelid."

**Correct Coding:**
- This is **NOT** a [[H02.053]] case — the lid specificity is present in the slit lamp and procedure note
- Correct code: **[[H02.052]]** — **Trichiasis** without entropion, right lower eyelid
- CPT: [[67820]]-RT *(or -E4)* — Epilation by forceps, right lower eyelid

> [!danger] Always Read the Full Note Before Assigning [[H02.053]]
> This scenario is the most common [[H02.053]] overcoding error. The assessment line says "right eye" — but the slit lamp and procedure sections clearly identify the lower lid. [[H02.053]] would be an undercoding error here. Read the **entire note** — not just the assessment — before defaulting to the unspecified lid code.

---

### Scenario 3 — Both Lids Documented, Provider Writes "Right Eye Trichiasis" in the Assessment

> **Clinical Vignette:** A 70-year-old male. Assessment reads: "Recurrent **trichiasis** right eye." Slit lamp reads: "right upper and right lower eyelid — multiple misdirected lashes bilaterally on right eye lids — superior and inferior SPK OD on fluorescein." Epilation by forceps performed both upper and lower right eyelids.

**Correct Coding:**
- This is **NOT** a [[H02.053]] case — both lids are documented in the slit lamp
- Correct codes: **[[H02.051]]** (right upper) + **[[H02.052]]** (right lower)
- CPT: [[67820]][[-E3]] + [[67820]][[-51]][[-E4]] *(per-lid payers)* — or [[67820]][[-RT]] *(per-eye payers)*

> [!tip] "Right Eye Trichiasis" in the Assessment ≠ [[H02.053]] When the Slit Lamp Has the Answer
> Providers frequently shorthand the assessment to the eye level even when the slit lamp clearly documents both lids. This is a documentation pattern recognition skill — the assessment is a summary; the slit lamp exam is the detailed source of truth. Train yourself to always cross-reference the assessment with the slit lamp section before reaching for an unspecified code.

---

### Scenario 4 — [[H02.053]] as Additional Diagnosis, Inpatient, Documentation Insufficient for Query

> **Clinical Vignette:** An 80-year-old male admitted for hip fracture repair. H&P (completed by hospitalist) documents: "Chronic **trichiasis** right eye — managed by outpatient ophthalmologist." No lid specification, no slit lamp exam documented. The treating ophthalmologist is unavailable for query during the admission.

**Principal Diagnosis:**
- [[S72.001A]] — Fracture of right femoral neck *(principal — reason for admission)*

**Additional Diagnoses:**
- **[[H02.053]]** — **Trichiasis** without entropion, right eye, unspecified eyelid *(documented active condition meeting UHDDS criteria — query not possible — appropriate use of unspecified code)*

> [!note] UHDDS + Unspecified Code — Document Your Query Attempt
> As a CIC, your audit trail matters. If you assign [[H02.053]] because a query was attempted and not responded to, document that in your coding notes. "Query sent [date] — no response obtained — coded to highest specificity available per documentation: H02.053." This protects you in an audit and demonstrates good faith coding practice.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never use [[H02.053]] when the slit lamp exam documents a specific lid** — [[H02.051]] or [[H02.052]] is always preferred when the lid is identifiable |
| ❌ | **Never use [[H02.053]] when the corneal staining pattern clearly points to a specific lid** — inferior SPK = lower ([[H02.052]]); superior SPK = upper ([[H02.051]]) |
| ❌ | **Never use [[H02.053]] alongside [[H02.059]]** — if you know the eye (right), use the laterality-specific code; [[H02.059]] adds nothing |
| ❌ | **Never assign [[H02.053]] for congenital trichiasis / epiblepharon** — Excludes1 at H02 blocks use with Q10.0-Q10.3 |
| ❌ | **Never omit the -RT modifier on [[67820]]/[[67825]]** — even when lid is unspecified, right eye laterality must be on the claim |
| ✅ | **Always query first** — in ophthalmology, lid specificity is almost always available if you look in the right section of the note |
| ✅ | **Check the procedure note** — if the physician documented "right upper eyelid" or "right lower eyelid" anywhere in the procedure section, use that specificity |
| ✅ | **Use [[H02.053]] without guilt when it's genuinely appropriate** — ED docs, hospitalist H&Ps, non-ophthalmologist notes are valid use cases for this code |
| ✅ | **Flag [[H02.053]] usage for provider education** — repeated use on ophthalmology claims signals a documentation improvement opportunity |
| ✅ | **No per-lid E-modifier when using [[H02.053]]** — -RT only; the E-modifier requires knowing the specific lid |
| ✅ | **If you suspect both lids** — query; if confirmed, assign both [[H02.051]] and [[H02.052]] instead of [[H02.053]] |

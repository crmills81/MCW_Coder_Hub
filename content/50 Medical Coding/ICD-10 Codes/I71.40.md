# 🧬 ICD-10 CM I71.40 — Abdominal Aortic Aneurysm, Without Rupture, Unspecified

> [!success] Billable Code Confirmed
> **ICD-10 CM [[I71.40]]** is a **5-character code** (**I, 7, 1, 4, 0**) and is the final, reportable level under the **I71.4 subcategory.**<sup>2,3</sup> It is valid for claims because it carries the full character set required, and it is the default when a provider documents "**AAA**" without a location or rupture.

> [!warning] Non-Billable Parent Codes
> **I71.4** — **Abdominal aortic [[aneurysm]], without rupture**. This header requires a fifth character for **aneurysm** location.<sup>1,2</sup>
> **I71** — **Aortic [[aneurysm]] and [[dissection]]**. This category is non-billable and requires subcategory and location detail.

> [!important] Clinical Context
> The **selection driver** is documentation of **[[aneurysm]]** location (**pararenal, juxtarenal, infrarenal**) and **rupture** status. When location is not documented but the **[[aneurysm]]** is abdominal and unruptured, **[[I71.40]]** is the correct choice.

> [!danger] Code Classification
> **ICD-10 CM [[I71.40]]** is an **ICD-10-CM diagnosis code** used for **inpatient** and **outpatient** reporting. It is not a procedure code (**CPT/ICD-10-PCS**).

---

## 🔍 Code Description

**ICD-10-CM [[I71.40]]** describes a **[[dilation]]** (**[[aneurysm]]**) of the **abdominal aorta that has not ruptured**, with no documented segment.<sup>3</sup> Documentation of the location is what moves the code to **[[I71.41]]** (**[[pararenal]]**), **[[I71.42]]** (**[[juxtarenal]]**) or **[[I71.43]]** (**[[infrarenal]]**).<sup>4</sup> An **[[aneurysm]]** is generally distinguished from **[[ectasia]]** by size, with a diameter of about 3.0 cm or larger commonly used as the threshold.<sup>9</sup>

Because most **abdominal aortic aneurysms** are found incidentally on imaging, **[[I71.40]]** is frequently the first code assigned before the **surgeon's operative detail** is available. Clinical terms mapped to this code include **inflammatory, recurrent, enlarging** and **familial AAA**.<sup>2</sup> Once rupture is documented, the family changes to the ruptured category (**I71.3-**) and **[[I71.30]]** becomes the unspecified ruptured option.

> [!example] Specificity Over Default
> **ICD-10 CM [[I71.40]]** and **[[I71.43]]** group to the same **MS-DRGs**, so the payment impact is usually **nil**. The value of specificity is data quality, device selection (**fenestrated/branched grafts for pararenal and juxtarenal disease**) and **audit** defensibility.

> [!tip]
> If the **operative report** documents the aneurysm location, report the specific code rather than **[[I71.40]]**. The treating **surgeon's documentation** can support the more specific code even when the **H&P** says only "**AAA**".

## ✅ Includes

- **Abdominal aortic [[[aneurysm]]] without rupture, location not documented** — the core use of **[[I71.40]]**.<sup>3</sup>
- **"Abdominal [[aneurysm]]" without mention of rupture** — indexes to the AAA family and defaults here when no segment is stated.<sup>2</sup>
- **Inflammatory, recurrent, enlarging or familial AAA with no location specified** — clinical descriptors map here unless a segment is documented.<sup>2</sup>

## ❌ Excludes

### Excludes 1

- **[[I71.30]]** — Ruptured, unspecified AAA. Rupture status is mutually exclusive, so a single aneurysm is either ruptured or not.
- **[[I71.9]]** — Aortic aneurysm of unspecified site, without rupture. Do not use it when the abdominal aorta is documented as the site.<sup>8</sup>
- **[[I77.811]]** — Abdominal aortic ectasia. [[Ectasia]] (a milder [[dilation]]) and aneurysm are not reported together for the same segment.

**ICD-10 CM [[I71.40]]** itself carries no formal **Excludes1 note** in the references reviewed. The pairs above reflect **rupture/site/ectasia logic**, so confirm against the Tabular List.<sup>1,2</sup>

> [!danger]
> The most common **error** is reporting **[[I71.40]]** alongside a **ruptured code**, or reporting **I71.4** (**the header**) on the claim. Both create edit **failures** and **rupture status** changes the clinical picture and procedure selection.

### Excludes 2

- **P04-P96** — **Certain conditions originating in the perinatal period.** These can be coded alongside **[[I71.40]]** when both are present, which is rare in an adult **AAA**.<sup>2</sup>
- **[[I70.0]]** — **[[Atherosclerosis]] of aorta**. This is not a formal **Excludes2**, but it is commonly reported together with **[[I71.40]]** when both are documented.

## 📋 Clinical Overview

### Rupture Status and Location Specificity

**Rupture status** and documented segment are the two details that separate **[[I71.40]]** from its neighbors. The table below compares it with the **infrarenal** and **ruptured-unspecified options**.

| **Feature** | **[[I71.40]]** | **Related [[I71.43]]** | **Related [[I71.30]]** |
|---|---|---|---|
| **Rupture status** | Without rupture. | Without rupture. | Ruptured. |
| **Location documented** | No segment documented. | Infrarenal segment documented. | No segment documented. |
| **Typical trigger** | "AAA" on imaging or H&P with no segment. | Operative or imaging report specifies infrarenal. | Acute hemorrhage with no segment documented. |

> [!important]
> **CDI trigger**: a diagnosis of "**AAA**" with no segment or size. Query for location (**[[pararenal]]/[[juxtarenal]]/[[infrarenal]]**), diameter and rupture status, especially before a planned repair.

### Manifestations & Symptom Burden

- **Asymptomatic or incidental** — most **AAAs** are found on imaging done for another reason.
- **Abdominal or back pain** — can signal expansion, and urgent evaluation for rupture is warranted.
- **Pulsatile abdominal mass** — a classic exam finding.
- **Distal embolization** — thrombus from the sac can embolize and needs separate code assignment.

> [!tip]
> **Signs and symptoms** that are integral to the **AAA** are not coded separately. Add a **code** only when a symptom is not routinely associated with the **[[aneurysm]]**.

## 🏥 MS-DRG Assignment

| **Scenario** | **MS-DRG** | **Title** |
|---|---|---|
| **PDx [[I71.40]], no OR procedure** | **299** | Peripheral Vascular Disorders with MCC<sup>4</sup> |
| **PDx [[I71.40]], no OR procedure** | **300** | Peripheral Vascular Disorders with CC<sup>4</sup> |
| **PDx [[I71.40]], no OR procedure** | **301** | Peripheral Vascular Disorders without CC/MCC<sup>4</sup> |
| **Endovascular repair performed (verify in MS-DRG v44 definitions)** | **268-269** | Aortic and Heart Assist Procedures Except Pulmonary Artery with/without MCC |
| **Open repair performed (verify in MS-DRG v44 definitions)** | **252-254** | Other Vascular Procedures with MCC/CC/without CC/MCC |

With **no procedure**, the **[[aneurysm]]** as **PDx** groups to **MS-DRGs 299-301** and the **CC/MCC tier** is set by **secondary** diagnoses.<sup>4</sup> When a repair is performed, the **ICD-10-PCS procedure** takes precedence and the **PDx** supports medical necessity. Do **not** assume **[[I71.40]]** is a **CC** or **MCC** as a secondary diagnosis; check the current **CC/MCC** tables.

- **LCD/NCD:** **CMS Article A53124** (**Billing and Coding: Endovascular Repair of Aortic and/or Iliac Aneurysms**) governs **CPT [[34701]]-[[34708]]** reporting, including that contained or stable ruptures are reported with the **non-ruptured EVAR codes**.<sup>6</sup> Confirm whether the associated **LCD** applies to your **MAC jurisdiction** (**Noridian JE/JF**) in the **CMS Medicare Coverage Database.**
- **NCD:** No **NCD** specific to **[[I71.40]]** was identified in the sources reviewed; verify in the **MCD**.

### NCCI Bundling Considerations

**Nonselective** **[[catheterization]]** is inherent to **[[34701]]**-**[[34708]]** and is not separately reportable.<sup>6</sup> Add-on **[[34709]]** is reported only with a primary **EVAR code**, and imaging is bundled into the endograft codes since 2018.<sup>6,10</sup> Check current **NCCI PTP edits** before appending **[[-59]]**.

## 💊 Coding Scenarios and Examples

<br>

### Example 1

> **Clinical Scenario:**
> A 71-year-old man undergoes elective endovascular repair with an aorto-bi-iliac endograft. The diagnosis line reads "AAA" with no location or rupture noted.

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[34705]]-[[-62]] | Aorto-bi-iliac endograft; [[-62]] applies only if two surgeons each perform distinct parts. |
| PDx | [[I71.40]] | Unruptured AAA with no segment documented. |

> [!tip]
> Sequence the AAA as PDx because it is the reason for the repair.
> CDI note: query the surgeon for location, since the operative report may support [[I71.43]].

### Example 2

> **Clinical Scenario:**
> A surgeon repairs an unruptured AAA with an aorto-aortic tube endograft and places a proximal extension prosthesis to complete the seal.

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[34701]]-[[-62]] | Primary endograft code; co-surgeon modifier only if two surgeons share the work.<sup>10</sup> |
| CPT 2 | [[34709]] | Add-on for the extension prosthesis, once per vessel.<sup>6</sup> |
| PDx | [[I71.40]] | Unruptured AAA, location not specified in the diagnosis. |

> [!tip]
> The add-on is reported only with the primary EVAR code, with no [[-51]].
> CDI note: if the aneurysm is documented as infrarenal, switch to [[I71.43]].

### Example 3

> **Clinical Scenario:**
> A vascular surgeon personally interprets a complete aorto-iliac duplex on a hospitalized patient with a known unruptured AAA.

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[93978]]-[[-26]] | Professional interpretation of the complete duplex. |
| PDx | [[I71.40]] | Known unruptured AAA, no segment documented. |

> [!tip]
> Report the diagnosis that justifies the study, not a rule-out.
> CDI note: ask for the measured diameter and segment when documenting surveillance.

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Reporting the header **I71.4** on a claim; **Tips**: Always add the **fifth character** (**[[I71.40]]**-**[[I71.43]]**).<sup>1,2</sup>
- **Pitfall 2**: Defaulting to **[[I71.40]]** when the operative report documents the segment; **Tips**: Use the specific code from the treating surgeon's documentation.
- **Pitfall 3**: Mismatch between **ICD-10-CM** and **CPT** on contained rupture. **ICD-10-CM** reports a ruptured code (**[[I71.30]]**), while contained or stable ruptures use the **non-ruptured EVAR codes** (**[[34701]]**, **[[34703]]**, **[[34705]]**, **[[34707]]**); **Tips**: Read the **CPT guidance** and **A53124** before choosing the CPT.<sup>6</sup>
- **Pitfall 4**: Using **[[I71.9]]** when the abdominal site is documented; **Tips**: Use the **I71.4- family** once "**abdominal**" is stated.<sup>8</sup>
- **Pitfall 5**: Reporting **[[I77.811]]** (**[[ectasia]]**) for an **[[aneurysm]]** or the reverse; **Tips**: Follow the provider's term and the **Excludes1 logic**.<sup>9</sup>
- **Pitfall 6**: Coding pain or back pain separately when attributed to the **AAA**; **Tips**: Do **not** code integral symptoms.

# 🧬 ICD-10 CM M51.17 — Intervertebral Disc Disorders With Radiculopathy, Lumbosacral Region

> [!success] Billable Code Confirmed  
> **ICD-10 CM [[M51.17]]** is a highly specific **6-character billable code** that identifies both the structural pathology (**intervertebral disc disorder**) and the neurological result (**[[radiculopathy]]**) specifically within the **[[lumbosacral]] junction**. This code is fully billable for the **2027 fiscal year** as it satisfies all requirements for anatomical and clinical specificity.<sup>1</sup>

> [!warning] Non-Billable Parent Codes  
> **M51.1** — **Intervertebral disc disorders with [[radiculopathy]]**: This 4-character code is non-billable because it requires a **5th** and **6th** character to specify the spinal region involved.<sup>1</sup>  
> **M51** — **Other intervertebral disc disorders**: This 3-character category code is non-billable because it lacks the required specificity regarding the presence of **[[radiculopathy]]** and the anatomical location.<sup>1</sup>

> [!important] Clinical Context  
> Selection of **[[M51.17]]** is driven by documentation of a **disc-related pathology** (**e.g., [[herniation]], [[extrusion]], or [[protrusion]]**) at the **L5-S1 level** causing radicular symptoms.<sup>2</sup> It must be distinguished from **[[radiculopathy]]** caused by bony changes (**[[spondylosis]]**), which is coded as **[[M47.27]]**.<sup>1</sup>

> [!danger] Code Classification  
> This is a clinical diagnosis code used to describe a **musculoskeletal** and **neurological** condition. It is not a procedure code and should be used to establish the medical necessity for **CPT codes** such as **[[63030]]** or **[[64483]]**.<sup>2</sup>

---

## 🔍 Code Description  

**ICD-10 CM [[M51.17]]** identifies **a clinical condition where structural failure of the lumbosacral intervertebral disc**—most commonly at the **L5-S1 junction**—results in **mechanical [[compression]]** or **biochemical irritation** of the exiting **spinal nerve roots**.<sup>1,2</sup> This process leads to **[[radiculopathy]]**, which manifests as **radiating pain, sensory loss, or motor weakness** that typically follows the **S1 dermatomal distribution**, often extending down the posterior leg to the lateral foot.<sup>2</sup> This combination code ensures that both the cause (**disc disorder**) and the effect (**[[radiculopathy]]**) are captured in a single entry.<sup>1</sup>

From a **reimbursement standpoint**, **[[M51.17]]** is a critical code for justifying the medical necessity of advanced imaging, such as **MRI**, and **interventional procedures**.<sup>2,3</sup> It provides the required specificity for insurers to approve **transforaminal epidural steroid injections** reported under CPT **[[64483]]** or surgical microdiscectomies coded as **[[63030]]**.<sup>3</sup> Precise documentation of the **[[lumbosacral]] region** prevents the use of non-**billable parent codes** and reduces the likelihood of claim denials based on insufficient specificity.<sup>1</sup>

> [!example] LUMBAR VS. LUMBOSACRAL SPECIFICITY
> Using **[[M51.17]]** rather than **[[M51.16]]** is crucial for **surgical planning and billing** when the pathology is specifically at the **L5-S1 junction**. **Payers** and **surgeons** require this anatomical precision to verify that the treated level matches the diagnostic findings.<sup>1,3</sup>

> [!tip] 
> Review the **MRI repor**t for "**L5-S1 disc [[herniation]] with S1 nerve root impingement**" to accurately support the assignment of **[[M51.17]]**.<sup>2</sup>

## ✅ Includes  

- **Lumbosacral disc herniation with radiculopathy**: Specifically describes the nucleus pulposus protruding into the lumbosacral canal and compressing a nerve root.<sup>1</sup>
- **Lumbosacral disc protrusion with nerve root impingement**: Includes cases where the disc bulges but remains contained, still resulting in radicular symptoms.<sup>1</sup>
- **Lumbosacral disc bulge with radiculopathy**: Captures generalized lumbosacral disc displacement that results in neural [[compression]].<sup>1</sup>

## ❌ Excludes  

### Excludes 1  

- **[[M54.17]]** — **[[Radiculopathy]], [[lumbosacral]] region**: This code is used for **[[radiculopathy]]** without a documented underlying disc disorder; if a disc disorder is documented, **[[M51.17]]** must be used.<sup>1</sup>
- **[[M47.27]]** — **Other [[spondylosis]] with [[radiculopathy]], [[lumbosacral]] region**: This is used when the **[[radiculopathy]]** is caused by bony changes (**[[spondylosis]]**) and **facet [[hypertrophy]]** rather than disc pathology.<sup>1</sup>

> [!danger] 
> The most common **Excludes 1 error** is coding **[[M54.17]]** (the symptom) and **[[M51.27]]** (the cause) separately; these must be combined into **[[M51.17]]** per official coding guidelines.<sup>1</sup>

### Excludes 2  

- **[[M51.27]]** — **Other intervertebral disc displacement, lumbosacral region**: May be coded if a distinct displacement is present at a different lumbosacral level than the radiculopathy.<sup>1</sup>
- **[[M51.37]]** — **Other intervertebral disc degeneration, lumbosacral region**: Represents degenerative changes that may coexist with the radicular disorder.<sup>1</sup>

## 📋 Clinical Overview  

### Radiating Lumbosacral Pathology

The **lumbosacral region**, specifically the **L5-S1 junction**, is the most common site for **intervertebral disc [[herniation]]**. When a disc disorder occurs here, it typically compresses the **S1 nerve root**, leading to classic "**[[sciatica]]**" symptoms. Understanding the difference between **disc-driven and bone-driven compression** is vital for determining the appropriate surgical or interventional approach.<sup>2,3</sup>

| **Feature** | **[[M51.17]]** | Related **[[M47.27]]** | Related **[[M54.17]]** |
|:---:|---|---|---|
| **Primary Cause** | Intervertebral disc protrusion/herniation.<sup>2</sup> | Spondylosis/Facet hypertrophy.<sup>1</sup> | Unspecified neural irritation.<sup>1</sup> |
| **Imaging Finding** | Disc extrusion on MRI.<sup>3</sup> | Osteophytes/Joint hypertrophy.<sup>3</sup> | No structural cause identified.<sup>3</sup> |
| **Treatment Goal** | Disc decompression/Removal.<sup>2</sup> | Management of bony stenosis.<sup>2</sup> | Symptomatic pain relief.<sup>2</sup> |

> [!important] 
> A **CDI trigger** occurs when a provider documents "**S1 radiculopathy**" and **"L5-S1 disc bulge**" as two separate findings. The coder should query the provider to link these as a single condition to capture the combination code **[[M51.17]]**.

### Manifestations & Symptom Burden  

- **S1 Radicular Pain**: Sharp, lancinating pain radiating down the posterior thigh and calf to the lateral aspect of the foot.<sup>2</sup>
- **[[Paresthesia]]**: "**Pins and needles**" or numbness specifically felt in the lateral foot and small toe.<sup>2</sup>
- **Motor Deficit**: **[[Weakness]]** in **[[plantarflexion]]** (difficulty with toe-walking) due to S1 nerve root compromise.<sup>3</sup>
- **Reflex Changes**: Diminished or absent Achilles tendon reflex.<sup>3</sup>

> [!tip] 
> When documenting symptoms, always ensure they are linked to the **lumbosacral disc disorder** to justify the use of **[[M51.17]]** over a simple symptom code.<sup>1</sup>

|---|---|---|---|

| **454** | Spinal Fusion without MCC | Surgical | ~3.42 |

If **[[M51.17]]** is the principal diagnosis for an admission involving non-**surgical pain management**, the case maps to **MS-DRG 551 or 552**. If the patient undergoes a **[[laminectomy]]** or **[[fusion]]**, the case shifts to a **surgical DRG**.<sup>1</sup>

- **NCD/LCD Note**: Many **MACs** require documentation of **radicular symptoms** (such as those identified by **[[M51.17]]**) to support the medical necessity of **lumbosacral epidural steroid injections**.<sup>3</sup>

## 🛠️ Commonly Associated CPT Codes  

- **[[63030]]** — [[Laminotomy]]/[[hemilaminectomy]] with [[decompression]] of nerve root, lumbar. The gold standard surgical treatment for L5-S1 disc [[radiculopathy]].<sup>2</sup>
- **[[64483]]** — Transforaminal epidural steroid injection, lumbar. Used to treat radicular pain by delivering steroids directly to the S1 nerve root.<sup>2</sup>
- **[[62323]]** — Interlaminar epidural injection, lumbar. An alternative injection approach for [[lumbosacral]] [[radiculopathy]].<sup>2</sup>
- **[[99214]]** — Office visit, established patient, moderate complexity. Standard E/M for the management of chronic [[lumbosacral]] disc disorders.<sup>2</sup>
- **[[97110]]** — Therapeutic procedure, [[neuromuscular]] reeducation. Used in physical therapy to restore motor function in patients with S1 [[radiculopathy]].<sup>2</sup>

### NCCI Bundling Considerations  

**Fluoroscopic guidance** is bundled into transforaminal injections (**[[64483]]**) and cannot be reported separately. An **E/M service** performed on the same day as a **procedure** requires modifier **[[-25]]** and must be documented as a separate and significant service.<sup>2</sup>

## 💊 Coding Scenarios and Examples  

<br>

### Example 1
> **Clinical Scenario:**  
> A 48-year-old patient presents with radiating pain down the right posterior leg to the lateral foot. MRI confirms an L5-S1 disc herniation compressing the right S1 nerve root. The physician performs a right-sided lumbosacral transforaminal epidural steroid injection.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[64483]]-[[-RT]] | Transforaminal injection on the right lumbosacral level.<sup>2</sup> |
| PDx | [[M51.17]] | Confirms the lumbosacral disc disorder causing the radiculopathy.<sup>1</sup> |

> [!tip] 
> Verify that the "L5-S1" documentation is present to justify the "lumbosacral" (.17) code rather than the "lumbar" (.16) code.

### Example 2
> **Clinical Scenario:**  
> An inpatient patient with a documented lumbosacral disc herniation causing severe S1 radiculopathy undergoes an open laminectomy and microdiscectomy at the L5-S1 level.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[63030]] | Surgical decompression of the S1 nerve root at one lumbosacral level.<sup>2</sup> |
| PDx | [[M51.17]] | The underlying lumbosacral disc disorder requiring surgery.<sup>1</sup> |

> [!tip] 
> In inpatient settings, the surgical note must explicitly state that the nerve root was decompressed to support this CPT.

### Example 3
> **Clinical Scenario:**  
> An established patient returns for follow-up of chronic lumbosacral disc-related radiculopathy. The physician performs a neurological exam and adjusts the patient's neuropathic medication.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99214]] | Moderate complexity E/M for managing a chronic radicular condition.<sup>2</sup> |
| PDx | [[M51.17]] | The chronic lumbosacral disc disorder being managed.<sup>1</sup> |

> [!tip] 
> If a trigger point injection was also performed, add modifier [[-25]] to the E/M code.

## ⚠️ Coding Pitfalls and Tips  

- **Pitfall 1**: Using **[[M54.17]]** (**[[radiculopathy]]**) when a disc **[[herniation]]** is documented; **Tips**: Use the combination code **[[M51.17]]** to capture both the cause and the symptom.<sup>1</sup>
- **Pitfall 2**: Confusing **[[M51.17]]** with **[[M47.27]]**; **Tips**: If the cause is a disc, use **[[M51.17]]**; if the cause is **bone/facet joints**, use **[[M47.27]]**.<sup>1</sup>
- **Pitfall 3**: Failing to use the **6th** character '**7**'; **Tips**: Ensure the **lumbosacral region** is specified to avoid using the non-billable parent code **[[M51.1]]**.<sup>1</sup>
- **Pitfall 4**: **Unbundling fluoroscopic guidance**; **Tips**: Remember that imaging is bundled into **[[64483]]** per **NCCI guidelines**.<sup>2</sup>
- **Pitfall 5**: Documentation only stating "**disc bulge**" without "**[[radiculopathy]]**"; **Tips**: If no **radicular symptoms** are documented, you must use **[[M51.27]]** or **[[M51.37]]** instead of **[[M51.17]]**.<sup>1</sup>

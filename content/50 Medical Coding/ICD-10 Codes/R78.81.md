# 🧬 ICD-10 CM R78.81 — Bacteremia

> [!success] Billable Code Confirmed  
> **ICD-10 CM [[R78.81]]** is a **5-character code**: **R78** (**findings of substances not normally found in blood**), **.8** (**other specified substances**), **1** (**[[bacteremia]]**). It is complete and valid for **FY2026** claims.<sup>1</sup>

> [!warning] Non-Billable Parent Codes  
> **R78.8** (**Finding of other specified substances, not normally found in blood**) is a header and needs a 5th character. **R78** (**Findings of drugs and other substances, not normally found in blood**) is also non-billable.<sup>1</sup>

> [!important] Clinical Context  
> **[[Bacteremia]]** means **bacteria in the bloodstream** and says nothing about a systemic response. Use **[[R78.81]]** only when no **[[sepsis]]** or definitive infection is documented, and code sepsis to the specified infection.<sup>4</sup>

> [!danger] Code Classification  
> This is an **ICD-10-CM symptom and abnormal-finding diagnosis code** (**Chapter 18**). It is not a procedure code and not a definitive-infection code.

---

## 🔍 Code Description  
**ICD-10 CM [[R78.81]]** reports **bacteria in the blood, usually from a positive blood culture**, without a documented diagnosis of **[[sepsis]]** or another definitive **[[infection]]**. It is a finding code, so the index points to it for "**[[Bacteremia]]**" and "**Positive culture, blood (nonspecific)**." The index entry "**Bacteremia, with sepsis**" directs to the **Excludes1 note** instead, so **[[sepsis]]** is coded to the infection.<sup>5</sup>

When the organism is known, add a **B95-B97** organism code only if a definitive **infection** is documented. **[[Bacteremia]]** usually comes from a source such as the **urinary tract**, a line or the skin, and that source should be coded when the provider documents it.<sup>4</sup> An **ACDIS Q&A note**s that **bacteremia** as a principal diagnosis is unlikely to meet inpatient medical necessity, while sepsis would.<sup>4</sup>

> [!example] Bacteremia vs Sepsis  
> Documentation of "**[[bacteremia]]**" with a **fever** and **antibiotics** is not **[[sepsis]]** unless the provider says so. The choice between **[[R78.81]]** and **[[A41.9]]** changes the **DRG**, the medical necessity review and quality reporting.

> [!tip]  
> Treat **[[R78.81]]** as a code of last resort. **Query** for the **infection**, the source and any **[[sepsis]]** before assigning it as principal.

## ✅ Includes  
- **[[Bacteremia]]:** the only inclusion term, bacteria present in the blood without sepsis.<sup>5</sup>
- **Positive blood culture (nonspecific):** the index sends this to **[[R78.81]]** when no diagnosis is made.<sup>5</sup>
- **Abnormal finding without a diagnosis:** a culture result the provider has not tied to an infection.

---

## ❌ Excludes  

### Excludes 1  
- **[[Sepsis]] (A41.-):** the note says to code to the specified infection, so **[[bacteremia]]** is never reported with sepsis.<sup>4</sup> For example, use **[[A41.9]]** for **[[sepsis]]** of unspecified organism.
- **F10-F19:** at the **R78 category level**, substance use disorders cannot be reported with these findings. Verify the note type in the 2026 tabular.

> [!danger]  
> The most common **error** is reporting **[[R78.81]]** alongside a **[[sepsis]]** code because the culture was positive. The **Excludes1 note** prohibits it, and the **[[sepsis]]** code already covers the **bloodstream infection**.

### Excludes 2  
- None listed at **[[R78.81]]**. Related code: **[[B96.20]]** (**E. coli as the cause of diseases classified elsewhere**) is not an **Excludes2** item but is often paired when a definitive **infection** is documented.

## 📋 Clinical Overview  

### Bacteremia vs Sepsis vs Definitive Infection  
**[[Bacteremia]]** describes the lab finding, **[[sepsis]]** describes the body's response and a definitive infection names the site or organism. Each has a different code family, so the provider's wording drives selection.

| **Feature** | **[[R78.81]]** | **Related [[A41.9]]** | **Related [[A41.51]]** |
|:---:|---|---|---|
| **Meaning** | Bacteria in blood, no diagnosis. | Sepsis, organism unspecified. | Sepsis due to E. coli. |
| **Systemic response** | Not required or documented. | Documented by the provider. | Documented by the provider. |
| **Principal Dx use** | Rarely, with a medical necessity risk. | Yes, when sepsis is present on admission. | Yes, when sepsis with E. coli is documented. |

> [!important]  
> **CDI trigger**: "**bacteremia**" documented with **[[fever]]**, **[[tachycardia]]**, **[[hypotension]]** or **[[antibiotics]]**. Query whether the clinical picture represents **[[sepsis]]** and, if so, the organism and source.

### Manifestations & Symptom Burden  
- **Fever and chills:** common acute signs.<sup>6</sup>
- **[[Tachycardia]] and [[tachypnea]]:** common acute signs.<sup>6</sup>
- **Asymptomatic or transient:** some [[bacteremia]] has no symptoms and is found only on culture.
- **Source-related findings:** line site erythema, urinary symptoms or a skin [[infection]].

> [!tip]  
> **[[Fever]]** alone is not a reason to add a separate code when **bacteremia** is documented. Code the source **infection** or **sepsis** when the provider documents it.

## 🔬 ICD-10-PCS Crosswalk  
**ICD-10 CM [[R78.81]]** is a diagnosis only, and no **PCS code** maps directly to it. These **procedures** are often seen with the admission:
- **[[3E03329]]** — Introduction of other anti-infective into peripheral vein, **[[percutaneous]]**. Reported when IV antibiotic therapy is documented and facility policy captures it.
- **[[02HV33Z]]** — Insertion of infusion device into superior vena cava, **[[percutaneous]]**. Reported for a PICC placed for prolonged antibiotics.

## 💊 Coding Scenarios and Examples  

### Example 1
> **Clinical Scenario:**  
> A patient with a low-grade fever has one blood culture positive for bacteria. The provider documents "transient bacteremia," sees no source, and the patient has no sepsis criteria and is discharged without admission.

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[87040]] | Blood culture with isolation. |
| PDx | [[R78.81]] | Bacteremia with no sepsis and no definitive infection documented. |

> [!tip]  
> This works as an outpatient finding. CDI: query for a source and whether sepsis was considered and ruled out.

### Example 2
> **Clinical Scenario:**  
> A patient is admitted with a UTI and two positive blood cultures for E. coli. The provider documents "E. coli UTI with E. coli bacteremia" and does not diagnose sepsis.

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[87040]]-[[-91]] | Repeat blood culture to confirm clearance, with modifier 91 for the repeat. |
| CPT 2 | [[87186]] | Susceptibility testing on the isolate. |
| PDx | [[N39.0]] | The UTI is the definitive infection and is sequenced first. |

> [!tip]  
> Add [[B96.20]] for the organism and [[R78.81]] as secondary only if bacteremia is documented and no sepsis applies. CDI: query for sepsis if systemic signs are present.

### Example 3
> **Clinical Scenario:**  
> A patient with fever, hypotension, tachycardia and positive cultures is documented as "sepsis due to MSSA."

| **Field** | **Code** | **Rationale** |
|:---:|---|---|
| CPT | [[99223]] | Initial hospital care, high MDM. |
| PDx | [[A41.01]] | Sepsis due to MSSA, so R78.81 is not reported. |

> [!tip]  
> The Excludes1 note bars [[R78.81]] with sepsis. CDI: make sure the sepsis diagnosis is supported with clinical indicators to withstand audit.

## ⚠️ Coding Pitfalls and Tips  
- **Pitfall 1**: Reporting **[[R78.81]]** with a **[[sepsis]]** code; **Tips**: Code **[[sepsis]]** to the specified infection and drop **[[R78.81]]**.
- **Pitfall 2**: Using **[[R78.81]]** as principal when a **definitive infection** is documented; **Tips**: Sequence the definitive infection first.
- **Pitfall 3**: Coding **[[bacteremia]]** from a lab value alone; **Tips**: The provider must document it, so query when only the culture result is present.
- **Pitfall 4**: Assuming contaminant cultures are **[[bacteremia]]**; **Tips**: Only code what the provider documents as **[[bacteremia]]**, not a possible **contaminant**.
- **Pitfall 5**: Adding an organism code without a definitive **infection**; **Tips**: Use **B95-B97** codes only when they identify the cause of a condition classified elsewhere.
- **Pitfall 6**: Expecting **severity credit** from **[[R78.81]]**; **Tips**: Verify its **CC/MCC status** in your encoder and capture severity from other documented conditions.

# 🧠 ICD-10-CM G54.4 — Lumbosacral Root Disorders, NEC

> [!success] Billable Code Confirmed
>
> **ICD-10-CM [[G54.4]]** is a valid, billable **4-character ICD-10-CM
> code** for FY2026. The code is fully specified: `G54` (**nerve root
> and plexus disorders**) + `.4` (**lumbosacral root disorders, NEC**).
> All four characters are required for valid reporting.

> [!warning] Non-Billable Parent Code — Never Submit Alone
>
> - ❌ `G54` — 3-character category header — non-billable; never submit alone
>
> Always submit **[[G54.4]]** (all 4 characters). The 4th character is
> required and available.

> [!important] NEC Code — G54.4 Is a Residual Code; Specificity Hierarchy Applies
>
> **[[G54.4]]** carries the NEC (Not Elsewhere Classified) designation,
> meaning it is the appropriate code **only when a more specific code
> does not exist** for the documented condition. Before assigning [[G54.4]],
> the coder must confirm that the lumbosacral root disorder is not more
> accurately captured by a spondylosis code ([[M47.2-]]), a disc disorder
> code ([[M51.1-]]), or — critically — **cauda equina syndrome ([[G83.4]])**
> when CES is explicitly documented. [[G54.4]] does not replace [[G83.4]];
> these are distinct codes on different pathways.

> [!info] Code Classification
>
> **ICD-10-CM Diagnosis Code** — Fields for wRVU, assistant payable, and
> global period are not applicable. This is a nerve root disorder code
> used across inpatient, outpatient, and pain management settings when
> lumbosacral root dysfunction is documented and no more specific structural
> or syndromic code applies.

## 🔍 Code Description

**ICD-10-CM [[G54.4]]** classifies **lumbosacral root disorders, not
elsewhere classified** — a residual category capturing diseases and
disorders of the lumbosacral nerve roots (lumbar L1-L5 and sacral S1-S5)
that are not attributable to a specific, separately-classified structural
condition such as intervertebral disc disease, spondylosis, or an
identified inflammatory or infectious etiology.

The lumbosacral nerve roots transmit sensory and motor signals to and from
the lower extremities, perineum, and pelvic viscera (bladder, bowel,
sexual function). Disruption at this level — whether from compression,
inflammation, infarction, or infiltration — produces **lower extremity
radiculopathy** (pain, paresthesia, weakness in dermatomal/myotomal
distributions), **neurogenic bladder and bowel** (when sacral roots S2-S4
are involved), and **saddle sensory disturbance**.

**[[G54.4]]** occupies a specific position in the coding hierarchy:
it is more specific than an unspecified nerve disorder code but less
specific than cauda equina syndrome ([[G83.4]]), disc-driven radiculopathy
([[M51.1-]]), or spondylosis with radiculopathy ([[M47.2-]]). The NEC
designation signals that this code should only be reached when the workup
does not establish a specific structural, inflammatory, or compressive
etiology that maps to a more defined code.

**The critical distinction in practice:** If the physician documents
"cauda equina syndrome" → assign **[[G83.4]]**, not [[G54.4]]. If the
physician documents lumbosacral radiculopathy without specifying cauda
equina involvement and without a discrete structural disc or spondylosis
code applying → [[G54.4]] may be appropriate. Always apply the hierarchy.

> [!tip] G54.4 vs. G54.1 — Root Disorders vs. Plexus Disorders
> **[[G54.4]]** is specifically for **nerve root** disorders (radiculopathy
> at the root level as it exits the spinal canal). **[[G54.1]]** is for
> **lumbosacral plexus** disorders (pathology at the level of the
> lumbosacral plexus formed from the nerve roots — e.g., diabetic
> amyotrophy, plexopathy). If the physician documents plexopathy or
> plexus involvement, [[G54.1]] is the correct code, not [[G54.4]].

## ✅ Includes

The following clinical documentation patterns may map to **[[G54.4]]**
when a more specific code is not available:

- Lumbosacral root disorders NEC — documented by physician; no specific
  disc, spondylosis, or CES code applicable
- Lumbosacral radiculopathy NEC — when not attributable to a specific
  structural lesion with its own code
- Lumbosacral neuritis NOS — inflammatory nerve root syndrome without
  confirmed specific etiology
- Lumbosacral nerve root lesion NEC — documented lesion without
  sufficient specificity for a more defined code
- Post-infectious or post-inflammatory lumbosacral root syndrome
  (e.g., post-herpetic lumbosacral root involvement — verify if
  [[B02.29]] + [[G54.4]] is appropriate)

> [!important] Always Apply the Specificity Hierarchy Before Assigning G54.4
> The NEC designation means **look for a more specific code first**:
> 1. Is cauda equina syndrome documented? → **[[G83.4]]**
> 2. Is there disc herniation with radiculopathy? → **[[M51.1-]]**
> 3. Is there spondylosis with radiculopathy? → **[[M47.2-]]**
> 4. Is there a specific inflammatory etiology? → Condition-specific code
> 5. None of the above? → **[[G54.4]]** is appropriate

## 📋 Clinical Overview

### Code Hierarchy in Practice — When G54.4 Is and Is Not Appropriate

This is the central clinical coding question with [[G54.4]]:

| Clinical Documentation | Correct Code | G54.4 Appropriate? |
|---|---|---|
| "Cauda equina syndrome" | [[G83.4]] | ❌ No — use G83.4 |
| "L4-L5 disc herniation with radiculopathy" | [[M51.16]] | ❌ No — disc code covers it |
| "Spondylosis with lumbosacral radiculopathy" | [[M47.26]] | ❌ No — M47.2x covers it |
| "Lumbosacral radiculopathy, sciatica" | [[M54.4-]] | ❌ No — M54.4x covers it |
| "Lumbosacral root disorder, etiology unclear" | **[[G54.4]]** | ✅ Yes |
| "Post-radiation lumbosacral root injury" | **[[G54.4]]** | ✅ Yes — with etiology code |
| "Lumbosacral neuritis NOS" | **[[G54.4]]** | ✅ Yes |
| "Diabetic lumbosacral plexopathy" | [[G54.1]] + [[E11.40]] | ❌ No — plexus code, not root |

### Etiology

| Etiology | Notes | Associated Code(s) |
|---|---|---|
| Idiopathic — no structural cause identified | Most common G54.4 scenario | [[G54.4]] alone |
| Post-radiation lumbosacral root injury | Radiation-induced radiculopathy | [[G54.4]] + [[Y84.2]] (radiation adverse effect) |
| Herpes zoster lumbosacral root involvement | Viral radiculitis | [[B02.29]] + [[G54.4]] |
| Lyme disease — lumbosacral radiculopathy | Infectious radiculitis | [[A69.22]] + [[G54.4]] |
| Neoplastic — nerve root infiltration | Leptomeningeal carcinomatosis, perineural spread | Neoplasm code + [[G54.4]] |
| Arachnoiditis | Inflammatory adhesive disease | [[G03.9]] context + [[G54.4]] |
| Post-surgical root injury without CES | Following lumbar surgery, isolated root damage | [[G97.32]] + [[G54.4]] |

### Clinical Presentation

Patients with [[G54.4]] typically exhibit:

- **Dermatomal pain** — sharp, burning, or shooting pain radiating
  from the lumbar/sacral spine into the lower extremity in a root
  distribution (e.g., L4: anterior thigh/knee; L5: lateral leg/dorsal
  foot; S1: posterior leg/lateral foot)
- **Paresthesia and sensory disturbance** — numbness, tingling in
  dermatomal distribution
- **Motor weakness** — myotomal distribution; L4 (tibialis anterior),
  L5 (extensor hallucis longus), S1 (gastrocnemius)
- **Reflex changes** — diminished knee jerk (L4), diminished ankle
  jerk (S1)
- **Bladder/bowel involvement** — only when sacral roots (S2-S4)
  are involved; when present and severe, query for cauda equina syndrome
- **No UMN signs** — no hyperreflexia, no Babinski; purely LMN
  peripheral root syndrome

### Documentation Requirements

For accurate assignment of [[G54.4]]:

1. **Explicit root disorder documentation** — physician documentation
   of lumbosacral root disorder, radiculopathy, or nerve root lesion
2. **Absence of more specific code** — coder must verify no disc code,
   spondylosis code, or CES code is more appropriate
3. **Etiology statement** — even if etiology is unknown, a statement
   that no specific structural cause was identified supports the NEC
   assignment
4. **Functional deficits** — motor level, sensory changes, bladder/bowel
   involvement — important for additional code selection and CC/MCC capture

## 💊 Coding Scenarios and Examples

---

### Scenario 1 — Lumbosacral Radiculopathy, Idiopathic (Outpatient Neurology)

> **Clinical Vignette:** A 52-year-old female presents with a 4-month
> history of right lower extremity pain, numbness in the S1 dermatomal
> distribution, and diminished ankle jerk. MRI lumbar spine: mild
> degenerative changes without significant disc herniation or nerve
> root compression. EMG/NCS: evidence of right S1 radiculopathy.
> Neurology documents: "Lumbosacral root disorder — right S1 distribution;
> no compressive structural lesion identified on MRI. Etiology unclear;
> may represent inflammatory radiculopathy."

**CPT Codes:**
- [[99205]] — New patient office visit, high complexity
- [[95886]] — Needle EMG, right lower extremity, complete

**ICD-10-CM:**
- [[G54.4]] — Lumbosacral root disorders, NEC *(no more specific code
  applicable — structural cause not established; NEC code appropriate)*

> [!tip] G54.4 Is Appropriate Here — No More Specific Code Applies
> The MRI does not demonstrate a compressive disc or spondylosis lesion,
> eliminating [[M51.1-]] and [[M47.2-]]. The physician explicitly
> documents unclear etiology. [[G54.4]] is the correct residual code
> for this presentation.

---

### Scenario 2 — Post-Radiation Lumbosacral Root Disorder (Outpatient)

> **Clinical Vignette:** A 67-year-old male with a history of prostate
> cancer (currently in remission) treated with pelvic radiation 3 years
> ago now presents with progressive bilateral lower extremity weakness,
> paresthesia, and urinary urgency. MRI: lumbosacral nerve root
> thickening consistent with radiation-induced polyradiculopathy. No
> tumor recurrence. Neurology documents: "Radiation-induced lumbosacral
> root disorder — late effect of prior pelvic radiation therapy."

**ICD-10-CM:**
- [[G54.4]] — Lumbosacral root disorders, NEC *(radiation-induced
  polyradiculopathy — no more specific code; G54.4 is appropriate)*
- [[Y84.2]] — Radiological procedure as cause of abnormal reaction
  *(adverse effect/sequela of prior radiation — code additionally)*
- [[Z85.46]] — Personal history of malignant neoplasm of prostate *(relevant history)*

> [!important] Radiation Sequelae — Always Code the Cause
> When lumbosacral root disorder results from prior radiation therapy,
> code [[G54.4]] for the root disorder and an appropriate late effects/
> adverse effects code to identify the causative agent. This pairing
> provides complete clinical documentation and supports medical necessity
> for ongoing neurological management.

---

### Scenario 3 — Lumbosacral Root Disorder vs. CES — Query Scenario (Inpatient)

> **Clinical Vignette:** A 48-year-old male is admitted with new onset
> bilateral lower extremity weakness and difficulty voiding. MRI shows
> moderate central canal stenosis at L3-L4 and L4-L5. The attending
> neurosurgeon documents: "Lumbosacral root compression with bladder
> involvement — recommend surgical decompression." No explicit mention of
> "cauda equina syndrome" in any note.

**Coding Decision:**
- Document does NOT explicitly state "cauda equina syndrome"
- Coder **should initiate CDI query** asking: "Does the patient's clinical
  presentation — bilateral lower extremity weakness, urinary retention, and
  bilateral lumbosacral root compression on MRI — represent cauda equina
  syndrome ([[G83.4]]) or lumbosacral root disorder ([[G54.4]])?"

**If physician responds "cauda equina syndrome":**
- [[G83.4]] — Cauda equina syndrome *(more specific — use this code)*

**If physician does not respond or documents only "lumbosacral root disorder":**
- [[G54.4]] — Lumbosacral root disorders, NEC *(with N31.x for neurogenic bladder)*
- [[M48.06]] or [[M48.07]] — Spinal stenosis, lumbar/lumbosacral *(structural cause)*

> [!danger] Do Not Assume CES Without Physician Documentation
> The clinical picture may strongly suggest cauda equina syndrome, but
> **[[G83.4]] requires explicit physician documentation of "cauda equina
> syndrome."** Coders cannot upgrade from [[G54.4]] to [[G83.4]] based
> on clinical inference alone. CDI query is the correct pathway.

---

### Scenario 4 — Herpes Zoster Lumbosacral Radiculitis (Outpatient)

> **Clinical Vignette:** A 71-year-old female presents with acute-onset
> left S2-S3 dermatomal pain and rash confirmed as herpes zoster. She
> reports urinary urgency and mild left lower extremity weakness.
> Neurology documents: "Herpes zoster lumbosacral radiculitis — sacral
> root involvement with vesicular rash in S2-S3 distribution, neurogenic
> bladder symptoms."

**ICD-10-CM:**
- [[B02.29]] — Other postherpetic nervous system involvement *(herpes
  zoster as primary etiology — sequences as principal or first-listed)*
- [[G54.4]] — Lumbosacral root disorders, NEC *(nerve root manifestation
  of the zoster — code additionally)*
- [[N39.41]] — Urge incontinence *(or appropriate N31.x if neurogenic
  bladder is fully established)*

> [!tip] Infectious Etiology — Code Both the Cause and the Root Disorder
> When an infectious process (herpes zoster, Lyme disease) causes
> lumbosacral root involvement, code both the infectious etiology
> (which sequences as principal/first-listed) and [[G54.4]] for the
> nerve root manifestation. This dual coding reflects the complete
> clinical picture.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|--|----------------|
| ❌ | **Do not submit G54 alone (3 characters)** — non-billable parent; always submit [[G54.4]] |
| ❌ | **Do not use [[G54.4]] when [[G83.4]] (cauda equina syndrome) is explicitly documented** — [[G83.4]] is the more specific code and must be used when CES is stated |
| ❌ | **Do not use [[G54.4]] when a disc code ([[M51.1-]]) or spondylosis code ([[M47.2-]]) more accurately captures the root disorder** — apply the specificity hierarchy |
| ❌ | **Do not use [[G54.4]] simultaneously with [[M54.4-]] for the same clinical condition** — Excludes 1; these represent the same presentation on different coding pathways |
| ❌ | **Do not infer cauda equina syndrome and assign [[G83.4]]** without explicit physician documentation — query is required |
| ✅ | **[[G54.4]] is appropriate for idiopathic, post-radiation, infectious, and neoplastic lumbosacral root disorders** when no more specific code applies |
| ✅ | **Always code the underlying etiology alongside [[G54.4]]** when identified — herpes zoster, diabetes, radiation, neoplasm |
| ✅ | **[[G54.4]] does not carry HCC weight** — but the etiology driving it often does; pursue etiology documentation for RAF capture |
| ✅ | **When urinary symptoms accompany [[G54.4]], always query and code neurogenic bladder separately** — [[N31.x]] is codeable, frequently missed, and may represent a CC |
| ✅ | **Every inpatient [[G54.4]] with bladder/bowel involvement is a CDI query opportunity** for cauda equina syndrome ([[G83.4]]) — the clinical threshold difference is the phrase in the physician's note |

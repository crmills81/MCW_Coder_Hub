# 🧬 ICD-10 CM M54.16 — Radiculopathy, Lumbar Region

> [!success] Billable Code Confirmed
> **ICD-10 CM [[M54.16]]** is a **5-character code**: **M54** is **[[dorsalgia]]**, the **4th character 1** is **[[radiculopathy]]**, and the **5th** character **6** is the lumbar region. No further characters exist below it, so it is fully billable as a principal or secondary diagnosis.<sup>1</sup>

> [!warning] Non-Billable Parent Codes
> **M54** (**Dorsalgia**) is a non-billable category header that groups all **back pain** and **radiculopathy** codes, so it is never reported on a claim. **M54.1** (**Radiculopathy**) is a non-billable subcategory that needs a **5th character** for the **spinal region**, and the region for this code is lumbar.<sup>1</sup>

> [!important] Clinical Context
> **ICD-10 CM [[M54.16]]** is for **nerve root irritation or compression in the lumbar spine** when the provider does not link it to disc disease or **[[spondylosis]]**. If a **disc disorder** or **[[spondylosis]]** is documented as the cause, **Excludes1** pushes you to **M51.1- or M47.2-** instead.<sup>1</sup>

> [!danger] Code Classification
> This is an **ICD-10-CM diagnosis code**, a sign/symptom-level **musculoskeletal code**, and not a procedure code. It supports medical necessity for procedures reported with **CPT** or **ICD-10-PCS**.

---

## 🔍 Code Description

**ICD-10 CM [[M54.16]]** reports **[[radiculopathy]] of the lumbar region, meaning dysfunction of a lumbar spinal nerve root that causes radiating pain, numbness, tingling or weakness into the lower extremity**. The inclusion terms under **M54.1 allow [[radiculitis]] NOS, lumbar [[neuritis]] NOS and [[radiculopathy]] NOS** to land here when no cause is documented.<sup>1</sup>

The **code** has no laterality, so right versus left is reported with **CPT modifiers** such as **[[-RT]]** and **[[-LT]]** on procedures. If the provider documents the **[[lumbosacral]]** region, report **[[M54.17]]** instead. If a **herniated** disc is documented as the cause, report **[[M51.16]]**.<sup>1</sup>

> [!example] Specificity: Region and Cause Drive Selection
> **[[Lumbar]] versus [[lumbosacral]] and disc-related versus non-disc [[radiculopathy]]** lead to different codes. Imaging-confirmed **disc [[herniation]]** with **[[radiculopathy]]** belongs in **[[M51.16]]** or **[[M51.17]]**, not **[[M54.16]]**, and payers reviewing **epidural injections** look at that documentation.

> [!tip]
> Look for the word "**cause**" in the assessment. If the provider writes "**lumbar [[radiculopathy]] due to L4-L5 disc herniation**," **Excludes1** removes **[[M54.16]]** from the claim.

## ✅ Includes

- **[[Radiculitis]] NOS:** Provider documents **radiculitis** of the lumbar nerve root without a stated cause, which indexes to **[[M54.16]]**.<sup>1</sup>
- **Lumbar [[neuritis]] NOS:** **Neuritis** or **radiculitis** described as lumbar NOS is included under this code.<sup>1</sup>
- **[[Radiculopathy]] NOS (lumbar):** "**Lumbar radiculopathy**" with no disc or **[[spondylosis]]** link reports here.<sup>1</sup>
- **Related specific codes:** Use **[[M54.17]]** for the **[[lumbosacral]]** region and **[[M54.15]]** for the thoracolumbar region.<sup>1</sup>

## ❌ Excludes

### Excludes 1
> **M79.2 ([[Neuralgia]] and [[neuritis]], unspecified):** **[[M79.2]]** is for unspecified nerve pain with no **[[radiculopathy]]**, so it cannot be reported with M54.16 for the same condition.<sup>1</sup>
> **M50.1- (Cervical disc disorder with [[radiculopathy]]):** This is a cervical-region parent category, so it is a different region and a different mechanism.<sup>1</sup>
> **M51.1- (Lumbar and other intervertebral disc disorders with [[radiculopathy]]):** Disc-related lumbar **radiculopathy** is captured by **[[M51.16]]** or **[[M51.17]]**, which includes the **radiculopathy**, so **[[M54.16]]** is not added.<sup>1</sup>
> **M47.2- (Other [[spondylosis]] with [[radiculopathy]]):** **[[Spondylosis]]-related lumbar [[radiculopathy]]** is captured by **[[M47.26]]**, which includes the **radiculopathy**, so **[[M54.16]]** is not reported with it.<sup>1</sup>

> [!danger]
> The most **common error** is reporting **[[M54.16]]** alongside **[[M51.16]]** or **[[M47.26]]** to "**show the radiculopathy**." Those combination codes already include the **[[radiculopathy]]**, and **Excludes1 blocks** the pair. Remove **[[M54.16]]** when a cause is documented.

### Excludes 2
> **M46.4- ([[Discitis]]):** **[[M46.46]]** (**[[discitis]], unspecified, lumbar region**) can be reported with **[[M54.16]]** if the provider documents both, because they are separate conditions. Add it only when the provider documents **[[discitis]]**; imaging alone is not enough.<sup>1</sup>
> **Current injury of the spine:** **[[Radiculopathy]]** from a current traumatic injury goes to the injury code by body region, which is outside the **M50-M54 dorsopathy block**. If the provider documents an acute injury, code the injury first.<sup>1</sup>

## 📋 Clinical Overview

### Non-Disc vs. Disc-Related vs. Lumbosacral Radiculopathy
**ICD-10 CM [[M54.16]]** is the default when a provider documents **lumbar [[radiculopathy]]** with no stated cause. Once the provider ties it to a **disc** or to the **[[lumbosacral]] region**, a different code applies. The table below shows the three codes you will compare most often.<sup>1</sup>

| **Feature** | **[[M54.16]]** | **Related [[M51.16]]** | **Related [[M54.17]]** |
|:---:|---|---|---|
| **Cause documented** | None, or not linked to disc or spondylosis. | Intervertebral disc disorder causing radiculopathy. | None documented, but region is lumbosacral. |
| **Region** | Lumbar. | Lumbar. | Lumbosacral (L5-S1 junction). |
| **Excludes1 relationship** | Excluded when disc disorder with radiculopathy is documented. | Used instead of M54.16 when disc disease is the cause. | Reported when the provider documents lumbosacral rather than lumbar. |

> [!important]
> **CDI trigger**: a query is warranted when a record says "**lumbar radiculopathy**" and the **MRI** shows a **[[herniation]]** or **foraminal [[stenosis]]** but the provider never links them. The answer decides between **[[M54.16]]** and the **disc** or **[[spondylosis]]** combination codes.

### Manifestations & Symptom Burden
- **Radiating pain:** Pain travels from the low back into the buttock or leg along the affected root's distribution.
- **Sensory changes:** Numbness or [[paresthesia]] follows a dermatomal pattern.
- **Motor weakness:** Weakness in the muscles served by the affected root, such as foot dorsiflexion for L5.
- **Reflex changes:** Decreased reflexes, such as a diminished knee jerk for L4 or an ankle jerk for S1.
- **Positional pain:** Pain worsens with sitting, coughing or sneezing, and straight leg raise may reproduce it.

> [!tip]
> **Pain, numbness or [[weakness]]** are integral to the **[[radiculopathy]]** and are not coded separately. Do not add a separate pain code for the same radiating symptoms.

## 🏥 MS-DRG Assignment

| **Role** | **MS-DRG** | **Title** |
|:---:|---|---|
| **Principal diagnosis** | **551** | Medical Back Problems with MCC |
| **Principal diagnosis** | **552** | Medical Back Problems without MCC |
| **Secondary diagnosis** | **N/A** | Not a CC or MCC |
| **MDC** | **08** | Musculoskeletal System and Connective Tissue |

**ICD-10 CM [[M54.16]]** as principal diagnosis falls into **MDC 08, DRG 551/552**, which splits on **MCC only**, so there is no CC tier.<sup>2</sup> If a **spinal procedure** is performed, the case moves to a **surgical DRG** and the diagnosis supports the procedure rather than driving the **DRG**. Before assigning **[[M54.16]]** as principal, confirm that no disc disease or **[[spondylosis]]** with **[[radiculopathy]]** is documented.

**NCD/LCD information:**
- **NCD:** I found no **NCD** that specifically governs **[[M54.16]].**
- **LCD:** The **Palmetto GBA (JM) Epidural Steroid Injections** for **Pain Management LCD (L38994)** and its **Billing and Coding article** apply to **North Carolina Part B**. **Epidural steroid injection** articles list the M54.1- **[[radiculopathy]]** codes, including **[[M54.16]]**, among the diagnoses supporting the service.<sup>3</sup><sup>4</sup>
- **Billing limits (per the ESI articles):** Only one spinal region may be treated per session, with a maximum of two levels per session. **Interlaminar and caudal ESIs** are not billed bilaterally, so **[[62323]]** is not a bilateral procedure. Bilateral **[[64483]]** and **[[64484]]** use modifier **[[-50]]** on one line.<sup>3</sup>
- **Review:** Verify the current **LCD version** and article diagnosis list before submission.

## 🛠️ Commonly Associated CPT Codes

- **[[62323]]** — Lumbar or sacral interlaminar epidural injection with imaging guidance. Imaging is included, and the Palmetto article treats it as not bilateral.<sup>3</sup>
- **[[62322]]** — Lumbar or sacral interlaminar epidural injection without imaging guidance. Use it only when no fluoroscopy or CT was used.
- **[[64483]]** — Transforaminal epidural injection, lumbar or sacral, single level, with imaging guidance. This is the primary code for the first level.<sup>3</sup>
- **[[64484]]** — Each additional level, add-on. Report it with [[64483]] only, within the two-level limit.<sup>3</sup>
- **[[72148]]** — MRI lumbar spine without contrast. Commonly used to look for a disc or [[spondylosis]] cause, and the result may change the dx from [[M54.16]].
- **[[95860]]** — Needle EMG, one extremity with or without paraspinals. Used to confirm [[radiculopathy]], and the documented diagnosis supports medical necessity.
- **[[99214]]** — Established patient office visit. Often reported with [[M54.16]] in the clinic setting when the evaluation is separate from a procedure.

### NCCI Bundling Considerations
**Imaging guidance** such as **fluoroscopy** or **CT** is included in **[[62323]]**, **[[64483]]** and **[[64484]]**, so do not bill **[[76000]]** or **[[77003]]** separately.<sup>5</sup> **[[Epidurography]]** is also generally bundled into the same-session injection. Always confirm current **NCCI PTP edits**.

## 🔬 ICD-10-PCS Crosswalk

- **3E0S33Z** — Introduction of anti-inflammatory into epidural space, percutaneous. This is the inpatient code for a steroid injection. It is assigned by facility coders, and professional billing uses CPT.
- **3E0S3BZ** — Introduction of local anesthetic into epidural space, percutaneous. Use it only when the record documents anesthetic delivery and facility policy requires it.
- **BR39ZZZ** — Magnetic resonance imaging of lumbar spine. Many facilities do not code imaging in the inpatient setting. Check your facility policy.

## 💊 Coding Scenarios and Examples

### Example 1
> **Clinical Scenario:**
> A patient with 8 weeks of right leg radicular pain and no imaging-confirmed disc cause has a right L5-S1 transforaminal steroid injection under fluoroscopy. The provider documents "right lumbar radiculopathy."

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[64483]] [[-RT]] | Single-level transforaminal lumbar injection with imaging, done on the right side only. |
| PDx | [[M54.16]] | Lumbar radiculopathy with no linked cause, so Excludes1 does not apply. |

> [!tip]
> Sequence the radiculopathy first because it supports the procedure. If the provider adds "due to disc herniation," switch to [[M51.16]] or [[M51.17]].

### Example 2
> **Clinical Scenario:**
> A patient has bilateral lumbar radiculopathy and receives bilateral transforaminal injections at L4-L5 and L5-S1. The note documents fluoroscopic guidance and two levels.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[64483]] [[-50]] | First level done on both sides, billed on one line with one unit. |
| CPT 2 | [[64484]] [[-50]] | Add-on for the second level, also bilateral, within the two-level limit. |
| PDx | [[M54.16]] | Lumbar radiculopathy supports both levels. |

> [!tip]
> Report the primary code first and the add-on second. A third level would exceed the LCD limit.

### Example 3
> **Clinical Scenario:**
> A patient is admitted for uncontrolled lumbar radicular pain that did not respond to outpatient management. MRI shows no disc herniation or stenosis. The provider documents "acute lumbar radiculopathy," treats with IV steroids and analgesics, and the patient is discharged on day 3 with no MCC.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99223]] None | Initial hospital care by the admitting provider, with no modifier needed. |
| PDx | [[M54.16]] | Lumbar radiculopathy with no linked cause, so it is the reason for admission. |

> [!tip]
> The facility claim groups to MS-DRG 552 with no MCC.<sup>2</sup> Because the MRI is negative, no disc or [[spondylosis]] code applies, and a CDI query is unnecessary.

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Reporting **[[M54.16]]** with **[[M51.16]]** or **[[M47.26]]** violates **Excludes1**; **Tips**: Use the combination code only when a cause is documented.
- **Pitfall 2**: Coding **[[sciatica]]** **M54.3-** alongside **[[M54.16]]** for the same leg pain; **Tips**: Documented **[[radiculopathy]]** is the more specific diagnosis, and **[[sciatica]]** should not be added for the same radiating symptoms.
- **Pitfall 3**: Coding from imaging alone; **Tips**: Radiculopathy must be documented by the treating provider, because a **radiology** report cannot establish the diagnosis.
- **Pitfall 4**: Billing **[[62323]]** with **[[-50]]** or with separate imaging; **Tips**: **Interlaminar ESIs** are not bilateral, and imaging is bundled. Use **[[64483]]** with **[[-50]]** for **bilateral transforaminal injections**.<sup>3</sup><sup>5</sup>
- **Pitfall 5**: Exceeding two levels or two regions in a session; **Tips**: The **Palmetto article limits** this, so check the policy before billing a third level.<sup>3</sup>
- **Pitfall 6**: Choosing **[[M54.16]]** when documentation says **[[lumbosacral]]**; **Tips**: Use **[[M54.17]]** for **L5-S1 root** involvement.

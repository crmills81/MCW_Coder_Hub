# 🧬 ICD-10 CM     Z89.9 — Acquired Absence of Limb, Unspecified

> [!success] Billable Code Confirmed
>
> **[ICD-10 CM] [[Z89.9]]** is a valid, billable **5-character ICD-10-CM status code** for FY2026. Character 1 (Z) designates a Z-code factor influencing health status; characters 2–3 (89) define the category as **acquired absence of limb**; character 4 (.) is a structural separator; and character 5 (9) specifies the "**unspecified**" subcategory — meaning neither the specific limb nor laterality is documented. This code is **POA Exempt** and does not require a Present on Admission indicator assignment.

> [!warning] Non-Billable Parent Code — Never Submit This
>
> - ❌ `Z89` — 3-character header — missing limb site specificity and laterality; non-billable category header only
>
> Always submit **[[Z89.9]]** (all 5 characters) when limb absence is documented but the specific limb and/or laterality is genuinely not documented or cannot be determined. When site and laterality ARE documented, a more specific sibling code is required.

> [!important] Clinical Context: Use Z89.9 Only When Specificity Is Truly Unavailable
>
> **ICD-10-CM [[Z89.9]]** is the "last resort" code within the Z89 category. **ICD-10-CM Official Guidelines** and **CDI** best practice require coders to assign the most specific code supported by documentation. If the medical record documents which limb or limb segment is absent — even from a prior operative report, nursing assessment, or physical exam note — the site-specific and laterality-specific Z89 code must be used instead. **Z89.9** is appropriate primarily when only "amputee" or "limb absence" is documented with no further detail available after CDI query.

> [!danger] Code Classification
>
> **ICD-10-CM Diagnosis / Status Code** — **wRVU**, assistant payable status, and global period fields are not applicable to **Z**-code diagnoses. For prosthetic device billing, refer to **HCPCS L-code** crosswalk. For surgical amputation procedures, refer to the **ICD-10-PCS** Crosswalk and **CPT** Procedural Crosswalk sections of this note.

## 🔍 Code Description

**ICD-10 CM [[Z89.9]]** classifies the **acquired absence of a limb, unspecified** — **meaning the patient has lost one or more limbs after birth due to surgical amputation or traumatic injury**, and the specific limb and level of absence is not documented. This code is used as a **status code** to indicate the patient's ongoing condition, not to describe an active disease process.

The underlying etiologies driving limb loss are varied and critically important to code separately: **diabetic peripheral vascular disease (most common cause of lower extremity amputation in the U.S.)**, **[[peripheral artery disease]], [[osteomyelitis]], malignant neoplasm, or [[traumatic amputation]]**. Because **Z89.9** carries no **HCC** weight on its own, always code the underlying cause — such as **[[E11.51]]**, **[[E11.52]]**, or **[[I70.261]]** — as an additional diagnosis to fully capture the patient's clinical complexity and support accurate risk adjustment.

> [!tip] Specificity First — Z89.9 Is the Last Resort
> **Payers**, **auditors**, and **CMS** expect the highest level of specificity supported by documentation. Before assigning **Z89.9**, review the entire record — operative reports, physical therapy notes, nursing assessments, and prior encounter records all may document the specific amputated limb and level. If documentation is genuinely absent, issue a **CDI** query before defaulting to **Z89.9**.

## ❌ Excludes

### Excludes 1 — Cannot Be Coded Simultaneously with Z89.9

| Code | Description | Note |
| ---- | ----------- | ---- |
| **M20–M21** | Acquired deformities of limbs | Mutually exclusive — **M20–M21** reflects structural deformity of a limb that is still present; **Z89.9** indicates the limb is absent entirely. These conditions cannot coexist. |
| **Q71–Q73** | Congenital absence of limbs | Mutually exclusive — Z89 is strictly for post-birth acquired loss. If the patient was born without a limb, code Q71–Q73, not **Z89.9**. |

> [!danger] Excludes 1 Violation Risk
> The most common **Excludes 1 error** involves confusing a congenital limb absence (**Q71–Q73**) with an acquired one (**Z89.9**), particularly in pediatric patients. Always confirm in the medical record whether the limb absence was present at birth or acquired after birth. Additionally, do not code **Z89.9** alongside M20–M21 (**acquired limb deformities**) — a limb cannot simultaneously be absent and deformed. Verify documentation carefully when both conditions appear in a patient's problem list.

> [!important] CDI Query Trigger — Unspecified Limb Absence
> If the medical record contains any reference to prior amputation without specifying the limb (**e.g., "patient is a bilateral below-knee amputee" would support [[Z89.519]] × 2, not Z89.9**), issue a CDI query: *"Documentation references prior amputation/limb loss. Can you please confirm which limb(s) and the level of amputation (e.g., below-knee, above-knee, transmetatarsal) to allow specific code assignment?"* This single query can upgrade **Z89.9** to a billable site-specific code and avoids audit exposure.

### Common Clinical Presentations and Associated Conditions

**Patients** presenting with acquired limb absence commonly carry significant **comorbidities** that must be separately coded:

- **Diabetic peripheral vascular disease:** Leading cause of lower extremity amputation in the U.S.; code underlying DM with PVD (**e.g., [[E11.51]], [[E11.52]]**) separately — these are HCC-mapped
- **Peripheral artery disease (PAD):** Code **[[I70.201]]–[[I70.269]]** series depending on laterality and presence of rest pain/**[[ulceration]]**/**[[gangrene]]**
- **[[Osteomyelitis]]:** Code **[[M86.671]]–[[M86.679]]** for chronic **[[osteomyelitis]]** of foot if the underlying infection drove the amputation
- **[[Phantom limb syndrome]]:** Code **[[G54.6]] (Phantom limb syndrome with pain)** or **[[G54.7]] (without pain)** if documented — these are separate reportable conditions
- **Stump complications:** Code **Z89.9** alongside T87.3x (**neuroma of amputation stump**), T87.4x (**infection of amputation stump**), or T87.5x (**[[necrosis]] of amputation stump**) when documented

> [!tip] Coding Manifestations
> Always code the documented etiology and manifestations to fully capture the patient's complexity. **Examples include:**
> - **[[E11.51]]** — Type 2 diabetes mellitus with diabetic peripheral angiopathy without gangrene
> - **[[E11.52]]** — Type 2 diabetes mellitus with diabetic peripheral angiopathy with gangrene
> - **[[G54.6]]** — Phantom limb syndrome with pain
> - **[[I70.261]]** — **[[Atherosclerosis]]** of native arteries of extremities with gangrene, right leg

## 💰 HCC Risk Adjustment (CMS-HCC v28)

| Field | Detail |
|-------|--------|
| **CMS-HCC Model Version** | v28 (2024–2025 Implementation) |
| **HCC Assignment** | ❌ Not HCC-Mapped |
| **HCC Category** | N/A |
| **RAF Coefficient** | N/A |

**[[Z89.9]]** does not map to an **HCC** category under **CMS-HCC v28** and does not directly contribute to a patient's Risk Adjustment Factor (**RAF**) score.

> [!caution] Capture the Etiology — That's Where the HCC Value Lives
> While **Z89.9** itself carries no **HCC** mapping, the conditions that caused the amputation almost always do. **Diabetic peripheral vascular disease** (**HCC 108 — Vascular Disease with Complications**), peripheral artery disease, and lower extremity ulceration all map to high-weight **HCC** categories. Every encounter with a **limb-absent** patient should include the underlying etiology codes to ensure complete and defensible risk adjustment capture. Failure to code the etiology is one of the most common **HCC** documentation gaps in the **amputee population**.

> [!warning] Sequencing Reality — Z89.9 Is Rarely the Principal Diagnosis
> In actual inpatient practice, **Z89.9** is almost never sequenced as the principal diagnosis. It serves as a secondary status code alongside a clinically active reason for admission (**stump complication, wound infection, rehabilitation, vascular intervention**). When **Z89.9** is incorrectly sequenced as principal, the resulting **DRG (555/556)** typically underrepresents case complexity and generates lower reimbursement than the clinically appropriate principal diagnosis would. Always sequence the active condition driving the admission as principal per **UHDDS** guidelines.

## 💊 Coding Scenarios and Examples

---

### Scenario 1 — Inpatient: Amputee Admitted for Stump Wound Infection

> **Clinical Vignette:** A 67-year-old male with a history of type 2 diabetes mellitus and peripheral vascular disease presents with a 5-day history of increasing pain, warmth, and purulent discharge from his right lower extremity residual limb. He underwent a right below-knee amputation (BKA) at this facility 4 months ago. On examination, the stump wound is dehisced with surrounding cellulitis. Blood cultures are pending. The admitting physician documents "infection of amputation stump, right leg" and "type 2 DM with diabetic peripheral angiopathy." The physician does NOT document which level the BKA was performed at beyond "below knee."

**Principal Diagnosis:**
- [[T87.41]] — Infection of amputation stump, right lower extremity *(Reason for admission — stump wound infection)*

**Secondary Diagnoses:**
- [[Z89.511]] — Acquired absence of right leg below knee *(amputation status; site/laterality documented — do NOT use Z89.9 here)*
- [[E11.51]] — Type 2 diabetes mellitus with diabetic peripheral angiopathy without gangrene *(comorbidity; HCC-mapped)*
- [[I70.261]] — Atherosclerosis of native arteries of extremities with gangrene, right leg *(if gangrene documented)*

**MS-DRG Assignment:** Principal of T87.41 + E11.51 comorbidity → groups based on wound/trauma DRG grouper; comorbidities may drive CC/MCC tier.

---

### Scenario 2 — Inpatient: Rehabilitation Admission, Limb Not Documented

> **Clinical Vignette:** A 54-year-old female is transferred from an acute care facility to inpatient rehabilitation following a recent surgical amputation. The transfer paperwork notes "amputee, rehab evaluation" but does not specify which limb was amputated or at what level. The rehabilitation physician documents "acquired absence of limb" without further specification on the admission H&P. CDI query is sent but the response from the outside facility physician is pending at time of discharge.

**Principal Diagnosis:**
- [[Z89.9]] — Acquired absence of limb, unspecified *(appropriate use — limb and level genuinely undocumented despite CDI query effort; document query attempt in the coding note)*

**Secondary Diagnoses:**
- [[Z74.09]] — Other reduced mobility *(functional limitation secondary to amputation)*
- [[Z87.39]] — Personal history of other musculoskeletal disorders *(as applicable)*

**MS-DRG Assignment:** Z89.9 as principal with rehabilitation procedures groups into MDC 08 or rehabilitation MDC depending on PCS codes present for therapy; verify with grouper. This case illustrates appropriate (if suboptimal) use of Z89.9 when specificity is genuinely unavailable.

---

### Scenario 3 — CDI Query: "Amputee" Documented Without Site

> **Clinical Vignette:** A 78-year-old male with known bilateral lower extremity vascular disease is admitted for management of a non-healing wound. The H&P problem list includes "bilateral amputee." Review of the surgical history tab shows a right below-knee amputation in 2018 and a left above-knee amputation in 2021, but the attending's note does not specify the levels. The coder must determine whether Z89.9 is appropriate or whether specificity can be established.

**Action / Outcome:**
The problem list entry "bilateral amputee" without level documentation would default to Z89.9 × 2 or a single Z89.9. However, the surgical history tab supports specific code assignment. Per ICD-10-CM guidelines, coders may reference the entire medical record — not just the attending's note — for status codes. The surgical history supports:

- **[[Z89.511]]** — Acquired absence of right leg below knee (from 2018 operative history)
- **[[Z89.612]]** — Acquired absence of left leg above knee (from 2021 operative history)

**Query Response:** A CDI query is still recommended to have the attending confirm: *"Your H&P references bilateral lower extremity amputation. Per surgical history, can you confirm right BKA (2018) and left AKA (2021)? Please document the specific level in your note."* Provider confirms in an addendum.

**Corrected ICD-10-CM Coding:**
- [[Z89.511]] — Acquired absence of right leg below knee *(upgraded from Z89.9)*
- [[Z89.612]] — Acquired absence of left leg above knee *(upgraded from Z89.9)*

## ⚠️ Coding Pitfalls and Tips

|     | Pitfall or Tip |
| --- | -------------- |
| ❌  | **Defaulting to [[Z89.9]] When Documentation Supports Specificity.** **[[Z89.9]]** is appropriate only when the specific limb and level are genuinely unavailable after CDI query. If any record element (surgical history, PT notes, nursing assessment, prior encounter) documents the limb and level, use the site-and-laterality-specific Z89 code. Routine use of **Z89.9** is an audit flag. |
| ❌  | **Confusing Acquired with Congenital Absence.** Z89 (including **[[Z89.9]]**) is exclusively for post-birth limb loss. Congenital limb absence is coded with **Q71–Q73** and is mutually exclusive (**Excludes 1**) with Z89. Always confirm with the record whether the absence is congenital or acquired. |
| ❌  | **Using Z89.9 as Principal Diagnosis When an Active Condition Is Present.** **[[Z89.9]]** is a status code reflecting a patient's baseline condition. When the admission is for a complication, wound, or procedure related to the amputation, the active condition (e.g., **[[T87.41]]** stump infection, **[[T87.50]]** stump necrosis) should be sequenced as principal per **UHDDS** guidelines. |
| ❌  | **Failing to Code the Underlying Etiology.** **Z89.9** alone gives no information about why the limb was amputated. The etiology — DM, PVD, trauma, malignancy — must be coded separately. Omitting etiology codes means missing HCC-mapped diagnoses and understating the patient's risk profile. |
| ✅  | **Always Query for Limb, Level, and Laterality.** A single focused CDI query asking for the specific limb(s) absent and the amputation level (**BKA, AKA, transmetatarsal, etc.**) converts **Z89.9** into a specific, lateralized Z89 code that accurately reflects the patient's status and supports medical necessity for prosthetic and rehabilitation services. |
| ✅  | **Code Stump Complications and Phantom Limb Separately.** Phantom limb pain (**[[G54.6]]**), stump infections (**[[T87.40]]**), stump neuromas (**[[T87.30]]**), and stump **[[necrosis]]** (**[[T87.50]]**) are separately reportable conditions — they are NOT included in Z89.9. Capture all documented manifestations. |
| ✅  | **Support DMEPOS and Prosthetic Claims with Z89 Codes.** When a patient is being fitted for a prosthetic device and a Z89 code is listed as the supporting diagnosis on the **HCPCS** L-code claim, ensure the Z89 code is as specific as possible (site, level, laterality) to match the prosthetic being prescribed. **Z89.9** is the least defensible diagnosis for prosthetic authorization and may trigger payer denials. |

# 🧬 ICD-10 CM T38.0X5A — Adverse Effect of Glucocorticoids, Initial Encounter
>

> [!success] Billable Code Confirmed — 7 Characters Complete
> **ICD-10 CM [[T38.0X5A]]** is a valid, billable 7-character **ICD-10-CM code** for
> FY2026. Structure: `T38` (**hormones**) + `.0` (**glucocorticoids**) + `X` (**placeholder**) + `5` (**adverse effect**) + `A` (initial encounter). Complete and current.
> 

> [!danger] 🚨 NEVER SEQUENCE T38.0X5A AS PRINCIPAL DIAGNOSIS
> **Per ICD-10 CM Official Guidelines Section I.C.19.e:**
> The condition caused by the adverse effect is coded **FIRST**.  **[[T38.0X5A]]** is **ALWAYS** an additional code — never the lead.  **Correct:** **[[H40.61X3]]** (principal) → **[[T38.0X5A]]** (additional) **Wrong:** **[[T38.0X5A]]** (principal) → **[[H40.61X3]]** (additional)
> 

> [!warning] 7th Character A vs. D — Know the Difference
> **A (THIS CODE)** = Active treatment — first diagnosis visit, surgical intervention, new treatment initiation
> **D ([[T38.0X5A]])** = Routine follow-up — ongoing monitoring visits ← most common long-term
> **S ([[T38.0X5S]])** = Sequela — late effect after steroid exposure ended

## 🔍 Code Description

**ICD-10 CM [[T38.0X5A]]** classifies the **adverse effect of glucocorticoids and synthetic analogues at the initial encounter** — the coding mechanism that identifies the drug responsible when a correctly prescribed and correctly administered **corticosteroid** causes a harmful reaction. This **T-code** is never a standalone diagnosis — it is the mandatory secondary code that answers the question *"what drug caused this?"* whenever a **steroid-induced** complication is documented.

Every **steroid-induced glaucoma** note in this vault — **[[H40.61X1]]** through **[[H40.63X2]]** — carries this code's companion **[[T38.0X5A]]** as a mandatory additional code on follow-up visits, and **[[T38.0X5A]]** at the initial diagnosis encounter. The **T-code** transforms those **glaucoma** codes from generic secondary **[[glaucoma]]** to **drug-caused** secondary **glaucoma** in the claim record — a distinction that matters for payer reporting, **pharmacovigilance**, quality metrics, and longitudinal documentation of the prescribing cascade.

## 🔑 The Most Critical Concept — Adverse Effect vs. Poisoning

This is among the highest-yield distinctions in all of **Chapter 19** and is tested on virtually every **AAPC** certification exam, including the CIC.

> [!important] The Three Categories — Know Them Cold

| Category | 6th Character | Clinical Meaning | Sequencing Rule |
|---|---|---|---|
| **Adverse Effect** | **5** ← T38.0X**5**A | Drug correctly prescribed + correctly administered → harmful reaction | Code the HARM first, T-code additional |
| **Poisoning** | **1-4** | Wrong drug / overdose / without prescription / in error | T-code (poisoning) IS the principal; code the harm additional |
| **Underdosing** | **6** | Patient took less than prescribed | T-code + code the condition that resulted or worsened |

> [!tip] The Core Adverse Effect Test — Two Questions
> Ask **BOTH** questions. Both must be **YES** for adverse effect:
> 1. **Was the drug correctly prescribed** by the provider? ✅
> 2. **Was it correctly administered** (right dose, right route, right frequency)? ✅
>
> If both are **YES** and harm resulted → **adverse effect (6th char "5")**
> If either is **NO** → consider poisoning categories instead
>
> For **steroid-induced glaucoma** and **[[cataracts]]**, the answer is virtually always **YES** to both — the **ophthalmologist**, **rheumatologist**, **pulmonologist**, or other prescriber ordered the steroid appropriately, and the patient took it as directed. The IOP rise and lens opacity are unwanted but not caused by misuse. → **[[T38.0X5A]]/D every time.**

### Poisoning vs. Adverse Effect — Side-by-Side

| Scenario                                                               | Category                | Code                                             |
| ---------------------------------------------------------------------- | ----------------------- | ------------------------------------------------ |
| Patient on prescribed prednisone → develops steroid glaucoma           | **Adverse Effect ✅**    | **[[H40.61X2]] + [[T38.0X5A]]/D**                    |
| Patient accidentally takes double dose of prednisone → IOP spikes      | Poisoning (accidental)  | **[[T38.0X1A]] (principal) + H40.61X_ (additional)** |
| Patient intentionally takes extra prednisone for euphoria → IOP spikes | Poisoning (intentional) | **[[T38.0X2A]] (principal) + complication**          |
| Patient on prescribed inhaled fluticasone → develops PSC cataract      | **Adverse Effect ✅**    | **[[H26.13]] + [[T38.0X5A]]/D**                      |
| Patient given intravitreal triamcinolone → IOP elevation → glaucoma    | **Adverse Effect ✅**    | **H40.61X_ + [[T38.0X5A]]/D**                        |
| Patient on prescribed dexamethasone → stops taking it too soon         | Underdosing             | **[[T38.0X6A]] + worsening condition code**          |

## 📊 7th Character — Initial vs. Subsequent vs. Sequela

The **7th character** is the most commonly misapplied element of T-codes in coding practice — and it is absolutely tested on the CIC.

> [!important] A ≠ "First Time Patient Is Seen" — It Means Active Treatment

| 7th Character | Code | Meaning | When to Use |
|---|---|---|---|
| **A** | **[[T38.0X5A]] ← THIS CODE** | **Active treatment phase** | **First encounter documenting the adverse effect; surgical intervention for the effect; initiation of new treatment regimen** |
| **D** | [[T38.0X5A]] | Routine aftercare / follow-up | All ongoing monitoring visits; medication adjustments during stable management |
| **S** | [[T38.0X5S]] | Sequela — late effect | Condition persists AFTER the steroid has been discontinued; the late consequence of the prior exposure |

### Real-World 7th Character Application — Steroid Glaucoma Timeline

| Visit               | Clinical Event                                                   | T-Code                                                                              |
| ------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------------------------------- |
| **Visit 1**         | Steroid-induced glaucoma first diagnosed — starting latanoprost  | **[[T38.0X5A]]** ← Initial encounter                                                |
| **Visit 2**         | 4-month follow-up — IOP check, HVF monitoring                    | **[[T38.0X5A]]** ← Subsequent                                                       |
| **Visit 3**         | SLT performed — active surgical intervention                     | **[[T38.0X5A]]** ← Initial encounter again (new active treatment)                   |
| **Visit 4**         | 3-month post-SLT check — IOP stable                              | **[[T38.0X5A]]** ← Subsequent                                                       |
| **Visit 5**         | [[trabeculectomy]] — filtering surgery                           | **[[T38.0X5A]]** ← Initial encounter (new active treatment)                         |
| **Visit 6-ongoing** | Annual monitoring — steroid stopped years ago, glaucoma persists | **[[T38.0X5S]]** ← Sequela (if steroid stopped) OR [[T38.0X5A]] if still on steroid |

> [!tip] T38.0X5A Can Appear Multiple Times in a Patient's History
> Unlike some codes that are assigned only once, **[[T38.0X5A]]** can re-appear every time the patient undergoes a **new active treatment** for the steroid-related condition. Each new surgical intervention (**SLT, [[trabeculectomy]], tube shunt**) or a NEW adverse effect diagnosis represents an initial encounter. The "**A**" is not burned once — it resets with each new active treatment episode.

## 💊 What Drugs Are Covered Under T38.0X5A?

**T38.0** (**glucocorticoids and synthetic analogues**) is a broad category covering systemic **AND** topical **AND** inhaled AND intravitreal corticosteroids. If it's a glucocorticoid — regardless of route — **[[T38.0X5A]]**/D applies.

### Glucocorticoids by Route — All Map to T38.0X5

| Drug                                             | Route                                  | Common Clinical Indication                          | Ophthalmic Complication Risk                          |
| ------------------------------------------------ | -------------------------------------- | --------------------------------------------------- | ----------------------------------------------------- |
| **Prednisone**                                   | Oral, systemic                         | **RA, lupus, IBD, asthma, PMR**                     | High — dose-dependent SIG + PSC                       |
| **Prednisolone**                                 | Oral / topical ophthalmic (Pred Forte) | **Post-op inflammation, [[uveitis]]**               | High — most common post-surgical SIG trigger          |
| **Methylprednisolone** (Medrol, Solu-Medrol)     | Oral, IV, IM                           | **MS flares, transplant, severe inflammation**      | High — IV bolus → acute IOP spike                     |
| **Dexamethasone** (Ozurdex implant)              | Intravitreal                           | **DME, RVO, uveitis**                               | Very high — 30-40% IOP spike with implant             |
| **Triamcinolone acetonide** (Kenalog, Triesence) | Intravitreal, sub-Tenon, periocular    | **DME, BRVO, CRVO, uveitis**                        | High — 20-30% IOP elevation                           |
| **Fluocinolone acetonide** (Iluvien, Retisert)   | Intravitreal implant                   | **Chronic DME, uveitis**                            | Very high — sustained release → sustained IOP risk    |
| **Fluticasone** (Flonase, Flovent)               | Inhaled, intranasal                    | **Asthma, allergic rhinitis**                       | Moderate — systemic absorption → bilateral            |
| **Budesonide** (Pulmicort, Rhinocort)            | Inhaled, intranasal                    | **Asthma, Crohn's disease**                         | Moderate — systemic absorption                        |
| **Mometasone** (Nasonex)                         | Intranasal                             | **Allergic rhinitis**                               | Low-moderate                                          |
| **Beclomethasone**                               | Inhaled                                | **Asthma**                                          | Moderate                                              |
| **Loteprednol** (Lotemax)                        | Topical ophthalmic                     | **Post-op inflammation, allergic conjunctivitis**   | Lower than prednisolone but still present             |
| **Hydrocortisone**                               | Topical skin, oral, IV                 | **Skin conditions, adrenal insufficiency**          | Low topical, higher systemic                          |
| **Betamethasone**                                | Topical skin, IM, epidural             | **Skin conditions, preterm labor, joint injection** | Moderate — joint/epidural route → systemic absorption |
| **Cortisone**                                    | Oral                                   | **Adrenal insufficiency**                           | Moderate                                              |

> [!note] Mineralocorticoids Are NOT T38.0
> **Fludrocortisone (Florinef)** and **aldosterone** are **mineralocorticoids** — they are classified under **T50.0** (**corticosteroids** and synthetic analogues — which covers **mineralocorticoids**). Do not assign [[T38.0X5A]] for fludrocortisone adverse effects.

## 📋 Sequencing Rules — ICD-10-CM Official Guidelines Section I.C.19.e

The **Official Guidelines** are explicit and **unambiguous** on adverse effect sequencing.

> [!important] The Official Rule — Memorize This for the CIC
> **"When coding an adverse effect of a drug that has been correctly prescribed and properly administered, assign the appropriate code for the nature of the adverse effect followed by the appropriate adverse effect code."**
>
> Translation:
> 1. **Code the condition first** — the nature/manifestation of the adverse effect (**e.g., [[H40.61X3]] — severe drug-induced [[glaucoma]]**)
> 2. **Code the T-code second** — the drug that caused it (**e.g., [[T38.0X5A]]**)
>
> This is the **OPPOSITE** of poisoning, where the T-code is principal.

### Sequencing — Adverse Effect vs. Poisoning Side-by-Side

| Scenario | Principal Code | Additional Code |
|---|---|---|
| **Adverse Effect** (correct drug/dose) | **[[H40.61X3]]** — the HARM | **[[T38.0X5A]]** — the DRUG |
| **Poisoning** (wrong drug/overdose) | **[[T38.0X1A]]** — the DRUG (poisoning) | **[[H40.61X3]]** — the HARM |

## 💊 Coding Scenarios

---

### Scenario 1 — First Diagnosis of Steroid-Induced Glaucoma (Use T38.0X5A ✅)

> **Clinical Vignette:** A 60-year-old male presents to ophthalmology for the first time for IOP concerns. He has been on oral prednisone 20 mg daily for 2 years for RA. IOP OD: 32 mmHg, OS: 30 mmHg. OCT RNFL: bilateral moderate thinning. HVF: bilateral moderate field loss (MD OD -8.2 dB, OS -7.6 dB). Physician: "New diagnosis — bilateral steroid-induced glaucoma, moderate stage. Starting latanoprost OU. Referred back in 6 weeks."

**ICD-10-CM:**
- [[H40.63X2]] — Bilateral, moderate *(Code First — the nature of the adverse effect)*
- **[[T38.0X5A]]** — Adverse effect of glucocorticoids, **initial encounter** ← FIRST DIAGNOSIS → USE A
- [[M06.9]] — Rheumatoid arthritis *(reason for prednisone prescription)*

---

### Scenario 2 — 4-Month Monitoring Visit (Use T38.0X5D ✅)

> **Clinical Vignette:** Same patient returns for 4-month monitoring. IOP stable on latanoprost OU. No new symptoms. HVF stable. Routine adjustment — add dorzolamide OS.

**ICD-10-CM:**
- [[H40.63X2]] — Bilateral, moderate *(stable)*
- **[[T38.0X5A]]** — Adverse effect of glucocorticoids, **subsequent encounter** ← FOLLOW-UP → USE D
- [[M06.9]] — RA

---

### Scenario 3 — SLT Performed (T38.0X5A Again — New Active Treatment)

> **Clinical Vignette:** Same patient 1 year later. IOP not at target OS despite three medications. Decision made to perform SLT OS. SLT performed today.

**ICD-10-CM:**
- [[H40.62X2]] — Left eye, moderate *(targeted eye for procedure)*
- **[[T38.0X5A]]** — Adverse effect of glucocorticoids, **initial encounter** ← NEW ACTIVE TREATMENT → USE A AGAIN
- [[M06.9]] — RA

---

### Scenario 4 — Steroid Stopped, Glaucoma Persists (T38.0X5S — Sequela)

> **Clinical Vignette:** A 68-year-old female had steroid-induced glaucoma from 3-year prednisone course for polymyalgia rheumatica. Prednisone discontinued 2 years ago. Glaucoma persists — requires ongoing treatment. IOP controlled on latanoprost. Annual follow-up.

**ICD-10-CM:**
- [[H40.61X2]] — Right eye, moderate *(persistent glaucoma)*
- **[[T38.0X5S]]** — Adverse effect of **glucocorticoids**, **sequela** ← STEROID STOPPED, EFFECT REMAINS → USE S
- [[Z87.39]] — Personal history of other endocrine, nutritional, and metabolic diseases *(or PMR history code)*

> [!tip] T38.0X5S — The Forgotten Seventh Character
> **Sequela** (S) is the most underused 7th character in adverse effect coding. When a steroid is no longer being taken but its harmful consequence (**[[glaucoma]], [[cataract]], osteoporosis**) persists, **[[T38.0X5S]]** is the accurate code — not [[T38.0X5A]]. The drug is gone; the damage remains. The T-code with S documents the causal history while acknowledging the condition is now a late effect of prior exposure.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never sequence T38.0X5A as principal diagnosis** — the condition caused is ALWAYS listed first; T-code is additional only |
| ❌ | **Never use T38.0X5A for poisoning scenarios** — wrong drug, overdose, or incorrectly administered → use T38.0X1A-T38.0X4A instead |
| ❌ | **Never confuse "initial encounter" with "first visit"** — A means active treatment phase, not literally the patient's first appointment |
| ❌ | **Never use T38.0X5A at routine monitoring visits** — follow-up → T38.0X5D |
| ❌ | **Never apply T38.0 to mineralocorticoids** — fludrocortisone → T50.0x series |
| ✅ | **T38.0X5A at every NEW active treatment episode** — first diagnosis, surgery, new regimen initiation |
| ✅ | **[[T38.0X5A]] for the long haul** — the vast majority of glaucoma monitoring visits over a patient's lifetime use D |
| ✅ | **T38.0X5S when the steroid is gone but the damage remains** — sequela coding is accurate and more specific than D at that point |
| ✅ | **One T-code covers all affected organs** — same [[T38.0X5A]] covers both the glaucoma AND the PSC cataract when caused by the same steroid on the same claim |
| ✅ | **Covers all routes** — oral, IV, intravitreal, sub-Tenon, inhaled, intranasal, topical — any glucocorticoid regardless of route |
| ✅ | **Adverse effect vs. poisoning sequencing is CIC exam gold** — adverse effect = harm first, T-code second; poisoning = T-code first, harm second |

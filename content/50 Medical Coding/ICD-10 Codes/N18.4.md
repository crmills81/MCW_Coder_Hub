# ICD-10-CM:  N18.4  - Chronic Kidney Disease, Stage 4 (Severe)
>
## Code Description

**[[N18.4]]** is a billable/specific ICD-10-CM diagnosis code used to identify **Chronic Kidney Disease, Stage 4 (Severe)** for reimbursement and clinical documentation purposes. This code became effective October 1, 2015, and remains active for the fiscal year October 1, 2025 through September 30, 2026.

### Clinical Definition

Chronic Kidney Disease Stage 4 represents **severe kidney damage** with significantly reduced kidney function. At this stage, the glomerular filtration rate (GFR) ranges from **15-29 mL/min/1.73m²**. The kidneys are severely damaged and approaching kidney failure, requiring close monitoring and preparation for potential renal replacement therapy.

## Official Coding Guidelines

### Code First Requirements

When coding [[N18.4]], the following conditions must be coded **FIRST** if documented:

| Condition | ICD-10-CM Code |
|-----------|----------------|
| Diabetic chronic kidney disease | [[E08.22]], [[E09.22]], [[E10.22]], [[E11.22]], [[E13.22]] |
| Hypertensive chronic kidney disease | I12.-, I13.- |

### Use Additional Code Requirements

The following codes should be added when applicable:

| Condition | ICD-10-CM Code |
|-----------|----------------|
| Associated cachexia | [[E88.A]] |
| Kidney transplant status | [[Z94.0]] |
| Stage of CKD (when coding hypertensive CKD) | [[N18.1]]-[[N18.4]], [[N18.9]] |

### Important Coding Notes

1. **Always code the stage** of CKD when documented by the provider
2. **Do not code CKD stage** based solely on GFR results without provider documentation
3. **If both CKD stage and ESRD** are documented, assign code [[N18.6]] only
4. **CKD Stage 4** with dialysis dependence should be coded as [[N18.6]] (ESRD), not [[N18.4]]

### V28 Model Changes (2026)

The CMS-HCC Model V28 fully implemented in 2026 includes **115 HCC categories** to better stratify conditions by severity. Key changes affecting [[N18.4]]:

- **More granular CKD staging** compared to V24 model
- **Higher risk scores** for documented Stage 4 CKD vs. unspecified CKD
- **Requires annual recapture** for Medicare Advantage risk adjustment
- **eGFR documentation** strongly recommended to support stage assignment 

### HCC Coding Best Practices

1. **Document eGFR values** to support CKD stage assignment
2. **Capture CKD stage annually** for risk adjustment purposes
3. **Link CKD to underlying etiology** (diabetes, hypertension, etc.)
4. **Avoid unspecified CKD** ([[N18.9]]) when stage is known

## Clinical Documentation Requirements

### Required Documentation Elements

To support [[N18.4]], the following must be documented:

1. **Explicit CKD Stage 4 diagnosis** by treating provider
2. **eGFR values** supporting stage assignment (15-29 mL/min/1.73m²)
3. **Duration** of kidney disease (chronic = 3+ months)
4. **Underlying etiology** ([[diabetes]], hypertension, glomerulonephritis, etc.)
5. **Complications** related to CKD ([[anemia]], bone disease, electrolyte abnormalities)
6. **Treatment plan** including medication management and monitoring

### Laboratory Value Support

| Parameter | Stage 4 Range |
|-----------|---------------|
| **eGFR** | 15-29 mL/min/1.73m² |
| **Serum Creatinine** | Elevated (varies by patient) |
| **BUN** | Elevated |
| **Hemoglobin** | May show anemia of CKD |
| **Phosphorus** | Often elevated |
| **Calcium** | May be low or normal |
| **PTH** | Often elevated (secondary [[hyperparathyroidism]]) |

### Documentation Tips

- **Avoid** coding CKD stage based on lab values alone without provider diagnosis 
- **Query provider** if stage is not explicitly documented
- **Link CKD** to diabetes/hypertension when clinically related
- **Document complications** for complete risk adjustment capture

## Common Coding Errors to Avoid

| Error | Correct Approach |
|-------|------------------|
| Coding [[N18.4]] when patient is on chronic dialysis | Code [[N18.6]] (ESRD) instead |
| Assigning stage based on GFR without provider documentation | Query provider for explicit stage documentation |
| Coding [[N18.9]] when stage is documented | Use specific stage code ([[N18.1]]-[[N18.6]]) |
| Missing underlying etiology (diabetes/hypertension) | Code underlying condition first per guidelines |
| Failing to capture CKD annually for HCC | Document and code CKD stage at least once per calendar year |
| Coding both [[N18.4]] and [[N18.6]] together | Only code [[N18.6]] if ESRD is present |

## Clinical Pearls

1. **Stage 4 CKD** represents severe kidney damage with GFR 15-29 mL/min/1.73m²
2. **Nephrology referral** is strongly recommended at Stage 4 for transplant/dialysis planning
3. **Medication adjustments** are often necessary due to reduced kidney function
4. **Cardiovascular risk** is significantly elevated in Stage 4 CKD
5. **Annual HCC capture** is essential for Medicare Advantage risk adjustment
6. **Provider documentation** of stage is required; cannot code from labs alone
7. **Transition to ESRD** ([[N18.6]]) occurs when dialysis begins or transplant is needed

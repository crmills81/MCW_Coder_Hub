# 🧬 ICD-10 CM S61.401A — Unspecified Open Wound of Right Hand, Initial Encounter

> [!success] Billable Code Confirmed
> **ICD-10 CM [[S61.401A]]** is a **7-character code**: **S61** is the category, .**4** is the hand, **0** is the unspecified wound type, **1** is the right side, and **A** is the initial encounter. All 7 characters are present, so it is valid for claim submission.<sup>1,2</sup>

> [!warning] Non-Billable Parent Codes
> **S61** (**Open wound of wrist, hand and fingers**) is a category header. **S61.40** (**Unspecified open wound of hand**) and **S61.401** (**Unspecified open wound of right hand**) lack the 7th character for the episode of care.<sup>1,2</sup>

> [!important] Clinical Context
> This code is for **a right-hand open wound** when the type (**[[laceration]], puncture, bite**) is not documented. If the provider specifies the type, use the more specific **S61.41-, S61.42-, S61.43-, S61.44- or S61.45-** code instead.<sup>2</sup>

> [!danger] Code Classification
> This is an **ICD-10-CM diagnosis code** from the injury chapter, not a procedure code. The 7th character "**A**" means active treatment, not "**first visit**."

---

## 🔍 Code Description
**ICD-10 CM [[S61.401A]]** reports an **open wound of the right hand** when the documentation does not identify a wound type. An **open wound breaks the skin**. Wound type, such as **laceration**, **puncture** or **open bite**, is normally specified, and **S61.4** splits those types out (**[[S61.411A]]**, **[[S61.431A]]**, **[[S61.451A]]**).<sup>2,3</sup> The 7th character "A" is used while the patient receives active treatment, such as surgical repair, ED evaluation or a new provider's evaluation and treatment.<sup>4</sup>

The "**Code also**" note at category **S61** tells you to add any associated wound infection. **Open fractures** of the hand go to **S62.-** with **7th** character **B** (**Excludes1**), and **traumatic amputations** go to **S68.-**.<sup>2</sup> Related unspecified codes are **[[S61.402A]]** (**left hand**) and **[[S61.409A]]** (**unspecified hand**).

> [!example] Specificity Over "Unspecified"
> Use **[[S61.401A]]** only when the wound type is truly not documented. A provider's note that says "**[[laceration]]**" or "**puncture wound**" supports a more specific code, which also gives cleaner data and fewer payer edits.<sup>2</sup>

> [!tip]
> **Query** the provider for wound type (**laceration, puncture, bite**) and whether a **foreign body** is present. These details change both the code and the repair **CPT** selection.

## ✅ Includes
- **Open wound of right hand NOS**: A wound of the right hand with no wound type documented.<sup>2</sup>
- **Right hand wound, type not documented**: Use this code when the **ED** or **H&P** documents only "open wound, right hand."<sup>2</sup>
- **Traumatic open wound, type unspecified**: Applies when the mechanism is documented but not the wound type.<sup>2</sup>

---

## ❌ Excludes

### Excludes 1
> - **S62.- with 7th character B**: **Open fracture of wrist, hand and finger**. A wound over a fracture is classified as an open fracture and cannot be coded with the open wound code.<sup>2</sup>
> - **S68.-**: **Traumatic [[amputation]] of wrist and hand**. The amputation code captures the wound, so **[[S61.401A]]** is not added.<sup>2</sup>

> [!danger]
> The most common error is reporting **[[S61.401A]]** with an **open fracture code** (**S62.-B**) for the same injury. When the **hand wound** communicates with a fracture, only the open fracture code is reported.

### Excludes 2
> - **T20-T32** **Burns and corrosions**: A hand burn and a separate open wound may both be coded if both are documented.<sup>3</sup>
> - **T33-T34** **Frostbite**: Frostbite and a separate traumatic wound can be coded together when documented separately.<sup>3</sup>
> - **T63.4-** **Venomous insect bite or sting**: Code both when a sting and a separate wound are both documented.<sup>3</sup>

## 📋 Clinical Overview

### Wound Type Drives Code Selection
The key distinction is whether the provider documents the **wound type**. Unspecified (**S61.40-**) is the fallback. **[[Laceration]]**, **puncture** and **bite** each have their own subcategories, and a foreign body changes the code again.

| **Feature** | **[[S61.401A]]** | **Related [[S61.411A]]** | **Related [[S61.451A]]** |
|:---:|---|---|---|
| **Documentation** | "Open wound" of right hand, no type given. | Laceration with no foreign body in the right hand. | Open bite (animal or human) of the right hand. |
| **Infection risk** | Depends on mechanism, not captured by the code. | Lower if clean, higher if contaminated. | High risk (e.g., Pasteurella, Eikenella). |
| **Typical repair CPT** | Selected by length and layer of repair. | Same, based on length and layer. | Often irrigation, debridement and delayed closure. |

> [!important]
> **CDI trigger**: "**Open wound**" or "**hand wound**" without a type, depth or mechanism should prompt a query. Also ask about **foreign body, tendon, nerve or bone involvement**, which would change the code or add codes.

### Manifestations & Symptom Burden
- **Bleeding and pain**: Local pain and bleeding at the wound site.<sup>5</sup>
- **Functional loss**: Reduced grip or finger motion if deeper structures are involved.<sup>5</sup>
- **Infection signs**: Redness, warmth or drainage, reported with the "Code also" wound infection code.<sup>2</sup>
- **Neurovascular changes**: Numbness or poor **[[perfusion]]** that may prompt a hand surgery consult.<sup>5</sup>

> [!tip]
> Do **not** code pain or bleeding separately when they are integral to the wound. Add an **external cause code** (**e.g., W26.- for contact with knife**) when documented.

**ICD-10 CM [[S61.401A]]** is an acute injury code and does **not** map to a payment **HCC**. **Higher-risk** conditions (**e.g., open fracture, tendon injury**) are classified elsewhere. Do **not** report it as a chronic condition.

## 🏥 MS-DRG Assignment
| **Field** | **Value** |
|:---:|---|
| **MDC** | **MDC 21** — Injuries, Poisonings and Toxic Effects of Drugs |
| **MS-DRG (with MCC)** | **604** — Trauma to the Skin, Subcutaneous Tissue and Breast with MCC |
| **MS-DRG (without MCC)** | **605** — Trauma to the Skin, Subcutaneous Tissue and Breast without MCC |
| **CC/MCC status as secondary dx** | Non-CC |

As a principal diagnosis, **[[S61.401A]]** groups to **MS-DRGs 604-605** (**verify against the FY2027 v44 definitions manual**).<sup>6,7</sup> The tier depends on secondary **MCCs**. Isolated hand wounds are rarely the sole reason for **inpatient admission**, so confirm the principal diagnosis against the circumstances of admission. Surgical procedures such as **repair** or **grafting** can change the **DRG**.
- **NCD/LCD**: No **NCD** applies to this diagnosis. Check your **MAC**'s **LCDs** for **[[debridement]]** (e.g., **[[11042]]**) and wound-care services for covered diagnosis lists.

## 🛠️ Commonly Associated CPT Codes
- **[[12002]]**: Simple repair of superficial wounds of the scalp, neck, axillae, external genitalia, trunk and/or extremities (including hands and feet), 2.6 cm to 7.5 cm. Total wound length is based on the documented repair.
- **[[12001]]**: Same simple repair family, 2.5 cm or less. Report only when the wound is repaired, not just cleaned.
- **[[12032]]**: Intermediate (layered) repair of wounds of the scalp, axillae, trunk and/or extremities (excluding hands and feet), 2.6 cm to 7.5 cm. Hand wounds use the hand-specific rules, so verify the correct code family for your documentation.
- **[[11042]]**: Debridement, subcutaneous tissue, first 20 sq cm or less. Cannot be reported together with a repair of the same wound without documentation of separate work.
- **[[99283]]**: Emergency department visit, moderate medical decision making. Append [[-25]] when a procedure is also performed.
- **[[99213]]**: Established office E/M, low MDM, for wound recheck. Often included in a global repair period.
- **[[90714]]**: Tetanus and diphtheria toxoids (Td) vaccine, 7 years or older, preservative free. Report with the appropriate administration code.

### NCCI Bundling Considerations
**Wound repair codes (120xx-130xx)** are subject to **NCCI edits** with debridement (**[[11042]]**) and wound exploration. Debridement of the same wound is generally bundled into the repair unless it is documented as a separate, distinct service. Check the current **NCCI PTP edits** before using **[[-59]]**.<sup>8</sup>

## 🔬 ICD-10-PCS Crosswalk
**ICD-10 CM [[S61.401A]]** is a diagnosis, so there is no direct **ICD-10-PCS crosswalk**. For inpatient stays, the **PCS code** is built from the operative note: root operation (**such as Repair, Excision or Drainage**), body part and approach. I did not list specific PCS codes because I could not verify them. Confirm in your **FY2027 PCS tables** or **encoder**.

## 💊 Coding Scenarios and Examples

<br>

### Example 1
> **Clinical Scenario:**
> A patient comes to the ED after cutting the right hand on a broken glass. The ED note says "open wound, right hand, 3 cm" with no wound type documented. The wound is cleaned and closed with simple sutures.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[12002]]-[[-RT]] | Simple repair, 2.6-7.5 cm, right side. |
| PDx | [[S61.401A]] | Wound type not documented, so unspecified applies. |

> [!tip]
> Query the provider to document "laceration" so that [[S61.411A]] can be reported instead.
> CDI: Also ask about foreign body (glass), which would change the code to [[S61.421A]].

### Example 2
> **Clinical Scenario:**
> A patient is seen in the ED for an open wound of the right hand and has a significant evaluation of a separate, unrelated complaint. A simple repair is performed.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99283]]-[[-25]] | Significant, separately identifiable E/M. |
| CPT 2 | [[12001]] | Simple repair, 2.5 cm or less. |
| PDx | [[S61.401A]] | Initial active treatment of the right hand wound. |

> [!tip]
> Link the diagnoses to the correct line so the E/M carries the unrelated complaint code, not [[S61.401A]].
> CDI: The note must show the E/M was beyond the usual pre-repair work.

### Example 3
> **Clinical Scenario:**
> A patient returns 10 days after repair of a right hand wound for a suture removal and wound check. The wound is healing without complications.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99213]]-[[-24]] | Only if the visit is unrelated to the repair; routine suture removal is part of the global package. |
| PDx | [[S61.401D]] | Subsequent encounter during routine healing. |

> [!tip]
> Routine follow-up is usually included in the global period and not separately billed. Use "D" for the 7th character during healing and recovery.
> CDI: Confirm that the visit is a routine follow-up and not a new problem.

## ⚠️ Coding Pitfalls and Tips
- **Pitfall 1**: Using **[[S61.401A]]** with an open fracture code (**S62.-B**) for the same injury. **Tips**: **Excludes1** applies, so report the **open fracture code only**.
- **Pitfall 2**: Defaulting to **[[S61.401A]]** when the note says "**[[laceration]]**." **Tips**: Choose **[[S61.411A]]** or **[[S61.421A]]** based on documentation.
- **Pitfall 3**: Using "**A**" for every follow-up. **Tips**: Use **[[S61.401D]]** after active treatment ends and the wound is healing.
- **Pitfall 4**: Missing the **wound infectio**n code. **Tips**: Follow the "**Code also**" note and add the **[[infection]]** code when documented.
- **Pitfall 5**: Billing both a repair and a **[[debridement]]** of the same wound. **Tips**: Check **NCCI edit**s and require documented separate work before using **[[-59]]**.
- **Pitfall 6**: Skipping the external cause code. **Tips**: Add **W/X/Y external cause codes** when documented, because many payers and trauma registries expect them.

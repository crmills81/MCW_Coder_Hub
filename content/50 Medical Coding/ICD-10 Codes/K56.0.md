# 🧬 ICD-10-CM K56.0 — Paralytic Ileus

> [!success] Billable Code Confirmed — 5 Characters Complete
> **ICD-10 CM [[K56.0]]** is a valid, billable 5-character ICD-10-CM code for
> FY2025/2026. Complete as written —
> no additional characters required or available. Parent code K56
> is non-billable; **K56.0** itself is fully specific and billable.

> [!danger] Excludes1 — Three Codes That Are NOT K56.0
> **ICD-10 CM [[K56.0]]** Excludes1: 
> - **[[K56.3]]** — Gallstone ileus *(mechanical — stone in bowel lumen)*
> - **[[K56.7]]** — Ileus NOS *(unspecified — query for type first)*
> - **K56.69-** — Obstructive ileus NOS *(mechanical obstruction)*
>
> **ICD-10 CM K56.0** is **functional/paralytic** (no peristalsis, no mechanical cause).
> These excluded codes are **mechanical** obstructions — different etiology,
> different code. Know the functional vs. mechanical distinction cold.

> [!warning] Post-Procedural Ileus → K91.3-, NOT K56.0
> If the ileus is documented as a **complication of a specific procedure**
> → **K91.3-** (Postprocedural intestinal obstruction) applies instead
> of K56.0. Query when documentation says "**post-op ileus**" —
> the distinction matters for DRG assignment and complication flagging.

> [!success] 🚨 FY2024 Coding Clinic Update — Excludes1 Removed
> The K56 Excludes1 that previously blocked coding bowel obstruction
> alongside an underlying causative condition was **removed effective
> October 1, 2023**.  The 2017 Coding Clinic advice (do **NOT**
> code bowel obstruction with an underlying cause) is **no longer valid**.
> Coders MAY now code K56.0 when documented, even alongside a
> documented causative condition. Know this reversal for CIC.

## 🔍 Code Description

**ICD-10 CM [[K56.0]]** classifies **paralytic ileus** — a failure of intestinal peristalsis **(bowel motility**) in the absence of a mechanical obstruction, resulting in functional intestinal obstruction due to [[neuromuscular]] inhibition of the bowel. The bowel is physically open — there is no foreign body, adhesion, hernia, or luminal narrowing blocking the lumen. Instead, the **smooth muscle of the intestinal wall has lost its coordinated contractile function, causing bowel contents to stagnate, gas and fluid to accumulate, and the abdomen to distend**.

Also called **adynamic ileus**, **functional ileus**, or **neurogenic ileus**, K56.0 is one of the most common diagnoses encountered in the inpatient setting — particularly in the post-operative period, in critically ill patients, and in the setting of metabolic derangements, peritonitis, and opioid use. The key clinical and coding distinction is always **functional (K56.0) vs. mechanical (K56.1-K56.69-)** — the treatment, urgency, and coding are fundamentally different.

## 🔑 Paralytic vs. Mechanical Obstruction — The Core Distinction

> [!important] Functional vs. Mechanical — Know This for CIC

| Feature | **[[K56.0]] Paralytic Ileus** | Mechanical Obstruction (K56.1-K56.69-) |
|---|---|---|
| **Mechanism** | Neuromuscular failure — no peristalsis | Physical blockage of lumen |
| **Bowel lumen** | Open — no anatomical block | Blocked — adhesion, hernia, volvulus, etc. |
| **Bowel sounds** | ❌ Absent or markedly diminished | Variable — high-pitched, rushing early; absent late |
| **X-ray/CT pattern** | Diffuse gas throughout small + large bowel; no transition point | Dilated loops proximal to obstruction; transition point present |
| **Transition point on imaging** | ❌ Absent | ✅ Present — identifies level of blockage |
| **Causes** | Post-op, opioids, peritonitis, metabolic, retroperitoneal | Adhesions, hernia, volvulus, intussusception, malignancy |
| **Treatment** | Conservative — NPO, NG tube, treat underlying cause | Often surgical — relieve mechanical blockage |
| **ICD-10-CM Code** | **[[K56.0]]** | [[K56.1]] intussusception; [[K56.2]] volvulus; K56.5x adhesions; [[K56.69-]] other |

> [!tip] K56.0 vs. K56.7 — Paralytic Ileus vs. Ileus NOS
> **ICD-10 CM [[K56.0]]** = physician specifically documents "**paralytic ileus,**" "**adynamic ileus**," or "functional ileus" — the type is known and specified.
> **ICD-10 CM [[K56.7]]** = physician documents "[[ileus]]" without specifying type — NOS (not otherwise specified). **K56.7** is also an **Excludes1** from K56.0, confirming these are distinct codes. Always query to resolve **K56.7** → **K56.0** when clinical context supports paralytic etiology (post-op, opioids, metabolic, no mechanical cause on imaging).

## 🔬 Etiology — Common Causes of Paralytic Ileus

### Causes Frequently Documented Alongside K56.0

| Cause | Additional Code | Clinical Context |
|---|---|---|
| **Post-operative (non-procedural complication)** | Surgery/procedure codes | Most common cause — normal temporary post-op bowel dysfunction |
| **Peritonitis** | K65.x | Intra-abdominal infection inhibits peristalsis reflexively |
| **Opioid use/toxicity** | F11.x, [[T40.2X5A]] | Opioid-induced constipation → ileus → K56.0 |
| **Hypokalemia** | [[E87.6]] | Electrolyte derangement — potassium essential for smooth muscle function |
| **Hypomagnesemia** | [[E83.42]] | Electrolyte derangement — magnesium depletion |
| **Hypothyroidism** | [[E03.9]] | Systemic myxedema → bowel dysmotility |
| **Retroperitoneal hematoma/hemorrhage** | M54.x, S37.x | Retroperitoneal irritation — reflex ileus |
| **Spinal cord injury** | S14.x, S24.x, S34.x | Neurogenic ileus — loss of autonomic bowel regulation |
| **Sepsis** | A41.x | Systemic inflammatory response → gut dysmotility |
| **Pneumonia** | J18.x | Lower lobe pneumonia — reflex ileus via diaphragmatic/phrenic irritation |
| **Pancreatitis** | K85.x | Adjacent inflammation → paralytic response |
| **Diabetic autonomic neuropathy** | [[E11.43]] | Chronic neurogenic dysmotility |
| **Uremia / renal failure** | N17-N19 | Metabolic derangement |
| **Anticholinergic medications** | [[T44.3X5A]] | Drug-induced decreased bowel motility |

> [!important] FY2024 Update — Code K56.0 WITH the Underlying Cause
> Prior to October 1, 2023, a Coding Clinic from 2017 advised coders NOT to assign a bowel obstruction code when a specific cause was documented — e.g., if the physician wrote "**ileus due to peritonitis**," you would only code the peritonitis. 
>
> **Effective FY2024, that Excludes1 was removed and the 2017 advice is REVERSED.** You may now — and SHOULD — code **both** the paralytic ileus ([[K56.0]]) AND the documented underlying cause when both are present. Example:
>
> - Paralytic ileus due to peritonitis → **[[K56.0]] + K65.x** ✅ Code both
> - Paralytic ileus due to hypokalemia → **[[K56.0]] + [[E87.6]]** ✅ Code both
> - Paralytic ileus due to opioid use → **[[K56.0]] + F11.x** ✅ Code both
>
> This is a **high-yield CIC exam update** — pre-2024 and post-2024 logic are directly opposite. Know the cutoff: October 1, 2023.

## 🏥 K56.0 vs. K91.3- — The Post-Op Ileus Distinction

> [!danger] This Is the Most Common Coding Error With K56.0

| Scenario | Correct Code | Why |
|---|---|---|
| Ileus following abdominal surgery — documented as complication of the procedure | **[[K91.3-]]** Postprocedural intestinal obstruction | K56 Excludes1: postprocedural intestinal obstruction (K91.3-) [web:316] — procedure-specific complication |
| Ileus due to peritonitis (no specific procedure) | **[[K56.0]]** | Non-procedural cause — K56.0 is correct |
| Ileus due to hypokalemia in a non-surgical patient | **[[K56.0]]** | Non-procedural metabolic cause |
| Ileus documented in a post-surgical patient but attributed to opioid medications, NOT the surgery itself | **[[K56.0]]** | Cause is opioids, not the procedure |
| Paralytic ileus in a medical (non-surgical) inpatient | **[[K56.0]]** | No surgical procedure → K91.3- does not apply |

### K91.3- Family — Postprocedural Intestinal Obstruction

| Code | Description |
|---|---|
| [[K91.30]] | Postprocedural intestinal obstruction, unspec partial vs complete |
| [[K91.31]] | Postprocedural partial intestinal obstruction |
| [[K91.32]] | Postprocedural complete intestinal obstruction |

> [!tip] The Query Question When Documentation Says "Post-Op Ileus"
> Ask: **"Is this ileus a direct complication of the surgical procedure, or is it due to another cause (opioids, metabolic, peritonitis) that happens to be occurring in the post-operative period?"**
> Procedure caused it → K91.3-
> Something else caused it (in a post-op patient) → [[K56.0]]
> When ambiguous → **query the physician** before assigning K91.3- vs. K56.0.
> The distinction can affect complication/PSI reporting, quality metrics, and DRG assignment.

## 💊 Clinical Features and Diagnosis

### Signs and Symptoms

| Feature | Paralytic Ileus (K56.0) |
|---|---|
| **Abdominal distension** | ✅ Prominent — diffuse, symmetric |
| **Nausea/vomiting** | ✅ Common |
| **Inability to pass flatus/stool** | ✅ Present |
| **Abdominal pain** | Mild to moderate — dull, crampy; less severe than mechanical |
| **Bowel sounds** | ❌ Absent or very diminished — "silent abdomen" |
| **Fever** | Present if peritonitis or sepsis is the cause |
| **Abdominal tenderness** | Variable — depends on underlying cause |

### Imaging — Key Differentiators

| Imaging Finding | Paralytic Ileus | Mechanical Obstruction |
|---|---|---|
| **Gas pattern** | Diffuse throughout small and large bowel | Dilated loops proximal to obstruction only |
| **Transition point** | ❌ Absent | ✅ Present — identifies obstruction level |
| **Colon gas** | ✅ Present — diffuse | May be absent distal to obstruction |
| **Air-fluid levels** | Present — non-specific | Present — step-ladder pattern in mechanical |
| **Modality of choice** | CT abdomen/pelvis with contrast | CT abdomen/pelvis with contrast |

## 💊 Coding Scenarios

---

### Scenario 1 — Paralytic Ileus From Hypokalemia (Medical Inpatient)

> **Clinical Vignette:** A 72-year-old female on loop diuretics for CHF presents with 3 days of **abdominal distension, nausea, no bowel movements, absent bowel sounds**. KUB: diffuse gas throughout small and large bowel, no transition point. Labs: K+ 2.8 mEq/L. Impression: Paralytic ileus secondary to [[hypokalemia]]. Admitted for IV potassium repletion, NPO, NG tube.

**ICD-10-CM:**
- **[[K56.0]]** — Paralytic ileus *(principal — reason for admission)*
- [[E87.6]] — Hypokalemia *(documented underlying cause — FY2024 update allows dual coding)* [web:325]
- [[I50.9]] — Heart failure *(underlying condition driving diuretic use)*
- [[Z79.1]] — Long-term use of loop diuretics *(contributing factor)*

---

### Scenario 2 — Paralytic Ileus Post-Op, But Due to Opioids (NOT K91.3-)

> **Clinical Vignette:** A 58-year-old male on post-op day 3 following right hemicolectomy for colon cancer. Abdomen distended, no bowel sounds, no flatus. CT: diffuse bowel gas without transition point. Team documents: "Ileus — likely opioid-induced; patient on high-dose IV hydromorphone PCA. Not consistent with anastomotic leak or mechanical obstruction." Impression: Opioid-induced paralytic ileus.

**ICD-10-CM:**
- [[C18.2]] — Malignant neoplasm, ascending colon *(principal)*
- **[[K56.0]]** — Paralytic ileus *(additional — opioid-induced, NOT procedural complication → K56.0, NOT K91.3-)* 
- [[F11.29]] or [[T40.2X5D]] — Opioid-related disorder / adverse effect of opioids *(documented cause)*

> [!tip] Document the Cause Clearly for K56.0 vs. K91.3- Distinction
> The physician's statement "opioid-induced" is what keeps this as K56.0 instead of K91.3-. When the operative note or progress notes attribute the ileus to a cause OTHER than the procedure itself — even in a post-surgical patient — K56.0 is correct. Query when the cause is ambiguous.

---

### Scenario 3 — Paralytic Ileus With Peritonitis (FY2024 Dual Coding)

> **Clinical Vignette:** A 64-year-old male presents with perforated diverticulitis — peritonitis confirmed on CT. Abdomen distended with absent bowel sounds. No bowel movement for 4 days. Physician documents: "Peritonitis with secondary paralytic ileus." Emergent surgical washout performed.

**ICD-10-CM:**
- [[K57.20]] — Diverticulitis of large intestine with perforation and abscess without bleeding *(principal)*
- [[K65.0]] — Generalized (acute) peritonitis *(additional)*
- **[[K56.0]]** — Paralytic ileus *(additional — FY2024 update permits coding ileus alongside its documented cause)* 

> [!important] Pre-FY2024 vs. Post-FY2024 Coding — This Exact Scenario
> **Pre-October 1, 2023 (old guidance):** Per 2017 Coding Clinic — only code peritonitis; do NOT add K56.0 when ileus is due to documented peritonitis.
> **Post-October 1, 2023 (current guidance):** Excludes1 removed — code BOTH peritonitis AND K56.0. 
> This is a textbook CIC reversal question. Know the date and the direction of change.

---

### Scenario 4 — Post-Surgical Ileus = Procedural Complication → K91.3-, NOT K56.0

> **Clinical Vignette:** A 55-year-old female, post-op day 5 from total abdominal hysterectomy. No bowel function, distension, nausea. CT: dilated small bowel loops throughout with no transition point. Surgical team documents: "Postoperative ileus — complication of hysterectomy."

**ICD-10-CM:**
- [[N80.0]] — Endometriosis of uterus *(underlying condition — or appropriate surgical indication)*
- **[[K91.30]]** — Postprocedural intestinal obstruction, unspecified *(NOT K56.0 — explicitly documented as procedural complication)*

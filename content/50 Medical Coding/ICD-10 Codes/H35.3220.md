# 🧬 ICD-10-CM H35.3220 — Exudative AMD, Left Eye, Stage Unspecified

> [!danger] Last-Resort Code — Specificity Required
> **ICD-10 CM [[H35.3220]]** is technically a valid 7-character billable code, but **it should rarely — if ever — appear on a claim**. The 7th character `0` signals that the stage of the wet AMD was NOT documented in the medical record. Per **ICD-10-CM Official Guidelines Section I.B.4**, coders must assign the most specific code the documentation supports. Wet AMD stage is always determinable from OCT findings and physician notes — the absence of stage documentation is a **clinical documentation deficiency**, not an inherent coding limitation.

> [!warning] Non-Billable Parent Codes — Do Not Submit These Either
> - ❌ `H35.322` — 6-character — non-billable header — also missing stage
> - ❌ `H35.32` — 5-character header — missing laterality AND stage
>
> If you're considering **[[H35.3220]]** because the stage wasn't documented, the right answer is a **CDI query** — not submitting **[[H35.3220]]** as a shortcut.

> [!success] The Preferred Left-Eye Wet AMD Codes — Use These Instead
> | Code | Stage | Use When |
> |---|---|---|
> | [[H35.3221]] | Active CNV | SRF, IRF, hemorrhage, fluid on OCT or FA documented |
> | [[H35.3222]] | Inactive CNV | Macula dry, CNV regressed/quiescent, T&E or PRN protocol |
> | [[H35.3223]] | Inactive scar | Disciform scar, subretinal fibrosis documented |
> | **[[H35.3220]]** | **Unspecified ⚠️** | **ONLY if stage genuinely undocumentable + query failed** |

## 🔍 Code Description

**ICD-10 CM [[H35.3220]]** classifies **exudative (wet) age-related macular degeneration of the left eye at an unspecified stage** — meaning the medical record documents the presence of wet AMD in the left eye but does not contain sufficient clinical detail to assign the correct 7th character stage (**active CNV, inactive CNV, or inactive scar**).

The "**stage unspecified**" designation is a coding placeholder — it exists in the ICD-10-CM tabular to accommodate the rare scenario where complete documentation is unavailable. It is **not** intended for routine use. In real-world retina practice, every wet AMD note contains OCT results that definitively establish stage — which means **[[H35.3220]]** appearing on a claim almost always reflects a documentation gap that should have been resolved before billing.

## 📊 The 7th Character Decision Tree — Left Eye Wet AMD

> [!tip] Use This Decision Tree Before Reaching for H35.3220
> Before assigning **[[H35.3220]]**, work through every step. **[[H35.3220]]** should only be reached if all four pathways are exhausted.

```
STEP 1: Is left eye wet AMD (exudative) documented?  
└── YES → Continue to Step 2  
└── NO → Wrong code family — re-evaluate

STEP 2: Does the OCT note say "fluid" / "SRF" / "IRF" /  
"subretinal fluid" / "active CNV" / "hemorrhage"?  
└── YES → H35.3221 ✅ (Active CNV)  
└── NO → Continue to Step 3

STEP 3: Does the note say "dry" / "no fluid" / "quiescent" /  
"inactive" / "involuted CNV" / "regressed" / "controlled"?  
└── YES → H35.3222 ✅ (Inactive CNV)  
└── NO → Continue to Step 4

STEP 4: Does the note say "scar" / "disciform" / "fibrosis" /  
"disciform scar" / "subretinal fibrosis"?  
└── YES → H35.3223 ✅ (Inactive Scar)  
└── NO → Continue to Step 5

STEP 5: Send CDI QUERY to physician:  
"The record documents exudative AMD, left eye.  
Please specify the current stage:  
□ Active CNV (with subretinal/intraretinal fluid)  
□ Inactive CNV (fluid resolved, CNV regressed)  
□ Inactive scar (disciform scar/fibrosis present)"  
└── Response received → Assign specific code ✅  
└── No response / clinically not feasible → H35.3220 ⚠️
```

## 🚨 Why H35.3220 Is a Payer Red Flag

> [!danger] Payer Rejection Risk — Anti-VEGF Claims Especially Vulnerable
> The Lucentis/Genentech billing resource explicitly warns: **"Many payers will not accept unspecified codes."**  This applies with greatest force to anti-VEGF injection claims, where medical necessity is tied directly to documented CNV activity. If **[[H35.3220]]** appears as the diagnosis on a claim with [[67028]][[-LT]] and a drug J-code, the payer cannot determine whether:
>
> - The CNV was **active** (injection clearly indicated)
> - The CNV was **inactive** (injection requires T&E protocol rationale)
> - The eye had a **scar** (injection may not be indicated at all)
>
> This ambiguity triggers either **automatic denial** or **additional documentation requests** — both of which delay payment and increase administrative burden. The specific stage codes eliminate this ambiguity entirely.

### Payer Scenarios by Protocol

| Claim Type | H35.3220 Risk Level | Notes |
|---|---|---|
| **[[67028]][[-LT]] + J-code (injection)** | 🔴 HIGH — likely denial | Active CNV must be documented; **[[H35.3220]]** insufficient for most MACs |
| **[[92134]] (OCT monitoring)** | 🟡 MODERATE — may process | Monitoring is justified for any wet AMD; some payers accept unspecified for monitoring |
| **[[92014]] (exam only)** | 🟢 LOWER — may process | E&M less stage-dependent; still suboptimal |
| **[[92235]] (FA)** | 🟡 MODERATE | FA medical necessity tied to determining stage — unspecified undermines rationale |

## 📋 When H35.3220 Actually Belongs on a Claim

> [!note] The Four Legitimate **[[H35.3220]]** Scenarios — Rare but Real
> There are a small number of clinical documentation situations where **[[H35.3220]]** is genuinely the most appropriate code available:

### Scenario A — Referring Provider Note, Incomplete Documentation

A patient transfers care from another retina practice. The only available documentation is a referral note that reads: "Wet AMD, left eye — follow-up with your retina specialist." No OCT results included. The receiving physician has not yet seen the patient. An initial evaluation visit is being coded **before** the new physician's first OCT.

→ **[[H35.3220]] is appropriate** for the administrative/intake context. Update to specific stage code at first clinical encounter.

### Scenario B — Emergency Department Visit, Ophthalmology Not Available

A patient with known wet AMD left eye presents to an ED with a new complaint (**fall, syncope, cardiac event**). The ED chart documents the wet AMD history but no eye exam or OCT was performed. No **ophthalmology** consult was obtained. The ED coder needs to capture the AMD as an additional diagnosis.

→ **[[H35.3220]] is appropriate** — stage cannot be determined without an eye examination or OCT.

### Scenario C — Inpatient Admission, Historical AMD, No Ophthalmic Evaluation

A patient is admitted for a systemic condition. The H&P documents "history of wet AMD, left eye, treated with injections." The admitting physician does not specify stage. No ophthalmology consult is placed. Query sent → no response within coding window.

→ **[[H35.3220]] may be appropriate** after query attempt — code to the specificity available. Note in the record that a query was sent.

### Scenario D — Physician Documents "Wet AMD" With No Additional Detail

An outpatient note documents only "wet AMD, left eye — continue monitoring" with no OCT report, no fluid status, no stage language. CDI query sent → physician responds "I don't document the stage — just use whatever code you need."

→ **[[H35.3220]] as last resort** — document the query attempt and physician's non-response in the coding workflow.

> [!caution] Scenario D Is Also a Compliance Red Flag
> A retina physician routinely failing to document AMD stage in their notes is a **clinical documentation compliance issue** that should be escalated — not repeatedly coded as **[[H35.3220]]**. A pattern of **[[H35.3220]]** claims from a single provider may trigger payer audits. Work with your CDI team to implement provider education and note template changes that prompt stage documentation at every wet AMD visit.

## 🛠️ CDI Query Template — H35.3220 → Specific Stage

> [!success] Copy-Paste CDI Query for Wet AMD Stage
> When the record documents wet AMD left eye but lacks stage documentation, use this query to resolve **[[H35.3220]]** to the correct specific code:
> 
```
CLINICAL DOCUMENTATION IMPROVEMENT QUERY  
Date: _  
Patient: _ MRN: _  
Encounter Date: _ Provider: _

RE: Dry (Nonexudative) AMD — Laterality AND Stage Clarification Required

The medical record documents age-related macular degeneration  
(dry/nonexudative type). Accurate ICD-10-CM coding requires  
both the affected eye AND the disease stage.

QUESTION 1 — WHICH EYE IS AFFECTED?  
□ Right eye only  
□ Left eye only  
□ Both eyes (bilateral)  
□ Cannot be determined

QUESTION 2 — WHAT IS THE CURRENT STAGE?  
(Answer separately for each affected eye)

Right Eye Stage:  
□ Early dry (medium drusen, no pigment changes)  
□ Intermediate (large drusen or pigment changes)  
□ Advanced — geographic atrophy, NOT at foveal center  
□ Advanced — geographic atrophy AT foveal center (subfoveal)  
□ Stage unspecified / cannot be determined

Left Eye Stage:  
□ Early dry (medium drusen, no pigment changes)  
□ Intermediate (large drusen or pigment changes)  
□ Advanced — geographic atrophy, NOT at foveal center  
□ Advanced — geographic atrophy AT foveal center (subfoveal)  
□ Stage unspecified / cannot be determined

Physician Signature: _ Date: _

NOTE: Without laterality and stage, only the lowest-specificity  
ICD-10-CM code is assignable, which may affect claim processing  
and quality metric reporting.
```

## 💊 Coding Scenarios

---

### Scenario 1 — Transferred Patient, No Prior OCT Records (Outpatient)

> **Clinical Vignette:** A 76-year-old female transfers from out-of-state retina practice. Today is her first visit. She reports receiving "eye injections" for her left eye for the past two years. No prior records received. The new physician performs a comprehensive exam and orders OCT — however, the OCT machine is down today. Impression: "Wet AMD, left eye — history of treatment — will obtain baseline OCT at next visit."

**CPT / HCPCS:**
- [[92004]] — Comprehensive ophthalmological exam, new patient
- **No [[92134]]** — OCT not performed today (machine down)
- **No [[67028]]** — No injection today pending baseline

**ICD-10-CM:**
- **[[H35.3220]]** — Exudative AMD, left eye, stage unspecified *(acceptable here — no OCT performed, no prior records, stage genuinely unknown at this visit; update to specific code at next visit when OCT available)*

> [!success] This Is the Legitimate H35.3220 Scenario
> The stage is genuinely unknown at this specific visit because no diagnostic testing was available and no prior records exist. **[[H35.3220]]** is appropriate. **At the next visit**, when OCT is obtained, the specific stage code must be used — do not carry **[[H35.3220]]** forward once stage is established.

---

### Scenario 2 — Inpatient Admission, Wet AMD in H&P, No Eye Consult (Inpatient)

> **Clinical Vignette:** A 79-year-old male admitted for **NSTEMI**. H&P by admitting cardiologist notes: "Ocular history: wet AMD left eye, on monthly injections, followed by retina specialist." No ophthalmology consult placed. No OCT available in the inpatient record. CDI query to cardiologist: "Unable to specify — please contact retina specialist." Stage not available within coding window.

**Additional Diagnosis:**
- **[[H35.3220]]** — Exudative AMD, left eye, stage unspecified *(appropriate for inpatient additional diagnosis — stage not determinable from available inpatient record; cardiologist appropriately redirected to retina specialist but no consultation obtained)*

> [!note] Document the Query Attempt in Your Coding Workflow
> Even when **[[H35.3220]]** is the correct code given the circumstances, always document in your coding workflow that a CDI query was attempted and the outcome. This protects the facility in the event of an audit and demonstrates coding compliance effort.

---

### Scenario 3 — Lazy Documentation Pattern — CDI Escalation Needed (Outpatient)

> **Clinical Vignette:** A coder reviews 15 encounters from the same retina physician. Every wet AMD note reads: "**Wet AMD — continue monitoring — OCT obtained.**" The OCT reports are scanned but not referenced in the physician's assessment. No fluid status, no stage language, no injection rationale. **[[H35.3220]]** has been assigned for all 15 encounters spanning 8 months.

**Correct Action:**
1. **Do NOT continue assigning [[H35.3220]]** — the OCT reports are in the record and contain stage-determining information
2. **Read the OCT reports** — "no fluid" = [[H35.3222]]; "subretinal fluid" = [[H35.3221]]; "fibrosis" = [[H35.3223]]
3. **UHDDS and coding guideline principle**: coders may reference any part of the medical record — if the OCT report establishes stage even without physician narrative restatement, assign the specific code
4. **Escalate the documentation pattern** to the CDI or compliance team — provider education needed
5. **Retroactively correct** the prior 15 claims if within the correction window — **[[H35.3220]]** on injection claims may have caused denials already

> [!danger] The OCT Report IS Part of the Medical Record
> This is a critical coding compliance point. The physician does not need to repeat "active CNV with subretinal fluid" in their assessment if the attached OCT report clearly documents it. The OCT report is part of the legal medical record and may be used to support code assignment. A coder who has access to OCT results showing active fluid has the documentation needed to assign [[H35.3221]] — assigning **[[H35.3220]]** when the OCT result is available is **under-coding**, not appropriate caution.

| ❌ | **Never carry H35.3220 forward across visits** — once stage is established at any visit, the specific code applies from that point on |
| ❌ | **Never bill H35.3220 with [[67028]][[-LT]] + J-code without checking your MAC's LCD** — many payers auto-deny unspecified wet AMD on injection claims [web:130] |

# 🧠 ICD-10-CM G35.B1 — Active Primary Progressive Multiple Sclerosis

> [!success] Billable Code Confirmed — FY2026 New Code
>
> **ICD-10-CM [[50 Medical Coding/ICD-10 Codes/G35.B1]]** is a valid, billable ICD-10-CM code **new for
> FY2026**, effective **October 1, 2025**. It is the designated billable
> code for **primary progressive multiple sclerosis with documented
> disease activity** — defined by new gadolinium-enhancing lesion(s),
> new T2/FLAIR lesion(s) on MRI, or a superimposed clinical relapse.

> [!danger] CRITICAL FY2026 Change — G35 and G35.B Are Not Billable
>
> - ❌ **[[G35]]** — Non-billable parent code as of October 1, 2025
> - ❌ **[[G35.B]]** — Non-billable subcategory header — never submit alone
> - ✅ **[[50 Medical Coding/ICD-10 Codes/G35.B1]]** — Billable code for PPMS with confirmed active disease
>
> Submitting standalone **[[G35]]** or **[[G35.B]]** after October 1, 2025
> is invalid and will reject. When PPMS with active disease is confirmed
> by the treating physician, **[[50 Medical Coding/ICD-10 Codes/G35.B1]]** is the required code.

> [!important] Physician Documentation Required — Coders Cannot Assign G35.B1 from MRI Alone
>
> **ICD-10 CM [[50 Medical Coding/ICD-10 Codes/G35.B1]]** requires explicit **physician documentation** confirming
> that the PPMS is currently active. A radiology report showing a
> gadolinium-enhancing lesion is not sufficient on its own — the treating
> neurologist must interpret that finding and document active disease
> status in their note, consult, or discharge summary. This is the
> **#1 compliance risk** with the new FY2026 MS activity codes.

> [!info] Code Classification
>
> **ICD-10-CM Diagnosis Code** — Fields for wRVU, assistant payable, and
> global period are not applicable. For associated inpatient procedure
> coding, see the **ICD-10-PCS** Crosswalk section below.

## 🔍 Code Description

**ICD-10-CM [[50 Medical Coding/ICD-10 Codes/G35.B1]]** classifies **active primary progressive multiple
sclerosis** — the subtype of MS defined by a gradual, continuous worsening
of neurological function from symptom onset (primary progressive course),
combined with **current inflammatory disease activity** as evidenced by
new MRI lesion formation or a superimposed clinical relapse.

The distinction between **active** ([[50 Medical Coding/ICD-10 Codes/G35.B1]]) and **non-active**
([[G35.B2]]) PPMS is clinically and administratively critical. **Activity**
in the context of the FY2026 MS code family is defined per the 2013
Lublin et al. MS phenotype framework as the presence of **clinical
relapse activity** (discrete new neurological episode lasting >24 hours
with objective deficit) and/or **MRI activity** (new T1 gadolinium-enhancing
lesion or new T2/FLAIR lesion on MRI compared to a prior scan within
the monitoring period). A single qualifying criterion — clinical OR
MRI — is sufficient to classify disease as active.

**[[50 Medical Coding/ICD-10 Codes/G35.B1]]** is the code subtype that most directly supports **ocrelizumab
(Ocrevus) authorization** in PPMS patients, as the pivotal ORATORIO
trial was conducted in patients with active PPMS (Gd+ lesions or recent
clinical activity). Payers increasingly use ICD-10-CM subtype codes to
validate DMT authorization — accurate [[50 Medical Coding/ICD-10 Codes/G35.B1]] assignment supports the
medical record's alignment with the prescriber's authorization request.

## 📋 Clinical Overview

### Defining "Active" in PPMS — The 2013 Lublin Framework

The FY2026 MS activity codes are grounded in the **2013 revised MS
phenotype descriptions** by Lublin et al., which introduced "active" and
"non-active" as modifiers across all MS subtypes. For PPMS specifically,
**activity** is defined by:

| Activity Criterion | Definition | ICD-10 Impact |
|---|---|---|
| **Clinical relapse** | New discrete neurological episode lasting >24 hours with objective deficit, superimposed on the progressive baseline | Supports [[50 Medical Coding/ICD-10 Codes/G35.B1]] |
| **MRI activity — T1 Gd+** | New gadolinium-enhancing lesion on T1-weighted post-contrast MRI | Supports [[50 Medical Coding/ICD-10 Codes/G35.B1]] |
| **MRI activity — T2/FLAIR** | New or enlarging T2/FLAIR hyperintense lesion compared to a prior MRI within the monitoring interval | Supports [[50 Medical Coding/ICD-10 Codes/G35.B1]] |
| **Stable / no new lesions** | No new clinical activity and no new MRI lesions on surveillance imaging | Supports [[G35.B2]] |

> [!important] The Single Most Important Compliance Rule for G35.B1
> **Physician documentation of activity is mandatory.** The coder cannot
> look at a radiology report showing a Gd+ lesion and assign [[50 Medical Coding/ICD-10 Codes/G35.B1]]
> independently. The treating neurologist must document something
> equivalent to: *"MRI shows new gadolinium-enhancing lesion — PPMS
> currently active"* or *"Active primary progressive MS."* Without
> physician interpretation in the clinical note, [[G35.B0]] is the
> appropriate code and a CDI query is the correct pathway.

### Pathophysiology

**Active primary progressive MS** shares the same foundational
neurodegeneration of PPMS — progressive axonal loss from a smoldering
innate immune response in the spinal cord and brain — but is distinguished
by the concurrent presence of **focal inflammatory demyelination** with
active lesion formation. The gadolinium-enhancing lesion represents
**breakdown of the blood-brain barrier** at a site of active
inflammatory activity — macrophage infiltration, reactive astrogliosis,
and ongoing myelin destruction — superimposed on the chronic progressive
substrate.

The presence of MRI activity in PPMS has critical therapeutic implications
because it indicates that the **adaptive immune arm** (B-cell and T-cell
driven focal inflammation) is still contributing to disease activity
alongside the innate neurodegeneration. This is the mechanistic rationale
for **ocrelizumab** — an anti-CD20 B-cell depleting agent — being most
effective in active PPMS ([[50 Medical Coding/ICD-10 Codes/G35.B1]]) compared to non-active PPMS
([[G35.B2]]).

### Clinical Presentation

Patients coded to [[50 Medical Coding/ICD-10 Codes/G35.B1]] present with the progressive myelopathic
picture of PPMS alongside evidence of active inflammatory disease:

- **Progressive gait disturbance** — the cardinal PPMS feature; worsening
  leg stiffness, foot drop, balance impairment on a continuous trajectory
- **New or acutely worsening neurological deficit** — may represent a
  superimposed relapse in active PPMS; >24-hour discrete episode with
  objective deficit on exam
- **Spastic paraparesis / paraplegia** — lower extremity spasticity and
  weakness; [[G82.20]] or [[G82.10]] codeable when severity documented
- **Neurogenic bladder** — urinary urgency, frequency, retention;
  [[N31.9]] when documented; near-universal in PPMS
- **MRI surveillance findings prompting visit** — new Gd+ or T2 lesion
  detected on scheduled monitoring MRI leading to clinical reassessment
- **Fatigue, cognitive impairment, pain** — common across all PPMS stages

### Documentation Requirements

For accurate assignment of [[50 Medical Coding/ICD-10 Codes/G35.B1]] — and to distinguish from [[G35.B0]]
and [[G35.B2]] — physician documentation must include:

1. **MS subtype** — "primary progressive MS" or "PPMS" explicitly stated
2. **Activity status — confirmed active** — physician must document:
   "active," "new Gd+ lesion," "new T2 lesion," or "clinical relapse"
3. **MRI findings interpreted by the neurologist** — not just a radiology
   report; the physician's clinical note must reference the active finding
4. **Current DMT** — ocrelizumab documentation directly supported by
   [[50 Medical Coding/ICD-10 Codes/G35.B1]] assignment; supports prior authorization alignment
5. **Disability level and functional status** — documents severity,
   supports CC/MCC coding of complications

### Scenario 1 — Active PPMS, New Gd+ Lesion on Surveillance MRI (Outpatient)

> **Clinical Vignette:** A 54-year-old male with known PPMS presents for
> his 6-month neurology follow-up. Surveillance MRI brain performed prior
> to visit. Neurologist reviews MRI and documents in the visit note:
> "MRI shows one new gadolinium-enhancing lesion in the right cerebellar
> peduncle compared to prior study 6 months ago. Primary progressive MS —
> currently active. Will proceed with ocrelizumab infusion series."

**CPT Codes (Outpatient):**
- [[99215]] — Office visit, established patient, high complexity *(new
  MRI lesion requiring DMT decision — high MDM complexity)*

**ICD-10-CM:**
- [[50 Medical Coding/ICD-10 Codes/G35.B1]] — Active primary progressive MS *(physician explicitly
  documents "currently active" and references new Gd+ lesion —
  G35.B1 is correct and required)*

> [!tip] This Is the Ideal G35.B1 Documentation Scenario
> The neurologist did exactly what is needed — interpreted the MRI
> finding AND stated activity status in the clinical note. No CDI query
> required. [[50 Medical Coding/ICD-10 Codes/G35.B1]] is assigned with confidence. This documentation
> also directly supports ocrelizumab prior authorization alignment.

---

### Scenario 2 — Active PPMS, Superimposed Relapse, Inpatient

> **Clinical Vignette:** A 49-year-old female with known primary progressive
> MS is admitted for acute new right arm weakness and dysarthria developing
> over 36 hours. MRI brain shows new T2 hyperintense lesion in the left
> internal capsule with gadolinium enhancement. Neurology documents:
> "Primary progressive MS with superimposed acute relapse — active disease.
> Initiating IV methylprednisolone 1g daily x 3 days."

**Principal Diagnosis:**
- [[50 Medical Coding/ICD-10 Codes/G35.B1]] — Active primary progressive MS *(PPMS with confirmed
  active disease — physician documents superimposed relapse and active
  disease; sequences as principal)*

**Additional Diagnoses:**
- [[G81.10]] — Flaccid hemiplegia, unspecified side *(right arm weakness
  documented — code if severity threshold met per physician documentation)*
- [[R47.81]] — Dysarthria *(documented speech impairment — code additionally)*

**MS-DRG Assignment:**
- DRG 059 — Multiple Sclerosis and Cerebellar Ataxia with CC *(if
  G81.10 qualifies as CC — confirm CC/MCC tier)*
- DRG 058 — with MCC if higher-tier complication also present

> [!note] Superimposed Relapse in PPMS — Correct Code Is Still G35.B1
> Some coders question whether a relapse in a PPMS patient shifts the
> code to [[G35.A]] (RRMS). It does not. The **disease subtype** is
> determined by the overall clinical course — PPMS is progressive from
> onset with no early relapses. A relapse superimposed on an established
> PPMS course does not reclassify the patient as RRMS. The physician
> documents the subtype; the activity modifier changes to "active" →
> **[[50 Medical Coding/ICD-10 Codes/G35.B1]]** is correct.

### Scenario 3 — Active PPMS, Ocrelizumab Infusion Encounter (Outpatient Infusion)

> **Clinical Vignette:** A 58-year-old male with active PPMS presents
> for his second ocrelizumab infusion. Prior authorization was obtained
> based on documented active disease (new T2 lesion on last MRI). The
> infusion center note documents: "Active primary progressive MS — scheduled
> Ocrevus infusion per neurology plan."

**CPT Codes:**
- [[96413]] — IV infusion, chemotherapy, first hour *(ocrelizumab)*
- [[96415]] — IV infusion, each additional hour
- [[96360]] — Hydration infusion, initial 31-90 minutes *(pre-medication
  hydration if separately documented)*

**ICD-10-CM:**
- [[50 Medical Coding/ICD-10 Codes/G35.B1]] — Active primary progressive MS *(explicitly documented
  in infusion center note — correct)*

> [!caution] Modifier -25 on E/M If Billed Same Day as Infusion
> If the neurologist performs a separate E/M at the same infusion
> encounter (beyond pre/post infusion assessment), **modifier [[-25]]**
> is required on the E/M code. The infusion itself does not include a
> separately billable E/M without that modifier.

### Scenario 4 — Radiology Shows Gd+ But Physician Hasn't Documented Activity Yet (Inpatient)

> **Clinical Vignette:** A 53-year-old female with PPMS is admitted for
> urinary sepsis. During the admission, MRI brain is performed and
> radiology reports one new Gd+ lesion. The attending internal medicine
> physician's notes reference PPMS but do not address the MRI activity
> finding. No neurology consult is obtained. Discharge summary documents
> "primary progressive MS" without activity status.

**Principal Diagnosis:**
- *(Urinary sepsis — sequences as principal per reason for admission)*

**Additional Diagnoses:**
- [[G35.B0]] — Primary progressive MS, unspecified *(Gd+ is in radiology
  report ONLY — the attending did not document active PPMS; coder cannot
  assign G35.B1 from radiology report alone; G35.B0 is correct)*

> [!danger] This Is the Most Important Compliance Scenario for G35.B1
> **Do not assign [[50 Medical Coding/ICD-10 Codes/G35.B1]] based solely on a radiology report.**
> The radiologist's finding of a Gd+ lesion is not physician documentation
> of active PPMS. A CDI query to the attending or a neurology consult
> request is the correct pathway. If no physician documents active
> disease status before bill drop → **[[G35.B0]]** is the correct code.
> Assigning [[50 Medical Coding/ICD-10 Codes/G35.B1]] without physician activity documentation is a
> compliance violation.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|--|----------------|
| ❌ | **Do not submit [[G35]] or [[G35.B]] alone** — both are non-billable after 10/1/2025; minimum valid PPMS code is [[G35.B0]] for unspecified activity |
| ❌ | **Do not assign [[50 Medical Coding/ICD-10 Codes/G35.B1]] from a radiology report alone** — physician documentation of active disease status is required; radiology interpretation without clinical documentation = [[G35.B0]] + CDI query |
| ❌ | **Do not assign [[50 Medical Coding/ICD-10 Codes/G35.B1]] alongside [[G35.B0]] or [[G35.B2]]** — mutually exclusive; only one G35.B code per encounter |
| ❌ | **Do not reclassify PPMS as RRMS because of a superimposed relapse** — a relapse in a PPMS patient → [[50 Medical Coding/ICD-10 Codes/G35.B1]], not [[G35.A]]; subtype is the overall disease course, not a single episode |
| ❌ | **Do not assign [[50 Medical Coding/ICD-10 Codes/G35.B1]] simultaneously with [[G37.9]]** — Excludes 1; mutually exclusive |
| ✅ | **[[50 Medical Coding/ICD-10 Codes/G35.B1]] requires explicit physician documentation of active disease** — "active," "new Gd+ lesion," "new T2 lesion," or "clinical relapse" must appear in physician note, consult, or discharge summary |
| ✅ | **[[50 Medical Coding/ICD-10 Codes/G35.B1]] directly supports ocrelizumab prior authorization** — accurate assignment aligns the medical record with the DMT authorization request |
| ✅ | **[[50 Medical Coding/ICD-10 Codes/G35.B1]] carries CMS-HCC v28: HCC 198 / RxHCC v08: HCC 159** — confirm mapping on current CMS crosswalk |
| ✅ | **Capture all PPMS complications** — neurogenic bladder ([[N31.x]]), paraplegia ([[G82.x]]), aspiration pneumonia ([[J69.0]]), pressure ulcers ([[L89.x]]) drive DRG tier and RAF |
| ✅ | **[[J69.0]]** is MCC — moves active PPMS admission to DRG 058; never miss in non-ambulatory patients with documented dysphagia |
| ✅ | **Query before bill drop** when Gd+ lesion is in the radiology report but physician hasn't addressed activity status — one clarifying sentence upgrades [[G35.B0]] to [[50 Medical Coding/ICD-10 Codes/G35.B1]] |

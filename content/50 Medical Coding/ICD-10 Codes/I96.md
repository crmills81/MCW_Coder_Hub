# 🧬 ICD-10-CM  I96 — Gangrene, Not Elsewhere Classified

> [!success] Billable Code Confirmed
> **ICD-10-CM [[I96]]** is fully billable at **3 characters** — one of a small subset of **ICD-10-CM codes** that require no additional specificity characters to be reported on a claim.<sup>1</sup> The designation "**not elsewhere classified**" (**NEC**) signals that this code applies only when the **[[gangrene]]** cannot be attributed to a more precisely defined etiology that has its own dedicated code in the classification system.<sup>2</sup> Before assigning **[[I96]]**, coders must exhaust all applicable **Excludes1 alternatives**; NEC is a specificity residual, not a catch-all default.<sup>3</sup>

> [!warning] Non-Billable Parent Codes
> The block header **I95–I99** (**Other and unspecified disorders of the circulatory system**) is a classification range, not a reportable code; it exists only to organize the tabular hierarchy and may never be submitted on a claim.<sup>1</sup> The category **I97** (**Intraoperative and postprocedural complications and disorders of the circulatory system, not elsewhere classified**) is a non-billable parent that requires a 4th and 5th character to specify complication type and encounter context before it becomes billable.<sup>1</sup> **I99** (**Other and unspecified disorders of circulatory system**) similarly requires extension to **[[I99.8]]** or **[[I99.9]]** before a claim can be submitted.<sup>1</sup>

> [!important] Clinical Context
> **ICD-10-CM [[I96]]** is reserved for **gangrene** that is not attributable to a more specific underlying etiology covered by another **ICD-10-CM code** — it should never be used when documentation clearly identifies an **Excludes1 condition** such as **PAD** with **[[gangrene]]** (I70.26-), **peripheral vascular disease with gangrene** (I73.-), or **diabetic gangrene (E08–E13 with .52)**.<sup>2,4</sup> Common legitimate use cases include idiopathic dry **gangrene**, senile gangrene without a documented **vascular** diagnosis, and **gangrenous** cellulitis not classified elsewhere when physician query fails to yield a more specific etiology.<sup>4</sup> Because specificity almost always exists upon physician clarification, CDI query should be initiated for virtually every inpatient encounter where **[[I96]]** is under consideration.<sup>3</sup>

> [!danger] Code Classification
> **ICD-10-CM [[I96]]** is a **diagnosis** code classified under **Chapter 9 — Diseases of the Circulatory System** — reflecting the dominant etiology of **vascular ischemia**, even though **[[gangrene]]** represents a pathological tissue process that may involve multiple organ systems.<sup>1</sup> It is not a procedure code, and it is not synonymous with gas **[[gangrene]]** (**[[A48.0]]**), which is a distinct clostridial infectious process that is **Excludes1 to [[I96]]** and must never be coded alongside it.<sup>2</sup> As a secondary diagnosis, **[[I96]]** carries MCC status in the **MS-DRG CC/MCC table**, making accurate secondary code capture a direct factor in inpatient **DRG** tier assignment and **IPPS** reimbursement.<sup>5</sup>

## 🔍 Code Description

**Gangrene refers to the necrosis** — or **death** — of body tissue, most commonly resulting from ischemia (**loss of blood supply**), **bacterial infection**, or a combination of both mechanisms acting simultaneously.<sup>2,4</sup> Clinically, **gangrene** is categorized as dry (**arterial occlusion causing mummification without superinfection**), wet (**associated with bacterial putrefaction, edema, and malodor**), or mixed (**ischemia complicated by infection**); **ICD-10-CM [[I96]]** captures any of these presentations when a more specific code does not apply.<sup>4</sup> The condition most commonly affects the distal extremities — toes, feet, fingers — but may also involve internal organs, the perineum (**see [[N49.3]] for the more specific Fournier's disease code**), or soft tissue of the face and neck in rare cases such as **noma (cancrum oris)**.<sup>4,6</sup> The "**not elsewhere classified**" qualifier embedded in the code title is a built-in signal that this code sits at the bottom of the specificity hierarchy; whenever a more precise etiology-specific code exists — whether in the v**ascular, diabetic, or infectious chapters** — that code takes precedence over **[[I96]]**.<sup>2,3</sup>

From an inpatient coding perspective, **[[I96]]** is a high-acuity, **MCC**-level diagnosis with direct implications **for** DRG assignment, risk adjustment, and clinical documentation integrity.<sup>5</sup> Accurate use requires the coder to systematically exclude all **Excludes1 alternatives** — including **[[I70.261]], [[I70.262]]**, and condition-specific diabetic gangrene codes (**e.g., [[E11.52]]**) — before defaulting to this **NEC** designation.<sup>2,3</sup> When **[[gangrene]]** appears in the medical record and **[[I96]]** seems applicable, a CDI query documenting the physician's clinical reasoning for why no more specific etiology applies should accompany the final code assignment and serve as audit support documentation.<sup>3,4</sup>

> [!example] Why I96 Is Rarely the Correct Final Code at Discharge
> In most inpatient encounters, **[[gangrene]]** can be traced to a documented etiology — **PAD**, diabetes, sepsis, or hernia — that has a more specific combination code; **[[I96]]** should survive to final coding only after physician query has failed to yield a more specific **Excludes1 alternative**.<sup>3,4</sup> Using **[[I96]]** as a default without completing the query process undermines CDI program integrity and leaves higher-weighted codes — and potentially **HCC** capture — on the table.<sup>3</sup>

> [!tip]
> **ICD-10-CM [[I96]]** is one of the very few **ICD-10-CM codes** billable at 3 characters without further subdivision, but that structural completeness does not replace the need for clinical specificity at the documentation level — **the physician should always describe the type (dry, wet, mixed) and presumed etiology of gangrene**.<sup>2,4</sup> When documentation reads "**[[gangrene]]**" with no qualifier, assign **[[I96]]** for claim submission and simultaneously generate a CDI query to capture the underlying cause for current and future risk adjustment encounters.<sup>3</sup>

## ✅ Includes

- **Gangrene NOS** — Applies when the physician documents gangrene without any qualifier and no more specific code is clinically supported; use **[[I96]]** and initiate **CDI** query to capture etiology.<sup>1</sup>
- **Senile gangrene** — Refers to dry gangrene typically occurring in elderly patients secondary to advanced arteriosclerotic changes, when the physician has not documented a specific vascular diagnosis such as PAD; assign **[[I96]]** only when **Excludes1 alternatives** have been ruled out.<sup>1,4</sup>
- **Gangrenous cellulitis NOS** — **[[Cellulitis]]** with superimposed tissue necrosis in the absence of a more specific **ICD-10-CM classification**; represents an infectious and ischemic overlap presentation that may warrant **CDI** query to distinguish from necrotizing fasciitis (**[[M72.6]]**).<sup>1,4</sup>

## ❌ Excludes

### Excludes 1

**I70.26-** — **Gangrene** in **[[atherosclerosis]]** of native arteries of the extremities — When PAD with gangrene is documented, the laterality-specific I70.26- code (**e.g., [[I70.261]] right leg, [[I70.262]] left leg**) replaces **[[I96]]** entirely; these codes cannot appear together on the same claim under any circumstance.<sup>2</sup> The I70.26- codes carry built-in etiology and laterality specificity that is always preferred over the **NEC** designation of **[[I96]]** whenever atherosclerosis is the documented underlying mechanism.<sup>2</sup>

**I73.-** — **[[Gangrene]]** in other peripheral vascular diseases — When **PVD** with **[[gangrene]]** is documented (**e.g., thromboangiitis obliterans, [[I73.1]]**), the I73.- combination code is assigned in preference to **[[I96]]**; the mutually exclusive nature of this exclusion means querying for the specific **PVD** type is a high-yield CDI opportunity.<sup>2</sup>

**[[A48.0]]** — **Gas gangrene** — **Gas gangrene** is a life-threatening clostridial myonecrosis that is biologically, clinically, and classificationally distinct from the vascular and idiopathic gangrene captured by **[[I96]]**; **[[A48.0]]** is always assigned in preference to I96 when the physician explicitly documents gas **gangrene**, and the two codes may never appear together on a claim.<sup>2</sup>

**[[K40.1]] / [[K40.4]] / [[K41.1]] / [[K41.4]] / [[K42.1]] / K43.1- / [[K44.1]] / [[K45.1 ]]/ [[K46.1]]** — **Gangrene in hernia** — Each **[[hernia]]** type in **ICD-10-CM includes** a dedicated "**with gangrene**" combination code; whenever gangrene complicates a **[[hernia]]**, the **hernia-gangrene** combination code from the **K40–K46 range** is assigned and **[[I96]]** is excluded.<sup>2</sup>

**L88** — **Pyoderma gangrenosum** — Despite its name, **[[pyoderma gangrenosum]]** is an **autoinflammatory ulcerative skin disorder** — not ischemic or infectious **gangrene** — and has its own dedicated code **[[L88]]**; assigning **[[I96]]** for **pyoderma gangrenosum** is both clinically incorrect and an **Excludes1 violation**.<sup>2</sup>

> [!danger]
> The most frequent **Excludes1 error** with **[[I96]]** is assigning it alongside a diabetic gangrene code such as **[[E11.52]]** or **[[E10.52]]**; when diabetes is the documented etiology of the gangrene, the **E08–E13 .52** **combination code** captures both conditions and I96 must not be additionally assigned — this is a payer audit trigger.<sup>3,4</sup> An equally common violation is pairing **[[I96]]** with **[[I70.261]]** or **[[I70.262]]** on the same claim when **PAD** with gangrene is clearly documented; the more specific code wins every time, and the two are never billable together.<sup>3</sup>

### Excludes 2

Per the **ICD-10-CM FY2026 official tabular**, there are no **Excludes2 notations** at the **[[I96]]** level. Coders should verify the current year's tabular at each annual update, as **Excludes2** entries can be added in subsequent fiscal year releases.<sup>1</sup>

## 📋 Clinical Overview

### I96 vs. Condition-Specific Gangrene Codes — Choosing Correctly

**[[Gangrene]]** is a final common pathway for multiple underlying diseases, and **ICD-10-CM provides etiology-specific combination codes** for the most common causes; **[[I96]]** is appropriate only after those alternatives have been considered and documented as not applicable.<sup>2,4</sup> The table below contrasts **[[I96]]** with two high-frequency **Excludes1 alternatives** to illustrate the documentation-driven distinction that should drive code selection at the inpatient level.<sup>2,3</sup> Understanding these distinctions is critical for both **DRG** optimization and **HCC risk adjustment** accuracy.<sup>5,7</sup>

| Feature | **[[I96]]** | **[[I70.261]]** | **[[E11.52]]** |
|---|---|---|---|
| **Etiology** | Unspecified or NEC — no identifiable cause, or etiology not classifiable elsewhere; includes senile and [[gangrenous]] [[cellulitis]] NOS | Peripheral arterial disease — [[atherosclerosis]] of native arteries of the right leg with gangrene as the documented endpoint | Type 2 diabetes mellitus with peripheral angiopathy progressing to gangrene — DM is the primary documented cause |
| **Laterality** | Not captured — no laterality character exists in this code | Right leg — left leg uses [[I70.262]]; laterality must be specified in operative and progress notes | Not captured in this code — laterality of the gangrenous limb may be captured via associated wound or ulcer codes |
| **HCC Impact (v24)** | HCC 106 — high RAF; gangrene tier; annual recapture required | HCC 106 — same HCC tier; more specific etiologic capture; preferred when PAD is documented | HCC 18 — Diabetes with Chronic Complications; stacks with vascular HCC when both PAD and DM are documented as separate conditions |
| **Excludes1 Interaction** | Excluded whenever I70.26-, I73.-, [[E11.52]], or hernia-gangrene codes apply | Mutually exclusive with [[I96]] — if assigned, [[I96]] cannot also be reported | Mutually exclusive with [[I96]] when DM is the documented gangrene etiology; both cannot appear on the same claim for the same limb |
| **CDI Trigger** | Always — specificity almost always available upon physician query | Query for laterality confirmation and vascular study correlation | Query for DM type if unspecified; query for relationship between DM and gangrene if not explicitly documented |

> [!important]
> When a patient has both documented **PAD** and type 2 diabetes with **[[gangrene]]**, query the physician to identify which condition is the primary driving etiology — this answer determines whether **[[I70.261]]/[[I70.262]] or [[E11.52]]** is the principal or most significant secondary code, directly affects which **HCC** tiers are captured, and governs the **Excludes1 restrictions** in effect for the encounter.<sup>3,4</sup> Never assume the relationship between a comorbidity and gangrene without explicit physician linkage in the documentation.<sup>3</sup>

### Manifestations & Symptom Burden

- **Tissue [[necrosis]] / discoloration** — **Dry gangrene** presents with shriveled, mummified, black or brown tissue; wet **[[gangrene]]** shows **[[edema]]**, **[[malodor]]**, skin blistering, and sometimes crepitus if gas-forming organisms are involved — documentation of these findings anchors the diagnosis.<sup>4</sup>
- **Pain progressing to anesthesia** — Early **ischemic gangrene** presents with severe **ischemic pain**; as neural tissue dies, the affected area becomes insensate — this progression, when documented, supports the severity staging expected for **MCC**-level coding.<sup>4</sup>
- **Demarcation line** — A clear boundary between viable and **necrotic tissue** is a hallmark clinical finding; when documented by the physician, it provides strong audit support for the **[[gangrene]]** diagnosis and differentiates it from severe **[[cellulitis]]** or deep tissue injury.<sup>4</sup>
- **Systemic toxicity / sepsis** — Wet and mixed gangrene frequently precipitate SIRS or frank **[[sepsis]]**; **sepsis** (**[[A41.9]] or organism-specific alternatives**) should be additionally coded when documented, and sequences as principal diagnosis per **CG I.C.1.d** when it is the primary reason for admission.<sup>4,6</sup>
- **Limb loss requiring amputation** — Advanced gangrene frequently necessitates surgical amputation; post-procedural limb absence is captured with Z89.- status codes (**e.g., [[Z89.511]], [[Z89.512]]**) in subsequent encounters.<sup>6</sup>

> [!tip]
> When the **physician** documents **[[sepsis]]** in the setting of gangrenous tissue, sequence sepsis as the principal diagnosis per the **[[sepsis]]** sequencing guidelines and assign **[[I96]]** as a secondary code — this captures **[[I96]]**'s **MCC** weight, elevating the **DRG** tier and maximizing compliant reimbursement for the encounter.<sup>3,5</sup> Confirm that the physician has explicitly linked the gangrene to the infectious source before coding both; coders may not independently infer a causative relationship between **[[sepsis]]** and **[[gangrene]]** without documentation support.<sup>3</sup> Additionally, when **[[necrotizing fasciitis]]** is suspected or documented alongside gangrenous tissue, query whether **[[M72.6]]** should be assigned as a more specific code for the deep tissue component.<sup>4</sup>

## 💰 HCC Risk Adjustment

| HCC Model | HCC Category | Label | Est. RAF Weight |
|---|---|---|---|
| **CMS-HCC v24** | HCC 106 | Atherosclerosis of the Extremities with Ulceration or Gangrene | ~1.488 |
| **CMS-HCC v28** | Verify via CMS crosswalk | Reorganized model — confirm current mapping annually | TBD |
| **RxHCC** | N/A | Not mapped in the Rx-HCC model | N/A |

**ICD-10-CM [[I96]]** is among the **highest-acuity vascular ICD-10-CM codes** in the **CMS-HCC** framework, reflecting the significant resource utilization, mortality risk, and downstream care costs associated with **gangrenous limb loss** and its sequelae.<sup>7</sup> Under **CMS-HCC** **v24, HCC 106** carries an approximate **RAF** weight of 1.488, representing a substantial contribution to capitation payments for **Medicare Advantage plans**; the **CMS-HCC v28** restructuring (**effective for payment year 2024**) reorganized several vascular **HCC** categories, and coders should verify the current **[[I96]]** mapping using the CMS-published **ICD-10-CM-to-HCC crosswalk** file for the applicable plan year.<sup>7</sup> Because **gangrene** is not classified as a chronic condition in the **HCC** model, it is not carried forward by default year to year — it must be actively re-documented and re-coded at each risk adjustment encounter, making annual recapture a priority for **MA** plan **CDI** programs.<sup>7</sup> Concurrent documentation of the underlying chronic diseases driving the **gangrene** (**PAD, DM, CKD**) is critical for capturing the full **HCC** hierarchy and stacking **RAF** weights across multiple mapped conditions.<sup>7</sup>

## 🏥 MS-DRG Assignment

| Scenario | MDC | DRG | Title |
|---|---|---|---|
| **[[I96]]** as PDx — no OR procedure — with MCC | MDC 05 | DRG 299 | Peripheral Vascular Disorders with MCC |
| **[[I96]]** as PDx — no OR procedure — with CC | MDC 05 | DRG 300 | Peripheral Vascular Disorders with CC |
| **[[I96]]** as PDx — no OR procedure — no CC/MCC | MDC 05 | DRG 301 | Peripheral Vascular Disorders without CC/MCC |
| **[[I96]]** as SDx — lower extremity amputation performed | MDC 08 | DRG 483–489 | Major Lower Extremity Amputation (varies by level and CC/MCC) |

When **[[I96]]** is the principal diagnosis without a qualifying **OR** procedure, the case groups to **MDC 05** medical **DRGs 299–301**, with the tier determined by whether other secondary diagnoses qualify as **CCs** or **MCCs**.<sup>5</sup> I96 itself carries **MCC status** in the **MS-DRG** **CC/MCC** designation table; when it appears as a secondary diagnosis, it independently pushes the case into the MCC tier for any principal diagnosis — making failure to code it as a secondary diagnosis a missed reimbursement opportunity.<sup>5</sup> When **amputation** or major **[[debridement]]** with **OR**-qualifying status is the principal inpatient procedure, the case migrates to a surgical **DRG** — typically in the **DRG 483–489 amputation range** for lower extremity procedures — substantially elevating the relative weight and **IPPS** base payment.<sup>5</sup> Coders must confirm that the procedure qualifies as an OR procedure under grouper logic; bedside wound care and **non-selective [[debridement]]** (**CPT [[97602]]**) do not meet the threshold, while **excisional [[debridement]]** (**CPT [[97597]]/[[97598]]**) and **bone debridement** (**CPT [[11044]]**) may, depending on documentation depth and facility grouper version.<sup>3,5</sup>

## 🛠️ Commonly Associated CPT Codes

**[[97597]]** — **[[Debridement]], open wound; first 20 sq cm or less** — Primary **excisional debridement** service for **gangrenous** tissue; reportable per session performed, and requires documentation of wound size, depth, and tissue layers removed.<sup>8</sup> Note that **[[97597]]** is **selective/excisional debridement** and may qualify as an **OR** procedure under some inpatient grouper logic when documentation supports the depth of tissue removal.

**[[97598]]** — **Debridement, open wound; each additional 20 sq cm** — Add-on code to **[[97597]]** for wounds exceeding 20 sq cm; subject to **NCCI** bundling edits and cannot be reported without the primary **[[97597]]** service on the same date.<sup>8</sup>

**[[27882]]** — **Amputation, leg, below the knee**; with immediate fitting technique including application of first cast — **Below-knee amputation** for non-salvageable distal **[[gangrene]]**; triggers the surgical **DRG partition (DRG 483–489)** when reported on an inpatient claim, substantially increasing relative weight.<sup>8</sup> Operative note must document the level of transaction and laterality to support both **CPT** selection and **ICD-10-PCS code assignment**.

**[[27880]]** — **Amputation, leg, through tibia and fibula** — Standard below-knee amputation through the **[[diaphysis]]** without immediate cast technique; distinguish from **[[27882]]** based on operative note documentation of fitting technique, and from partial foot amputation (**[[28800]]/[[28805]]**) based on the documented level of resection.<sup>8</sup>

**[[93925]]** — **Duplex scan of lower extremity arteries or arterial bypass grafts, bilateral** — Vascular flow assessment frequently ordered to evaluate arterial perfusion prior to surgical decision-making in gangrenous limb patients; reportable separately and not bundled with wound care or amputation CPT codes.<sup>8</sup>

**[[11044]]** — **[[Debridement]], bone (includes epidermis, dermis, subcutaneous tissue, muscle and bone); first 20 sq cm or less** — Used when gangrenous tissue involvement reaches bone level, commonly in the setting of concurrent **[[osteomyelitis]]**; a higher-complexity, separately reportable service distinct from soft tissue debridement.<sup>8</sup>

### NCCI Bundling Considerations

**Debridement CPT codes [[97597]]** and **[[97598]]** are subject to NCCI edits when billed with E/M services on the same date; modifier **[[-25]]** on the E/M (**or [[-59]]/[[-XS]] on the [[debridement]] per payer policy**) may be required to override the edit when a separately identifiable **E/M** service is documented.<sup>8,9</sup> Amputation codes (**[[27880]], [[27882]]**) bundle routine closure and stump wound care; do not additionally report wound closure **CPT codes** for the amputation stump unless a distinctly separate repair is documented.<sup>8</sup> Code **[[11044]]** for bone debridement is only reportable when the operative note explicitly documents bone resection; infer this from the clinical context — imaging alone is not sufficient to support the code selection.<sup>8,9</sup>

## 🔬 ICD-10-PCS Crosswalk

**0Y6N0Z0** — **Detachment of Right Foot, Complete, Open Approach** — Assigned when complete amputation of the right foot is performed for gangrenous tissue loss; Root Operation is Detachment (**6**), Body System is Anatomical Regions Lower Extremities (**Y**), Body Part is Right Foot (**N**), Approach is Open (**0**), Qualifier is Complete (**0**).<sup>10</sup> The Complete qualifier applies when the foot is amputated at or proximal to the metatarsal-tarsal joint; verify the level in the operative report before assigning.

**0Y6P0Z0** — **Detachment of Left Foot, Complete, Open Approach** — Mirror code for left foot amputation; identical Root Operation, Body System, Approach, and qualifier logic as **0Y6N0Z0**; laterality is the only distinction and must be confirmed from operative documentation.<sup>10</sup>

**0HBMXZZ** — **Excision of Right Foot Skin, External Approach** — Assigned when debridement is limited to the skin layer of the right foot; Root Operation is Excision (**B**), Approach is External (**X**) capturing sharp or excisional surface debridement without open incision; confirm tissue depth in the operative note before defaulting to this code over a deeper excision alternative.<sup>10</sup>

**0JBN0ZZ** — **Excision of Right Foot Subcutaneous Tissue and Fascia, Open Approach** — When debridement extends into subcutaneous tissue and fascia below the dermis, this **PCS** code replaces the skin-only Excision; Root Operation remains Excision (**B**); the Open approach (**0**) reflects incisional entry into the tissue plane; depth of **[[debridement]]** must be explicitly documented in the operative note to support code selection at this level.<sup>10</sup>

## 💊 Coding Scenarios and Examples

**Scenario 1 — Dry Gangrene, Unspecified Etiology, No OR Procedure**
A 79-year-old male is admitted with blackened, mummified tissue of the right second and third toes. Vascular studies are ordered but not resulted at discharge. The attending physician documents "dry gangrene of the right second and third toes — etiology under investigation." Wound care is performed at bedside; no OR procedure is documented.
- **Principal diagnosis:** [[I96]]
- **Additional diagnoses:** Document and code any separately managed comorbidities (e.g., HTN, CKD) that meet UHDDS criteria as additional diagnoses
- **DRG:** DRG 301 (Peripheral Vascular Disorders without CC/MCC) if no secondary CCs or MCCs are present; DRG 299 or 300 if comorbidities qualify
- **Sequencing note:** [[I96]] is appropriate here because the etiology is genuinely unspecified at discharge; the record should be flagged for possible amendment if outpatient workup yields a definitive vascular or metabolic diagnosis
- **CDI note:** Query the attending: "Does the patient have underlying peripheral arterial disease, diabetes mellitus, or another systemic condition that may be the etiology of the documented gangrene? If so, please document the clinical relationship to support more specific code assignment."

**Scenario 2 — Wet Gangrene with Sepsis, Below-Knee Amputation, PAD Documented**
A 66-year-old female with documented type 2 diabetes and peripheral arterial disease is admitted with wet gangrene of the left foot and systemic sepsis. The physician explicitly documents "gangrenous left foot secondary to peripheral arterial disease" with positive blood cultures for Streptococcus species. Below-knee amputation is performed via open approach.
- **Principal diagnosis:** [[A40.9]] (Streptococcal sepsis, unspecified) — sepsis is the reason for admission; sequences first per CG I.C.1.d
- **Additional diagnosis:** [[I70.262]] (Atherosclerosis of native arteries of left leg with gangrene) — PAD is the documented etiology; [[I96]] is **NOT** assigned — Excludes1 applies
- **Additional diagnosis:** [[E11.65]] — Type 2 diabetes mellitus with hyperglycemia, if documented as managed during the admission
- **Procedure (ICD-10-PCS):** 0Y6P0Z0 — Detachment of Left Foot, Complete, Open Approach (verify level from operative report)
- **DRG:** Surgical partition — MDC 08 DRG 483–489 depending on amputation level and CC/MCC profile
- **Sequencing note:** [[I96]] is explicitly excluded by [[I70.262]] and must not be additionally assigned; assigning both is an Excludes1 violation and audit risk

**Scenario 3 — Fournier's Gangrene (Perineal Necrotizing Fasciitis)**
A 52-year-old male is admitted emergently with rapidly spreading necrosis of the perineum, scrotum, and inner thighs with gas on CT imaging. The physician documents "Fournier's gangrene — necrotizing fasciitis of the scrotum and perineum" with evidence of systemic sepsis.
- **Principal diagnosis:** [[A41.9]] (Sepsis, unspecified organism) — if sepsis is documented as the driving reason for admission; sequences first per sepsis CG
- **Additional diagnosis:** [[N49.3]] (Fournier's disease) — the specific code for perineal gangrene; I96 is **NOT** assigned — [[N49.3]] is the applicable specific code that takes precedence
- **DRG:** Surgical DRG if operative debridement with OR status is performed; otherwise groups under sepsis MDC 18 DRGs
- **Sequencing note:** I96 is displaced by [[N49.3]], which is the correct etiology-specific code for Fournier's disease; coding both would be redundant and incorrect
- **CDI note:** Query the physician for organism documentation; source-specific sepsis codes (A40.-, A41.-) provide greater specificity and strengthen the audit defense for this high-risk, high-acuity case.

## ⚠️ Coding Pitfalls and Tips

1. **Never assign [[I96]] when an Excludes1 alternative applies.** The most frequent audit finding associated with **[[I96]]** is pairing it with **[[I70.261]], [[I70.262]], [[E11.52]], or [[E10.52]]**; when gangrene has a documented etiology, the etiology-specific combination code replaces I96 entirely — it does not supplement it.<sup>3</sup>
2. **I96 in secondary position is a high-yield reimbursement lever.** When **[[gangrene]]** is a complicating secondary diagnosis — for example, **gangrenous toes** in a patient admitted for sepsis — **[[I96]]** in the secondary position carries **MCC** weight and pushes the **DRG** to a higher tier; failure to code it as an additional diagnosis when documented is a missed revenue opportunity with direct IPPS impact.<sup>5</sup>
3. **Pyoderma gangrenosum ([[L88]]) is not true gangrene.** **Pyoderma gangrenosum** is an autoinflammatory ulcerative skin disorder driven by **immune dysregulation**, not **[[ischemia]]** or infection; assigning **[[I96]]** for this condition is both clinically incorrect and an **Excludes1 violation** — always use **[[L88]]** when the physician documents **pyoderma gangrenosum**.<sup>2</sup>
4. **Do not assign [[A48.0]] without explicit physician documentation of gas gangrene.** Imaging findings such as **[[subcutaneous]]** gas on X-ray or CT do not independently support **[[A48.0]]**; in the absence of physician documentation of clostridial gas **[[gangrene]]**, **[[I96]]** with a secondary **[[sepsis]]** code is the appropriate interim assignment pending CDI query response.<sup>3,4</sup>
5. **The NEC designation in [[I96]] is a CDI prompt, not a coding permission slip.** The built-in "**not elsewhere classified**" qualifier signals that specificity exists somewhere in the classification; in virtually every inpatient encounter with gangrene, a physician query will yield either a more specific **Excludes1 code** or explicit documentation supporting **[[I96]]** as a deliberate final choice — both outcomes are superior to defaulting to **[[I96]]** without query.<sup>3</sup>
6. **Amputation level drives DRG selection — verify from the operative report.** Partial foot amputation, below-knee (**transtibial**), and above-knee (**transfemoral**) procedures each map to different **ICD-10-PCS codes** and different **DRGs**; an incorrectly assigned **[[amputation]]** level results in significant undercoding or overcoding of the relative weight and is an **OIG** focus area for inpatient surgical claims.<sup>5,10</sup>

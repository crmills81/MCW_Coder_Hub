# 🧬 ICD-10-CM S01.81XA — Open Wound of Other Part of Head, Initial Encounter

> [!success] Billable Code Confirmed
>
> **ICD-10-CM [[S01.81XA]]** is a valid, billable **7-character ICD-10-CM
> code** for FY2026. Characters confirmed: `S01` (open wound of head) +
> `.8` (other parts of head) + `1` (other specified part) + `X`
> (**placeholder — required structural character**) + `A` (initial
> encounter). All 7 positions are occupied. This code is complete and
> will process on a claim.

> [!important] ⭐ CIC Exam Concept — The X Placeholder Rule
>
> The **placeholder X** in S01.81XA is one of the most important structural
> rules in all of ICD-10-CM and a high-frequency CIC exam topic.
> Understanding it completely:
>
> **The Rule:** When a code requires a 7th character but the base code
> has fewer than 6 characters, a dummy **X** is inserted to fill
> each empty position between the base code and the 7th character.
>
> **Why it matters:** **ICD-10-CM** 7th characters MUST occupy the **7th
> position** — not any earlier position. The X holds the place so the
> encounter type always lands in slot 7.
>
> **S01.81XA breakdown:**
> ```
> Position:  1    2    3    4    5    6    7
> Character: S    0    1    .    8    1    X    A
>                                    ↑         ↑
>                          5-char base    7th char (encounter)
>                                    X fills position 6
> ```
>
> **Without the X:** S01.81A would place `A` in the 6th position —
> making the code structurally invalid and claim-rejectable.
>
> **Multiple placeholder Xs:** Some codes need more than one X. Example:
> [[T36.0X1A]] (**poisoning by penicillins, accidental, initial encounter**) uses
> X to fill position 5 before the intent character in position 6 and
> encounter character in position 7.

> [!warning] Non-Billable Parent Codes — Never Submit These
>
> - ❌ `S01.8` — 5-character subcategory — non-billable header; missing
>   6th character, placeholder, and 7th character
> - ❌ `S01.81X` — 6-character — missing 7th character encounter type;
>   will reject
> - ❌ `S01.81` — 5-character — non-billable header
>
> Always submit **[[S01.81XA]]** (all 7 characters) for an initial
> encounter open wound of this head site.

## 🔍 Code Description

**ICD-10 CM [[S01.81XA]]** classifies an **open wound of another specified part of
the head, presenting at the initial encounter** — meaning the patient is
actively receiving treatment for the wound at this visit. "**Open wound**" in
ICD-10-CM indicates a break in the integrity of the skin and underlying
tissues — encompassing lacerations, puncture wounds, incised wounds, open
bites, and avulsions at the specified head site, when not classified to a
more specific S01.x subcategory (**scalp, eyelid, nose, ear, cheek,**
**lip/oral cavity**).

At the **initial encounter (7th character A)**, the treating provider is
delivering active wound management — this includes the emergency department
visit where the wound is first evaluated and repaired, any subsequent
visits while the wound is still actively being treated (**e.g., infected**
**wound requiring repeat debridement and antibiotic packing**), and the
initial surgical repair. Once active treatment concludes and the wound
is in the routine healing phase, the 7th character transitions to **D
(subsequent encounter)**.

## ⭐ The 7th Character — Most Critical Concept in Chapter 19

The 7th character in Chapter 19 (S00-T88) is the single most important
coding decision for every injury code. It determines the phase of care,
drives billing compliance, and is one of the highest-tested concepts on
the CIC exam. Understanding when to use A, D, and S is non-negotiable
for inpatient and outpatient injury coding.

### 7th Character Options for S01.81X_

| 7th Char | Code | Description | When to Use |
|----------|------|-------------|-------------|
| **A** | **[[S01.81XA]]** | **Initial encounter** | Active treatment of the wound — ED visit, first repair, wound still actively managed; may span MULTIPLE visits if patient is still receiving active treatment for the same injury |
| **D** | [[S01.81XD]] | Subsequent encounter | Routine follow-up during healing phase — suture removal, dressing change, wound check when active treatment is complete and wound is healing normally |
| **S** | [[S01.81XS]] | Sequela | A NEW condition arising as a DIRECT late effect of the original wound — scarring ([[L90.5]]), disfigurement, nerve damage, chronic pain documented as sequela; the sequela condition is sequenced FIRST, S01.81XS as additional code |

> [!danger] The #1 7th Character Mistake — Misapplying A vs. D
>
> **The most common error:** Assuming that "initial encounter" means
> the patient's **FIRST** visit ever. It does not. "Initial encounter" means
> the patient is receiving **active treatment** for the injury — regardless
> of how many visits have occurred.
>
> **Example:** A patient has an open head wound repaired in the ED (**Visit 1 →**
> **S01.81XA**). She returns 3 days later because the wound is infected and
> requires debridement and resuturing (Visit 2 → **still S01.81XA** —
> still receiving active treatment). She returns again 10 days later only
> for suture removal and wound check, healing well (Visit 3 → **S01.81XD**
> — now in the subsequent/routine healing phase).
>
> **The rule in plain language:**
> - Still treating the wound → **A**
> - Wound is healing, just monitoring → **D**
> - Old healed wound caused a NEW problem → **S** (with the new problem
>   coded first)

### 7th Character A — Does NOT Mean "First Visit Only"

> [!tip] CIC Exam Tip — "Initial" Means Active Treatment, Not First Contact
>
> ICD-10-CM Official Coding Guidelines (**Section I.C.19.a**) explicitly
> state: *"While the patient may be seen by a new or different provider
> over the course of treatment for an injury or condition, assignment of
> the 7th character is based on whether the patient is undergoing active
> treatment and not whether the provider is seeing the patient for the
> first time."*
>
> This means:
> - Patient transferred to a different hospital → still **A** if active
>   treatment continues
> - Patient sees a specialist for the first time for the same injury →
>   still **A** if active treatment continues
> - Patient returns to the same ED 5 times for wound management → all
>   visits are **A** until active treatment is complete
>
> The transition from **A → D** happens when the nature of the visit
> shifts from **treatment** to **monitoring/healing management**.

## 📋 Clinical Overview

### Open Wound Classification — Types Captured Under S01.81XA

**[[S01.81XA]]** encompasses multiple types of open wounds at the
specified head site when the wound type is not further specified in
the documentation:

| Wound Type | Clinical Description | Documentation Cue |
|---|---|---|
| **Laceration** | Irregular tear through skin and soft tissue — typically from blunt force | "Laceration," "lac," "torn," "jagged wound" |
| **Incised wound** | Clean, sharp-edged cut — from knife, glass, sharp object | "Cut," "incised," "sharp wound," "knife wound" |
| **Puncture wound** | Deep, narrow wound from pointed object — skin may close over depth | "Puncture," "stab," "nail wound," "penetrating" |
| **Open bite** | Wound from teeth — animal or human | "Bite wound," "dog bite," "human bite," "animal attack" |
| **Avulsion** | Tearing away of skin/tissue from underlying structures | "Avulsion," "degloving," "flap injury," "skin torn away" |

> [!important] Foreign Body Presence — Code It When Documented
>
> If the physician documents a **foreign body** within the wound
> (embedded glass, gravel, wood fragment, metal), a more specific code
> within the S01.8x family may be appropriate — separate from S01.81XA
> which represents an unspecified open wound. Review the tabular for
> S01.8x foreign body subcodes. Foreign body documentation also drives
> CPT code selection — wound exploration with foreign body removal
> ([[97602]], [[10120]], [[10121]]) may be separately billable.

### Wound Depth and Associated Structures

The clinical documentation of **wound depth** is critical for both code
specificity and CPT wound repair tier selection:

| Depth | Structures Involved | CPT Repair Level |
|---|---|---|
| **Superficial** | Epidermis ± dermis only | Simple repair (12011-12018) |
| **Subcutaneous** | Into subcutaneous fat | Simple to intermediate |
| **Deep/muscular** | Fascia, muscle involvement | Intermediate to complex |
| **Bone/periosteum** | Down to skull/facial bone | Complex ± exploration |
| **Intracranial** | Dural penetration → TBI workup | Code associated TBI (S09.x) |

> [!danger] Open Wound + Skull/Facial Fracture — Code Both
>
> When a patient has an open wound of the head AND an underlying skull
> fracture ([[S02.x]]) or facial bone fracture, **code both** — the open
> wound code (S01.81XA) and the fracture code are not mutually exclusive.
> In fact, an open wound overlying a skull fracture may constitute an
> **open fracture** — review fracture codes for open vs. closed distinction
> and whether the fracture code itself captures the open nature. When
> the fracture code specifies "open," the wound may be captured within
> the fracture code rather than separately — review documentation and
> tabular instructions carefully.

## 🔢 External Cause Coding — Required for Every Injury

External cause codes are **mandatory companion codes** for S01.81XA
under ICD-10-CM Official Coding Guidelines (Section I.C.20). They do
not affect DRG grouping but are required for:

- Trauma registry reporting
- Public health injury surveillance
- Workers' compensation claims (often required by payer)
- Legal/liability documentation
- Quality and safety metrics

### External Cause Code Structure for S01.81XA

Every S01.81XA encounter should have ALL four external cause components:

| Component | Code Series | Purpose | Example |
|---|---|---|---|
| **Cause/mechanism** | W00-X58, X71-Y09 | HOW the injury occurred | [[W50.0XA]] Struck by/against object; [[X00.01XA]] Flames; [[Y04.0XXA]] Assault |
| **Place of occurrence** | Y92.x | WHERE it happened | [[Y92.000]] Home, kitchen; [[Y92.480]] Sports/athletic area |
| **Activity** | Y93.x | WHAT patient was doing | [[Y93.89]] Other activity; [[Y93.K9]] Unknown activity |
| **External cause status** | Y99.x | Work vs. leisure | [[Y99.0]] Civilian activity done for income; [[Y99.8]] Other external cause status |

### Most Common External Cause Codes Paired with S01.81XA

| Scenario | External Cause Code |
|---|---|
| Fall striking head on object | [[W18.09XA]] — Fall on/from other specified surface |
| Struck by object | [[W22.8XXA]] — Striking against or struck by other objects |
| Motor vehicle accident (driver) | [[V49.50XA]] — Driver of car in collision |
| Assault — struck by fist | [[Y04.0XXA]] — Assault by unarmed brawl or fight |
| Dog bite | [[W54.0XXA]] — Dog bite |
| Sports injury | [[W19.XXXA]] — Unspecified fall (if from sporting activity) |
| Cut by glass | [[W25.XXXA]] — Contact with sharp glass |
| Workplace injury | W/X code + [[Y99.0]] external cause status |

> [!tip] Sequencing — Injury Code Always Sequences Before External Cause
>
> External cause codes (W, X, Y series) are **never** principal or
> first-listed diagnosis codes. They are always additional codes,
> sequenced **after** the injury code:
>
> 1. [[S01.81XA]] — Open wound of other part of head, initial encounter
>    *(principal/first-listed)*
> 2. [[W22.8XXA]] — Struck by other objects, initial encounter
>    *(additional — cause)*
> 3. [[Y92.000]] — Home, kitchen *(additional — place)*
> 4. [[Y93.E9]] — Activity, other *(additional — activity)*

## 🏥 MS-DRG Assignment

**Note:** ICD-10 CM S01.81XA as an isolated open wound of the head is an
**extremely rare inpatient principal diagnosis** — the vast majority
of open head wound encounters are managed in the emergency department
or outpatient setting. The DRG information below applies to the rare
inpatient scenario where the wound itself (**or associated complications**)
drives admission.

| DRG | Title | Est. Relative Weight* |
|-----|-------|-----------------------|
| **DRG 913** | Traumatic Injury **with MCC** | ~1.80-2.20 |
| **DRG 914** | Traumatic Injury **with CC** | ~0.90-1.20 |
| **DRG 915** | Traumatic Injury **without CC/MCC** | ~0.60-0.80 |

<small>*Approximate. Verify against IPPS FY2026 Final Rule tables.</small>

> [!note] When S01.81XA Appears as Inpatient Additional Diagnosis
>
> In the inpatient setting, **S01.81XA** most commonly appears as an
> **additional diagnosis** alongside a more severe injury driving
> admission — a traumatic brain injury ([[S09.90XA]]), subdural hematoma
> ([[S06.4XXA]]), skull fracture ([[S02.0XXA]]), or polytrauma (**T07**). In
> these cases, the more specific/severe injury is sequenced as principal,
> and **S01.81XA** is captured as a secondary/concurrent injury. Under UHDDS
> and Official Coding Guidelines (**Section II**), principal diagnosis for
> trauma = the injury most responsible for the admission after study.

| [[12056]] | Intermediate repair, same sites | 6.05 | 20.1-30.0 cm |
| [[12057]] | Intermediate repair, same sites | 7.51 | over 30.0 cm |

#### Complex Repair — S01.81XA (Head/Face Site)

| CPT | Description | wRVU | Length Range |
|-----|-------------|------|-------------|
| [[13131]] | Complex repair, forehead/cheeks/chin/mouth/neck/axillae/genitalia/hands/feet | 5.18 | 1.1-2.5 cm |
| [[13132]] | Complex repair, same sites | 7.70 | 2.6-7.5 cm |
| [[13133]] | Complex repair, same sites — each additional 5 cm | 3.54 | add-on per 5 cm |

> [!important] Repair Complexity Definitions — Know These for CIC
>
> | Complexity | Definition |
> |---|---|
> | **Simple** | Superficial wound — epidermis, dermis, [[subcutaneous]] tissue; one-layer closure; no deep sutures; no contamination requiring debridement |
> | **Intermediate** | Wound requires layered closure of deeper subcutaneous tissue AND/OR non-granulating contaminated wounds requiring single-layer closure after extensive cleaning |
> | **Complex** | Wounds requiring more than layered closure — scar revision, debridement, extensive undermining, retention sutures, complicated lacerations |
>
> **⚠️ Complexity is determined by what the physician DID, not the
> appearance of the wound.** A wound that looks complex but was closed
> with a single layer = simple. A wound repaired with deep and
> superficial layers = intermediate. Document complexity in the note.

### Wound Length Aggregation Rule

> [!tip] Add Wound Lengths Together — Same Site, Same Complexity
>
> When multiple wounds are repaired at the same anatomic site with
> the same complexity, **add all lengths together** and select one CPT
> code for the total combined length:
>
> Example: Three simple lacerations on the scalp/head — 1.5 cm + 2.0 cm
> + 1.8 cm = 5.3 cm total → **[[12013]]** (simple, 2.6-5.0 cm... wait,
> 5.3 cm → **[[12014]]** simple, 5.1-7.5 cm)
>
> Different sites OR different complexities = **separate CPT codes**,
> NOT added together.

| CPT | Description | wRVU | Application |
|-----|-------------|------|-------------|
| [[10120]] | Incision and removal of FB, subcutaneous tissue, simple | 1.28 | Simple subcutaneous FB in wound |
| [[10121]] | Incision and removal of FB, subcutaneous tissue, complicated | 2.99 | Deep or complicated FB removal |
| [[97602]] | Non-selective debridement | 0.73 | Wound debridement — infected/contaminated |
| [[97597]] | Debridement, open wound, first 20 sq cm | 1.77 | Active wound debridement |

### E/M + Wound Repair — Modifier -25 Rule

> [!caution] Modifier [[-25]] Required When E/M Is Billed Same DOS as Wound Repair
>
> In the outpatient/ED setting, when a **separately identifiable E/M
> service** is performed on the same day as a wound repair, the E/M
> must be reported with **modifier -25** (significant, separately
> identifiable E/M service on the same day as a procedure). The E/M
> work must be documented as distinct from the wound repair itself —
> evaluation of the mechanism, neurological assessment, co-management
> of comorbidities, or evaluation of associated injuries qualifies.
>
> A routine wound evaluation immediately preceding repair (the
> "look at the wound, clean it, repair it" sequence without additional
> clinical decision-making) does NOT support a separate E/M — it is
> bundled into the repair. Documentation should clearly distinguish
> the separately identifiable E/M work from the procedure.
>
> Example: ED physician evaluates patient for head wound + performs
> neurological exam + orders CT head + makes management decisions
> regarding underlying TBI → **[[99283]][[-25]]** (E/M, moderate complexity)
> + **[[12013]]** (wound repair) — both billable.

## 💊 Coding Scenarios and Examples

---

### Scenario 1 — Simple Laceration Repair, ED, Initial Encounter (Outpatient)

> **Clinical Vignette:** A 28-year-old male presents to the ED after
> a fall from a ladder at a construction site. He has a 3.2 cm
> laceration to the right forehead/temple area (not scalp — above the
> hairline). The ED physician performs a neurological exam (normal),
> orders no imaging, and closes the wound with a single-layer simple
> closure using 4-0 nylon sutures. No foreign body. No loss of
> consciousness. Patient discharged home.

**Diagnosis Codes:**
- [[S01.81XA]] — Open wound of other part of head, initial encounter
  *(forehead — not scalp, not cheek/nose/ear/lip — other specified part)*
- [[W11.XXXA]] — Fall on and from ladder, initial encounter *(external
  cause — mechanism)*
- [[Y93.H9]] — Activity, building and construction *(activity code)*
- [[Y99.0]] — Civilian activity done for income *(worker at time of
  injury)*
- [[Y92.69]] — Other industrial and construction area *(place of
  occurrence)*

**CPT Codes:**
- [[99283]]-25 — ED E/M, moderate medical decision making *(neurological
  assessment, clinical decision-making — separately identifiable from
  the repair; modifier -25 required)*
- [[12013]] — Simple repair, face/ears/eyelids/nose/lips/mucous membranes,
  2.6-5.0 cm *(3.2 cm single-layer closure, face/head site)*

> [!tip] Forehead Maps to S01.81XA — Not Scalp
> The **forehead** (**frontalis region, above eyebrows, below hairline**)
> is NOT part of the scalp — scalp codes (S01.0x) apply to the
> hair-bearing cranial surface. A forehead laceration is correctly
> coded as **[[S01.81XA]]** (other part of head). A laceration that
> extends from the forehead into the scalp would require clinical
> documentation of the predominant injury site and coding guidance
> review for multiple wound sites.

### Scenario 2 — Complex Repair with Foreign Body Removal, Initial Encounter

> **Clinical Vignette:** A 19-year-old female is brought to the ED
> after a motor vehicle accident — unrestrained passenger. She has a
> 4.5 cm jagged laceration on the right temple with embedded glass
> fragments. The ED surgeon performs extensive irrigation and
> [[debridement]], removes multiple glass fragments, and closes the wound
> with deep absorbable sutures (**[[subcutaneous]] layer**) followed by
> superficial nylon suture closure. CT head negative for intracranial
> injury.

**Diagnosis Codes:**
- [[S01.81XA]] — Open wound of other part of head, initial encounter
- [[V49.50XA]] — Passenger in car in collision with unspecified motor
  vehicle, initial encounter *(external cause)*
- [[Y92.410]] — Street and highway as place of occurrence

**CPT Codes:**
- [[13132]] — Complex repair, forehead/cheeks/etc., 2.6-7.5 cm *(4.5 cm,
  layered closure with undermining/debridement = complex complexity)*
- [[10120]] — Incision and removal of FB, subcutaneous tissue, simple
  *(glass fragments removed — separately reportable)*
- [[99285]][[-2]]5 — ED E/M, high complexity *(polytrauma evaluation, CT
  imaging ordered, clinical complexity)*

> [!important] Why This Is Complex, Not Intermediate
> The wound required:
> - **Deep layered closure** (absorbable subcutaneous layer)
> - **Extensive debridement** (glass fragment removal, irrigation)
> - **Undermining** (documented tissue manipulation)
>
> All three criteria point to **complex** repair ([[13132]]), not
> intermediate ([[12052]]). The documentation should explicitly
> describe these elements — "extensive [[debridement]]," "layered closure
> with deep absorbable sutures," and "undermining of wound edges"
> are the exact phrases that support complex repair billing. A note
> that only says "sutured in layers" without debridement/undermining
> documentation may only support intermediate.

---

### Scenario 3 — Subsequent Encounter — Suture Removal, Healing Well

> **Clinical Vignette:** The same patient from Scenario 1 returns 10
> days later to the clinic for suture removal. The wound is well-healed,
> no infection, no complications. Sutures are removed. No new treatment
> required.

**Diagnosis Code:**
- [[S01.81XD]] — Open wound of other part of head, **subsequent
  encounter** *(active treatment is complete — wound is healing; 7th
  character transitions from A to D)*

**CPT Code:**
- [[99212]] or [[99213]] — Office visit, established patient *(evaluation
  of healing wound; suture removal is included in the global period of
  the repair CPT — NOT separately billable if within the global period of
  the original repair code)*

> [!caution] Suture Removal Within Global Period — Not Separately Billable
>
> Wound repair CPT codes ([[12011]]-[[13133]]) carry a **0-day global
> period** for Medicare and many payers — meaning the global period
> technically includes only the day of service. However, **suture removal
> is considered part of the normal follow-up of a wound repair** by most
> payers and is typically not separately billable during the routine
> healing process. If a medically necessary visit occurs for suture
> removal (or any routine healing check), the E/M may be billable
> depending on payer policy — but the suture removal itself is generally
> bundled. If the wound is infected or requires additional intervention
> at the follow-up visit, that additional intervention IS separately
> billable.
>
> ICD-10-CM: The 7th character **correctly transitions to D** at this
> visit — the active treatment (**repair**) is complete, and this visit is
> routine healing management.

### Scenario 4 — Inpatient — Head Wound as Additional Diagnosis in Polytrauma

> **Clinical Vignette:** A 52-year-old male is admitted following a
> high-speed MVA. He has a right temporal skull fracture ([[S02.0XXA]])
> with underlying epidural hematoma ([[S06.4X0A]]), right-sided flaccid
> hemiparesis ([[G81.01]]), and a 2.8 cm open laceration of the left
> forehead requiring wound repair in the OR during the same anesthetic
> session as the craniotomy.

**Principal Diagnosis:**
-  ICD-10 CM [[S06.4X0A]] — Epidural hemorrhage without loss of consciousness,
  initial encounter *(most responsible   condition after study — epidural hematoma driving neurosurgical
  intervention)*

**Additional Diagnoses:**
- [[S02.0XXA]] — Fracture of vault of skull, initial encounter
  *(concurrent traumatic injury)*
- [[S01.81XA]] — Open wound of other part of head, initial encounter
  *(forehead laceration — additional diagnosis; wound repaired
  intraoperatively)*
- [[G81.01]] — Flaccid hemiplegia affecting right dominant side **← MCC**
- [[V49.50XA]] — Passenger in car, collision with unspecified vehicle
  *(external cause)*

**ICD-10-PCS:**
- **00C40ZZ** — Extirpation of matter from epidural space, intracranial,
  open approach *(craniotomy for epidural hematoma evacuation)*
- **0HQ00ZZ** — Repair, skin of scalp/head, open approach *(OR wound
  repair of forehead laceration — concurrent with craniotomy)*

**MS-DRG Routing:**
- Principal = [[S06.4X0A]] → MDC 01 (Nervous System)
- [[G81.01]] = MCC → **DRG 64** *(intracranial hemorrhage/cerebral
  infarction with MCC)*

> [!note] Sequencing Polytrauma — Most Responsible Diagnosis Rule
> When multiple traumatic injuries are present, the Official Coding
> Guidelines (Section II.B) direct sequencing of the injury **most
> responsible for the admission after study** as principal. In this
> case, the epidural hematoma ([[S06.4X0A]]) drove the ICU admission
> and neurosurgical intervention — it is the unambiguous principal.
> [[S01.81XA]] is correctly captured as a secondary/additional trauma
> diagnosis. Both codes carry the same 7th character **A** because
> both injuries are being actively treated during this same admission.

### Scenario 5 — Sequela Encounter — Scarring After Healed Wound

> **Clinical Vignette:** The patient from Scenario 2 returns 14 months
> later to a plastic surgery clinic. The original temple laceration has
> healed but left a hypertrophic scar causing cosmetic disfigurement
> and mild pain at the scar site. The plastic surgeon documents:
> "Hypertrophic scar, right temple — sequela of prior traumatic
> laceration repaired 14 months ago."

**Diagnosis Codes:**
- [[L91.0]] — Hypertrophic scar *(sequela condition — sequences FIRST
  per Official Coding Guidelines; the new condition arising from the
  original wound)*
- [[S01.81XS]] — Open wound of other part of head, **sequela** *(7th
  character S — identifies the original wound as the cause of the
  current scar; always additional, always after the sequela condition)*

**CPT Code:**
- [[11305]] or scar revision code depending on procedure planned

> [!danger] Sequela Sequencing Rule — The New Condition Comes First
>
> This is one of the most commonly misapplied rules in all of Chapter
> 19. When coding a **sequela (7th character S)** encounter:
>
> **WRONG:** S01.81XS sequenced first, then [[L91.0]]
> **CORRECT:** [[L91.0]] (hypertrophic scar) first, then [[S01.81XS]]
> additionally
>
> ICD-10-CM Official Coding Guidelines (Section I.C.19.a) state:
> *"The sequela is sequenced first, followed by the injury code with
> the 7th character 'S'."*
>
> The injury code with 7th character S is purely the **causal link** —
> it answers "WHY does this patient have a hypertrophic scar?" It is
> never the principal or first-listed code. The condition that actually
> exists now — the scar, the chronic pain, the nerve damage — leads.
>
> **Common sequela conditions following open head wounds:**
>
> | Sequela Condition | Code | Sequences Before S01.81XS |
> |---|---|---|
> | Hypertrophic scar | [[L91.0]] | ✅ |
> | Scar/fibrosis of skin | [[L90.5]] | ✅ |
> | Post-traumatic headache | [[G44.309]] | ✅ |
> | Chronic pain at wound site | [[G89.28]] | ✅ |
> | Facial nerve damage | [[G51.8]] | ✅ |
> | Disfigurement | [[L90.5]] or [[M79.89]] | ✅ |

### Scenario 6 — Documentation Says "Laceration" — Is S01.81XA Still Correct?

> **Clinical Vignette:** An outpatient coder reviews an ED note.
> The physician documents: "2.5 cm laceration, right temple — repaired
> with simple interrupted sutures." The coder is deciding whether to
> use [[S01.81XA]] (open wound, other part of head, initial) or a
> more specific laceration subcode within S01.8x.

**Coding Action:**
Review the FY2026 tabular list for S01.8x to determine whether a
**laceration-specific subcode** exists at this family level:

- Some S01.x subcategories (e.g., S01.2x nose, S01.0x scalp) include
  specific subcodes distinguishing **laceration without FB**,
  **laceration with FB**, **puncture without FB**, **puncture with FB**,
  and **open bite** — each as a separate billable code
- At the **S01.8x level**, review the FY2026 tabular carefully for
  whether wound-type-specific subcodes exist for "other parts of head"
- If a more specific laceration subcode exists (e.g., S01.811xA —
  laceration without FB, other part of head) → **use the more specific
  code**
- If S01.81XA is the most specific available code at this body site →
  it is the correct assignment regardless of the documented wound type

> [!important] Always Use the Most Specific Code Available
> ICD-10-CM Official Coding Guidelines (Section I.B.3) direct coders
> to *"code to the highest degree of specificity."* This means:
> - **Check the full tabular expansion** at S01.8x before defaulting
>   to S01.81XA
> - If wound-type subcodes exist at this level for FY2026, select the
>   appropriate wound type (laceration, puncture, bite) over the
>   unspecified open wound code
> - If the physician documents only "open wound" without specifying
>   laceration vs. puncture → S01.81XA is appropriate
> - If documentation is ambiguous, query for wound type when the
>   distinction would change code assignment

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|--|----------------|
| ❌ | **Never omit the X placeholder** — S01.81A (without the X) places `A` in the 6th position; this is structurally invalid and will reject on claim; the X is non-negotiable |
| ❌ | **Never submit S01.81X (6 characters) without the 7th character** — the encounter type (A/D/S) is required; a claim without the 7th character is incomplete and will reject |
| ❌ | **Do not assume "initial encounter" means the first visit only** — 7th character A applies throughout active treatment regardless of visit number or provider; a wound being actively debrided on visit 4 is still 7th character A |
| ❌ | **Do not continue using A once active treatment is complete** — routine healing follow-up, suture removal visits, and wound checks after repair = 7th character D; failure to transition from A to D is a compliance risk |
| ❌ | **Do not sequence [[S01.81XS]] first** — when coding a sequela encounter, the sequela condition (scar, nerve damage, chronic pain) always sequences first; S01.81XS is always the additional code explaining the cause |
| ❌ | **Do not use S01.81XA when a more specific site code exists** — if the wound is on the scalp (S01.0x), nose (S01.2x), ear (S01.3x), cheek (S01.4x), or lip/oral cavity (S01.5x), use the site-specific code; S01.81XA is for other specified head locations not captured elsewhere |
| ❌ | **Do not use S01.81XA for burns, abrasions, or superficial wounds** — open wound codes (S01.x) require a break in skin integrity; abrasions map to S00.x (superficial injury of head); burns map to T20.x |
| ❌ | **Do not bill suture removal separately within the global period** — suture removal is bundled into the wound repair CPT; bill the E/M for the follow-up visit, not a separate suture removal procedure |
| ✅ | **The X placeholder rule is a CIC exam staple** — whenever a code has fewer than 6 characters before needing a 7th character, X fills every empty position; S01.81X + A = S01.81XA; multiple Xs are possible (T36.0X1A uses one X before intent, one before encounter) |
| ✅ | **External cause codes are required** — W/X/Y mechanism codes, Y92 place of occurrence, Y93 activity, Y99 status; sequence all after S01.81XA; never sequence external cause as principal |
| ✅ | **Modifier [[-25]] is required when E/M is billed same DOS as wound repair** — document separately identifiable E/M work beyond the wound evaluation itself (neurological exam, imaging decision-making, comorbidity management) |
| ✅ | **Aggregate wound lengths for same-site, same-complexity repairs** — add all wounds of the same complexity at the same anatomic site together before selecting the CPT repair code length range |
| ✅ | **Complex vs. intermediate vs. simple is determined by what was DONE** — layered deep closure + debridement + undermining = complex; layered closure without debridement/undermining = intermediate; single-layer closure = simple; documentation must support the complexity billed |
| ✅ | **Concurrent skull fracture or TBI — code both** — S01.81XA and the fracture/TBI code are not mutually exclusive; when both are documented, both should be coded; the more severe injury sequences as principal in the inpatient setting |
| ✅ | **In polytrauma — most responsible injury sequences first** — S01.81XA is rarely the principal diagnosis when competing with TBI, skull fracture, or hemorrhagic injury codes; sequence per OG Section II after study |
| ✅ | **Transition from A → D → S is linear but not automatic** — the 7th character changes based on clinical context at each visit; review what the provider is actually doing at each encounter before assigning; do not carry A forward indefinitely |

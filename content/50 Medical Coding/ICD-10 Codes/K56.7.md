# 🧬 ICD-10-CM K56.7 — Ileus, Unspecified

> [!success] Billable Code Confirmed — 5 Characters Complete
> **ICD-10 CM [[K56.7]]** is a valid, billable 5-character ICD-10-CM code for
> **FY2025/2026**.  Complete as written.

> [!warning] Unspecified Code — Use With Caution / Query First
> **ICD-10 CM [[K56.7]]** is the ileus code of last resort — use it ONLY when the
> type of **ileus** is genuinely undocumented or unknown.
> It is the **CDI query trigger** for the K56 family.
> Physician documents "ileus" without specifying type → **K56.7** interim
> → CDI query → resolve to specific code when response received.
> A more specific code is **ALWAYS** preferred when documentation supports it.

> [!danger] Excludes1 — K56.7 and K56.0 Are Mutually Exclusive
> **ICD-10 CM [[K56.7]]** and **[[K56.0]]** (**Paralytic Ileus**) cannot be coded
> together for the same condition — they are Excludes1.
> They are two different answers to the same question:
> **K56.7** = type UNKNOWN → **K56.0** = type KNOWN (**paralytic**)
> Once the type is determined → K56.7 is replaced by the specific code.

> [!note] FY2024 Coding Clinic Update Applies Here Too
> The October 1, 2023 removal of the **K56** **Excludes1** allows dual coding
> of **K56.7** WITH its documented underlying cause — same rule as [[K56.0]].
> See [[K56.0]] for full **FY2024** update discussion.

## 🔍 Code Description

**ICD-10 CM [[K56.7]]** classifies **ileus, unspecified** — a failure of intestinal motility or a bowel obstruction in which the specific **type** (**paralytic vs. mechanical; and if mechanical, the specific mechanism**) has not been documented or is not yet determinable from the medical record.  The condition itself is real and documented — the intestine is not moving normally, contents are not passing — but the physician has written only "**ileus**" without specifying whether the bowel failure is functional (**paralytic**) or structural (**mechanical**), or whether it represents a complete vs. partial obstruction.

## 💊 Coding Scenarios

---

### Scenario 1 — "Ileus" in the Progress Note — Query Required (K56.7 Interim)

> **Clinical Vignette:** An 81-year-old male is admitted with abdominal distension and nausea. Hospitalist documents "ileus" in the assessment. CT abdomen: dilated loops of small bowel, no clear transition point identified. No prior abdominal surgery. CDI query sent — response pending.

**ICD-10-CM (Interim — Pending Query):**
- **[[K56.7]]** — Ileus, unspecified *(interim — pending CDI query for type)*

**ICD-10-CM (After Query Response — Example A: Paralytic):**
- **[[K56.0]]** — Paralytic ileus *(replace K56.7 when physician confirms paralytic type)*

**ICD-10-CM (After Query Response — Example B: SBO from Adhesions):**
- **[[K56.51]]** — Intestinal adhesions with partial obstruction *(replace K56.7 when mechanical cause confirmed)*

---

### Scenario 2 — Post-Op Patient, "Ileus" Documented — K91.3- vs. K56.7 Decision

> **Clinical Vignette:** A 55-year-old female, post-op day 2 following laparoscopic cholecystectomy. Surgeon documents: "Post-op ileus" in progress note — no further specification. No CDI query submitted yet.

**Correct Approach:**
1. First check — is this a **postprocedural complication** of the cholecystectomy?
   → K56 Excludes1: postprocedural intestinal obstruction → [[K91.3-]] [web:327]
2. "Post-op ileus" explicitly attributing the ileus to the procedure → **[[K91.30]]** is the correct interim code — NOT K56.7
3. If attribution to the procedure is ambiguous → query: "Is this ileus a direct complication of the laparoscopic cholecystectomy, or is it due to another cause occurring in the postoperative period (opioids, metabolic, etc.)?"

> [!tip] "Post-Op Ileus" ≠ K56.7 Default
> The instinct to reach for [[K56.7]] when "post-op ileus" is documented is common but often wrong — the Excludes1 on K56 for postprocedural intestinal obstruction ([[K91.3-]]) means the procedural complication code takes priority when the ileus is attributed to the procedure. [web:327] K56.7 is appropriate when the ileus is postoperative in timing but NOT in causation.

---

### Scenario 3 — "Ileus" on Discharge Summary — Confirmed Unspecified (K56.7 Final)

> **Clinical Vignette:** An 88-year-old female with advanced dementia is admitted from a nursing home. Multiple comorbidities. Discharge summary documents "ileus — treated conservatively; resolved with bowel rest and IV fluids." No further specification. CDI query was submitted — physician responded: "Type not further specified; resolved with supportive care."

**ICD-10-CM (Final):**
- **[[K56.7]]** — Ileus, unspecified *(acceptable as final code — physician queried, responded with no further specificity; K56.7 accurately reflects what is known)* 
- Additional comorbidity codes per documentation

> [!note] K56.7 Is Acceptable as a Final Code When Query Yields No Specificity
> Per **ICD-10-CM guidelines**: "Unspecified codes are acceptable when clinical information is unknown or not available about a particular condition."  When a CDI query has been made and the physician confirms no further specification is possible or appropriate, **K56.7** is the correct final code — not a coding deficiency. The deficiency would be failing to query in the first place.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never use K56.7 when the type is documented** — paralytic → [[K56.0]]; mechanical → K56.1-K56.69-  |
| ❌ | **Never code K56.7 AND K56.0 together** — they are Excludes1; mutually exclusive  |
| ❌ | **Never default to K56.7 for "post-op ileus"** — check K56 Excludes1 for postprocedural obstruction (K91.3-) first  |
| ❌ | **Never skip the CDI query** — K56.7 without a query attempt is a coding deficiency; always attempt to resolve to a specific code |
| ✅ | **K56.7 = interim code + query trigger** — acceptable temporarily; goal is always resolution to a specific code  |
| ✅ | **K56.7 is acceptable as final code** after a CDI query yields no additional specificity from the physician  |
| ✅ | **FY2024 update applies** — K56.7 can be coded alongside underlying cause (peritonitis, hypokalemia, sepsis) effective October 1, 2023  |

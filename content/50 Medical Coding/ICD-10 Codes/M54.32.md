# 🧬 ICD-10 CM M54.32 — Sciatica, Left Side

> [!success] Billable Code Confirmed
> **ICD-10 CM [[M54.32]]** is a complete, billable **5-character ICD-10-CM diagnosis code** in the **FY2027** code set (**effective October 1, 2026**), where the fifth character "**2**" specifies the left side.<sup>1</sup> The parent **M54.3** subcategory was expanded with laterality characters **effective October 1, 2021** (**FY2022**), and no changes were made to the **M54.3- family** in the **FY2027** update.<sup>1</sup><sup>2</sup> It is valid for **HIPAA-covered claims** with dates of service October 1, 2026 through September 30, 2027.<sup>1</sup>

> [!warning] Non-Billable Parent Codes
> **M54** (**[[Dorsalgia]]**) is a non-billable category header requiring at minimum a fourth character.<sup>2</sup> **M54.3** (**[[Sciatica]]**) is a non-billable subcategory header that must be completed with a fifth-character laterality code.<sup>2</sup> Neither header may be submitted on a claim.<sup>2</sup>

> [!important] Clinical Context
> **[[Sciatica]]** describes **pain radiating from the back or buttock into the posterior or lateral leg along the sciatic nerve distribution**, most commonly from **L4, L5, or S1 nerve root irritation**.<sup>4</sup> **[[M54.32]]** is used only when the pain is documented on the left side, when **lumbago** is not documented alongside it, and when the provider has not attributed the **[[sciatica]]** to a specific structural cause such as an **intervertebral disc disorder.**<sup>2</sup>

> [!danger] Code Classification
> This is an **ICD-10-CM diagnosis** (symptom) code, not a procedure code. It is a **manifestations-type symptom code** in the **[[dorsalgia]]** family, and it may never substitute for the etiologic diagnosis when one is documented.<sup>2</sup>

## 🔍 Code Description

**ICD-10 CM [[M54.32]]** sits in subcategory **M54.3-** (**[[Sciatica]]**) within the **M54 Dorsalgia category of Chapter 13**, block **M50-M54** (**Other dorsopathies**).<sup>2</sup> The code was created in the **FY2022** update to add laterality specificity to **[[sciatica]]**, giving coders **[[M54.30]]** (unspecified side), **[[M54.31]]** (right side), and **[[M54.32]]** (left side) — notably, no bilateral code exists in this subfamily, which has not changed for **FY2027**.<sup>1</sup><sup>2</sup> When documentation specifies the affected side, the unspecified code **[[M54.30]]** should be avoided because payers increasingly question unspecified laterality on repeat encounters when the chart clearly identifies the side.<sup>2</sup>

**ICD-10 CM [[M54.32]]** is **a symptom code**, not an etiology code, and the **Excludes1 structure** of the subcategory is what forces correct etiologic coding.<sup>2</sup> If the provider documents **[[sciatica]]** due to a **[[lumbar]]** or **[[lumbosacral]]** **intervertebral disc disorder**, the applicable code is **[[M51.16]]** or **[[M51.17]]** rather than any **M54.3- code**.<sup>2</sup> If low back pain (**[[lumbago]]**) coexists with the **left-sided sciatica**, the correct code is **[[M54.42]]** (**lumbago with sciatica, left side**).<sup>2</sup> If the documentation describes a true **sciatic nerve lesion** or **[[neuropathy]]** rather than radicular pain, code **[[G57.00]]** instead.<sup>2</sup>

> [!example] Laterality Drives Code Selection
> Selecting **[[M54.32]]** over **[[M54.30]]** matters for payer review because **MAC LCDs** for **epidural steroid injections** require laterality-consistent documentation between the diagnosis, the operative report, and any laterality modifier on the **injection CPT code**.<sup>4</sup> A mismatch (**e.g., [[M54.32]] with a [[-RT]] injection**) is a common denial trigger under pre- and post-payment review.<sup>4</sup>

> [!tip]
> There is no **bilateral sciatica code** in the **M54.3- subfamily** — if documentation describes **bilateral sciatic pain**, query the provider rather than inventing a combination, and note that the **lumbago-with-sciatica family** (**M54.40-M54.42**) mirrors this same three-code, no-bilateral structure.<sup>2</sup>

## ✅ Includes

- **Left-sided sciatic distribution pain documented as sciatica without an established structural etiology**; this is the pure symptom-code use case.<sup>2</sup>
- **Radicular pain** from the left buttock to the posterior or lateral left lower extremity when the provider labels it sciatica and does not link it to a **disc disorder, [[stenosis]], or lumbago**.<sup>2</sup>
- **Post-traumatic or idiopathic left sciatica** when no more specific etiologic code is documented; if trauma is the cause and meets coding criteria, an injury code from **Chapter 19** sequenced per guideline may also apply.<sup>2</sup>
- **Left sciatica** documented by a provider who explicitly states the underlying cause is unknown or not yet established diagnostically.<sup>2</sup>

## ❌ Excludes

### Excludes 1

- **[[G57.00]]** — **Lesion of sciatic nerve**: a documented **sciatic nerve lesion**, **[[neuropathy]]**, or injury of the sciatic nerve itself is coded to **G57.0** and never to M54.3-; the two cannot be reported together for the same symptom.<sup>2</sup>
- **M51.1-** — **Sciatica due to intervertebral disc disorder**: when the [[sciatica]] is attributed to a [[lumbar]] or [[lumbosacral]] disc displacement, code the etiology (**[[M51.16]]** or **[[M51.17]]**) and do not add an M54.3- code.<sup>2</sup>
- **M54.4-** — **Sciatica with lumbago**: when low back pain coexists with [[sciatica]], the combination code family (**[[M54.40]]-[[M54.42]]**) replaces the [[sciatica]]-only code entirely.<sup>2</sup>
- **[[M51.361]]** / **[[M51.371]]** — **Intervertebral disc [[degeneration]] of the lumbar or lumbosacral region with lower extremity pain only**: these [[degeneration]]-with-pain codes capture the radiating leg pain scenario without a separate [[sciatica]] code.<sup>2</sup>
- **[[F45.41]]** — **Psychogenic [[dorsalgia]]**: at the category level, [[dorsalgia]] due to a somatic symptom disorder is excluded from the entire **M54 category**.<sup>2</sup>

> [!danger]
> The most frequent **Excludes 1 error** is coding **M54.3-** alongside a disc disorder code, or coding **[[M54.32]]** alongside **[[M54.42]]** when **[[lumbago]]** is documented. In both cases the **Excludes 1 note** makes the combination invalid — assign only the more **specific combination or etiology code**.<sup>2</sup> **Auditors** treat this as a compliance finding, not just a claim edit.

### Excludes 2

- No **Excludes 2 note** is published at the **M54.3- subcategory level**; there are no conditions flagged as separately reportable by virtue of an **Excludes 2** at this level of the **tabular**.<sup>2</sup> Always check the **parent M54 category notes** in the current-year tabular for any additions each October 1.

## 📋 Clinical Overview

### Sciatica: Symptom Code vs Etiology Code vs Combination Code

The distinction among these codes is the single biggest driver of correct code selection for **left-sided radicular leg pain**, because the **Excludes 1** architecture forces the coder to pick exactly one of these pathways.<sup>2</sup>

| **Feature** | **[[M54.32]]** | **[[M54.42]]** | **[[M51.16]]** |
|---|---|---|---|
| **Definition** | Sciatica, left side — symptom code with no etiologic component.<sup>2</sup> | Lumbago with sciatica, left side — combination symptom code requiring both low back pain and left sciatica.<sup>2</sup> | Other intervertebral disc displacement, lumbar region, with radiculopathy — etiologic structural code.<sup>2</sup> |
| **When to use** | Provider documents left sciatica only, cause unspecified, no lumbago.<sup>2</sup> | Provider documents both low back pain and left-sided sciatica together.<sup>2</sup> | Provider attributes the left leg radicular pain to a lumbar disc displacement/herniation.<sup>2</sup> |
| **Etiology documented** | No; symptom-level coding only. | No; symptom-level coding only. | Yes; structural disc pathology is integral to the code.<sup>2</sup> |
| **Mutual exclusivity** | Excludes 1 against M51.1-, M54.4-, and G57.0-, so it cannot be reported with them for the same symptom.<sup>2</sup> | Replaces [[M54.32]] when lumbago is present — M54.3- is Excludes 1 to M54.4-.<sup>2</sup> | [[M54.32]] cannot be added as an additional code — the radiculopathy/sciatica component is built in.<sup>2</sup> |

> [!important]
> **CDI trigger**: any note that says "**[[sciatica]]**" near mention of **[[disc herniation]]**, **[[stenosis]]**, **[[spondylolisthesis]]**, or **[[lumbago]]** should be reviewed before final code assignment. The presence of an etiologic diagnosis or coexisting **low back pain** immediately redirects the coder away from **M54.32** to **[[M51.16]]**, **[[M51.17]]**, **[[M54.42]]**, or **[[M48.062]]** (**lumbar spinal [[stenosis]] with neurogenic [[claudication]]**).<sup>2</sup>

### Manifestations & Symptom Burden

- **Radiating pain from the left buttock down the posterior or lateral thigh and leg**, often to below the knee, following the L4-S1 dermatomal pattern of the sciatic nerve.<sup>2</sup>
- **Positive straight leg raise (Lasègue sign) on the left with reproduction of radicular pain**, a hallmark exam finding supporting the diagnosis.<sup>2</sup>
- **[[Paresthesia]], numbness, or [[dysesthesia]] in the affected left dermatome**; sensory symptoms alone should prompt evaluation for **G57.0** or a radiculopathy code such as **[[M54.16]]** instead.<sup>2</sup>
- **Functional impairment** — the MAC epidural steroid injection LCDs expect documentation that pain is severe enough to cause functional or vocational impairment or disability before interventional treatment is considered reasonable and necessary.<sup>4</sup>
- **Objective neurologic findings** (**weakness, reflex asymmetry, dermatomal sensory loss**) that support [[radiculopathy]]; concordant imaging is required before most interventional pain procedures are covered.<sup>4</sup>

> [!tip]
> **Sciatica manifestations** are not separately coded — **[[M54.32]]** captures the symptom complex itself, and any distinct **neurologic deficit** or **causative structural finding** must be evaluated for its own etiologic code per the **Excludes 1 logic**.<sup>2</sup>

## 🏥 MS-DRG Assignment

| **DRG** | **Title** | **FY2027 Relative Weight** | **GMLOS** | **Notes** |
|---|---|---|---|---|
| **551** | Medical Back Problems with MCC | ≈1.6366 (about 70.7% above 552) | — | Requires an MCC as a secondary diagnosis.<sup>3</sup> |
| **552** | Medical Back Problems without MCC | 0.9584 | 2.9 | Two-tier family — CC-only complications also group here; average national operating payment ≈ $6,563.<sup>3</sup> |

When **[[M54.32]]** is the **principal diagnosis**, the claim groups to **MDC 08**, **Diseases and Disorders of the Musculoskeletal System and Connective Tecture**, in the two-tier **Medical Back Problems family**.<sup>3</sup> Because the family has only an **MCC tier (551)** and a **without-MCC tier (552)**, a CC-listed secondary diagnosis does not increase payment — the coder should still capture all CCs accurately for **severity-of-illness profiling** and **quality reporting** even when the **DRG** does not change.<sup>3</sup> Sequencing is straightforward when **[[sciatica]]** is the reason for admission, but if the **[[sciatica]]** is due to a documented **disc disorder**, the etiologic code becomes the principal diagnosis and the **DRG logic** follows it identically within the same family.<sup>2</sup><sup>3</sup>

**NCD/LCD Information:**

- There is **no NCD** for **epidural steroid injections**; coverage is governed entirely by **MAC LCDs**, such as **LCD L36920** (**Epidural Steroid Injections for Pain Management**).<sup>4</sup>
- Under the **ESI LCDs**, coverage requires documented **[[radiculopathy]]/radicular pain** with a structural correlate (**[[disc herniation]], [[osteophyte]] complex, severe DDD producing [[stenosis]]**), pain of at least 4 weeks' duration or failure of conservative care, and **concordant CT/MRI imaging**; **ESIs** are limited to 4 sessions per spinal region per rolling 12 months, **TFESIs** are limited to 2 levels per region per session, and **CT** or **fluoroscopic guidance** with contrast is required (**ultrasound without contrast only for documented contrast allergy or pregnancy**).<sup>4</sup><sup>5</sup>
- **Trigger point injections** are **not reasonable and necessary for low back pain** under the **TPI LCDs**, and routine use beyond 3 sessions per rolling 12 months is non-covered — do **not** rely on **[[M54.32]]** to support a **TPI claim** for **sciatica/low back pain**.<sup>6</sup>
- **North Carolina** is served by **Palmetto GBA, A/B MAC Jurisdiction M** — verify the **active ESI** and **TPI LCD versions** on the **CMS MCD** for **JM** before submission.<sup>8</sup>

## 🛠️ Commonly Associated CPT Codes

- **[[99213]]** / **[[99214]]** — Established patient E/M for evaluation and conservative management of sciatica; append **[[-25]]** when a significant, separately identifiable E/M is performed the same day as an injection.<sup>9</sup>
- **[[64483]]** — Transforaminal epidural steroid injection, lumbar/sacral, single level; append **[[-LT]]** for left-sided treatment to stay laterality-consistent with **[[M54.32]]**; fluoroscopic/CT image guidance is included per CPT and LCD requirements.<sup>4</sup><sup>9</sup>
- **[[64484]]** — Add-on code for each additional lumbar/sacral TFESI level in the same session; report with **[[64483]]** without a modifier, and remember the LCD caps TFESI at 2 levels per region.<sup>4</sup><sup>9</sup>
- **[[62323]]** — Interlaminar lumbar/sacral epidural steroid injection; bill one spinal level per session and no more than 4 injection sessions per rolling 12 months under the LCDs.<sup>4</sup><sup>5</sup>
- **[[20552]]** — Trigger point injection(s), 1-2 muscles; **not covered for low back pain under the TPI LCDs**, so verify [[myofascial]] trigger point criteria are independently met before billing with a [[sciatica]] diagnosis.<sup>6</sup>
- **[[20553]]** — Trigger point injection(s), 3 or more muscles; same LCD limitation of 3 sessions per rolling 12 months and no coverage for low back pain diagnoses.<sup>6</sup>
- **[[72148]]** — MRI lumbar spine without contrast; the diagnostic study that supports the concordant imaging requirement of the ESI LCDs.<sup>4</sup>
- **[[63030]]** — Lumbar [[laminotomy]] ([[hemilaminectomy]]) with [[decompression]] of nerve root(s) and excision of herniated intervertebral disc, the outpatient surgical decompression option when conservative measures fail.<sup>10</sup>

### NCCI Bundling Considerations

**Fluoroscopic image guidance** and **contrast administration** are inherent to **[[64483]]** and **[[62323]]** and are not separately billable — **never** append an image guidance code alongside the **injection** for the same session.<sup>4</sup> **[[20552]]** and **[[20553]]** are mutually exclusive with each other (**report one per session**), and a **same-day E/M** requires a significant, separately identifiable service with **[[-25]]** or it bundles into the **injection**.<sup>6</sup><sup>9</sup>

## 🔬 ICD-10-PCS Crosswalk

For **inpatient facility coding** when **[[sciatica]]** leads to surgical intervention:

- **0SB20ZZ** — **Excision of Lumbar Vertebral Disc, Open Approach**: assigned for open lumbar discectomy when a herniated disc is excised; this is the classic inpatient procedure path for refractory sciatica from disc displacement.<sup>11</sup>
- **0SB24ZZ** — **Excision of Lumbar Vertebral Disc, Percutaneous Endoscopic Approach**: assigned for minimally invasive endoscopic discectomy; note that the etiologic diagnosis (e.g., **[[M51.16]]**) is what supports the procedure, not **[[M54.32]]** itself.<sup>11</sup>
- **0S520ZZ** — **Destruction of Lumbar Vertebral Disc, Open Approach**: assigned for intradiscal ablative/nucleolysis-type procedures; percutaneous variants (**0S543ZZ**) apply to needle-based techniques.<sup>11</sup>
- **0SG30J0** — **Fusion of Lumbosacral Joint with Synthetic Substitute, Anterior Approach, Anterior Column, Open Approach**: an example of the fusion table for spinal stabilization procedures; per AHA Coding Clinic, decompressive laminectomy performed to free a nerve root codes to root operation Release (e.g., **01NB0ZZ**, Release of lumbar nerve, open approach), not excision.<sup>11</sup><sup>12</sup>

## 💊 Coding Scenarios and Examples

<br>

### Example 1

> **Clinical Scenario:**
> A 58-year-old established patient presents with 6 weeks of pain radiating from the left buttock down the posterior-lateral left leg to the calf, a positive left straight leg raise, and failure of 4 weeks of physical therapy and NSAIDs. MRI shows no discrete disc herniation or stenosis, and the provider documents "left sciatica, etiology unclear" and performs a left L5 transforaminal epidural steroid injection under fluoroscopic guidance.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99214]]-[[-25]] | Significant, separately identifiable E/M supported by the expanded history and exam and the medical decision making for the failed conservative care plan. |
| CPT 2 | [[64483]]-[[-LT]] | Single-level left lumbar TFESI; [[-LT]] keeps the procedure laterality consistent with the left-sided diagnosis, and the LCD criteria (4+ weeks, failed conservative care, functional impairment, exam findings) are all documented. |
| PDx | [[M54.32]] | Sciatica documented on the left with no lumbago and no attributed structural etiology, so the symptom code is correct and complete. |

> [!tip]
> Sequencing is straightforward — [[M54.32]] supports the medical necessity of the injection, but the LCD also requires concordant imaging; here the negative MRI is documented, which keeps the claim defensible under L36920-type criteria.<sup>4</sup> CDI note: if the provider had tied the pain to even a mild disc protrusion on that MRI, the correct code would become [[M51.16]] under the Excludes 1 note.<sup>2</sup>

### Example 2

> **Clinical Scenario:**
> A 66-year-old Medicare beneficiary is admitted with intractable left-sided sciatica unresponsive to outpatient management, managed inpatient with IV analgesics and an interlaminar lumbar epidural steroid injection. On hospital day 2 she develops acute kidney injury attributed to NSAID therapy, which progresses and meets MCC criteria before resolving. The physician documents sciatica as the reason for admission with the AKI attributed to medication.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[99223]] | Initial hospital care, high complexity — the admission E/M for the inpatient profee claim; the admission MDM reflects the severe uncontrolled symptom burden and treatment decisions. |
| PDx | [[M54.32]] | After study of the record the sciatica is the condition established after study to be chiefly responsible for the admission, with no structural etiology documented. |
| SDx | [[N17.9]] | Acute kidney injury meeting MCC criteria as a secondary diagnosis drives the assignment from DRG 552 up to DRG 551 (Medical Back Problems with MCC).<sup>3</sup> |

> [!tip]
The MCC is what converts the two-tier family from 552 to 551, raising the relative weight by roughly 70% — capture the AKI and its cause, and query if the AKI documentation lacks specificity.<sup>3</sup> CDI note: confirm the provider did not attribute the sciatica to an underlying stenosis or disc, which would change the principal diagnosis and require re-review of the Excludes 1 logic.<sup>2</sup>

### Example 3

> **Clinical Scenario:**
> A 47-year-old presents with chronic left low back pain accompanied by radiating left leg pain in an L5 distribution; the provider documents "low back pain with left sciatica" after 8 weeks of failed conservative therapy and proceeds with a lumbar interlaminar epidural steroid injection.

| **Field** | **Code** | **Rationale** |
|---|---|---|
| CPT | [[62323]] | Lumbar interlaminar epidural steroid injection; one spinal level per session per the LCD, with all coverage criteria (duration, conservative failure, exam, imaging) documented. |
| PDx | [[M54.42]] | Lumbago with sciatica, left side — the combination code replaces [[M54.32]] entirely because the M54.4- family is Excludes 1 to M54.3-, so the sciatica component cannot be split out. |

> [!tip]
> Do not code this as [[M54.59]] plus [[M54.32]] — the classification provides the combination code precisely for this documentation pattern.<sup>2</sup> CDI note: query the provider whenever lumbago and sciatica are both documented but the linkage is ambiguous, because the choice between [[M54.32]] and [[M54.42]] changes the code even though both group to the same DRG family.<sup>2</sup>

## ⚠️ Coding Pitfalls and Tips

- **Pitfall 1**: Defaulting to **[[M54.30]]** when the side is clearly documented in the record. **Payers** increasingly question unspecified **laterality** on repeat encounters and may deny for lack of specificity. **Tips**: Query for or extract the side from the **exam** and **procedure notes** before settling on unspecified; **[[M54.30]]** is a last resort.<sup>2</sup>
- **Pitfall 2**: Assigning **[[M54.32]]** when documentation attributes the **sciatica** to a **lumbar disc disorder**. The **M51.1- Excludes 1 note** makes this an invalid combination. **Tips**: Code **[[M51.16]]** or **[[M51.17]]** instead, and treat any "**sciatica secondary to HNP**" documentation as an automatic redirect away from the **M54.3- family**.<sup>2</sup>
- **Pitfall 3**: Coding **[[M54.32]]** alongside **[[M54.42]]** or a low back pain code when **[[lumbago]]** and **[[sciatica]]** are both documented. The **combination code** replaces the pair entirely. **Tips**: Use **[[M54.42]]** alone for **left lumbago with sciatica**, and never report a **sciatica** code with an **M54.4- code** for the same encounter.<sup>2</sup>
- **Pitfall 4**: Using **[[M54.32]]** to support a **trigger point injection** claim. The **TPI LCDs** explicitly state **TPIs** are not reasonable and necessary for low back pain and limit coverage to documented **myofascial trigger point syndromes**. **Tips**: Verify independent **trigger point** criteria (**taut band, twitch response, failed conservative care, ≥50% measured relief for repeats**) are met and documented before billing **[[20552]]**/**[[20553]]**.<sup>6</sup>
- **Pitfall 5**: Exceeding **ESI LCD utilization limits**. **ESIs** are capped at 4 sessions per **spinal region** per rolling 12 months, **TFESIs** at **2 levels per region** per session, and **image guidance** is mandatory. **Tips**: Track **injection** history across the record and append laterality **modifiers** that match the diagnosis to avoid pre-payment review denials.<sup>4</sup>
- **Pitfall 6**: Assuming **[[sciatica]]** risk adjusts or groups to a **neurology MDC**. **[[M54.32]]** maps to no **HCC** in **V28** and groups to **MDC 08, DRGs 551/552.** **Tips**: Capture the **code** accurately anyway because it drives procedure medical necessity, and do not chase a nonexistent **RAF impact** by **overcoding** etiologic diagnoses.<sup>3</sup><sup>7</sup>

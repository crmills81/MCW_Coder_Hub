# 🦽 ICD-10-CM Z99.3 — Dependence on Wheelchair

> [!success] Billable Code Confirmed — 4 Characters Complete
> **[[Z99.3]]** is a valid, billable 4-character ICD-10-CM code — complete
> as written. Valid FY2025 and FY2026. No additional
> characters required.

> [!danger] 🚨 UNACCEPTABLE AS PRINCIPAL DIAGNOSIS
> **[[Z99.3]]** CANNOT be sequenced as the principal diagnosis on any
> claim. It is a status/circumstance code that documents
> wheelchair dependence as a condition influencing health status — not
> an illness, injury, or reason for admission in its own right.
> Always sequence the **underlying cause** first.

> [!warning] Code First — Mandatory Sequencing Instruction
> ICD-10-CM instructs: **"Code first cause of dependence"** 
> The condition responsible for wheelchair dependence must be coded
> before [[Z99.3]]. The "Code First" list (muscular dystrophy, obesity)
> is illustrative only — any documented cause is acceptable. In PM&R,
> this most commonly means stroke sequelae (I69.3x), spinal cord
> injury, MS, ALS, or severe neurological/orthopedic conditions.

> [!note] POA Exempt
> **[[Z99.3]]** is exempt from Present on Admission (POA) reporting —
> no POA indicator is required or expected for this code on inpatient
> claims.

## 🔍 Code Description

**ICD-10 CM [[Z99.3]]** classifies **dependence on a wheelchair** — the condition in which a patient requires a wheelchair as the primary means of locomotion due to an underlying medical condition that limits or eliminates the ability to ambulate independently. The **ICD-10-CM** includes "**wheelchair confinement status**" as an included term, making this code appropriate for any patient whose documented **mobility status is wheelchair-dependent**, regardless of whether they have any residual ambulatory capacity with maximal assistance.

This is one of the most functionally descriptive codes in the **PM&R coding toolkit**. It communicates a patient's baseline mobility status, supports the medical necessity narrative for rehabilitation services, equipment authorization, and home modification planning, and contributes to the completeness of the clinical picture on inpatient rehabilitation claims. It is a **status code**, not a diagnosis of illness — its purpose is to document a functional circumstance, not a pathology.

---

## 🏥 PM&R Context — Why This Code Matters in Rehabilitation

In the inpatient rehabilitation setting, [[Z99.3]] does critical clinical documentation work that the impairment and etiologic diagnosis codes alone cannot accomplish. 

### What Z99.3 Communicates That Other Codes Don't

| Information Conveyed | How It's Used |
|---|---|
| **Patient's baseline mobility status** | Establishes pre-admission functional level for FIM scoring context |
| **Equipment need documentation** | Supports DME authorization for power wheelchair, manual wheelchair, accessories |
| **Home modification necessity** | Documents functional basis for ramp, widened doorway, accessible bathroom modifications |
| **Discharge planning complexity** | Wheelchair-dependent patients require more complex discharge arrangements — SNF, home with modifications, LTACH |
| **Caregiver burden documentation** | Informs documentation of caregiver need for transfers, skin integrity monitoring |
| **Therapy goal framing** | OT/PT goals in IRF are calibrated to wheelchair mobility, not ambulation |

### IRF-PAI and Z99.3

> [!important] Z99.3 on the UB-04 — Not on the IRF-PAI
> The **IRF-PAI** (Patient Assessment Instrument) does not use [[Z99.3]] as an IGC or etiologic code — those positions on the **IRF-PAI** are occupied by the impairment group code and the condition causing the impairment (e.g., [[I69.351]] for post-stroke hemiplegia). 
>
> **ICD-10 CM [[Z99.3]]** is reported on the **UB-04 claim form** as an additional/comorbidity diagnosis code that documents the patient's functional status. It does not drive the Case Mix Group (**CMG**) calculation directly but contributes to the overall clinical completeness of the record.
>
> FIM locomotion scoring at a wheelchair-dependent level (**FIM score 1-2 for locomotion: wheelchair**) should align with the presence of [[Z99.3]] in the medical record — coding and functional assessment should tell the same story.

## 🔗 Code First — Mandatory Underlying Condition

[[Z99.3]] cannot stand alone. The condition causing wheelchair dependence must be coded first and sequenced before [[Z99.3]] on the claim. In **PM&R**, these are the most common "**Code First**" conditions:

### PM&R — Most Common Underlying Conditions at Z99.3

| Underlying Condition | Code | Notes |
|---|---|---|
| **Stroke sequelae — hemiplegia** | [[I69.351]] / [[I69.352]] | Most common cause in IRF — right or left dominant hemiplegia |
| **Stroke sequelae — other** | [[I69.398]] | Other stroke sequelae driving wheelchair dependence |
| **Spinal cord injury — paraplegia** | [[G82.20]] / [[G82.21]] / [[G82.22]] | Complete or incomplete paraplegia |
| **Spinal cord injury — quadriplegia** | [[G82.50]]-[[G82.54]] | Complete or incomplete — C1-C8 levels |
| **Multiple sclerosis** | G35.- | Progressive MS with severe motor deficit |
| **ALS** | [[G12.21]] | Progressive — eventually complete wheelchair dependence |
| **Parkinson's disease** | G20.- | Advanced stage — falls risk → wheelchair for safety |
| **Muscular dystrophy** | [[G71.01]]-[[G71.09]] | Explicitly named in "Code First" instruction  |
| **Hip fracture — nonunion/severe** | M84.35x | Functional decline preventing ambulation |
| **Lower extremity amputation** | Z89.5x - Z89.6x | Post-amputation, non-prosthetic user |
| **Morbid obesity** | [[E66.01]] | Explicitly named in "Code First" instruction — obesity-related immobility |
| **Severe osteoarthritis — bilateral knees/hips** | [[M17.11]]/[[M16.11]] | Severe joint disease preventing weight-bearing |
| **Guillain-Barré syndrome** | [[G61.0]] | Acute phase — temporary wheelchair dependence |
| **Traumatic brain injury sequelae** | [[F07.81]] / I69.x | Post-TBI motor and cognitive deficits |
| **Cerebral palsy** | G80.x | Non-ambulatory CP — lifelong wheelchair use |

> [!tip] The "Code First" List Is Not Exhaustive — Code the Actual Documented Cause
> The **ICD-10-CM tabular** lists muscular dystrophy and obesity as examples under "**Code First**" — not as the only valid causes.  Any condition documented by the physician as the reason for **wheelchair dependence** is appropriate. In your inpatient profee and **PM&R** encounters, the cause is almost always explicitly documented in the H&P or rehab evaluation. Code what's documented — don't restrict yourself to the tabular examples.

### Mobility and Functional Status — Commonly Co-Coded with Z99.3

| Code | Description | When |

| [[I69.351]] | Hemiplegia, right dominant, post-stroke | Stroke is the cause → Code First → then Z99.3 |
| [[I69.352]] | Hemiplegia, left dominant, post-stroke | Left dominant side weakness → wheelchair |
| [[G82.20]] | Paraplegia, unspecified | SCI-related wheelchair dependence |
| [[G82.50]] | Quadriplegia, unspecified | Complete SCI → power wheelchair |
| [[Z74.09]] | Other reduced mobility | Mild/partial mobility limitation — less severe than Z99.3 |
| [[Z74.01]] | Bed confinement status | More severe — cannot transfer to wheelchair |
| [[R26.89]] | Other abnormalities of gait and mobility | Gait disorder — may co-exist if partial ambulation remains |
| [[Z89.511]] | Acquired absence of right leg below knee | Amputation → wheelchair pending prosthesis |
| [[Z96.641]] | Presence of right artificial hip joint | Post-THR — temporary wheelchair phase |

> [!note] Z99.3 vs. Z74.09 — Wheelchair Dependent vs. Reduced Mobility
> **[[Z99.3]]** = full wheelchair dependence — wheelchair is the primary means of locomotion
> **[[Z74.09]]** = reduced mobility — patient has limited mobility but is not fully wheelchair dependent
>
> Do not use [[Z74.09]] interchangeably with [[Z99.3]]. When the physician documents "wheelchair bound," "**wheelchair dependent**," or "**non-ambulatory**" → [[Z99.3]] is appropriate. When documentation states "limited mobility" or "uses walker with assistance" → [[Z74.09]] or a more specific gait/mobility code may be more accurate.

> [!caution] Z74.01 — Bed Confinement vs. Wheelchair Dependence
> **[[Z74.01]]** (**bed confinement status**) is assigned when the patient is **bedbound** — unable to transfer to a wheelchair. This is more severe than [[Z99.3]]. A bedbound patient cannot be a wheelchair user — do not assign both for the same patient simultaneously unless documentation supports that the patient is both bedbound for most of the day AND uses a wheelchair for limited transfers.

## 🏠 DME Coding Connection — Wheelchair Authorization

**ICD-10 CM [[Z99.3]]** is the foundational ICD-10-CM code supporting **DME authorization** for wheelchair equipment. In the outpatient and home health settings, this code — paired with the underlying cause — drives medical necessity for:

| Equipment | HCPCS Code | Z99.3 Role |
|---|---|---|
| **Manual wheelchair, standard** | E1130 | Primary supporting Dx |
| **Manual wheelchair, lightweight** | E1240 | Primary supporting Dx |
| **Power operated vehicle (scooter)** | K0010-K0014 | Primary supporting Dx |
| **Power wheelchair, Group 1** | K0813-K0816 | Primary supporting Dx |
| **Power wheelchair, Group 2** | K0820-K0843 | Primary supporting Dx |
| **Tilt-in-space wheelchair** | E1161 | Z99.3 + pressure injury/tone/positioning Dx |
| **Custom manual wheelchair** | E1161-E1239 | Z99.3 + complex rehab justification |
| **Seat cushion (pressure-relieving)** | E2601-E2622 | Z99.3 + pressure injury risk Dx |

> [!important] CMS Wheelchair Coverage — Z99.3 Is Never Enough Alone
> For Medicare DME coverage, [[Z99.3]] paired with the underlying cause establishes the **diagnosis basis** for the equipment, but medical necessity documentation must also include:
> - Physician face-to-face evaluation (**F2F encounter**)
> - Detailed written order (DWO) from the treating physician
> - Functional assessment documenting inability to ambulate
> - For complex rehab technology (**power wheelchairs**): PT/OT evaluation of seating needs
>
> [[Z99.3]] is the coding foundation; the clinical documentation is the coverage superstructure.

## 💊 Coding Scenarios

---

### Scenario 1 — Post-Stroke IRF Admission (Standard PM&R Use)

> **Clinical Vignette:** A 71-year-old male is admitted to the IRF 10 days after right MCA stroke. Left hemiplegia documented — left-sided weakness, unable to ambulate. Using standard manual wheelchair for all locomotion. FIM locomotion score: 2 (wheelchair, maximal assistance). FIM transfer score: 2. Rehabilitation goals: improve transfer independence, wheelchair mobility, and ADL participation.

**UB-04 Diagnoses:**
- [[I69.351]] — Hemiplegia and hemiparesis following cerebral infarction, right dominant side *(Code First — the stroke sequelae driving wheelchair dependence)*
- **[[Z99.3]]** — Dependence on wheelchair *(additional — accurately documents functional status; aligns with FIM locomotion score)*
- [[I63.311]] — Cerebral infarction, right MCA *(if acute stroke still documented as ongoing at IRF admission)*
- [[I10]] — Hypertension *(comorbidity)*
- [[R13.10]] — Dysphagia *(rehab target)*

> [!tip] Stroke Acute Code (I63.x) vs. Sequelae Code (I69.x) at IRF Admission
> At IRF admission, if the acute stroke is still within the acute phase (generally the initial inpatient stay), I63.x remains appropriate. Once the patient is in post-acute rehab and the acute phase has resolved, **I69.3x** (sequelae) becomes the appropriate code family. In practice, most IRF admissions are sequelae-phase — confirm the timing with the admitting documentation and transition to I69.x codes when appropriate per UHDDS guidelines.

---

### Scenario 2 — Spinal Cord Injury, Permanent Wheelchair Dependence

> **Clinical Vignette:** A 34-year-old male with T6 ASIA A complete paraplegia from motor vehicle accident 18 months ago presents for annual PM&R outpatient visit. Uses power wheelchair full time. No ambulatory capacity. ICD-10-CM documentation: "Complete paraplegia, T6 level, permanent. Wheelchair dependent."

**ICD-10-CM:**
- [[G82.21]] — Paraplegia, complete *(Code First — the cause of wheelchair dependence)*
- **[[Z99.3]]** — Dependence on wheelchair *(additional — permanent status; documents ongoing DME need)*
- [[S34.109S]] — Injury of unspecified nerve at T6 level — sequela *(if traumatic etiology still documented)*

> [!note] Permanent vs. Temporary Wheelchair Dependence — Same Code
> [[Z99.3]] does not distinguish between temporary (e.g., post-fracture recovery) and permanent (e.g., paraplegia) wheelchair dependence. The permanency of the underlying condition is documented through the underlying diagnosis code and the physician note — not through a modifier on [[Z99.3]]. Both scenarios use the same code.

---

### Scenario 3 — Obesity-Induced Wheelchair Dependence (The "Code First" Example)

> **Clinical Vignette:** A 52-year-old female with morbid obesity (BMI 58) is admitted to SNF after hospitalization for cellulitis. Unable to ambulate due to weight — wheelchair for all locomotion. No neurological deficit. Physician documents: "Wheelchair dependent due to morbid obesity — unable to bear weight for ambulation."

**ICD-10-CM:**
- [[E66.01]] — Morbid (severe) obesity due to excess calories *(Code First — explicitly listed in tabular instruction; directly causes wheelchair dependence)*
- **[[Z99.3]]** — Dependence on wheelchair *(additional — obesity-caused immobility)*
- [[L03.115]] — Cellulitis, right lower limb *(reason for admission)*

> [!important] Obesity as Code First for Z99.3 — Directly From the Tabular
> The ICD-10-CM tabular explicitly names obesity ([[E66.-]]) as one of the "Code First" examples for [[Z99.3]].  This is not hypothetical — severely obese patients who cannot ambulate due to weight represent a real and growing PM&R and SNF coding scenario. When the physician documents obesity as the direct cause of inability to ambulate → [[E66.01]] Code First, then [[Z99.3]].

---

### Scenario 4 — Temporary Wheelchair Dependence (Post-Surgical)

> **Clinical Vignette:** A 68-year-old female is discharged from acute care after right hip fracture ORIF to home health. Non-weight-bearing on right lower extremity per surgeon orders. Using wheelchair for all locomotion during non-weight-bearing phase. Expected to progress to ambulation with assistive device in 6-8 weeks.

**ICD-10-CM:**
- [[M84.351A]] — Stress fracture, right femur, initial encounter *(or appropriate hip fracture code per type)*
- **[[Z99.3]]** — Dependence on wheelchair *(additional — current functional status; non-weight-bearing = wheelchair dependent)*
- [[Z96.641]] — Presence of right artificial hip joint *(if joint replacement was performed)*

> [!note] Remove Z99.3 When Patient Progresses to Ambulation
> Unlike permanent neurological conditions, post-surgical wheelchair dependence is temporary. When the patient progresses to ambulation with a walker or cane, **[[Z99.3]] should be removed** from the active diagnosis list and replaced with a mobility/gait code if still applicable ([[R26.89]]). Status codes should reflect the patient's **current** functional status — not historical limitations.

## ⚠️ Coding Pitfalls and Tips

| | Pitfall or Tip |
|---|---|
| ❌ | **Never sequence Z99.3 as principal diagnosis** — it is unacceptable as a standalone reason for admission  |
| ❌ | **Never submit Z99.3 without coding the underlying cause first** — "Code First" is a mandatory sequencing instruction, not a suggestion |
| ❌ | **Never assign Z99.3 and [[Z74.01]] (bed confinement) together** for the same patient — bedbound and wheelchair-dependent are mutually exclusive functional states |
| ❌ | **Never use Z99.3 for a patient who uses a walker, cane, or crutches** — those are ambulatory assistive devices; [[Z99.3]] is for patients whose PRIMARY locomotion is a wheelchair |
| ❌ | **Never forget POA exempt status** — no POA indicator needed for Z99.3 on inpatient claims |
| ✅ | **Z99.3 = complete wheelchair dependence** — primary locomotion via wheelchair; not partial or assisted ambulators  |
| ✅ | **Code First = the documented medical cause** — stroke sequelae, SCI, MS, ALS, muscular dystrophy, obesity, amputation — whatever is documented as causing the dependence |
| ✅ | **Aligns with FIM locomotion score 1-2** — wheelchair level FIM scores in the IRF-PAI should correspond with [[Z99.3]] in the claim coding  |
| ✅ | **Supports DME authorization** for manual/power wheelchairs, seating systems, pressure cushions — critical for home discharge planning |
| ✅ | **Remove Z99.3 when patient progresses to ambulation** — status codes must reflect current functional status |
| ✅ | **Temporary or permanent — same code** — [[Z99.3]] applies regardless of whether the wheelchair dependence is expected to resolve |
| ✅ | **IRF comorbidity tier** — Z99.3 itself does not carry IRF comorbidity tier weight, but the underlying conditions causing it (stroke, SCI) do — code the underlying cause completely for maximum IRF-PPS comorbidity capture |

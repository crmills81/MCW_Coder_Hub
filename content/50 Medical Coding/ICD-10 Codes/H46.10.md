# 🧬 ICD-10-CM H46.10 — Retrobulbar Neuritis, Unspecified Eye

> [!success] Billable Code Confirmed
>
> **ICD-10-CM [[H46.10]]** is a valid, billable **5-character diagnosis code**. The characters build up as `H46` (**category — optic neuritis**) + `.1` (**retrobulbar neuritis**) + `0` (**unspecified eye / laterality**). No additional characters are required.

> [!warning] Non-Billable Parent Codes — Never Submit These
>
> - ❌ `H46` — 3-character category header — Lacks the specific type of optic neuritis.
> - ❌ `H46.1` — 4-character subcategory — Retrobulbar neuritis, but missing the required laterality (7th-character not used here; the 5th character carries laterality).
>
> Always submit **[[H46.10]]** (all 5 characters) when **retrobulbar neuritis** is documented without a specified eye. When the affected eye **is** documented, a more specific laterality code is required — **[[H46.11]]** (right), **[[H46.12]]** (left), or **[[H46.13]]** (bilateral).

> [!important] Clinical Context: "Unspecified" Refers to Laterality, Not Type
>
> In **ICD-10-CM [[H46.10]]**, the "**unspecified**" qualifier refers to the **eye (laterality)**, not the type of neuritis — the code already specifies the **retrobulbar** form. Assign [[H46.10]] only when the documentation does not identify which eye is affected. Because laterality is almost always clinically known, [[H46.10]] should be a **query opportunity**: prefer [[H46.11]]/[[H46.12]]/[[H46.13]] whenever the eye is documented.

> [!danger] Code Classification
>
> **ICD-10-CM Diagnosis Code** — **wRVU**, assistant payable, and global period fields are not applicable. See **CPT** Procedural Crosswalk for associated professional-services billing.

## 🔍 Code Description

**ICD-10-CM [[H46.10]]** classifies **retrobulbar neuritis of the unspecified eye** — an inflammatory demyelinating process of the **optic nerve posterior to the globe (retrobulbar)**, where the head of the optic nerve appears normal on funduscopic examination during the acute phase.

**Pathophysiologically**, retrobulbar neuritis is a form of **optic neuritis** in which inflammation and demyelination affect the orbital or intracranial portion of the optic nerve rather than the optic disc. Because the inflammation is behind the eye, the classic teaching is that "**the patient sees nothing and the doctor sees nothing**" — the patient has profound visual symptoms while the optic disc looks normal early on.

Clinically, patients present with **subacute, usually monocular vision loss** developing over hours to days, **periocular pain that worsens with eye movement**, **dyschromatopsia** (impaired color vision, especially red desaturation), and a **relative afferent pupillary defect (RAPD)** on the affected side. Visual acuity and central field are commonly affected (central scotoma). The condition is strongly associated with **multiple sclerosis** and is frequently its first clinical manifestation.

## ❌ Excludes

### Excludes 1 — Cannot Be Coded Simultaneously with H46.10

| Code | Description | Note |
|------|-------------|------|
| **[[A52.15]]** | Syphilitic retrobulbar neuritis | Mutually exclusive (Excludes1 at the H46.1 subcategory). When retrobulbar neuritis is due to syphilis, assign the syphilitic code instead of [[H46.10]]. |

### Excludes 2 — May Be Coded in Addition if Separately Present

| Code | Description | Note |
|------|-------------|------|
| **H47.01-** | Ischemic optic neuropathy | Excludes2 at the H46 category level — a distinct (vascular) optic neuropathy; code in addition only if separately documented. |
| **[[G36.0]]** | Neuromyelitis optica [Devic] | Excludes2 at the H46 category level — NMO-associated optic neuritis is part of the NMO spectrum; code in addition only if both are separately confirmed and documented. |

> [!tip] Optic Neuritis as a Sentinel for Demyelinating Disease
> Retrobulbar/optic neuritis is frequently the **first presentation of multiple sclerosis** and may also occur in **neuromyelitis optica (NMO, [[G36.0]])** and **MOG antibody-associated disease (MOGAD, [[G37.81]])**. When a definitive demyelinating diagnosis is established, capture that underlying condition (e.g., [[G35.A]] for relapsing-remitting MS) in addition to or instead of [[H46.10]], following the applicable Excludes guidance.

## 📋 Clinical Overview

### Associated and Underlying Conditions (Code Also / Code First as Appropriate)
Retrobulbar neuritis is often a manifestation of a broader process. Review documentation and capture related conditions actively being evaluated or managed:
- **[[G35.A]]** — Relapsing-remitting multiple sclerosis *(or the appropriate G35.x variant when MS is the established cause)*
- **[[G37.9]]** — Demyelinating disease of CNS, unspecified *(clinically isolated syndrome presenting as optic neuritis)*
- **[[G36.0]]** — Neuromyelitis optica [Devic] *(when documented; see Excludes2)*
- **[[H53.12]]** — Transient visual loss / **[[H53.8]]** — Other visual disturbances *(when documented)*

> [!important] Laterality Is the Key Specificity Question
> Because the eye affected is nearly always documented clinically, **[[H46.10]] (unspecified eye) should rarely be the final code**. If the record identifies the side, assign **[[H46.11]]** (right), **[[H46.12]]** (left), or **[[H46.13]]** (bilateral). Query the provider when laterality is missing.

**MDC 02 — Diseases and Disorders of the Eye**

> [!warning] Predominantly an Outpatient Diagnosis
> **[[H46.10]]** is billed overwhelmingly in **outpatient / professional-services** settings (neuro-ophthalmology and neurology clinics, diagnostic imaging, steroid or infusion management). Inpatient admission solely for retrobulbar neuritis is uncommon. If an inpatient encounter is billed, the code groups within **MDC 02**; verify the exact MS-DRG against the **IPPS FY2026 grouper** and capture all CCs/MCCs.

## 💊 Coding Scenarios and Examples

### Scenario 1 — Acute Presentation, Eye Not Yet Documented

> **Clinical Vignette:** A 30-year-old woman is referred for acute, painful vision loss over 4 days with red desaturation. The triage/problem-list entry states only "retrobulbar neuritis" without specifying the eye. Workup including MRI orbit and brain is ordered.

**Diagnosis (interim, from incomplete documentation):**
- [[H46.10]] — Retrobulbar neuritis, unspecified eye *(laterality not yet documented — query the provider)*

> [!tip] Resolve the Laterality Before Final Coding
> Once the examining provider documents the affected side, update to **[[H46.11]]** (right) or **[[H46.12]]** (left). [[H46.10]] should not be the final billed code when the eye is known.

---

### Scenario 2 — Laterality Documented: Do Not Use H46.10

> **Clinical Vignette:** Neuro-ophthalmology note documents "acute retrobulbar optic neuritis, **left eye**, with RAPD and central scotoma; MRI brain shows periventricular demyelinating lesions; neurology consult for possible MS."

**Action / Outcome:**
Because the affected eye is documented, **[[H46.10]] is not used**. Assign the laterality-specific code, and capture the demyelinating workup/diagnosis when established.

**ICD-10-CM Coding:**
- [[H46.12]] — Retrobulbar neuritis, left eye
- [[G37.9]] — Demyelinating disease of CNS, unspecified *(or [[G35.A]] if MS criteria are met and documented)*

## ⚠️ Coding Pitfalls and Tips

|     | Pitfall or Tip |
| --- | -------------- |
| ❌ | **Defaulting to H46.10 when the eye is known.** "Unspecified eye" refers to laterality; if the side is documented, use [[H46.11]]/[[H46.12]]/[[H46.13]]. Query when laterality is missing. |
| ❌ | **Coding H46.10 for syphilitic retrobulbar neuritis.** Excludes1 directs syphilitic cases to [[A52.15]] instead. |
| ❌ | **Missing the underlying demyelinating disease.** Optic neuritis is often the first sign of MS. Capture the established underlying diagnosis ([[G35.A]] / G35.x, or [[G37.9]] for CIS) when documented. |
| ✅ | **Confirm HCC and DRG before relying on them.** H46.10 likely carries no HCC weight and is predominantly outpatient — verify against the current CMS-HCC crosswalk and IPPS grouper. |
| ✅ | **Document the diagnostic basis.** RAPD, dyschromatopsia, pain on eye movement, MRI orbit enhancement, and VEP delay support the diagnosis and the medical necessity of imaging. |

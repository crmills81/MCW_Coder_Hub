# 🧠 ICD-10 CM G35.D — Multiple Sclerosis, Unspecified

> [!success] Billable Code Confirmed — FY2026 New Code
>
> **ICD-10 CM [[G35.D]]** is a valid, billable ICD-10-CM code **new for FY2026**, effective **October 1, 2025**. It is the designated billable code for **multiple sclerosis when the subtype and activity level are not documented** in the medical record after a good-faith query attempt.

> [!danger] CRITICAL FY2026 Change — G35 Is No Longer Billable
>
> - ❌ **G35** — Now a **non-billable parent code** as of October 1, 2025
> - ✅ **[[G35.D]]** — New billable code for MS, unspecified subtype/activity
>
> Any claim submitted with standalone **G35** after October 1, 2025 is **invalid and will reject or deny**. **[[G35.D]]** is the correct replacement for all MS encounters where subtype and activity level are genuinely not documented. Do **not** use G35 alone under any circumstances in **FY2026**.

> [!warning] G35.D Is the Last Resort — Always Query First
>
> **ICD-10 CM [[G35.D]]** should only be assigned after a good-faith effort to identify MS subtype and activity from the **medical record** or via **CDI query**. The **FY2026** expansion exists specifically to capture clinical distinctions that carry therapeutic, prognostic, and **risk-adjustment** significance. If the physician documents **ANY** subtype — use that code. **ICD-10 CM [[G35.D]]** is appropriate only when the record is genuinely silent on both subtype and activity after query.

> [!info] Code Classification
>
> **ICD-10-CM Diagnosis Code** — Fields for **wRVU**, assistant payable, and global period are not applicable. For associated inpatient procedure coding, see the **ICD-10-PCS** Crosswalk section below.

## 🔍 Code Description

**ICD-10 CM [[G35.D]]** classifies **multiple sclerosis, unspecified** — **a chronic, immune-mediated demyelinating disease of the central nervous system** in which the subtype (**relapsing-remitting, primary progressive, or** **secondary progressive**) and/or activity status (**active vs. non-active**) have not been documented in the medical record. It is the **FY2026** replacement for the previously standalone billable code **G35**.

**Multiple sclerosis** is characterized by **demyelination and axonal injury** throughout the CNS — brain, spinal cord, and optic nerves — producing plaques of inflammation and scarring at multiple sites. Clinical manifestations are highly variable depending on lesion location, ranging from **[[optic neuritis]] and sensory disturbances to motor weakness, [[spasticity]],** **cerebellar [[ataxia]], bladder dysfunction, and cognitive impairment.**

The **FY2026** restructuring of the **G35 category** reflects the clinical reality that MS subtype profoundly affects treatment selection, prognosis, and payer authorization. **[[G35.D]]** exists as a catch-all for encounters where this granularity is genuinely unavailable — it is not a preferred default. At every encounter coded with **[[G35.D]]**, a CDI query opportunity exists to upgrade to **[[G35.A]], [[G35.B0]]-[[G35.B2]],** **or [[G35.C0]]-[[G35.C2]]**.

## 📋 Clinical Overview

### The FY2026 MS Code Expansion — Why It Happened

Prior to **FY2026**, all of multiple sclerosis collapsed into a single billable code — **G35**. The **FY2026** expansion aligns ICD-10 CM M with the clinical reality neurologists have documented for decades: MS subtype (**RRMS, PPMS, SPMS**) and disease activity (**active vs. non-active**) are clinically fundamental distinctions that drive **FDA-approved DMT selection, payer authorization, and prognostic stratification**. The new structure directly reflects the 2013 MS Phenotype Descriptions published by the International Advisory Committee on Clinical Trials of MS.

|  FY2026 Code  | MS Subtype            |       Activity       | Key Clinical Notes                                                                                        |
| :-----------: | --------------------- | :------------------: | --------------------------------------------------------------------------------------------------------- |
|   [[G35.A]]   | Relapsing-remitting   | Active by definition | Most common subtype (~85% at diagnosis); relapses + remissions; all relapse-specific DMTs authorized here |
|  [[G35.B0]]   | Primary progressive   |     Unspecified      | Gradual worsening from symptom onset, no discrete relapses; activity unspecified — query                  |
|  [[G35.B1]]   | Primary progressive   |        Active        | New T1 Gd+ lesion or clinical relapse in PPMS context                                                     |
|  [[G35.B2]]   | Primary progressive   |      Non-active      | Stable PPMS — no new MRI lesion activity                                                                  |
|  [[G35.C0]]   | Secondary progressive |     Unspecified      | Began as RRMS, now worsening without clear relapses; activity unspecified — query                         |
|  [[G35.C1]]   | Secondary progressive |        Active        | New MRI activity or clinical relapse superimposed on SPMS progression                                     |
|  [[G35.C2]]   | Secondary progressive |      Non-active      | Steadily worsening SPMS without new MRI activity                                                          |
| **[[G35.D]]** | **Unspecified**       |   **Unspecified**    | **Only when both subtype and activity are undocumented after query — THIS CODE**                          |

> [!important] CDI Query Trigger — MS Subtype and Activity Level 
> If the physician documents only **"multiple sclerosis"** without specifying subtype or activity, a **CDI query is warranted** at every inpatient encounter. The distinction between **[[G35.A]], [[G35.B0]]**- **[[G35.B2]]**, and **[[G35.C0]]-[[G35.C2]]** requires physician documentation and carries meaningful HCC, clinical, and authorization significance. **[[G35.D]]** is the appropriate default **only after the query has been exhausted** or the record is genuinely silent.

### Pathophysiology

**Multiple sclerosis** is a **chronic autoimmune demyelinating disease** in which **autoreactive T-lymphocytes** and **B-cells breach the blood-brain** **barrier** and attack the **myelin sheath** surrounding CNS axons. The resulting **demyelinating plaques** — areas of **[[inflammation]]**, myelin loss, and reactive gliosis (**[[sclerosis]]**) — disrupt saltatory conduction along **myelinated axons**, producing the clinical deficits characteristic of MS.

Plaques form throughout the **CNS** but have predilection sites: the **periventricular white matter**, **corpus callosum** (Dawson's fingers on MRI sagittal FLAIR), **corticospinal tracts** (motor), **posterior columns** (sensory, proprioception), **cerebellar pathways** (**coordination**), **optic nerves** (**vision**), and **spinal cord**. The location of active plaques determines the clinical presentation at any given relapse or progressive phase. Over time, **axonal loss** — beyond **[[demyelination]]** alone — drives irreversible disability accumulation independent of relapse activity.

### Clinical Presentation

Patients coded to **[[G35.D]]** may present with any manifestation of MS
across any disease course. Common **inpatient presentation**s include:

- **Acute relapse / [[exacerbation]]** — new or worsening neurological deficit
  lasting >24 hours; treated with IV corticosteroids (Solu-Medrol)
- **Motor deficits** — limb weakness, **[[hemiparesis]], [[paraparesis]]; [[spasticity]]**
  (see **[[M62.838]]** or **[[R25.2]]** per documentation specificity)
- **Sensory disturbances** — **[[paresthesias]]**, numbness, Lhermitte's sign
  (electric shock sensation with neck flexion)
- **[[Optic neuritis]]** — painful vision loss, typically unilateral;
  **relative afferent pupillary defect (RAPD)**; coded additionally as H46.x
- **Cerebellar / brainstem symptoms** — **[[ataxia]], [[dysarthria]], [[diplopia]]**,
  internuclear **[[ophthalmoplegia]]** (INO), vertigo
- **Bladder and bowel dysfunction** — neurogenic bladder (N31.x),
  urinary retention, incontinence — **extremely common; always query and code**
- **Cognitive impairment** — processing speed, memory, executive function
- **Fatigue** — one of the most disabling MS symptoms; often underdocumented

### Documentation Requirements

For precise code assignment within the **G35 family** — and to minimize
default to **[[G35.D]] — physician documentation should include**:

1. **MS subtype** — relapsing-remitting, primary progressive, or secondary progressive; established from clinical history and MRI pattern
2. **Activity status** — active (new MRI lesion activity or clinical relapse within the monitoring period) vs. non-active
3. **Current disease status** — in relapse, in remission, progressing
4. **Specific neurological deficits** — motor, sensory, cerebellar, visual,  bladder — each supports additional **ICD-10-CM** code assignment
5. **Disease-modifying therapy** — current DMT and any changes; relevant for medical necessity and payer authorization
6. **Disability level** (EDSS or equivalent) — supports severity documentation

### Scenario 1 — MS, Subtype Undocumented, Carried Over from Pre-FY2026 Record (Outpatient)

> **Clinical Vignette:** A 48-year-old female presents to neurology for routine follow-up. Her chart reflects a prior diagnosis of "multiple sclerosis" coded as G35 on all prior encounters through September 2025. The physician's current note documents "[[multiple sclerosis]] — stable, continue current DMT." No subtype is specified in the current note. Prior records in the chart reference RRMS from the initial diagnosis 8 years ago.

**CPT Codes (Outpatient):**
- [[99214]] — Office visit, established patient, moderate complexity

**ICD-10-CM:**
- ⚠️ **Query first** — prior chart documentation references RRMS from initial diagnosis; if confirmed by physician, use [[G35.A]]
- [[G35.D]] — Multiple sclerosis, unspecified *(only if query yields  no subtype confirmation from the current encounter provider)*

> [!important] Prior Chart Entries Are Not Sufficient — Current Encounter Documentation Governs
> Coders cannot unilaterally apply [[G35.A]] based on older records without the current treating physician confirming the diagnosis in the current encounter documentation. A CDI query is the appropriate pathway. If the physician responds confirming RRMS → [[G35.A]]. If the physician does not respond or the subtype remains undocumented → [[G35.D]] with a documented query attempt on file.

### Scenario 2 — MS, Acute Relapse, Subtype Not Documented (Inpatient)

> **Clinical Vignette:** A 35-year-old male is admitted with acute onset bilateral lower extremity weakness and urinary retention over 48 hours. MRI spine reveals new T2 hyperintense lesion at T6-T7 with gadolinium enhancement. Neurology consult documents: "Multiple sclerosis — acute relapse. IV Solu-Medrol initiated." No MS subtype is specified in any note during the admission. Neurogenic bladder documented.

**Principal Diagnosis:**
- [[G35.D]] — Multiple sclerosis, unspecified *(subtype not documented  after query — MS driving admission; sequences as principal)*

**Additional Diagnoses:**
- [[N31.9]] — Neuromuscular dysfunction of bladder, unspecified *(neurogenic bladder — document separately; supports clinical picture)*
- [[G82.20]] — Paraplegia, unspecified *(if bilateral lower extremity paralysis meets documented severity threshold)*

**MS-DRG Assignment:**
- DRG 059 — Multiple Sclerosis and Cerebellar Ataxia with CC *(if [[N31.9]] or [[G82.20]] qualifies as CC; confirm CC/MCC tier)*
- DRG 058 — with MCC if higher-tier complication documented

> [!note] CDI Query Opportunity — Active Lesion Strongly Suggests G35.A or G35.B1/C1
> The gadolinium-enhancing lesion on MRI is a hallmark of **active disease**. A CDI query asking the neurologist to specify MS subtype and confirm active vs. non-active status could upgrade [[G35.D]] to [[G35.A]] (if RRMS) or [[G35.B1]]/[[G35.C1]] (if progressive with active lesion). Do not infer activity from imaging alone — physician documentation is required.

### Scenario 3 — MS, Aspiration Pneumonia Complication (Inpatient MCC)

> **Clinical Vignette:** A 62-year-old female with known MS is admitted with aspiration [[pneumonia]] secondary to [[dysphagia]] from brainstem MS lesions. Physician documents "multiple sclerosis with brainstem involvement — aspiration pneumonia." MS subtype not documented.

**Principal Diagnosis:**
- [[G35.D]] — Multiple sclerosis, unspecified *(MS driving admission)*

**Additional Diagnoses:**
- [[J69.0]] — Aspiration [[pneumonia]] *(MCC — elevates DRG to 058)*
- [[R13.10]] — [[Dysphagia]], unspecified *(brainstem MS complication)*

**MS-DRG Assignment:**
- **DRG 058** — Multiple Sclerosis and Cerebellar Ataxia **with MCC**  *([[J69.0]] is MCC — maximum DRG weight for MS grouping)*

> [!warning] Aspiration Pneumonia Is MCC — Never Miss This
> **[[J69.0]]** (aspiration pneumonia) is a **Major Complication/Comorbidity** and moves the MS encounter from DRG 060 or 059 straight to DRG 058. In MS patients with documented brainstem disease and dysphagia, aspiration [[pneumonia]] is a predictable, clinically significant complication. Complete documentation and coding of [[J69.0]] is both clinically accurate and the difference between the lowest and highest MS DRG weight.

### Scenario 4 — Newly Diagnosed MS, Subtype Established at Discharge (Inpatient)

> **Clinical Vignette:** A 28-year-old female is admitted with new-onset bilateral optic neuritis and right arm numbness. MRI brain and spine reveal multiple periventricular white matter lesions and a right cervical cord lesion, consistent with MS. **CSF** oligoclonal bands positive. Neurology discharge summary: "Newly diagnosed relapsing-remitting **multiple sclerosis**. Initiating dimethyl fumarate at discharge."

**Principal Diagnosis:**
- [[G35.A]] — Relapsing-remitting multiple sclerosis *(subtype documented at discharge — [[G35.A]] is correct; do NOT use [[G35.D]] when RRMS is confirmed in the record)*

**Additional Diagnoses:**
- [[H46.10]] — Optic neuritis, unspecified *(bilateral optic neuritis  as presenting symptom — code additionally)*

> [!tip] G35.D Is Not Needed When Subtype Is Documented
> This scenario illustrates the upgrade: physician documents RRMS at discharge → [[G35.A]] is the correct and only MS code. [[G35.D]] is not assigned alongside [[G35.A]] — one code captures the MS diagnosis at the appropriate specificity level. [[G35.D]] would only apply here if the discharge summary had not specified the subtype.

## ⚠️ Coding Pitfalls and Tips

|     | Pitfall or Tip                                                                                                                                                                                                     |
| :-: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
|  ❌  | **Do not submit G35 alone after October 1, 2025** — it is a non-billable parent code and will reject; minimum valid code is **[[G35.D]]** for unspecified MS                                                       |
|  ❌  | **Do not default to [[G35.D]] without a CDI query attempt** — subtype and activity documentation may exist elsewhere in the record or can be obtained via query                                                    |
|  ❌  | **Do not assign [[G35.D]] simultaneously with [[G37.9]]** — **Excludes 1**; mutually exclusive                                                                                                                     |
|  ❌  | **Do not use [[G35.D]] for NMO / Devic disease** — assign **[[G36.0]]**; NMO is a distinct condition with distinct pathophysiology and treatment                                                                   |
|  ❌  | **Do not infer MS subtype or activity from imaging alone** — gadolinium enhancement suggests active disease but physician documentation is required for **[[G35.B1]] or [[G35.C1]]** assignment                    |
|  ✅  | **Query every [[G35.D]] in the inpatient setting** — ask neurologist/attending to document subtype (**RRMS, PPMS, SPMS**) and current activity status                                                              |
|  ✅  | **[[G35.D]] carries CMS-HCC v28: HCC 198 / RxHCC v08: HCC 159** — confirm mapping on current CMS crosswalk for new FY2026 subcategory codes                                                                        |
|  ✅  | **Capture all MS complications as additional diagnoses** — **neurogenic bladder** (N31.x), **dysphagia** (R13.1x), **aspiration pneumonia** (**[[J69.0]]**), **hemiplegia** (G81.x) — these drive DRG tier and RAF |
|  ✅  | **[[J69.0]]** (**[[aspiration pneumonia]]**) is MCC and moves MS encounter to **DRG 058** — never miss this complication in MS patients with brainstem disease                                                     |
|  ✅  | **[[G35.D]] sequences as principal** when MS is the reason for admission and no more specific subtype is documented; groups to **MDC 01 / DRG 058-060**                                                            |
|  ✅  | **Sweep for HCC-bearing complications at every [[G35.D]] encounter** — **[[paraplegia]], [[hemiplegia]], [[malnutrition]], pressure ulcers** carry independent RAF weight                                          |

# CPT 95873 — Electrical Stimulation Guidance for Chemodenervation [Add-On]

> [!summary] Quick Reference
> **Add-on code.** Reports electrical stimulation used to localize the target muscle(s) during a chemodenervation procedure. Always billed with a primary [[chemodenervation]] code ([[64642]], [[64643]], [[64644]], [[64645]], or the head/neck/limb [[dystonia]] codes).

## Description
**Electrical stimulation guidance** helps the physician confirm needle placement in the intended muscle before toxin injection, improving accuracy over anatomic landmark injection alone.¹

## Key Coding Rules
- **Mutually exclusive with [[95874]]** (needle EMG guidance) for the same muscle/session — one guidance modality per injection encounter, not both stacked on the same target.
- **Reportable once per extremity** where guidance was separately performed and documented — not once per muscle within that extremity.
- Never reported without a same-session [[chemodenervation]] code; guidance alone is not a stand-alone billable service.

## Modifier Notes
- When guidance is performed and documented separately for a **second extremity** in the same session, append modifier **[[-59]]** or **[[-XS]]** (separate structure) to the second unit to prevent NCCI bundling denial.

## Documentation Checklist
- [ ] Explicit statement that electrical stimulation (not EMG) was the guidance method
- [ ] Guidance tied to the specific extremity/muscles in the same note as the injection detail
- [ ] Distinct extremity clearly identified if billing a 2nd unit

## Common Pairings
- Primary: [[64642]], [[64643]]
- Diagnosis driving medical necessity: [[spasticity]], [[dystonia]] codes per encounter

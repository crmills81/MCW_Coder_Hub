# 🏷️ Facility Modifiers Guide

## 🎯 Purpose
Quick reference for facility‑appropriate modifiers.

---

# 🧩 Common Facility Modifiers
| Modifier | Meaning |
|----------|----------|
| **25** | Significant, separately identifiable E/M |
| **59** | Distinct procedural service |
| **XU/XS/XP/XE** | More specific versions of 59 |
| **LT/RT** | Left / Right |
| **50** | Bilateral procedure |
| **73/74** | Discontinued outpatient procedure |
| **91** | Repeat lab test |

---

# 🧠 Notes
- Modifier 25 applies to **professional**, not facility E/M  
- Use X‑modifiers when payer prefers specificity  
- 73/74 require **clear documentation** of reason

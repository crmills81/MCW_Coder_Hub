# 🧾 UB‑04 Field Reference

## 🎯 Purpose
Quick reference for key UB‑04 fields used in facility billing.

---

# 🧩 Key Fields
| Field | Description |
|--------|-------------|
| **FL 1** | Provider name/address |
| **FL 4** | Type of bill |
| **FL 12** | Admission date |
| **FL 13** | Admission hour |
| **FL 14** | Admission type |
| **FL 15** | Admission source |
| **FL 42-49** | Revenue codes |
| **FL 44** | HCPCS/Rates |
| **FL 66-69** | Diagnosis codes |
| **FL 74** | Principal procedure |
| **FL 76** | Attending provider |

---

# 🧠 Notes
- Type of bill drives **billing logic**
- Revenue codes must match **HCPCS**
- POA indicators required for IP claims

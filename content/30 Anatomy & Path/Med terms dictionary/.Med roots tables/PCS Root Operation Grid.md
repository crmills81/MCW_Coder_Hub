# 🛠 ICD‑10‑PCS Root Operation Grid

## 🎯 Purpose
Quick reference for PCS root operations by intent, with examples and documentation notes.

---

# 🔧 Root Operations by Intent

## 🧩 Objective: Take Out
| Root Operation | Definition | Example |
|----------------|------------|---------|
| **Excision** | Cutting out part of a body part | Liver biopsy |
| **Resection** | Cutting out all of a body part | Total nephrectomy |
| **Extraction** | Pulling or stripping out | D&C, vein stripping |

---

## 🧩 Objective: Put In / Put Back
| Root Operation | Definition | Example |
|----------------|------------|---------|
| **Insertion** | Putting in a device | Central line |
| **Replacement** | Putting in device that replaces body part | Hip replacement |
| **Supplement** | Reinforcing body part | Mesh repair |

---

## 🧩 Objective: Move / Alter
| Root Operation | Definition | Example |
|----------------|------------|---------|
| **Bypass** | Rerouting contents | CABG |
| **Restriction** | Partially closing | Gastric band |
| **Occlusion** | Completely closing | Tubal ligation |

---

## 🧩 Objective: Repair / Restore
| Root Operation | Definition | Example |
|----------------|------------|---------|
| **Repair** | Restoring body part | Hernia repair |
| **Reposition** | Moving to normal location | Undescended testicle |

---

## 🧠 Notes
- Root operation = **intent** of the procedure  
- Device must remain **after** procedure to count  
- If unsure: default to **Repair**

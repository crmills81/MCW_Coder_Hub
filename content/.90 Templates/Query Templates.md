# 📨 Query Templates

## 🎯 Purpose
Compliant, non‑leading provider query templates for clarification of diagnoses, procedures, POA status, and clinical indicators.

---

# 📘 Clinical Clarification Query
**Subject:** Clarification Needed for Documentation  
**Clinical Indicators:**  
-  
-  
-  

**Question:** Based on the clinical indicators above, can you clarify the diagnosis?  

**Options:**  
- Condition A  
- Condition B  
- Condition C  
- Other: __________  
- Unable to determine  

---

# 🩺 POA (Present on Admission) Query
**Subject:** POA Clarification  
**Clinical Indicators:**  
-  
-  

**Question:** Was this condition present on admission?  

**Options:**  
- Yes  
- No  
- Clinically undetermined  
- Other: __________  

---

# 🫁 Respiratory Failure Query
**Clinical Indicators:**  
- ABG results  
- O₂ saturation  
- Respiratory distress  
- Treatment (BiPAP, high‑flow, etc.)  

**Question:** Can you clarify whether acute respiratory failure was present?  

**Options:**  
- Acute respiratory failure  
- Hypoxia only  
- Other: __________  
- Unable to determine  

---

# 🧬 Sepsis Query
**Clinical Indicators:**  
- Fever/hypothermia  
- Tachycardia  
- Tachypnea  
- WBC elevation or bands  
- Lactate elevation  
- Organ dysfunction indicators  

**Question:** Based on the indicators above, can you clarify the diagnosis?  

**Options:**  
- Sepsis  
- Infection without sepsis  
- Other: __________  
- Unable to determine  

---

# 🏥 Procedure Detail Query
**Clinical Indicators / Documentation Gaps:**  
-  
-  

**Question:** Can you clarify the details of the procedure performed?  

**Options:**  
- Specific procedure name  
- Approach  
- Device used  
- Body part  
- Other: __________  
- Unable to determine  

---

# 🧠 Documentation Tips
- Always include **clinical indicators**  
- Never suggest a diagnosis not supported by documentation  
- Provide **multiple reasonable options**  
- Always include **“unable to determine”**  
- Keep tone factual and neutral
